A · 嵌入式（推荐）

Cursor 同款。Thread 列表是 chat panel 内部左半边一列，可一键折叠。整个 panel 还是右侧 overlay 但加宽到 ~640px。

+ 不会和主编辑器抢空间
− Panel 加宽后挡住的主内容更多

B · 抽屉式

Panel 还是当前 420px 宽度。点 header 上的"≡ Threads"按钮，列表从左边滑出来盖在消息区上面，再点一次收回。

+ 不需要加宽 panel，省空间
− 选 thread 时看不到当前消息，切换体验稍差

C · 命令面板

VS Code Cmd+P 同款。快捷键或点 header 按钮弹出居中模态框，搜索 + 列表，选完关闭。

+ 键盘党友好，搜索一等公民
− 没有"hover 浏览历史"那种感觉，不像聊天产品
