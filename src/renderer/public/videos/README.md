# 启动开场视频

应用启动时全屏播放的那段视频。

```
videos/intro.mp4
```

改片只需替换这个文件(保持文件名),`index.html` 里的 `<source>` 指的就是它。
**注意有两份**:`src/renderer/public/videos/`(当前 Vite 渲染端)和仓库根的
`videos/`(老 vanilla shell 的 index.html 引用),换片时两边一起换,否则两个宿主
会放不同的片子。

## 时长是唯一硬约束

「进入」按钮要等**视频播完**且应用初始化完成才出现(`checkReadyToEnter` 同时看
`videoEnded` 与 `appInitialized`)。所以**视频多长,用户就得等多久** —— 这不是加载
时间,是纯等待。选片时先看时长再看画质。

当前:`intro.mp4` 65.8s / 1920x1080 / 8.1MB / 有音轨。

用户随时可以点 SKIP 跳过,但默认路径就是从头看完。

## 其它约束(照实记,不是愿望)

- 格式 MP4 / H.264 —— Electron 的 Chromium 直接能放,不必额外解码器。
- 分辨率 1080p 足够。上一版是 1440p / 30MB,画质差别在这个尺寸的窗口里看不出来,
  但仓库里躺着两份 30MB。
- 带音轨没问题:自动播放被浏览器策略挡下时,代码会自动退到静音再播
  (`video.play()` 失败 → `muted = true` 重试)。
- 视频加载失败不会卡死:`error` 事件会切到备用加载动画并放行。
- 兜底超时是 **120 秒**(不是某些旧文档写的 10 秒):真出问题时最多等两分钟就
  显示「进入」。
