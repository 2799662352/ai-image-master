# CYBERPUNK 2077 Intro Video

将赛博朋克 2077 的 "早上好，夜之城" (Good Morning Night City) 视频放在此文件夹中。

## 设置步骤

1. 获取视频文件 (MP4 格式)
2. 将文件重命名为 `cyberpunk-intro.mp4`
3. 放入此 `videos/` 文件夹

## 视频要求

- **格式**: MP4 (H.264 编码)
- **建议分辨率**: 1920x1080 或 1280x720
- **建议时长**: 5-15 秒
- **文件大小**: 建议 < 10MB (优化加载速度)

## 视频来源建议

你可以使用以下视频:
- Cyberpunk 2077 官方开场动画
- "Good Morning Night City" 片段
- 自定义的赛博朋克风格视频

## 注意事项

- 如果视频文件不存在或加载失败，页面会自动显示备用加载动画
- 用户可以点击 "SKIP" 按钮或按 ESC/空格键跳过视频
- 视频会自动静音播放 (浏览器政策要求)
- 视频播放超过 10 秒会自动跳过

## 视频路径

```
videos/cyberpunk-intro.mp4
```
