# 角色设计档案构建器(编剧 / 美术 / 选角三版)

> 来源:忠实移植自 updream `character-design`(电影角色设计大师)。
> 用途:本 skill 正文管「跨镜一致性锚点」(face/build/outfit/markers 的复用与校验)。**本文件管角色的"从无到有"设计**——在你还没有锚点、需要先把一个角色**立起来**(性格/弧光/视觉方案)时用它;产出的「美术版」可直接转成本 skill 的 anchor 字段。
> 注意:本 app 人像锚点**默认**用「单锚点人像库(大头照 + 全身照)」;角色三视图/四视图**可作为可选补充**(场景需要时使用),不作默认产出。updream 的 character-turnaround(三视图+360转台+六表情)与 character-four-view(四视图合图)已适配本 app 工具、作可选补充融入 `character-multiview-supplement.md`。

## 执行流程

### Step 1 · 信息收集
姓名 / 年龄段 / 性别 / 职业身份 / 故事题材 / 时代背景 / 世界观 / 故事功能(主角·反派·配角)/ 已有特征描述。

### Step 2 · 深度访谈(按需,信息不足时提问)
- 核心动机是什么?
- 内在冲突或阴影是什么?
- 成长弧线如何?
- 与其他关键人物的关系?
- 标志性场景或台词?

### Step 3 · 角色档案构建

**3.1 核心档案**
- 基本信息:姓名、年龄、性别、职业、社会地位
- 外貌特征:身高体型、面部特征、眼神气质、标志性特征
- 性格画像:MBTI、核心特质、行为模式、语言风格
- 背景故事:成长环境、关键经历、创伤或成就
- 动机与欲望:表层目标、深层需求、终极追求
- 内在冲突:心理矛盾、道德困境、身份认同危机
- 人物弧光:起点状态 → 转变触发 → 成长过程 → 终点状态

**3.2 故事功能**
- 叙事作用(推动者/阻碍者/见证者)、关系网络、关键场景行为模式、象征意义与主题关联。

**3.3 视觉设计方案**
- 整体风格定位(写实/夸张/stylized/特定时代)
- 服装造型(日常 / 关键场景 / 色彩象征)
- 妆容发型(发型 / 妆容特点 / 年龄感)
- 道具配置(随身物 / 标志性道具 / 武器工具)
- 光影氛围(打光建议 / 色调倾向 / 视觉记忆点)

### Step 4 · 形象生成(对接本 app)
按视觉方案出:① 角色肖像(面部特写)② 全身造型 ③ 关键情绪瞬间 ④ 典型场景融入。
> 落到本 app:肖像 = 人像库「大头照(正脸无表情)」,全身造型 = 「全身照」,二者即角色唯一身份锚,全片复用。

### Step 5 · 交付三版

**编剧版**
```
【角色名称】
身份:[一句话定位]
年龄:[具体或范围]
外貌:[3-5 个关键词]
性格:[核心特质+矛盾点]
背景:[关键经历简述]
动机:[目标+深层需求]
弧光:[成长变化简述]
关系:[与主要角色的关系]
标志性:[台词/动作/道具]
```

**美术版**(可直接转成本 skill 的 CHARACTER ANCHOR 字段)
```
【视觉设计档案】
整体风格:[风格描述]
面部特征:[详细描述]          → anchor: Face
体型姿态:[身材+习惯性动作]    → anchor: Build
服装方案:
  - 日常:[描述]              → anchor: Outfit
  - 关键场景:[描述]
  - 色彩象征:[描述]
妆容发型:[详细描述]          → anchor: Face(hair)
道具配置:[列表]              → anchor: Markers
光影氛围:[打光+色调建议]
参考关键词:[用于 AI 生成的提示词]
```

**选角版**
```
【选角参考】
年龄范围 / 气质类型 / 外形要求 / 演技需求 / 参考演员(2-3) / 试镜建议
```

## 风格一致性规则
1. 视觉描述与故事题材/时代/世界观一致。
2. 外在形象服务于内在性格与剧情功能。
3. 色彩/光影/服装与影片整体视觉风格统一。
4. 生成图时提示词含:画风、色调、光影、时代特征等关键词。

## 质量检查清单
- [ ] 角色是否具独特性与辨识度?
- [ ] 设定是否与已知信息逻辑一致?
- [ ] 外貌与背景是否服务核心性格与剧情功能?
- [ ] 语言风格是否贴近剧本语境?
- [ ] 输出格式是否清晰可直接用?
- [ ] 是否提供可用于 AI 生成的提示词?
- [ ] 美术版是否已映射成本 skill 的 anchor 四要素(Face/Build/Outfit/Markers)?
