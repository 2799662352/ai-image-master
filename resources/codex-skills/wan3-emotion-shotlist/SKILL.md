# AI 视频人物情绪表演提示词生成系统（30 秒多角色约 20 镜头完整版）

<!-- skill-budget: fast -->

情绪/对白戏的专项叶子。通用方法与 30 秒骨架在底座 wan3-cinematic-30s 里。

⚠️ 本篇是全仓最大的一份 skill（约 6 万字，含 50 种情绪的完整词典与模板库）。
**按需加载,不要预载**；查表时直接跳到对应小节，不必通读。

本系统保留原版完整的「50 情绪细节矩阵」与「肌肉动作→视觉结果」表演知识，并把最终输出从秒级碎拍升级为剪辑镜头，同时整体对齐 wan3.0 提示词公式（主体+场景+运动+美学控制+风格化+音效；多镜头公式=总体描述+镜头序号+时间戳+分镜内容；声音公式=人声+音效+BGM）。主角承担 4–5 个连续情绪状态，对手角色负责触发、承接和反推；三人场景中的第三角色承担揭示、打断、见证或推动决定。台词、视线、距离、手部和核心道具共同推进剧情，不把情绪写成孤立的表情展示。

## 核心架构

```
[主角 4–5 状态情绪弧线] + [对手角色回声线] + [可选第三角色推动线] + [对白/动作/道具连续性] + [面部与呼吸细节] + [wan3.0 公式要素：总体描述/美学控制/声音三层/时间戳] → 一段总体描述 + 一份共享提示词 + 约 16–20 个带时间戳的编号镜头
```

融合逻辑：

- **50 情绪矩阵提供覆盖面**：五大分类（喜悦/愤怒/悲伤/惊恐/复杂/复合类）共 50 种情绪，每种情绪自带嘴角、眼部、面部、头部四维视觉锚点，保证任何情绪需求都有据可查。
- **肌肉解剖提供深度**：面部细节采用「肌肉动作→视觉结果」双层结构，→ 是因果关系而非"或"——前半段是精确指令，后半段是画面落地。
- **姿态与呼吸提供完整性**：核心姿态（手部/身体/视线）让表演从脸部延伸到全身，呼吸控制为激动、失控类情绪补上最容易穿帮的一层真实感。
- **双人回声提供因果性**：一方的台词、动作或沉默必须改变另一方的视线、呼吸、道具控制权或行动路径；收到反应的一方再被反推，形成可见的来回作用。
- **情绪阶段不是几张脸**：主角的相邻情绪通过遗留的泪光、未松开的手、未完成的转身和仍在原位的道具连续过渡；每次变化都由新信息或行为触发。
- **wan3.0 公式提供交付语法**：提示词越完整、精确、丰富，生成品质越高——主体与场景由参考图或描述锁定，运动由情绪库与姿态层提供，美学控制（光源、光线、景别、运镜）与风格化写入【全局锁定】，音效按「人声+音效+BGM」三层显式标注；分镜按多镜头公式带镜头序号与时间戳，确保模型不会在结构、台词和声音上自由发挥。

## 1. 最终交付

除非用户明确要求分析，最终只输出：

```text
【总体描述】
一句话概述整支约 30 秒视频的故事主题、叙述风格、主要情感与核心事件，并声明多镜头结构与全片美学基调（如「电影质感写实风格，以第三人称视角讲述……，由约 18 个镜头组成」）。

【全局锁定】
角色身份与位置、参考图一致性、场景范围、视线轴线、过肩规则、核心道具初始位置；全片一次性写明美学控制（光源、光线环境、主景别、运镜基调）与声音基调（台词音色、BGM 风格或「无背景音乐」）。

【固定台词】
按角色列出所有完整台词，并标注音色与语速（如「声音低沉，语速偏慢」）。无台词则写“全片无台词、无旁白”。

镜头1[0-2秒]：机位或景别。主要动作与关系变化；2–3 个最关键的情绪信号；如有台词，在本镜头内完整说完；必要的事件声音随镜头标注。
镜头2[2-3秒]：……
……
最后一个镜头：明确人物最终姿态、朝向与道具归属。

【禁止项】
文字、字幕、UI、水印、Logo、黑屏、平台尾页、角色错位、口型错配、台词跨镜、道具瞬移、无因同步变脸、未经要求的背景音乐与额外台词。
```

默认不输出长篇【故事与角色】、【机位与构图】、【声线描述】和【声音设计】。这些信息在内部完成；必要的美学控制写入【全局锁定】，声线与事件声音直接写入【固定台词】或对应镜头。用户明确要求这些模块时才增加。

### wan3.0 公式对齐说明

本系统的交付格式与 wan3.0 官方提示词公式逐要素对齐，写提示词时按以下口径执行：

1. **完整性原则**：提示词描述越完整、精确、丰富，生成视频品质越高。主体、场景、运动、美学控制、风格化、音效六要素必须在交付中全部有着落——参考图负责主体与场景外观，其余由本系统补足；不得留空让模型自由发挥。
2. **多镜头结构**：分镜按 wan 多镜头公式组织 = 总体描述 + 镜头序号 + 时间戳 + 分镜内容。时间戳标明每个镜头的时间范围并保持连续、互不重叠、总长约 30 秒，确保镜头内容与时间线对应；多镜头之间保持画面主体、场景、氛围的一致性（由【全局锁定】保证）。
3. **声音三层**：人声 = 说话内容 + 情绪 + 语调 + 语速 + 音色（写入【固定台词】）；音效 = 音源材质 + 行为 + 环境音（随动作写入对应镜头）；BGM = 配乐 + 风格（在【全局锁定】写明风格，或明确写「无背景音乐」）。
4. **图生/参考生视频口径**：参考图已确定主体、场景与风格，提示词只描述动态过程、情绪变化与运镜需求，不复述图中已有外观；需要强调一致性时写「严格保持参考图中人物与场景一致」。
5. **精准控制兜底**：未规定的分镜数量、台词与 BGM 模型会自主发挥——因此镜头数与时间戳显式写出，台词用 xx说：“xxx” 格式固定（不写台词的片子写「全片无台词」），BGM 显式声明风格或写「无背景音乐」。

## 2. 镜头数量与有效性

1. 默认输出 16–20 个镜头，内容充足时可到 22 个；以接近 20 个为参考，不强行凑满。
2. 每个镜头标注连续不重叠的时间戳（如「镜头1[0-2秒]」），总长约 30 秒；普通镜头约 1–2 秒，完整对白镜头可约 2–4 秒，关键停顿与结尾可更长。
3. 一个镜头至少完成一项：提供新信息、作出新决定、改变人物距离、改变道具控制权、产生一次有原因的情绪变化、给出会改变下一步行为的关键反应。
4. 删除某镜头后剧情、关系与人物决定完全不受影响，该镜头就是冗余镜头，必须删除或合并。
5. 眨眼、吸气、吞咽、手指轻动、单纯视线移动不能独立成镜，只能作为镜头内部的表演细节。
6. 同一次递交、拿起、放下或转身默认在一个镜头内完成；只有拒绝、争夺或中途撤回改变关系时才拆镜。
7. 角色“准备开口”与紧随其后的对白合并；配角在结尾前的点头、松气或微笑并入最终多人镜头。

## 3. 完整台词

1. 默认 6–10 轮自然短对白，每句优先 4–16 个汉字。
2. 一句台词必须在一个镜头、一个机位内从头到尾完整说完。
3. 禁止把一句话拆成上半句与下半句分配给两个镜头。
4. 长句允许在同一镜头内自然停顿，不得为停顿切镜。
5. 省略号只用于人物确实被打断、哽住或主动停口，全片默认最多一处。
6. 台词必须提供事实、试探、拒绝、质问、澄清或决定；删除后剧情不变的台词应删除。
7. 当前说话者口型完整同步，其他角色闭口，用一个关键反应承接即可。
8. 台词结束后不强制插入反应镜头。反应会改变下一步行动时才单独成镜，否则留在过肩镜头的前景或背景中。

## 4. 过肩与切镜

用户要求“谁说话就切到另一个人的过肩镜头”时：

- A 说话：从正在听的 B 肩后拍 A，A 清晰，B 的肩部或发丝虚化在前景。
- B 说话：从正在听的 A 肩后拍 B。
- 第三角色 C 说话：选择与 C 关系最直接的倾听者作为前景肩膀。
- 说话者看向倾听者的眼睛，不直视摄影机。
- 同一句台词期间不换机位、不插手部特写、不切听众反应。
- 台词完整结束后，才允许切关键反应、道具特写或下一位说话者的过肩镜头。
- 建立镜头、无台词反应镜头、道具特写和结尾镜头不强制使用过肩构图。
- 全片遵守 180 度轴线，人物左右位置不翻转。

## 5. 多角色分工

- 单人：角色与镜头或图中物件互动；允许画外声音触发，不虚构画外人的实体动作。
- 双人：一名主情绪角色承担 4–5 个连续状态，另一名角色提供阻力、澄清和回应。
- 三人：主情绪角色承担主要变化；关系对手提供冲突或回应；第三角色负责揭示、打断、见证或推动决定。
- 三人不可各演一套五情绪。第三角色必须改变局面，不能只负责点头和看人。

## 6. 单镜头情绪密度

1. 每个镜头只保留 2–3 个最能让观众读懂变化的可见信号。
2. 低强度镜头写一个面部信号和一个身体信号即可。
3. 高强度镜头最多写三类：眉眼、嘴部或呼吸、手部或身体。
4. 后文完整情绪库用于选材，不要求把同一情绪条目的全部部位塞进一个镜头。
5. 禁止在一个镜头中逐项报数眉毛、眼睛、鼻子、嘴巴、皮肤、胸腔和手指。
6. 微动作有因果作用时写入相关镜头；没有改变剧情或表演方向时省略。

## 7. 交付前硬检查

- 通常为 16–20 个有效镜头，每个镜头带连续不重叠的时间戳。
- 每句台词完整保留在一个镜头中。
- 没有“准备开口”后再单独说话的重复镜头。
- 没有只写眨眼、吸气、吞咽或手指轻动的镜头。
- 说话者、过肩前景、口型归属和视线方向一致。
- 主角有 4–5 个由事件触发的连续情绪状态。
- 配角的反应改变了主角或关系的下一步。
- 核心道具的持有者、移动过程与落点连续。
- 结尾用具体动作完成决定，无黑屏、无平台尾页。

## 三大使用模式

本系统的价值不只在「写得专业」，更在「接得住各种输入」。同一个 50 情绪库 + 肌肉级面部细节 + 核心姿态体系，面对三种不同密度的输入时，AI 的思考路径各不相同，但最终全部汇入**同一种交付形态**。

三种模式的区别在于：**信息缺口在哪里，AI 就补哪里**。模式一补「简单情绪话 → 完整表演」，模式二补「零文字 → 情绪方向 + 完整表演」，模式三补「多角色一致性 + 镜头节拍 + 情绪互动」。

### 统一交付形态

无论哪种模式，最终交付统一执行「v4 最高优先级执行协议」：**一段总体描述 + 一份多人共享提示词 + 约 16–20 个带时间戳的有效编号镜头**（wan 多镜头公式）。不按角色拆成多份，不输出长故事说明。角色动作、完整台词、表情、道具和接收方反应按剪辑顺序写入同一份【分镜】。正文不出现肌肉名、情绪编号、L1–L4 档位和设计层解释。

```
【总体描述】故事主题、叙述风格、主要情感与核心事件一句话概述，并声明多镜头结构与美学基调。
【全局锁定】角色位置、参考图一致性、场景范围、轴线、切镜与过肩规则、核心道具初始位置；全片美学控制（光源、光线、主景别、运镜基调）与声音基调（BGM 风格或「无背景音乐」）。
【固定台词】按角色列出完整台词并标注音色与语速；一句台词不得跨镜头；无台词写“全片无台词、无旁白”。
【分镜】镜头1[0-2秒]、镜头2[2-3秒]……通常 16–20 个；每镜头只保留一个主要动作、关系变化与 2–3 个关键情绪信号。
【禁止项】文字/UI/水印/Logo/角标/可读文字/真实UI/角色错位/口型错配/台词跨镜/道具瞬移/未经要求的背景音乐与额外台词。
```

**注意**：有参考图时不复述外观和场景，只在【全局锁定】中固定角色位置与一致性。无图或用户要求改写主体、场景时，才补充必要描述。

**30 秒多人默认口径**：先确定一名主情绪角色、一名关系对手；三人场景再指定一名推动角色。主角完成 4–5 个连续状态，配角不机械同步换脸。A 先输出，B 接住并改变下一步；第三角色只在真正改变信息或行动时进入主线。

**单人场景总原则**：画面中只有一个角色（单人表演）时，角色的表演对象默认就是镜头本身——「镜头即对手，对着镜头演」。禁止虚构、描写任何画外人物的实体行为与位置移动（不写"对方凑近""他不走""那人做势离开"这类）；允许画外音/画外声响（人声、消息提示音、环境异响等）作为情节触发器，但只写声音本身与角色对声音的反应，不描写发声者。单人场景的事件推进方式 = 角色与镜头的互动（发现镜头、对镜头说话、躲开镜头、视线回到镜头）+ 画外音/声响触发 + 图中已有物件或信息触发。多角色同框场景不受此规则限制。

### 模式一【图 + 一句话引导】

**一句话定位**：图给「皮」，一句话给「骨」，AI 补出整条「血肉丰满的表演」。

**【触发条件】**
用户同时提供：一张场景/人物参考图 + 一句极简情绪指令（如「她很伤心」「他生气了」「她假装没事」）。用户懒得写细节，但指明了情绪方向。

**【输入要素】**
- 参考图 1 张（含人物与场景，或仅人物特写）
- 一句话情绪指令（可能很笼统，可能含隐含指向如「假装」「差点」「忍住」等限定词）

**【分析流程】**
> 以下为设计层内部推理步骤，用于选条定档，不写入交付文本；进入分镜时全部翻译成白话。

1. **拆图建档案**：从图中提取人物外观（性别、年龄段、发型、五官特征、服装、配饰、妆容状态）与场景（空间性质、时间感、光线来源与色温、氛围基调）。这些档案用于内部一致性判断，有图输入时不输出到交付正文。
2. **解析那句话**：识别指令中的情绪核（伤心/生气/开心）与限定词（很/有点/假装/忍住/快要）。限定词决定**强度档位**和**是否需要假笑/隐忍类对抗结构**。
3. **库内匹配**：在 50 情绪库中定位最佳条目。原则——「伤心」≠ 自动选悲伤，要按限定词精确选：「很伤心但忍着」→ 21 无声落泪 或 23 抽泣哽咽；「假装没事」→ 30 无奈苦笑（嘴眼分离结构）；「生气但不敢发作」→ 12 隐忍怒意；「气炸了」→ 11 雷霆狂怒。
4. **强度校准**：用限定词调节肌肉收缩强度（轻度/中度/强力/极限）与姿态幅度。如「有点生气」= 12 隐忍怒意 的降阶版：咬肌仅轻度隆起，皱眉肌中度收缩。
5. **情绪-场景一致性检查**：确认所选情绪与图中光影氛围不冲突（如暖黄烛光下的悲伤优先走忧郁惆怅而非嚎啕大哭）；在相关镜头中自然调整，不加解释性文字。
6. **建立 4–5 状态弧线**：按用户主语、核心道具、构图和表情证据确定主情绪角色。用户给出的情绪可作为起点、峰值或落点；其余状态必须与它存在因果关系。关系对手配置 3–4 个响应状态；三人场景再指定一名揭示或推动角色。
7. **补足事件与触发器**：若那句话只有情绪没有事件，按协议⑮设计 4–6 个因果相连的事件，其中至少 4 个事件会改变人物的动作路径、关系距离、道具控制权或说话决定，分别承担四次情绪换挡。转折须从参考图中的人物距离、视线、核心物件和空间关系生长；四个触发器类型不得完全重复。图中只有一个角色时才执行单人规则。
8. **组装输出**：先展开主角 4–5 个情绪状态和配角状态取材，再建立完整对白、核心道具状态与人物承接，最后写成约 16–20 个有效编号镜头。一句台词完整保留在一个镜头内，微动作合并到相关镜头；不为镜头数量拆碎动作或反应。

**【输出格式模板】**

```
【总体描述】故事主题、叙述风格、主要情感与核心事件，声明多镜头结构与美学基调。
【全局锁定】角色身份与位置、参考图一致性、场景范围、轴线、过肩规则、核心道具初始位置；全片美学控制与声音基调。
【固定台词】按角色列出所有完整台词并标注音色与语速；无台词则写明“全片无台词、无旁白”。
【分镜】镜头1[0-2秒]、镜头2……默认 16–20 个有效镜头；完整台词不得跨镜头。
【禁止项】文字/UI/水印/Logo/角标/可读文字/真实UI/角色错位/口型错配/台词跨镜/道具瞬移/未经要求的背景音乐与额外台词。
```

**【关于示例】**

本模式不再附完整示例——输出严格按上方【分析流程】与【输出格式模板】组装；补事件造微剧情时，转折必须从图中独有视觉证据生长（协议⑮防套路化规则）。

### 模式二【全自动识图生成】

**一句话定位**：只给图、不给字，AI 自己读出一整场戏，并交出主推方案 + 备选方向。

**【触发条件】**
用户只上传一张图（人物特写、场景带人、或氛围图），没有任何文字指令。

**【输入要素】**
- 参考图 1 张（仅此而已）

**【分析流程】**
> 以下为设计层内部推理步骤，用于定方向、选条定档，不写入交付文本；进入分镜时全部翻译成白话。

1. **拆图建档案**：同模式一，先提取人物外观与场景要素，作为内部一致性基准。
2. **读表情现状**：识别图中人物当前的表情状态——是中性空白（待表演）、已有微弱表情（可在其上演化）、还是强烈定格（可延展或反转）。中性空白脸给最大创作自由；已有表情则优先设计「承接/转换」而非另起炉灶。
3. **读语境线索**：搜集场景中的剧情暗示——物件（撕碎的照片、两把伞、空药盒、行李箱）、构图（人物在门框内/窗后/镜子前）、光影（逆光剪影/冷蓝夜雨/暖黄晨光）、人物与环境的关系（被包裹/被孤立/即将离开）。
4. **确定多人主从**：确定一名主情绪角色和一名关系对手；三人场景再指定推动角色。主角获得一条最符合图像证据的 4–5 状态情绪链，配角用 2–4 个响应状态制造触发、阻力和澄清。
5. **造 30 秒因果剧情**：用户没给剧情时，必须自创 4–6 个因果事件。每个事件须引入新信息、改变道具状态、改变双方距离或迫使人物作出新决定；四次情绪换挡分别由不同的可拍摄触发器启动。图中只有一个角色时才使用镜头互动、画外声响和图中物件推进。
6. **组装输出**：主推方案只给一份多人共享提示词。把完整对白、动作、视线、呼吸和道具状态合并为约 16–20 个编号镜头；备选方向只在用户明确要求时简要提供。

```

【全局锁定】角色身份与位置、参考图一致性、场景范围、轴线、过肩规则、核心道具初始位置；全片美学控制与声音基调。

【分镜】镜头1[0-2秒]、镜头2……默认 16–20 个有效镜头；完整台词不得跨镜头。
【禁止项】文字/UI/水印/Logo/角标/可读文字/真实UI/角色错位/口型错配/台词跨镜/道具瞬移/未经要求的背景音乐与额外台词。
```

本模式不再附完整示例——主推方案严格按 v4 输出格式组装【总体描述】【全局锁定】【固定台词】【分镜】【禁止项】；微剧情的转折必须从参考图独有的视觉证据中生长，禁止套用“只剩最后一瓶”式通用剧情模板。

### 模式三【多角色 + 场景 + 剧情】

**一句话定位**：多图定角色、剧情定节拍，AI 做「情绪导演」——拆镜头、保一致、写呼应。

**【触发条件】**
用户提供：多张图（≥1 张单独角色图 + ≥1 张场景图，或一张多角色同框图）+ 一段剧情描述（故事梗概、分场文字、或一段对话）。

**【输入要素】**
- 角色图 1-N 张（每角色至少 1 张，用于锁定外观）
- 场景图 1 张（或多张，对应不同场景）
- 剧情描述 1 段（含事件顺序、冲突点、角色关系）

**【分析流程】**
> 以下为设计层内部推理步骤，用于建档案、拆镜头、配情绪，不写入交付文本；情绪选条进入分镜时全部翻译成白话。

1. **建立角色档案**：从图片提取每个角色的不可变标签。多镜头中保持身份、左右位置、发型、服装和体型一致；有参考图时不在每个镜头重复外观。
2. **建立场景档案**：同法固化场景标签；若剧情跨场景，逐场景各建一份。
3. **拆分事件与镜头**：先把剧情按改变行为路径的事件切成 4–6 个因果节点，再组织为约 16–20 个有效镜头。眨眼、呼吸、吞咽和手指变化放在相关镜头内部，不得把同一动作切碎后冒充多个事件或镜头。
4. **建立 4–5 状态主线与回声线**：指定一名主情绪角色，从 50 情绪库选出 4–5 个有因果关系的状态；关系对手用 3–4 个响应状态触发、承接和反推，第三角色只在真正改变信息或决定时介入。
5. **建立对白轮次与道具状态机**：对白默认 6–10 轮，每句优先 4–12 个汉字；同一时刻只允许一人说话，倾听者保持闭口并给出可见回声。为核心道具逐事件记录持有者、方位、开合、露出内容与交接动作；任何转移必须写清启动、过程和落点。
6. **一致性巡检**：逐镜头核对角色标签、左右站位、视线轴线、说话人口型、道具控制权、上一镜头遗留状态与下一镜头起点。检查状态变化是否有触发器，是否存在多人无缘无故同步换脸，是否有台词跨镜或空对白。
7. **组装输出**：同一连续片段只输出一份共享提示词。多人动作、完整台词、面部、呼吸、距离和道具变化按剪辑顺序写进同一【分镜】，不得按角色拆分提示词。

> **单人镜头适用规则**：本模式虽为多角色模式，但若拆分后某个镜头为单人镜头（画面中只有一个角色），该镜头同样适用单人场景口径（见「统一交付形态」）——对着镜头演，转折由镜头互动、画外音/声响或图中物件触发，不虚构画外人物。

**【输出格式模板】**

```
【总体描述】故事主题、叙述风格、主要情感与核心事件，声明多镜头结构与美学基调。
【全局锁定】角色身份与位置、参考图一致性、场景范围、轴线、过肩规则、核心道具初始位置；全片美学控制与声音基调。
【固定台词】按角色列出所有完整台词并标注音色与语速；无台词则写明“全片无台词、无旁白”。
【分镜】镜头1[0-2秒]、镜头2……默认 16–20 个有效镜头；完整台词不得跨镜头。
【禁止项】文字/UI/水印/Logo/角标/可读文字/真实UI/角色错位/口型错配/台词跨镜/道具瞬移/未经要求的背景音乐与额外台词。
```

**【关于示例】**

本模式不再附完整示例——输出严格按 v4 格式组装一份共享提示词；角色档案全程锁定，各角色沿同一编号分镜按“输出→回声→反推”配置互动。

### 模式选择速查

| 用户给了什么 | 用哪个模式 | AI 重点补什么 |
|---|---|---|
| 图 + 一句话情绪 | 模式一 | 情绪精确选条 + 强度校准 + 有效镜头展开 |
| 只有图 | 模式二 | 语境推理 + 情绪方向决策（主推+备选） |
| 多图 + 剧情 | 模式三 | 角色标签锁定 + 节拍拆分 + 情绪互动呼应 |

> 备注（单人场景统一口径）：单人场景口径见「统一交付形态」——一句话口径：镜头即对手，对着镜头演；不虚构画外人物，画外音只写声音与角色反应。多角色同框场景不受此限。

三种模式共享同一交付形态：**一份多人共享提示词 + 约 16–20 个有效编号镜头**。肌肉术语、情绪编号、阶段标签和状态表只留在设计层，完整台词和可拍摄动作进入分镜。

## 内部故事设计（默认不输出）

先在内部用 4–6 个因果事件建立约 30 秒微剧情，再转成编号镜头。最终默认不输出长篇故事梗概；用户明确要求故事说明时，才补充 150–250 字摘要。

1. **零文字输入**：从参考图独有的人物距离、视线、光线和物件中生长转折；无图时自创一个可在单场景完成的日常事件。
2. **简单描述输入**：保持用户的人物关系、事件方向和情绪基调，只补足行动目标、阻力、真相和决定。
3. **详细剧情输入**：保留关键设定，压缩到约 30 秒可以表演的规模。
4. **时长约束**：默认 1–3 名角色、4–6 个因果事件、一个核心道具与至多一个次级内容物；不用闪回、心理旁白或大段背景解释。
5. **单人场景**：不虚构画外人物实体动作；通过镜头互动、画外声音和图中已有物件推进。
6. **镜头转换**：每个事件只拆成完成叙事所需的镜头。动作准备与动作结果能够在一个镜头内读懂时，不再拆分。
7. **内部自检**：主角是否完成 4–5 个有触发的连续状态；关系对手和第三角色是否真正改变主角的下一步。

# 30 秒多角色情绪互动协议

默认任务是：**单场景、1–3 名角色、约 30 秒、一名主角完成 4–5 个连续情绪状态，关系对手提供因果回声，第三角色按需揭示或推动，最终输出约 16–20 个有效编号镜头。**

## 一、先定主从，不做“双人各演五种”

1. **主情绪角色**：承担 4–5 个连续状态，观众主要通过其视线、眉眼、嘴角、呼吸、手部和行动决定读取剧情。
2. **回声角色**：承担触发、阻力、误导、澄清、承接，可配置 3–5 个状态；不要求与主角同步完成五种情绪。
3. **主从可交换一次**：剧情中段或转折后允许回声角色短暂接管主动权，但全片只能有一条清晰主弧线。
4. **禁止同步换脸**：除共同受到外部瞬时刺激外，两人不可同帧同时换挡。常态节奏是 A 输出 → B 在 0.2–0.8 秒后反应 → B 的反应改变 A 的下一步。

## 二、4–5 个状态的功能位置

状态不是固定情绪名单，而是剧情功能位。先按功能搭骨架，再从 50 情绪库精确选条：

| 阶段 | 默认时间参考 | 剧情功能 | 必须出现的可见证据 |
|---|---:|---|---|
| ① 初始期待/表面状态 | 0.0–5.5 秒 | 建立关系、目标与当前控制权 | 视线落点、身体距离、核心道具初始持有者 |
| ② 第一偏差 | 5.5–10.5 秒 | 新信息使原判断失效 | 笑意收敛、视线改道、手部停顿或道具状态变化 |
| ③ 关系受压 | 10.5–16.5 秒 | 误会、受伤、恐惧或羞耻加深 | 呼吸断裂、言语中断、距离变化、未完成动作 |
| ④ 主动反击/最高压力 | 16.5–23.0 秒 | 主角作出改变行动路径的决定 | 推回、抽走、转身、逼近、拒绝或夺回控制权 |
| ⑤ 新认知与落点 | 23.0–30.0 秒 | 澄清、决裂、和解、反转或开放结尾 | 前段遗留痕迹仍在，新的决定落到具体动作上 |

时间仅为设计参考，不要求平均分配。相邻阶段必须保留前一阶段的物理痕迹：泪光未退时可以变得锐利，手仍握着道具时可以从犹豫转为拒绝，笑意刚敛时不允许下一拍凭空满脸愤怒。

## 三、状态变化必须由触发器启动

主角相邻状态之间必须有真实触发。每次变化都要回答：**什么新东西进入了局面，它改变了谁的下一步？**

可选触发器：

- **台词触发**：一句短台词改变信息或关系定义；禁止用长台词解释背景。
- **动作触发**：递出、抽回、推开、转身、靠近、停止触碰，直接改变双方距离或控制权。
- **道具触发**：打开、翻转、滑落、露出第二层内容、被另一人夺走或重新共同握住。
- **沉默触发**：应当回答的人没有回答；沉默后必须有吞咽、避视、抬手中断等可见证据。
- **声音触发**：门响、提示音、脚步或环境变化改变行动路径；同一片中不要反复用声音打断。
- **误会与澄清**：后出现的物理证据推翻前一判断；澄清必须由画面或短句完成，不能靠解释性独白。

全片触发器尽量覆盖三种不同类型。仅仅“表情变了”不算触发器；删除该节点后动作链仍完全相同，也不算事件。

## 四、多人镜头公式

每个镜头只设一个主导动作，但同一镜头必须能看见人物关系：

```
[输出方：完整台词/动作/沉默中的一个主动作]
+ [接收方：同镜头前景、背景或下一个必要反应镜头中的关键回声]
+ [物理承接：道具、距离、泪光、衣料、发丝或姿势的遗留状态]
```

执行规则：

1. 每个镜头至少包含一个真正推进叙事的动作或信息；禁止连续多个镜头只有嘴和眼睛变化。
2. 每一轮互动必须改变至少一项：视线落点、说话权、身体距离、道具控制权、动作方向、呼吸模式。
3. 回声角色的反应不可总是“看着对方”；必须交替使用避视、追视、伸手中断、退让、接住、松手、转身跟随、保持距离等行为。
4. 重复动作必须换力度与目的：第一次接道具可以轻而迟疑，第二次接可以快而用力，第三次重新握住可以慢而松。
5. 每镜头写 1–3 句。低强度镜头保留一个面部信号和一个身体信号；高强度镜头最多保留三个重点，不逐项枚举全部部位。

## 五、对白轮次协议

对白是情绪触发器，不是剧情说明书。用户允许台词时默认遵守：

1. 全片通常 **6–10 轮短台词**，总口语量按自然语速控制；单句优先 4–16 个汉字。确需长句时在同一镜头内自然停顿，不拆镜。
2. 先在【固定台词】按角色列出全部台词，再在【分镜】逐字调用；分镜不得临时新增台词。
3. 同一时间只允许一人说话。当前说话者口型与字词同步，倾听者双唇闭合并通过视线、呼吸和肢体回应。
4. 倾听者的关键回声优先留在过肩前景或背景；只有反应改变下一步行动时才单独切反应镜头。
5. 保留必要的无台词表演镜头，让手部、距离和道具完成叙事；不为比例机械添加停顿。
6. 允许至多一处真正的言语中断；普通停顿不得把完整句子拆到两个镜头。
7. 禁止台词直接说“我现在很伤心/我很生气”；台词负责提供事实、施压、拒绝、试探或澄清，情绪由身体呈现。

用户要求无台词时，把每轮对白替换为可见的信息动作：展示物件、翻转内容、伸手受阻、撤回、滑落、重新递出；仍需保留“输出→回声→反推”的双人轮次。

## 六、核心道具状态机

30 秒双人近景默认使用 **一个核心道具 + 至多一个次级内容物**。设计层先建立状态表，状态表不进入最终提示词：

| 节点 | 持有者 | 方位/角度 | 开合或显露状态 | 下一次变化的触发 |
|---|---|---|---|---|
| 首帧 | A / B / 共同 | 画面固定锚点 | 关闭、完整或部分露出 | 第一轮递交/查看 |
| 第一转折 | 明确到哪只手 | 旋转/抽出/抬高 | 出现新信息 | 台词或对方反应 |
| 压力段 | 控制权发生争夺 | 推近/抽回/贴向身体 | 折弯、滑动或重新合上 | 行为决定改变 |
| 澄清段 | 另一方接住或共同持有 | 重新进入画面中心 | 第二层内容显露 | 新认知成立 |
| 结尾 | 明确最终归属 | 固定最终朝向 | 保留前段物理痕迹 | 定格 |

道具每次交接都写启动、过程、落点与次级运动后果。禁止一拍在 A 手中、下一拍无过程出现在 B 手中；禁止内容物数量、朝向和开合状态漂移。

## 七、30 秒镜头密度

1. 正文默认约 **16–20 个有效镜头**，内容充足时可到 22 个；不提前收尾，也不为数量补镜头。
2. 普通镜头约 1–2 秒，完整对白镜头可约 2–4 秒，关键停顿与结尾可适当延长；最终为每个镜头标注连续不重叠的 [起-止秒] 时间戳，总长约 30 秒。
3. 一次完整台词、普通递交或完整反应能够在一个镜头中读懂时，不再拆分。
4. 全片通常包含 4–6 个因果事件、5–8 个改变行为路径的主动作和 6–10 轮完整对白。
5. 不把动作数量机械翻倍成满场走动。大动作可以是递出、抽回、推回、接住、转身、迈步和重新靠近；微动作只负责镜头内部的情绪纹理。
6. 情绪强度曲线至少有一处下降或假平静；高唤醒峰值通常 1–2 个，峰后保留生理痕迹。

## 八、交付前多人专检

- 是否明确主情绪角色、4–5 个状态及各自触发器？
- 回声角色是否每轮都在改变关系，而非作为静止陪衬？
- 两人是否避免同帧无因同步换挡？
- 每句台词是否完整位于一个镜头，并有说话人、口型归属和倾听者回声？
- 核心道具的持有者、朝向、开合和内容数量是否逐镜头连续？
- 30 秒是否通常为 16–20 个有效镜头，没有微动作凑数？
- 高强度段是否提高生理与全身细节密度，低强度段是否保持克制？
- 结尾是否通过具体动作完成决定，并写清最终双人姿态与道具归属？

任一项明显缺失，先局部修补；主线、道具或对白轮次互相矛盾时，整份分镜退回重排。

# 情绪调配决策层

三大使用模式解决「输入怎么接」，本层解决「情绪怎么配」。面对任何需求，按以下顺序决策：

1. 是单情绪还是复合情绪？
2. 复合是**先后转换（A→B）**还是**同刻叠加（A×B）**？
3. 强度定哪一档（L1–L4）？

## 一、复合情绪的两种结构

| 结构 | 含义 | 例子 | 调配方法 |
|---|---|---|---|
| A→B 转换链 | 先后变化，随时间推进 | 惊→喜、怒→释然 | 起幅/过渡/落幅时间轴（见附录 B） |
| A×B 同刻叠加 | 同一时刻两种情绪并存 | 又气又委屈、笑中带泪 | 本节主导/底色规则 |

## 二、A×B 同刻叠加调配规则

1. **定主色，禁止五五开**：两种情绪必须分出主导与底色。主导情绪占据面部高信号区（眼部+眉额），底色情绪占据低信号区（嘴部+面部/气色）；剧情焦点在哪，主导就是哪个。
   - 例：又气又委屈（焦点在「气」）→ 眉额/眼部给 12 隐忍怒意（皱眉肌强力收缩、目光如刃），嘴部给 26 委屈巴巴（颏肌收缩→下巴起皱、下唇前突）。
2. **同一肌肉只听一个指令**：一个肌肉群同一时刻只能服务一种情绪。若两种情绪争夺同一肌肉（怒要皱眉肌下压、悲要皱眉肌上提成八字眉），必须写明对抗态——「皱眉肌在两种指令间交替争夺，眉心纹路忽竖忽八」，不允许含糊带过。
3. **姿态跟主色，留一个破绽**：手部/身体/视线整体服从主导情绪，但允许恰好 1 个姿态细节泄露底色——主导是怒，手指却无意识地捻着衣角，委屈从这个小洞里漏出来。
4. **呼吸跟唤醒度更高的那个**：两种情绪生理唤醒度不同时（怒高、悲低），呼吸模式按更高的写。
5. **命名规范**：输出写作「主导 × 底色」，如【主体情绪】隐忍怒意 × 委屈巴巴（怒为主导，委屈为底）。

**叠加示例**（又气又委屈，焦点在气；设计层示意，不进入交付）：

```
【主体情绪】12 隐忍怒意 × 26 委屈巴巴（怒为主导）
嘴部: 口轮匝肌紧绷→双唇紧闭成线（怒）；颏肌同时收缩→下巴皮肤起细密皱褶,
      下唇被微微推向前（委屈从下巴漏出）
眼部: 提上睑肌张力↑→目光如利刃紧盯对方（怒）；泪腺分泌增加→下睑缘泪膜反光,
      眼眶泛红但泪水被强行悬住不落（委屈被怒压在水位线下）
眉额: 皱眉肌强力收缩→眉头内收下沉（怒主导）；皱眉肌间歇性向上抽动→
      眉心纹路在竖纹与八字之间轻微交替（两种指令的争夺痕迹）
核心姿态: 躯干僵硬挺直、下颌下沉锁定（怒）；手指无意识捻着衣角（委屈的破绽）
呼吸: 鼻呼吸主导，吸气短促带颤——怒的压抑节奏里混进了委屈的抽气前兆
```

## 三、情绪强度四档标准词表（L1–L4）

任何情绪条目都可整体升阶或降阶。换挡时**肌肉措辞、视觉幅度、姿态幅度、呼吸四层必须同步换**，不允许只换形容词。

| 档位 | 触发限定词 | 肌肉措辞 | 视觉幅度措辞 | 姿态幅度 | 呼吸 |
|---|---|---|---|---|---|
| L1 轻度 | 有点、一丝、隐隐 | 轻度收缩、微微参与 | 微、略、一丝、若隐若现 | 局部小动作 | 平稳，省略呼吸行 |
| L2 中度（默认档） | 很、明显 | 中度收缩、持续收缩 | 明显、清晰、可见 | 完整姿态响应 | 略促，可选写 |
| L3 强力 | 非常、压不住 | 强力收缩、持续紧绷 | 大幅、高高、死死 | 幅度大、全身参与 | 必须写，节奏紊乱 |
| L4 极限 | 炸了、崩溃、失控 | 极限收缩、锁死、痉挛 | 暴起、极限、彻底扭曲 | 失控/僵直/瘫垮 | 必须写，崩溃呼吸链（附录 C） |

换挡规则：

1. **档位可以换条目**：强度跨档时允许更换情绪条目本身——「有点生气」用 12 隐忍怒意 L1，「气炸了」直接换 11 雷霆狂怒 L4，不必在同一条目里硬拉。
2. **L1 省略呼吸行，L3 起必须写呼吸**，L4 必须落到完整崩溃呼吸链（深长吸→卡喉→短促喷气→断续抽吸）。
3. **示例**（生气四档对照）：
   - 有点生气 = 12 隐忍怒意 L1：咬肌仅轻度隆起，皱眉肌中度收缩，双唇紧闭但唇色不变
   - 生气 = 12 隐忍怒意 L2：咬肌明显凸起成鼓包，目光如刃，头部僵硬锁定
   - 非常生气 = 11 雷霆狂怒 L3：咆哮张口，怒目圆睁，躯干大幅前倾逼近
   - 气炸了 = 11 雷霆狂怒 L4：全部表情肌极限收缩，青筋暴起，呼吸喷爆，伴随肢体失控

# 有效镜头输出协议（编号分镜版）

本协议把情绪库、角色回声与道具连续性组织为约 16–20 个有效编号镜头。设计层负责选条、定主从与建立状态机；输出层负责剪辑镜头、完整台词和必要反应。微动作只作为镜头内部细节，不单独成镜。

---

## 一、十六条输出规则

**① 镜头划分与动作密度**
每个镜头只承担一个主导动作或一轮完整对白。默认约 30 秒、16–20 个有效镜头，按 wan 多镜头公式使用“镜头1[0-2秒]、镜头2[2-3秒]……”编号并标注连续不重叠的时间戳。说话镜头允许容纳完整句子及倾听者前景反应；普通机械动作能在一个镜头中读懂时不拆分。大动作使用递出、抽回、推回、接住、转身、迈步和重新靠近；微动作只承担镜头内部的衔接与情绪纹理。

**② 单镜头密度**
每镜头写 1–3 句并保留 2–3 个最关键的可见信号。平静段使用一个面部信号和一个身体信号；升级或崩溃段从眉眼、嘴部或呼吸、手部或身体中选择最重要的三类。完整情绪库用于选材，不要求把同一条目的全部部位写入一个镜头。

**③ 段间物理承接**
每段开头优先承接上一段**遗留的物理状态**：泪痕未干、泛红未退、笑意刚敛、呼吸还乱。不允许每段重置成「干净的起点」——情绪是连续流体，上一段的生理痕迹就是这一段的起跑线。例：上一段泪珠刚落，这一段开头先写「泪痕仍挂在颧骨上未干」，再写新动作。

**④ 生理细节词库**
升级与崩溃段落优先从这套词库取材：眼白/眼睑大面积泛红、眼底红血丝、泪腺逐渐分泌、眼眶蓄满水汽、泪珠饱满悬挂摇摇欲坠、泪痕顺面部纹路蜿蜒下移、鼻翼翕动开合、鼻腔溢出透明清涕、唇瓣不自觉收紧颤抖、嘴角牵拉出透亮口水丝。**崩溃级细节必须带定量**：丝长约 1-2cm、带透明反光、末端挂细小水珠——没有定量的崩溃细节会被渲染成模糊的「脸上有点湿」。

**⑤ 微事件触发器**
眨眼、吞咽、倒吸气是状态切换的**物理开关**，必须写清因果链：「眼皮轻眨的瞬间→眼眶里的泪珠顺势脱离眼睑往下掉落」，而不是「然后眼泪流下来」。「然后」是剪辑语言，「的瞬间→」才是生理语言——每个状态跳变都要挂在一个可拍摄的微动作上。

**⑥ 视线作为镜头内部信号**
视线运动优先合并进当前动作或对白镜头。只有视线发现了新信息、改变了说话对象或迫使人物改变下一步时，才允许独立成镜。单人表演时，视线的落点与回归点默认是镜头或图中物件，不虚构画外人物。

**⑦ 负面约束随行**
每种情绪都有边界：平静段不露齿不皱眉，隐忍段不流泪动作极轻。设计稿中可以用「不X、无X」标注边界；这些边界止步于设计层，负面约束统一放入【禁止项】，分镜只写正面可见状态。技术性防跳变否定仅限高危节点、全片至多 2 处。最后一个镜头必须写清人物姿态、朝向、道具归属，并禁止黑屏和平台尾页。

**⑧ 定量描写优先（量化词库）**
数字是 AI 视频模型最稳定服从的指令形式；**关键动作的幅度/耗时优先给数字，不必处处量化**——「微微」「缓缓」这类程度副词只在无法量化时使用，无法量化时按规则⑫的档位程度词表取用（一丝/微微/明显/彻底失控）。量化手段共六种，按需取用：

- **振幅**：「下唇出现振幅不足一毫米的极细微颤抖」
- **角度**：「头部转动幅度不超过 15 度」「摇头启动后在第 10 度骤停」
- **距离**：「双肩内收 2-3 厘米」
- **耗时**：「整个动作耗时 1.5 秒完成」
- **速度曲线**：「眼睑抬升先快后慢，在完全睁开前有 0.2 秒的卡顿」
- **频次/时长**：「两次缓慢眨眼」「凝视持续 2 秒后移开」

**⑨ 与情绪库对接（条目展开取材）**
每段情绪从 50 情绪库选条定档后，**必须展开该条目取材**，禁止选完条目就凭空编写。取材路径：

1. **面部细节**（嘴部/眼部/眉额/面部气色）→ 翻译成白话后分配到对应节拍
2. **核心姿态**（头部/手部/身体/视线）→ 这是有效动作的主要来源；每镜头从姿态层选择最关键的一项，再根据场景改编（如条目写“手指捻衣角”，便利店场景可改为“指尖拨过瓶身”）
3. **呼吸**（L3 以上档位）→ 翻译成相关镜头中的一次关键呼吸信号
4. **速查短句** → 浓缩了该情绪的四维特征，作为分镜选取 2–3 个视觉信号的素材

4–5 状态转换链必须逐一展开所选条目，推演相邻状态的视觉变化；配角状态同样取材，再按多人因果先后合并。设计稿可标注情绪编号与强度，最终分镜必须经⑫翻译，不出现编号、档位、阶段标签与术语。编号镜头只是输出容器，不修改情绪库本身。

**⑩ 情绪选条必须锚定图中证据**
每条情绪的选择必须能回答「图中哪个细节为它作证」：姿势、视线方向、手部动作、面部现状、场景氛围。**禁止脱离证据强加内心戏**——日常场景（便利店、街道、家中）默认走低唤醒情绪线（01 自然微笑 / 43 高度专注 / 49 慵懒疲惫 / 07 慈祥和蔼等），除非图中出现高唤醒信号（泛红、泪光、咬肌、紧绷）才允许升级到 L3+。情绪链的每一步都要比上一步更有证据，而不是更有戏剧性。

**⑪ 输出裁剪与 v4 五段式交付**
输入已含参考图时，不输出【主体描述】【场景环境】和设计分析。最终统一使用以下格式：

```
【总体描述】故事主题、叙述风格、主要情感与核心事件，声明多镜头结构与美学基调。
【全局锁定】角色身份与位置、参考图一致性、场景范围、轴线、过肩规则、核心道具初始位置；全片美学控制（光源、光线、主景别、运镜基调）与声音基调（BGM 风格或「无背景音乐」）。
【固定台词】按角色列出所有完整台词并标注音色与语速；无台词则写明“全片无台词、无旁白”。
【分镜】镜头1[0-2秒]、镜头2……默认 16–20 个有效镜头；完整台词不得跨镜头。
【禁止项】文字/UI/水印/Logo/角标/可读文字/真实UI/角色错位/口型错配/台词跨镜/道具瞬移/未经要求的背景音乐与额外台词。
```

仅当无图输入、用户要求改写主体场景或明确索要故事说明、声线、声音设计时，才增加相应模块。

**⑫ 白话输出层（设计层术语不出现在正文）**
肌肉解剖、情绪编号、L1–L4 档位是设计层图纸；进入【分镜】时必须翻译成白话电影语言，不出现肌肉术语、编号、档位标签和括号式注解。翻译规则：

1. **只保留「视觉结果」那半边**：双层结构「颧大肌收缩→嘴角上扬」在分镜里只写“嘴角浮现一丝笑意”；边界标注止步于设计层，负面约束统一放入【禁止项】
2. **情绪名翻成自然语言**：不写【44 迷茫困惑 L1】，写"一丝犹豫""怔了怔"；不写【22 嚎啕大哭 L4】，写"彻底哭出了声，完全收不住"
3. **档位翻成程度词**：L1 = 一丝/极淡/若有似无；L2 = 微微/渐渐；L3 = 明显/剧烈/再也压不住；L4 = 彻底失控/完全收不住
4. **允许克制的文学化比喻**："聚满而不落"——每片至多 1 句、仅 L3 以上档位可用，且必须落在可拍摄的部位+动作上，比喻不能替代部位
5. **定场句可选**：正文开头如需定场，只许用一句视觉锚点句——交代时间、光线或人物状态，如"午后斜光里，她安静地坐在窗边"——一句话即可，不展开；禁止写成动机句或心理旁白
6. **镜头颗粒度按事件驱动**：普通镜头约 1–2 秒，完整对白镜头可约 2–4 秒，关键停顿和结尾可更长；最终写镜头编号 + [起-止秒] 时间戳。低唤醒段通过减少镜头内细节体现克制，不通过拆分微动作制造节奏

**术语 → 白话对照表**（正文写作时查用）：

| 设计层术语 | 正文白话 |
|---|---|
| 颧大肌收缩→嘴角上扬 | 嘴角浮现笑意 / 嘴角悄悄扬起 |
| 皱眉肌收缩→眉心竖纹 | 眉头轻轻蹙起 / 眉心拧起一道痕 |
| 提上睑肌张力↑ | 眼睛微微睁大 / 目光抬了起来 |
| 眼轮匝肌参与（杜兴标记） | 笑意走到眼底 / 眼角弯了起来 |
| 嘴眼分离（假笑） | 笑意没走到眼睛里 / 笑只停在嘴角 |
| 颏肌收缩→下巴起皱 | 下巴微微发紧 / 下唇轻轻噘起 |
| 口轮匝肌紧绷 | 双唇抿成一条线 / 嘴唇抿得发白 |
| 降口角肌收缩 | 嘴角垮了下来 / 嘴角往下坠 |
| 咬肌隆起 | 咬紧牙关 / 腮帮绷出硬朗的线条 |

| 眨眼频率↓ | 几乎不眨眼 / 一眨不眨地盯着 |

**白话 ≠ 状态化**：白话输出层的正确形态是**白话运动解剖**——"眉心聚拢，挤出两道浅浅竖纹"（√），而不是"她露出伤心的表情"（×）。语言是日常的，内容仍是逐帧可执行的肌肉运动指令。禁止直接描述情绪结果，只描述部位的即时运动。

**⑬ 打破对称与冲突指令**
人类真实情绪从不纯粹、从不完整，AI 感的一大来源是表情过度对称、过度完成。三种冲突指令写法：

1. **单侧执行 + 区域隔离**：指定动作只发生在半张脸，同时用正面描写写清其余部位的静止状态——"嘴角向左侧微扯，扯出一个只有半弧的不完整苦笑，右侧嘴角与眉眼保持原状"。不完整本身就是指令。
2. **矛盾共存 + 同框呈现**：相反情绪同帧出现时，用可视化的同框描写把两组部位状态写进同一拍——"下眼睑微红湿润，瞳孔同时收缩、眼神对焦变锐利"。AI 默认会把矛盾抹平，不写在同一拍里就会被平均掉。
3. **极速转换 + 时间窗**：两种相反神情先后出现时，给出转换窗口——"破碎的悲伤与决绝的明亮在 0.5 秒内相继出现"。

**⑭ 克制与中断（失序感）**
AI 生成的情绪总有干净的起承转合，而真实微表情在于**中断和压抑**。四种阻断写法：

1. **动作中断**：动作启动后中途骤停——"抬手挥到一半突然僵在半空，像被按了暂停"
2. **生理阻断**：身体反应被强行压住——"眼眶泛红，但泪液在眼睑边缘被强行锁住，下眼睑肌肉紧绷颤动"，而不是"流泪"
3. **言语阻断**："涌至嘴边的话生生咽回，唇瓣张合一次后重新抿紧"
4. **欲望阻断**："手臂抬起似要拥抱自己，又在最后一刻克制地放下"

原则：让部分动作自然中断，全片保留几处没做完的瞬间即可，不必每镜头都有——没掉下来的泪、没说完的话、没做完的动作。

**⑮ 无剧情必造剧（微剧情设计 + 事件密度 + 转折防套路化）**
用户没有给定剧情时，**必须先设计一个与成片总时长匹配的微剧情，再让情绪链挂在剧情节拍上**——禁止人物原地站着只做表情。单个事件的最小结构是三幕：

1. **目标**（人物想要什么）：拿到某个具体物件、发出一条消息、等一条消息回进来
2. **转折**（发生了什么）：目标受阻、意外发现、被画外音或声响打断、回忆被触发……（按下文类型清单按图选型）
3. **结果**（人物做了什么决定）：拿起、放下、转身、笑了

三幕全部用**肢体动作**完成叙事（伸手→停住→收回，就是一部戏），情绪是剧情的副产品而非任务本身。面部特写片同样适用：事件可以是纯信息的（信息到达→消化→态度改变），但必须有"信息到达、态度改变、动作落点"三个节点。模式一用户给的一句话只有情绪没有事件时，也要先补事件再排情绪。

**故事模块的交付形态**：交付文本中的故事梗概必须写成连贯散文——事件编号、"第一/第二事件"标签、三幕标签、情绪换挡箭头一律止步于设计层，不进入故事模块正文；换挡对齐与事件数量是否达标属于内部检查项，不标注在交付文本里。

**单人场景的默认口径（镜头即对手）**：画面中只有一个角色时，表演对象默认就是镜头本身——发现镜头、对镜头说话、躲开镜头、视线回到镜头，就是天然的事件推进器。单人场景的事件推进 = **镜头互动 + 画外音/声响触发 + 图中已有物件或信息触发**。画外音只写声音本身与角色对声音的反应（人声、消息提示音、环境异响等），不描写发声者；禁止虚构、描写任何画外"那个人/对方"的实体行为与位置移动（不写"对方凑近""他不走""那人做势离开"）。多角色同框场景不受此规则限制。

**事件密度（30 秒多人片）**：一个“目标→转折→结果”通常只撑 5–8 秒；30 秒片默认需要 4–6 个因果事件，并至少有 4 个节点真正改变人物的动作路径、关系距离、道具控制权或说话决定。不得把一次递交拆成多个微动作后冒充多个事件或镜头。

1. **什么算一个事件**：有新东西进场（图中物件/声音/信息/与镜头的互动），或人物做了一个改变行为路径的决定。**判定标准：把这个事件删掉，人物的动作链是否还一样？一样就不算事件，只是氛围**——远处购物车声只让她手快了半拍，这是音效不是事件；货架上的瓶子被碰倒滚到脚边、她弯腰捡起、顺手把最外排的瓶子扶正——这才是事件。
2. **推荐骨架（30 秒）**：目标与关系建立 → 第一偏差 → 新信息加压 → 主角采取反向行动 → 新证据或对方决定改变局面 → 结果与余韵。中间至少包含一次控制权转移和一次行动路径改变。
3. **事件之间必须有因果链**：A 的输出引发 B，B 的反应逼出 C——不是并列流水账。四次关键换挡分别挂在四个事件节点上，其他事件负责加压、澄清或落地。
4. **事件与防套路化联动**：4–6 个事件的转折类型至少覆盖三类，不能连续两次都靠画外音、沉默或物件滑落推进。

**转折防套路化（反收敛规则）**：转折是全片最容易撞车的环节，禁止从记忆里调模板，必须从图里长出来——

1. **证据生长**：转折必须锚定这张参考图**独有的视觉证据**——具体物件、位置关系、光线、人物状态。每次生成须在设计说明中明确写出"图中哪个细节支持这个转折"；指不出图中证据的转折，一票否决，重选。
2. **转折类型清单（按图选型）**：目标受阻 / 意外发现 / 比较权衡 / 画外音或声响打断 / 回忆或联想触发 / 时间压力 / 误会与澄清。选型依据是图中证据支持哪一类，而不是哪一类"常用"；单人场景选"打断"类时一律用画外音/声响形式，只写声音本身与角色的反应，不描写发声者。
3. **点名禁用高频烂俗套路**：禁止"货架上只剩最后一瓶"式便利店缺货桥段——除非图中真有明确缺货证据（空货位、歪斜价签、补货箱）；同理禁止无证据套用"消息已读不回""那人擦肩而过"等模板转折。
4. **连续生成不重复**：同一用户连续生成时，转折类型不得与上一次重复；重复即退回重选。

**双线并行，不可偏废**：微剧情解决的是"人物在做什么"，不替代"人物脸上在演什么"。每一拍 = 肢体动作（叙事线）+ 面部情绪细节（表演线）——动作是骨架，表情是血肉。写了"她伸手拿瓶"的同时，必须写此刻的眼神、嘴角、眉心在干什么；情绪密度按档位规则（②）执行，不因剧情线而减配。缺了叙事线是站桩摆表情，缺了表演线是木偶做动作，两者都是废片。

**⑯ 声音三层写法（人声 + 音效 + BGM，对齐 wan 声音公式）**
基于模型原生音频能力，声音必须显式控制，不留白让模型自由发挥：

1. **人声** = 说话内容 + 情绪 + 语调 + 语速 + 音色（+ 口音，需要时）。台词在【固定台词】中按角色标注音色与语速（如“声音清亮，语速适中，语气轻松”），分镜中用 xx说：“xxx” 格式调用，模型会保持台词内容不变。
2. **音效** = 音源材质 + 行为 + 环境音，随动作写入对应镜头（如“玻璃杯磕在木桌上发出一声闷响，室内安静环境”）；只写剧情中真实发生的声音，不单独扩写声音设计章节。
3. **BGM** = 配乐 + 风格，在【全局锁定】一次性写明（如“配有低沉克制的钢琴配乐”）；用户不要音乐或文戏默认克制时明确写“无背景音乐”。不描述 BGM 时模型会自行发挥，禁止留白。
4. **控制兜底**：提示词未描述台词时模型会自由添加台词——无台词片必须写“全片无台词”；音色需要保持一致时可在台词处强调“保持人物音色和语气”。

# 交付模版 4.0（30 秒多角色有效镜头版）

> 本章是最终交付提示词的完整组装手册。默认输出一段总体描述 + 一份多人共享提示词、4–5 状态主线、角色回声、完整对白、核心道具连续性和约 16–20 个带时间戳的有效编号镜头（对齐 wan 多镜头公式）。

> **总隔离条款（先于一切字段标准与写法）**：凡是解释"为什么/不是什么"的句子，一律不得进入交付正文与故事模块。动机、防误读、节奏判断是写之前想清楚的设计层自检项，正文只交画面。
> 正例：「拇指在窗控键上停半秒，指腹压下去，玻璃开始下降。」
> 反例：「是她自己主动按下，不是自动、不是他人」——这类撇清/解说句只留在设计层，禁止写进正文。

## 一、五段式字段填写标准（4.0）

```
【总体描述】
① 一句话概述故事主题、叙述风格、主要情感与核心事件（如“以第三人称视角讲述一个关于放弃与重拾希望的短剧”）。
② 声明多镜头结构与全片美学基调（如“电影质感写实风格，由约 18 个镜头组成”）；风格化词汇（如“赛博朋克”“废土风格”）也在此声明。

【全局锁定】
① 约 30 秒；画幅跟随参考图，无图时默认 16:9。
② 锁定角色身份、左右位置、外貌、服装、场景和光线；有图时不复述细枝末节。
③ 允许切镜；锁定 180 度轴线和人物视线方向，不翻转左右关系。
④ 用户要求过肩时，谁说话就从倾听者肩后拍向谁；同一句话期间不换机位。
⑤ 锁定核心道具的初始持有者、位置、朝向和显露状态。
⑥ 一次性写明全片美学控制：光源与光线环境、主景别与视角、运镜基调（如“以固定机位与过肩正反打为主”）。
⑦ 写明声音基调：各角色台词音色、BGM 风格（如“配有低沉克制的钢琴配乐”）或明确写“无背景音乐”。
⑧ 单人场景不实体化拍摄者或画外人物。

【固定台词】
① 按角色列出所有完整台词，逐角色标注音色与语速（如“声音清亮，语速适中”）；分配不必平均。
② 每句优先 4–16 个汉字；长句可在同镜头自然停顿。
③ 分镜只能逐字调用，不能临时新增、改写或跨镜拆分。
④ 一次只允许一人说话，倾听者闭口；无台词时写“全片无台词、无旁白、无清晰说话口型”。

【分镜】
① 使用“镜头1[0-2秒]、镜头2[2-3秒]……”编号，通常 16–20 个，内容充足时可到 22 个；时间戳连续不重叠，总长约 30 秒。
② 每镜头写 1–3 句，只承载一个主导动作或一轮完整对白。
③ 说话镜头写清过肩前景、说话者、完整台词和倾听者的一个关键回声。
④ 无台词镜头必须提供新信息、决定、距离变化、道具控制权变化或关键情绪转折。
⑤ 必要事件声音（音源材质+行为+环境音）直接写进对应镜头，不单独扩写声音设计。

【禁止项】
文字/UI/水印/Logo/角标/可读文字/真实UI/字幕/黑屏/账号主页/平台尾页/搜索框/贴纸/角色错位/左右翻转/越轴/口型错配/倾听者同步动嘴/台词跨镜/道具瞬移/无因同步变脸/未经要求的背景音乐与额外台词。
```

## 二、分镜写法十二条

1. **事件驱动镜头粒度**：不按等长时间切片。普通镜头约 1–2 秒，完整对白镜头约 2–4 秒，关键停顿与结尾可更长；最终为每个镜头标注 [起-止秒] 时间戳（连续不重叠，总长约 30 秒）。动作、对白与反应能在同一构图中读懂时，合并为一个镜头。
2. **首帧三要素**：无图时使用动作中间态、非完整正脸和一个姿势或道具锚点；有参考图时严格从参考图自然动起来，只在【全局锁定】中固定位置和道具，不改写首帧。
3. **动力链句式**：大于 45° 的转身、俯身、起身等大动作，按部位先后拆写——"头部先转，肩膀再跟上，腰胯最后转过去"（或按画面可见顺序："先露出下颌和鼻梁，再露出一只眼睛"）。时序步数按需（一般 2–3 步即可）；小动作不分解，分解是稀缺资源，只花在最容易穿帮的地方。
4. **物理证据因果对**：主要动作尽量配一个可见的次级运动后果，不设固定句式——快速抬头带起碎发甩到眼前；转身时马尾横向甩开再落回；弯腰时腰侧衣料被拉紧。观众通过次级运动反推主动作的力度——这是"真"的关键。
5. **情绪两件套**：情绪词不裸奔，每个情绪词 = 情绪词 + 2–3 个部位证据。"眼神幽怨：眉心轻皱、内眉略抬、眼皮半垂，黑眼珠停在镜头上两秒没动"。动机是设计层前提：写部位证据前先想清楚她为什么是这个情绪，但动机本身不写进正文。白话规则⑫与术语对照表全部沿用。
6. **否定桩（仅指技术性防跳变否定）**：否定桩只用于防过程跳变（"不要一帧直接把头放到车外""不要让玻璃瞬间消失"），只打在过程易跳变的高危节点，全片至多 2 处；否定不平铺，只在要断的地方打桩。语义性辩白——解释"不是什么/为什么"的句子（如"必须是她自己主动按下，不是自动、不是他人""不是悲伤哭泣"）——一律禁止写入正文，这类解释句禁止入正文，只留在设计层自检。
7. **核心设定状态机**：贯穿全程的设定（含着东西/带伤/隐瞒身份）拆成 2–3 个二元可观察状态（嘴闭/嘴开、鼻呼吸/口呼吸），在关键时间段按需显式点名，不必每段都点；全文只设一个解禁时刻，用"终于"回收前文全部约束（"嘴唇终于快速张开"）；优先设计视觉容错（手掌挡住嘴部，单帧崩坏也不穿帮）。
8. **重复动作动机换档**：同一动作出现多次，动机差异用两次动作的部位细节、力度、速度差异体现（第一次捂嘴快而紧、指节发力，第二次慢而松、只虚掩）——差异靠画面说话，不写解说句，防止模型把重复动作渲染成机械循环。
9. **节奏曲线**：快慢相间，动作峰明确，情绪段落降速；爆发峰通常 1–2 个。速度词必须绑定具体部位或动作。单人表演的视线落点始终是镜头或图中物件，不虚构画外人物。
10. **结尾双行**：最后一帧的具体画面（姿态+表情+朝向）+ 枚举式负面清单（黑屏/账号主页/平台尾页/搜索框/字幕/水印/贴纸/UI），或简写"无黑屏、无转场"。
11. **多人回声句式**：说话镜头先写说话者的完整台词和动作，再写倾听者在过肩前景或背景中的一个关键回声；只有该反应改变下一步时才另切反应镜头。
12. **对白与道具并行**：台词出现时仍须写清说话人的身体动作、倾听者的闭口反应和道具状态；道具交接必须写启动、过程、落点与次级运动。对白不能替代动作，道具不能瞬移。

## 三、交付前自检（抽查参考）

> 以下为交付前抽查建议口径；发现问题优先局部修补，不必整篇退回重写。

- **数量**：通常为 16–20 个有效镜头，内容充足时才超过 20 个，不为数字补镜头；时间戳连续无断档、无重叠，总长约 30 秒
- **首帧**：无参考图时避免完整正脸摆拍开局；有参考图时首帧即参考图，抽查是否满足动量/姿势锚点，不满足则在机位与构图中补救
- **大动作**：抽查大动作是否按动力链分解
- **物理证据**：全片是否有足够的次级运动后果（凭整体观感抽查，不逐段计数）
- **情绪词**：抽查情绪词是否都带有部位证据
- **粒度**：有无明显无依据的等长切分（高动态片重点看）
- **设定**：核心设定在中后段是否仍有露面，不要长期失联
- **隔离**：正文与故事模块中无"为什么/不是什么"解释句、无"这次不是……而是……"句式
- **情绪状态**：主角 4–5 个连续状态是否清楚，每次变化是否有真实触发
- **多人回声**：每轮输出是否有关键接收反应，是否避免多人无因同步换脸
- **对白**：固定台词、完整句子、说话顺序、口型归属与倾听者闭口反应是否一致
- **声音**：各角色台词音色与语速是否标注，事件音效是否随镜头写明，BGM 风格是否显式声明或写“无背景音乐”，无台词片是否写“全片无台词”
- **美学**：光源、光线、主景别、运镜基调是否在【全局锁定】一次性写明，风格化词汇是否声明
- **道具**：持有者、方向、开合、内容数量和交接过程是否连续
- **密度**：每镜头是否有实际内容，是否不存在眨眼、吸气、准备开口和结尾点头等填数镜头

# 50 情绪融合表演库

> 每个情绪条目 = 面部细节（肌肉动作→视觉结果）+ 核心姿态（头/手/身/视线）+ 呼吸控制（需要时）+ 速查短句
>
> 注：库内条目中的"对方/对象"为抽象交互对象。单人表演时"对象"即镜头——取材时将条目里的对人动作改写为对镜头动作（看向对方→看向镜头、避开对方视线→避开镜头、朝对方说话→朝镜头说话），不虚构画外人物的实体行为。
>
> 取材纪律：取材只取部位动作与视觉结果；条目中的评价性措辞、括号情绪标签、阶段分层标记不随取材进入交付文本。

## 一、喜悦类情绪（01–10）

### 01. 自然微笑
**面部细节**（肌肉动作→视觉结果）：
- 嘴部: 颧大肌轻度收缩→嘴角微微向外上方牵引，弧度小而真实；口轮匝肌保持自然张力→双唇自然闭合不露齿
- 眼部: 眼轮匝肌外侧轻度收缩→外眼角出现极淡的辐射细纹，眼裂微微缩窄；提上睑肌平静态→眼神柔和自然，瞳孔略有微光
- 眉额: 额肌完全放松→额头平滑无纹；皱眉肌无参与→眉形自然平缓，眉间距正常
- 面部/气色: 面部肌肉完全放松，颧部被轻微上提→苹果肌微显，气色均匀温润
**核心姿态**：
- 头部: 头部保持中立或微侧，颈肩无紧张感
- 手部: 手指自然微张轻搭身侧，手掌放松不握拳
- 身体: 躯干挺拔不僵硬，肩膀自然下沉，胸腔微开
- 视线: 注视点柔和地落在对象面部，眼动轻快不粘滞，眨眼节奏均匀
**速查短句**: 嘴角微微上扬、双唇自然闭合，眼神柔和自然略有微光，面部肌肉完全放松、苹果肌微显，头部保持中立或微侧。

### 02. 开怀大笑
**面部细节**（肌肉动作→视觉结果）：
- 嘴部: 颧大肌强力收缩→嘴角大幅向外上方牵引，上唇展平露出整齐上齿；咬肌松弛→下颌自然打开，口轮匝肌完全松弛→双唇大幅分开
- 眼部: 眼轮匝肌外侧强力收缩→双眼眯成弯月状，外眼角挤出自然笑纹；下眼睑因眶部眼轮匝肌收缩上提（真笑杜兴标记完整）
- 眉额: 额肌完全放松→额头平滑；皱眉肌无参与→眉形展开、随笑意轻微上扬
- 面部/气色: 颧部被强力上提→苹果肌明显隆起并向上提拉，面颊因血液循环加快而透出红润
**核心姿态**：

### 14. 高傲鄙视

### 15. 嗔怒娇嗔

### 17. 义愤填膺

### 19. 冷酷杀意
**面部细节**（肌肉动作→视觉结果）：
- 嘴部: 颧大肌极轻微单侧收缩→嘴角噙着一抹毫无温度的冷笑；口轮匝肌低张力维持→双唇平直闭合，除此之外嘴角毫无波澜

- 手部: 双手完全静止地垂在身侧或缓慢抬向武器/物件，动作没有一丝多余；手指松弛而非握拳——松弛才是危险的信号

**速查短句**: 嘴角毫无波澜、噙着一抹毫无温度的冷笑，眼神空洞深邃且极其冰冷、视人如死物，面部如大理石雕塑般毫无生气完全凝固，头部极其缓慢机械且致命地转向目标。

## 四、惊恐类情绪（31–40）

> 本类情绪以**额肌（frontalis）主导**为共同特征——眉毛高抬、额头横纹密集（区别于悲伤类的皱眉肌主导）。恐惧越深，提上睑肌收缩越极限、巩膜暴露越多、瞳孔反应越极端。

### 31. 极度惊恐
**面部细节**（肌肉动作→视觉结果）：
- 嘴部: 咬肌完全松弛→下颌坠至最低，嘴巴不受控地张大到极限，呈惨烈的O型；口轮匝肌被撑开→双唇拉薄，唇色因拉伸泛白；降下唇肌收缩→下唇边缘外翻并伴随不可抑制的颤抖
- 眼部: 提上睑肌极限收缩→上眼睑抬至最高，虹膜四周巩膜全部可见，眼球几乎要凸出眼眶；眼轮匝肌无任何收缩→眼裂最大开度且完全失去眨眼反射；瞳孔极度放大→眼神碎裂涣散
- 眉额: 额肌极限收缩→双眉挑至最高位，额头挤出密集的平行横纹；皱眉肌轻微参与→眉头内侧略内收，恐惧与警觉并存
- 面部/气色: 面部所有表情肌张力达到最大值，呈"被冻结的极度展开"；极速缺血→面庞瞬间失去血色惨白如纸；交感神经爆发→额头冷汗直流、鬓角汗珠成串滑落

**速查短句**: 口轮匝肌松弛嘴巴虚脱半张，提上睑肌张力极低眼皮半睁半闭、眼布血丝暗淡无光，面部肌肉受重力彻底下垂拉垮，头部无力瘫靠椅背随身体东倒西歪，呼吸深缓偶带长叹。

### 50. 坚毅不屈
**面部细节**（肌肉动作→视觉结果）：
- 嘴部: 口轮匝肌强力收紧→双唇死死紧抿成一条铁线，毫无半分退缩妥协；咬肌隆起→下颌角两侧肌肉鼓包，牙关咬定；面部缺血→唇色铁青
- 眼部: 提上睑肌张力↑→眼裂有力睁开；眼轮匝肌部分紧张→眼裂微缩如鹰；注视点如钉子锁死正前方，眨眼频率↓，目光坚定如铁、锐利无比
- 眉额: 皱眉肌中度收缩→眉头内收下沉，眉心浅竖纹；额肌无参与→不抬眉，力量全部向下压而非向外惊
- 面部/气色: 下颌骨骨骼线条极度紧绷，面部充满坚不可摧的力量感与英气；气色因紧绷而略显铁青冷峻

**核心姿态**：
- 头部: 头部高高昂起，带着视死如归的骄傲姿态迎接一切挑战，下颌微抬但不傲慢
- 手部: 双手紧握成拳垂在身侧，指节泛白；或手臂沉稳交叉于胸前，肌肉线条绷紧不动
- 身体: 躯干挺直如松，肩膀向后展开下沉，胸腔打开，双脚稳扎地面与肩同宽，重心沉在中段不可撼动
- 视线: 直视正前方迎面而来的狂风暴雨，注视点稳定不移，不闪不避，像要把前方看穿

**呼吸**: 鼻呼吸主导，吸气深而稳→胸腔缓慢扩张到满；呼气克制绵长→从鼻腔匀速推出；节奏如战鼓般稳定，无一寸慌乱

**速查短句**: 口轮匝肌收紧双唇铁青紧抿成铁线、咬肌隆起牙关咬定，皱眉肌收缩眉头下沉，目光坚定如铁锐利直视正前方，下颌线条极度紧绷充满英气，头部高昂以视死如归的姿态迎接挑战。

## 附录 B：情绪转换与多阶段表达

当需要跨情绪的连续表演时，按时间轴分段推演（本附录为设计层推演方法，阶段标签与推演句型止步设计层）：

1. **起幅情绪**：想清楚初始肌肉状态
2. **过渡阶段**：想清楚肌肉对抗——哪两条肌肉在争夺控制权
3. **落幅情绪**：想清楚哪组肌肉最终接管
4. **中间态**：可用"颤动的本质是X与Y的交替争夺"这类句型推演中间态的肌肉对抗关系——该论文式句型仅限设计层推演，禁止进入交付文本；交付文本只写颤动本身的部位、幅度与频率

关键规则：

- 情绪转换必须想清肌肉间的权力转移，交付文本通过前后两组肌肉细节的此消彼长来呈现，不写"从A变到B"的解说句
- 中间态=对抗态，两套肌肉群同时参与但力量不均
- 每段想清楚该阶段的呼吸模式变化，再决定哪些写进正文
- 起幅/过渡/落幅是设计层阶段标签，止步设计层，不进入交付文本与故事模块
- 50 情绪库中任意两种情绪都可按此法组合成转换链（如 25.绝望死心 → 08.释然微笑、12.隐忍怒意 → 11.雷霆狂怒），先各查该情绪的肌肉配置，再按起幅/过渡/落幅推演拼接即可

## 附录 C：呼吸控制

情绪激动时的呼吸必须精确描写：

- **鼻呼吸 vs 口呼吸**：克制态用鼻，释放态口鼻交替
- **吸气节奏**：均匀→碎裂→抽搐（跟随情绪恶化程度）
- **呼吸锚点**：深长吸→卡喉→短促喷气→断续抽吸（完整的崩溃呼吸链）
- **胸腔幅度**：扩张→暂停→不规则起伏→膈肌痉挛
- **鼻翼参与**：鼻肌参与→鼻翼外扩幅度变化反映情绪恶化程度

## 附录 D：黄金法则（注意事项）

1. **绝不写抽象描述**：全部落在具体部位（鼻翼/眼眶/嘴角/下巴/喉结/眼尾/咬肌/眉心）+ 精确动词（急张/僵住/轻转/猛提/抽搐/锁死）+ 视觉结果，禁止"她很难过""他很愤怒"这类空泛句子。
2. **肌肉术语必须落在视觉上**：肌肉名称是引擎说明，每个肌肉动作后面必须用 → 给出画面可见的结果。
3. **双层结构是因果不是选择**：→ 前后的两段都要写全，AI 懂解剖则取前半段的干净信号，不懂也有后半段可执行。
4. **真假笑看嘴眼配合**：真笑 = 颧大肌 + 眼轮匝肌外侧同时收缩（杜兴标记）；假笑/空笑的核心是嘴眼分离——颧大肌参与但眼轮匝肌不参与。
5. **厌恶类必须写鼻部**：鼻肌收缩、鼻梁皱褶、鼻翼变化缺一不可，否则看起来像"嫌弃"而非"厌恶"。
6. **"忍"的本质是肌肉对抗**：咬肌隆起 + 口轮匝肌紧绷 = 隐忍即将爆发；所有"强忍/克制"都要写出两套对抗肌肉群同时收缩。
7. **区分相似情绪的肌肉主导**：悲伤的八字眉是皱眉肌内聚+额肌内侧上提的组合，区别于恐惧/惊讶的额肌整体上挑——同类轮廓，驱动方式不同。
8. **情绪转换写权力转移**：转换必须想清哪两条肌肉在争夺、哪组肌肉最终接管，不能只写"从A变到B"；中间态 = 对抗态。"权力转移/对抗态"是设计层术语，正文只呈现两组肌肉细节此消彼长的视觉变化。
9. **激动情绪必须配呼吸**：情绪越失控，呼吸描写越要精确（鼻/口切换、吸气节奏碎裂、鼻翼外扩幅度），平静类可省略呼吸行。
10. **姿态服务情绪强度**：手部/身体/视线要与情绪的强度和性格匹配——内敛情绪手臂内收、视线躲闪，外放情绪躯干前倾、视线锁死，不可张冠李戴。
11. **复合情绪禁止五五开**：同刻叠加（A×B）必须分主导与底色，主导占眼部/眉额高信号区，姿态跟主色，至多留 1 个姿态细节泄露底色；同一肌肉被两种情绪争夺时必须写明对抗态。
12. **换挡换四层**：强度升/降档时肌肉措辞、视觉幅度、姿态幅度、呼吸描写同步换挡（见情绪调配决策层 L1–L4 词表），只换形容词等于没换挡；"换挡"与 L1–L4 档位是设计层术语，止步设计层，正文用程度词与细节变化呈现结果。
13. **时间轴守承接与触发**：秒级分镜输出时，每段开头承接上段遗留的物理状态（泪痕未干、泛红未退），每个状态跳变必须挂在微事件上（眨眼→泪落、倒吸气→破防）；崩溃段按分部位写法组织并带定量细节——条目化是密度指引，正文按视觉焦点自然铺开，不必逐字按部位顺序报数（见时间轴高密度输出协议）。
14. **情绪链锚定证据，动作撑起镜头**（协议⑩①）：每条情绪必须能指出图中佐证细节，日常场景默认低唤醒情绪线，禁止无证据强加内心戏；每个无台词镜头必须有可拍摄的有效动作、信息或决定，纯情绪空镜不得用于凑数量。
15. **有图就不复述图**（协议⑪）：输入含参考图时省略【主体描述】【场景环境】及解说性头部，只在【全局锁定】中固定角色位置、场景范围与一致性。
16. **正文只说白话**：肌肉术语、情绪编号、L1–L4 档位是设计层图纸，落入正文必须翻译成白话电影语言——只写正面视觉结果，程度词替代档位；负面约束只进【禁止项】块（另见总隔离条款：凡是解释"为什么/不是什么"的句子，一律不得进入交付正文与故事模块）；文学化比喻必须落在可拍摄的部位上（见协议⑫对照表）。
17. **白话也是运动指令**：白话不等于抽象状态——"眉心聚拢，挤出两道浅浅竖纹"是白话，"她露出伤心的表情"是废话。禁止描述情绪结果，只描述部位的即时运动；关键动作的幅度、角度、耗时、速度优先给数字，其余用档位程度词即可，不追求处处量化（协议⑧⑫）。
18. **留一处没完成**（协议⑭）：全片保留若干处中断或压抑——没掉下来的泪、没说完的话、启动后骤停的动作、只有半弧的笑；这是全片定性要求，作为交付前自检（抽查参考），不逐段计数。矛盾情绪同帧用可视化写法呈现：把两种信号写进同一时刻的身体细节（如"泪挂在下睑缘，嘴角同时向上扯了一下"），或用先后紧接的动作顺序交代先后，不写"同时发生""0.5 秒内相继出现"这类标注句（协议⑬）。
19. **选条必取材，情绪流全身**：主角 4–5 个状态和配角状态都从完整情绪条目取材；面部细节翻成白话，姿态层提供动作。每镜头只选 2–3 个关键视觉信号，最终通常为 16–20 个有效镜头。
20. **无剧情必造剧，三线并行**：用户没给剧情时先设计 4–6 个因果事件，再让主角 4–5 状态情绪链挂在事件上。每个镜头同时维护叙事动作线、面部表演线和多人回声线；核心道具保证交接连续。
21. **交付必过自检**（交付模版 4.0）：检查首帧锚点、大动作动力链、情绪部位证据、完整台词、说话人口型、过肩前景、多人回声和核心道具连续性。技术性否定桩只用于易断裂节点，全片至多 2 处。
22. **单人对镜头法则**：画面中只有一个角色时，表演对象默认为镜头本身——镜头即对手，对着镜头演；情节推进靠角色与镜头的互动（发现镜头、对镜头说话、躲开镜头、视线回到镜头）+ 画外音/声响触发 + 图中已有物件或信息触发。禁止虚构、描写任何画外"那个人/对方"的实体行为与位置移动（如"对方凑近""他不走""那人做势离开"）；允许使用画外音/画外声响（人声、消息提示音、环境异响等）作为情节触发器，但只写声音本身与角色对声音的反应，不描写发声者。多角色同框场景不受此条限制。
23. **双人不同步换挡法则**：两人相邻反应必须有可见先后。A 的台词、动作或沉默先发生，B 在 0.2–0.8 秒后用眼神、呼吸、手部或身体接住；B 的反应再改变 A 的下一步。除共同受外部刺激外，禁止同帧无因同步换脸。
24. **对白不替代表演**：每句对白镜头同时写说话人的身体动作、倾听者的闭口回声和当前道具状态；完整台词不得跨镜。反应只有改变下一步行动时才单独成镜。
25. **一片一份提示词法则**：同一 30 秒连续片段只输出一份共享提示词和一组编号分镜，禁止按角色拆成多份正文。
