# 30秒电影视频提示词导演

一个面向中文 AI 视频创作的 Codex Skill，用“视觉复杂、逻辑简单”的方法，把角色图、故事概念或已有草稿变成可直接粘贴的完整30秒电影视频提示词。

## 它解决什么

- 画面很炫，但30秒里人物、场景和物件不断漂移。
- 提示词堆满“电影感、ALEXA、UE5”，却缺少清楚动作和因果。
- 参考角色图把白底、文字、多视图和摆拍姿势一起带进视频。
- 反转依赖突然出现的新角色、新地点或第二套世界规则。
- 双人运动、球体、道具和镜头轴线不连续。
- 每次优化都整篇重写，不知道究竟哪一项有效。

## 核心方法

> 一个主要空间 + 一个主角 + 一个关键物件 + 一条异常规律 + 一次选择 + 一次同场反转。

视觉奇观可以很大，但故事因果只保留一条。参考图只控制被明确分配的身份、服装、媒介、物件或构图职责；其余部分重新导演。

## 适用场景

- 30秒、16:9文生视频或图生视频提示词
- Wan、即梦及其他视频生成平台
- 角色卡改编、真人电影、2D、3D、运动广告、韩剧式反转
- 高概念成人科幻选集气质或 Series 式短篇
- 已有提示词的稳定性诊断与最小修复
- 多条彼此独立、可直接入队的批量成品

## 安装

将仓库克隆到个人 Skill 目录：

```bash
git clone https://github.com/petezbuilds/cinematic-30s-video-prompt-director.git ~/.codex/skills/cinematic-30s-video-prompt-director
```

重新打开 Codex 后，在请求中使用：

```text
$cinematic-30s-video-prompt-director 根据这张角色图写一条完整30秒、16:9、真人电影、结尾有反转的视频提示词。
```

也可以自然语言触发：

```text
写三条无垫图、纯文生视频、完整30秒、视觉复杂但逻辑简单的成人科幻短篇提示词，每条都能直接粘贴。
```

## 方法来源

本 Skill 来自 Pete Zhang 在多轮30秒 AI 视频提示词生产中的实际迭代：先发现“把故事变得非常简单”会损失高概念气质，再收敛为更准确的原则——视觉可以复杂，逻辑必须简单。公开版本提炼的是可复用控制方法，不包含第三方作品的角色、剧情或独特美术复刻。
