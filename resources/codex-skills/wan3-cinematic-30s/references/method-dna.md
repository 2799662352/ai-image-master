# 方法 DNA：视觉复杂，逻辑简单

## 什么是真正不可替代的部分

这套方法的表面形式可能是真人电影、二维动画、3D家庭动画、成人科幻选集、运动广告或韩剧反转。真正需要保留的是下面八个功能。

| 功能 | 作用 | 可变形式 |
|---|---|---|
| 成品优先 | 用户拿到即可直接粘贴生成 | 平台、模型、语言、时长 |
| 单线因果 | 让30秒在一次观看中被理解 | 题材、场景、任务 |
| 高概念钩子 | 第一秒出现值得继续看的异常 | 物件、影子、天气、空间、声音 |
| 复杂度预算 | 用少量变量换取角色和动作稳定 | 奇观大小、配角数量、镜头密度 |
| 媒介原生 | 让真人、2D或3D使用各自擅长的表演和材质 | 美术、渲染、摄影系统 |
| 连续性硬锁 | 防止换脸、换装、复制、瞬移、跨轴和光向变化 | 锁定字段的具体内容 |
| 回看成立的反转 | 用结尾重释前面，而非另起故事 | 空间、意图、物件、关系、规律 |
| 同步声音与定制禁令 | 让声音服务画面，并针对真实风险做约束 | 环境声、动作声、专业失败项 |

## 一行生成公式

```text
固定主角 + 固定空间 + 可见任务 + 单一异常规律 + 一次选择 + 同场重释 + 安静余韵
```

这条因果链必须先成立，再添加摄影机、灯光、材质、引擎或镜头品牌。

## 复杂度与视觉规模不是一回事

低逻辑复杂度不等于小场面。以下奇观仍然可以稳定：

- 同一场雨突然悬停；
- 同一建筑的灯光依次熄灭；
- 同一个影子开始独立行动；
- 同一块天空裂开一道可见缝隙；
- 同一台机器吐出不可能的物件；
- 同一条球路被严格追踪到落点。

它们共享一个机制、一个空间和一条因果。真正危险的是同时改变人物、场地、媒介、道具数量、时间、镜头轴线和世界规则。

## 反转的功能

反转不是为了证明作者聪明，而是承担三个任务：

1. 给前22秒的物件、动作或构图第二层含义；
2. 让主角的选择被重新评价；
3. 用一个可见动作或空间变化结束，不靠解释性对白。

好的反转使用已建立的信息。坏的反转突然引入新怪物、新地点、梦境、第二套规则或更大的爆炸。

## 媒介不是风格标签

媒介判断影响动作与反转的可执行性：

- 真人适合微表情、真实接触、环境异常和空间揭示。
- 风格化3D适合清楚轮廓、物理喜剧、材质反差和温暖表演。
- 二维动画适合线条、色块、纸张、图形规律和诗意变形。
- 专业运动适合严格轴线、单物体连续轨迹、重心与接触。

不要因为用户说“电影感”就把所有参考图都真人化，也不要因为用户说“3A”就堆砌引擎术语。

## 从参考图中提取责任，而不是全部复制

角色卡最常承担身份、发型、服装和媒介责任。白底、箭头、文字、多视图、展示姿势和棚拍光线通常是污染项。首帧图片才可能承担构图、位置与开场状态。

先写“这张图控制什么”，再写“它不能控制什么”，可以显著减少人物展示图、旧姿势冻结和场景污染。

## 最小修复为何重要

一次重写所有层会失去因果信息。只改一个变量，才能知道瑕疵来自：

- 故事变量太多；
- 参考职责冲突；
- 媒介判断错误；
- 动作或接触缺少前因后果；
- 摄影机没有物理位置；
- 反转需要新世界状态；
- 负面约束没有针对真实失败。

修复时保留已经成功的脸、衣服、场景、光线、焦段和动作，只处理最低分的一层。
