# 成品提示词模板

这些模板规定控制顺序，不要求在最终正文中保留所有标题。删除空字段，不要留下互相冲突的选项。

## 参考图改编模板

```text
生成一部完整{时长}、{画幅}、{帧率}的{媒介}短片《{唯一片名}》。{原创气质、情绪与唯一高概念，不复制具体作品}。

【参考图职责与人物锁定】
参考图只控制{身份、年龄、脸、发型、体型、服装、物件或媒介}，保真程度为{严格/接近/仅作灵感}。全片保持{不可变字段}。忽略{文字、箭头、白底、多视图、摆拍姿势、旧构图、旧光线等污染项}。

【固定场景与物件】
全片只发生在{一个空间或连续相邻空间}。固定物件只有{关键物件与数量、形状、位置}。{角色左右位置、入口出口、轴线和光线方向}保持不变。

【摄影与灯光】
摄影机位于{物理位置、高度、距离、角度、前景}，使用{焦段及其功能}。全片主要{观察/跟随/反应/揭示/停稳}，只因{可见事件}而运动。主光来自{真实来源、方向与层次}。

【30秒连续动作】
0—7秒：{钩子、任务、开场物理状态}。
7—14秒：{同一异常规律第一次升级，主角进行简单验证}。
14—22秒：{阈值、接触、选择；保持重心、手、道具和地理连续}。
22—27秒：{用既有空间、物件、关系或规律完成反转}。
27—30秒：{停稳、微反应、动作回声或小笑点}。

【连续性与质感】
保持{身份、服装、物件数量、几何、位置、惯用手、光线、天气、不可逆状态}。{媒介原生的皮肤/线条/材质/布料/毛发/动作要求}。

【声音】
不要背景音乐、歌曲、旋律或节拍。只保留{与画面逐项同步的环境、动作、接触、机械、风雨、呼吸与空间声}。

【严格禁止】
禁止{针对本条任务的身份漂移、媒介漂移、动作物理、道具、空间、镜头、质感、文字品牌失败}。
```

## 无垫图文生视频模板

```text
《{唯一片名}》

完整{时长}，{画幅}，{帧率}，{明确媒介}，原创{类型与情绪}高概念短片。{用可执行特征翻译用户提到的系列或作品气质，不复制已有角色、剧情或独特画风}。

固定角色：{一个主角的年龄、身份、脸、发型、体型、服装、惯用手和目标}。全片只有{人数}。
固定场景：{单一空间、关键地理、固定物件及数量}。

摄影机位于{位置、高度、距离、轴线、前景}，{焦段及功能}。全片只进行{一种主要摄影机行为}。主光来自{场景内来源}，{高光、阴影和肤色/材质政策}。

0—7秒：{异常钩子与任务}。
7—14秒：{验证与升级}。
14—22秒：{选择与阈值}。
22—27秒：{反转}。
27—30秒：{余韵}。

保持{连续性锁与物理要求}。
声音只保留{同步声列表}，不要背景音乐。
禁止{定制失败项}。
```

无垫图模板中不得出现 `@Image`、图片、参考图、角色卡、附件或外部文件。

## 专业运动或双人连续动作附加块

```text
双方固定为同一人物、同一服装、同一惯用手和同一球场半区。只使用一颗球和固定规格器材。每一次来球必须由上一拍产生，完整交代击球点、过网方向、落点、对手回击和下一次移动。摄影机不跨越运动轴线；脚步、制动、重心转移、挥拍、接触、球体压缩、旋转、弹跳和落点符合真实专业技术与物理。
```

## 即梦音频固定块

每条即梦视频提示词末尾必须原样追加：

> 音频要求：不要背景音乐、配乐、歌曲、旋律或节拍，不要任何音乐性铺底；只保留与画面严格同步的环境音、动作音、机械声、风声、掠过声、碰撞声和空间转场音效。音效具有电影级空间层次，但不能形成旋律或音乐节奏。

## 修复差量模板

```text
可见症状：{一个失败}。
只修改：{一个主要层和一个变量}。
严格保留：{已批准的故事、身份、服装、道具、机位、焦段、灯光、媒介、地理和状态}。
修正：{可观察、可执行的指令}。
成功标准：{什么必须改善，同时哪些锁不得漂移}。
```

## 批量交付规则

- 每条有唯一片名。
- 每条独立重复完整规格与锁定信息。
- 每条使用不同核心机制或反转功能，不只是换颜色和地点。
- 不写“同上”“沿用前一条”或依赖另一条提示词。
- 用户要求“只交成品”时，不输出概念列表或制作说明。
