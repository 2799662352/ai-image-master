# Seedance 2.0 · 技术铁律手册

这是把分镜判断编译成可执行 Seedance 提示词的检查表；运行时能力和参数以本 app
实际工具为准，不把经验值写成模型保证。

## 一、模型基础事实

| 项 | 数值 / 规则 |
|---|---|
| 单次生成时长 | 4-15 秒 |
| 参考输入 | 图片最多 9 张 / 视频最多 3 段且总≤15s / 音频最多 3 个且总≤15s |
| 本 app 输出 | 480p / 720p / 1080p(默认 720p；1080p 仅满血 2.0) |
| 宽高比 | 16:9 / 9:16 / 4:3 / 3:4 / 1:1 / 21:9 |
| 重点语言 | 中文原生支持,不需要英文 |

## 二、黄金提示词公式(每个镜头都这么写)

```
素材职责 + 具体画面 + 动作链 + 景别/焦段/运镜 + 光影色温 + 风格 + 正向稳定目标
```

### 必填 8 维度

1. **素材职责**——用规范序号 `图片N / 视频N / 音频N` 精确指派
2. **主体**——是谁,在哪儿
3. **动作**——具体做什么(要写动作链,而非状态)
4. **景别**——特写 / 近景 / 中景 / 全景 / 大全
5. **运镜**——**只能写一个主运镜**(推 / 拉 / 摇 / 移 / 跟 / 环绕 / 固定之一)
6. **光影**——方向 + 色温 + 光比 + 关键光效
7. **风格**——LUT 名称 + 2-3 个美学关键词
8. **稳定目标 / 约束**——默认写正向目标；只有特定失败风险需要时才追加简短排除项

## 三、6 铁律(每一条都是血泪教训)

### 铁律 1 · 一镜一事

```
❌ 三个人在公园里野餐,一个弹吉他,一个拍照,一只狗跑来跑去
✅ 一位年轻女生在公园草地上弹吉他,微微低头看琴弦,阳光洒在侧脸上
```

多人多动作容易争夺注意力。优先拆成多段生成再剪辑拼接；一段围绕一个主动作，
多人镜用明确站位和交互关系。

### 铁律 2 · 慢胜快

AI 生成慢动作通常比快动作稳定。想要"奔跑",可先尝试"快步走"。想要"打架",
可拆成"一方缓慢出拳 + 对方明确后仰反馈"。

关键词偏好:
- ✅ 缓慢 / 轻轻 / 微微 / 流畅 / 细腻 / 稳定 / 克制 / 舒展 / 绵长
- ❌ 快速 / 迅速 / 剧烈 / 高速 / 突然(除非情绪转折点)/ 猛烈

英文对应:
- ✅ slow / smooth / subtle / gentle / gradual / cinematic / intimate
- ❌ fast / rapid / sudden / violent / extreme

"fast" 是 Seedance 2.0 最容易触发画质崩坏的单词。即使真的需要快,也用"节奏加快"而非"快速"。

### 铁律 3 · 运镜和主体动作分开写

```
❌ 镜头围绕跳舞的女孩旋转
✅ 女孩缓慢原地旋转,裙摆飞扬;镜头保持固定中景框
```

或者:
```
✅ 女孩静立不动,侧脸微仰;镜头从侧面缓慢环绕 180 度
```

把"谁动"和"镜头动"写成两件独立的事。两者同时动是 Seedance 画面抖动的最大来源。

### 铁律 4 · 光影是最高杠杆

光源方向、色温和光比是高杠杆信息，比笼统“高级电影感”更可执行。

如果提示词里只能加一句话,加光影。必填内容:
- **方向**——前侧光 / 侧逆光 / 顶光 / 底光 / 正逆光
- **色温**——具体到 K 数(2800K 钨丝,3600K 暖室内,5200K 自然日光,6500K 冷白)
- **光比**——1:2 平光 / 1:3 柔和 / 1:4 戏剧 / 1:6 强戏剧
- **关键光效**——rim light / bloom / halation / 眼神光 / 体积光 / 光斑

### 铁律 5 · @ 素材逐镜重标

Seedance 每个镜头的生成都是**独立的推理过程**,它不会"记住"前一镜。所以:

- 未在 prompt 指派素材职责 = 白上传
- 写完每镜提示词,逐一核对 `图片N / 视频N / 音频N` 编号和职责
- 多素材场景容易把"角色 A"标成"角色 B"或把图片编号搞错

最小闭环写法:

```
图片1 的女生作为主角,保持面部特征和服装不变;
图片2 作为场景背景参考色调;
视频1 作为运镜节奏参考;
[具体画面内容]
[光影+风格+稳定目标]
```

多板参考再补职责：

```text
文字提示词：prompt-primary，主导故事、构图、动作、顺序、时长与导演调度；
图片1 / 图片2：identity-hard，锁角色身份和妆造；
图片3：keyframe-strong，锁当前片段空间、构图与画质；
图片4 / 图片5：atmosphere-loose，只参考色彩/光线/材质/时代感/空间气质/视觉母题；
director-free：转场、微动作、运镜插值、节奏与粒子可补完。
```

总览板不作 `firstFrame`，不控制故事/构图/动作/顺序/时长，不复制边框、编号、
文字、表格或拼贴版式；使用时必须先写提示词主导前缀。精确跟随某格时先裁出并
清理成干净关键帧。

### 铁律 6 · 正向稳定目标优先

默认把排除式句子改成模型应实现的画面：

```
画面稳定，人物身份、服装与发型连续；面部和手部结构清晰自然；
动作接触、重心与遮挡关系可信；高光保留层次，材质自然。
```

仅在明确风险时追加短排除项，例如“保持无无意字幕”“不复制总览板文字/边框”；
不要挂一长串彼此无关的负面词稀释主任务。

## 四、把抽象情绪改写为可见表演

这是提示词工程经验，不是对奖励模型训练数据或内部能力的断言：相比只写“悲伤/
愤怒”，写呼吸、视线、肌肉张力和动作过程通常更可执行、更容易检查。

### 翻译表(这是硬核刚需)

| 抽象情绪 | 正确的生理翻译 |
|---|---|
| 很伤心 | 眼眶泛红,下唇微微咬紧,喉结滚动一下,视线下移 |
| 很紧张 | 指节在桌沿捏得发白,鼻尖渗出细汗,喉结缓慢上下 |
| 很愤怒 | 太阳穴青筋轻跳,鼻翼微张,牙关咬紧颌线绷出 |
| 很震惊 | 瞳孔瞬间放大,嘴唇微启,呼吸停滞一拍 |
| 很害羞 | 耳尖发红,睫毛连续颤动两下,视线偏向一侧 |
| 很疲惫 | 眼皮半垂,肩线下沉,呼吸变长 |
| 很迟疑 | 眉心微蹙,上齿轻咬下唇内侧,指尖无意识摩挲 |
| 很坚定 | 下颌微抬,呼吸匀长,眼神聚焦不游移 |
| 气氛暧昧 | 两人呼吸可见的轻颤,耳尖微红,视线交接后错开 |

### 情绪变化过程(而非静态)

```
❌ 她很伤心
✅ 她先是一怔,眼眶慢慢泛红,下唇颤了一下终于咬紧,眼泪没有落
```

“过程 > 状态”是写作原则：视频需要可见变化，静态情绪标签无法说明变化如何发生。

## 五、运镜词库(只选一个,不叠加)

### 8 大常用主运镜

| 运镜 | 中文写法 | 情绪效果 | 适用场景 |
|---|---|---|---|
| 推镜 Dolly In | 缓慢推镜 / 从远推近到特写 | 代入、情绪递进 | 开场、揭示 |
| 拉镜 Dolly Out | 缓慢拉远 / 从特写拉到全景 | 抽离、落幕、环境交代 | 结尾、转场 |
| 摇镜 Pan | 水平缓摇 / 从 A 摇到 B | 展示、指引 | 介绍场景 |
| 移镜 Truck | 横向平移 / 跟随侧移 | 伴随、节奏 | 人物行进 |
| 跟镜 Follow | 背后跟拍 / 侧面跟拍 | 代入、紧随 | 动作戏、追逐 |
| 环绕 Orbit | 缓慢环绕半圈 | 立体展示 | 人物定格、造型展示 |
| 升降 Crane | 镜头缓慢升起 / 下降 | 史诗感、压迫感 | 开场、结尾 |
| 固定 Static | 固定机位,画面稳定,只有人物微动 | 沉静、克制、文艺 | 对话、特写、文艺片 |

### 速度修饰(就加在主运镜前)

- **Smooth ~**(流畅)→ 高级感
- **Slow ~**(缓慢)→ 呼吸感
- **Subtle ~**(微妙)→ 细腻感
- **Cinematic ~**(电影感)→ 万能词
- **Intimate ~**(亲密)→ 人物特写专用
- **Dreamy ~**(梦幻)→ 回忆 / 梦境

### 不要写的运镜(翻车高发)

- ❌ 希区柯克变焦(Seedance 识别但实际效果不稳定)
- ❌ 穿越镜 / VR 镜 / 无人机 360(太复杂)
- ❌ 同一镜头"推 + 摇 + 环绕"(只能选一个)
- ❌ "手持抖动"(真的会抖成鬼畜)

## 六、对白处理(A/B 方案)

### 方案 A · 原生音频

在提示词里直接写:
```
人物说话"具体台词",语气低沉带颤抖,咬字清晰
```

原生口型适合短句；长对白更容易挤压表演与镜头预算，必要时转后期配音。

### 方案 B · 后期配音

提示词里不写台词,只写情绪 + 嘴部动作:
```
嘴唇微启,似在自言自语,视线下移
```

后期在剪映里配音。**长对白、标准配音、竖屏短剧必选 B**(Seedance 长台词容易"加速"变形)。

判断:
- 对白 < 8 字/镜 → A
- 对白 ≥ 8 字/镜 → B

## 七、相对镜头顺序写法

优先写相对镜头顺序，不用伪精确绝对秒数：

```
图片1 作为首帧,参考 视频1 的运镜。
镜头1:从全景缓慢推近,逆光剪影,青橙调色
镜头2:切到场景全貌,体积光穿过窗格,电影胶片质感
镜头3:拉远到鸟瞰视角,以前景遮挡衔接并在末态停稳
全片保持 Cinematic 风格,高对比度,浅景深,15% 胶片颗粒。
```

每个镜头只保留一个主动作和一个主运镜；总动作量必须能在 4–15s 内完成。

## 八、画质关键词组(电影写实短剧专用)

**加分词(每镜必带 3-5 个):**
```
电影质感 / cinematic,高清且细节丰富,浅景深,胶片颗粒 X%,
色分级 ARRI Alexa 自然电影色,ARRI LUT,
面部清晰,皮肤毛孔级细节,光影立体
```

**避坑词(绝对不写):**
```
超清超锐利 / ultra-sharp → 容易变塑料感
HDR / 极致对比 → 画面会硬
8K / 原生 4K → 与本 app 480p/720p/1080p 输出不符；需要 4K 交付时后期上采
超饱和 / vibrant → AI 味重灾区
完美 / perfect → 含糊无效
```

## 九、常见翻车场景与排查

| 翻车现象 | 最可能的原因 | 对治 |
|---|---|---|
| 人物换脸 | @ 引用缺失或每镜没重标 | 每镜 @ 定妆图 + "保持面部特征" |
| 手部畸形 | 动作/接触关系不清 | 明确手指接触点、握持方式与重心，必要时简化动作 |
| 画面整体抖动 | 运镜 + 主体动作都快 | 只保留一个"快",或都改成"缓慢" |
| 风格每镜不一致 | 没锁 LUT 参数 | 每镜重复核心风格 3 词 |
| 场景背景乱变 | 场景图没 @ 或多段独立生成 | @ 场景参考图 + "背景保持一致" |
| 动作不连贯 | 没写动作链 | 拆成"先...然后...接着..."三步 |
| 情绪平淡 | 用了抽象情绪词 | 翻译成生理反应 |
| 台词听起来假 | 超过 8 字但用方案 A | 切到方案 B 后期配音 |
| AI 味浓 | 用了"完美/超清/极致"等魔咒词 | 删掉,换"自然 / 真实 / 电影感" |

## 十、Seedance 2.0 独有能力(要利用)

1. **多素材融合**——一次可喂 9 图 + 3 视频 + 3 音频,合理分配
2. **视频延长**——"将 视频1 延长 5s,角色从微笑直接过渡到转身,动作连贯"
3. **视频融合**——"在 视频1 和 视频2 之间加过渡,内容:角色停顿思考再看向镜头,动作自然衔接,无跳切" ——让两段素材在情绪上连成一气
4. **首尾帧控制**——可指定 `图片1` 为首帧、`图片2` 为尾帧,中间运动过程交给模型补全(适合做"变身 / 转场 / 时间流逝")
5. **风格与身份解耦**——"参考 `视频1` 的运镜节奏与调色,但人物用 `图片1`",把"怎么拍"和"拍谁"拆开,避免风格参考把人脸也带过去

## 十一、结语:把十条铁律内化成肌肉记忆

一镜一事 · 慢胜快 · 运镜主体分离 · 光影优先 · 逐镜标素材职责 · 正向稳定目标 ·
情绪生理化 · 运镜只选一个 · 相对镜头顺序 · 画质词可信。

每一条都对应常见失败模式，但不是成功率保证。写完每镜提示词，回到本手册第三节
核对 6 条，再交给 Seedance。
