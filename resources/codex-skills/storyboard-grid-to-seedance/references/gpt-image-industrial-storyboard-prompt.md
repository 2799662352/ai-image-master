# GPT Image 故事板生成提示词三（首选）

## 使用方式

把以下四类输入填到模板最前：

```text
[剧情]：
[角色参考]：
[场景参考]：
[氛围参考]：
```

本模板生成**工业化电影故事板工作台**。它可以作为导演评审资产，也可以作为视频
生成的 `atmosphere-loose` 氛围参考；它不是视频身份锚点或 `firstFrame`。

## 先消除三组歧义

1. **画幅**：整张故事板工作台是 21:9；如果成片是竖屏，分镜格内部画面用 9:16。
2. **文字**：“无字幕/无文字”只约束每个镜头画面内部，不禁止工作台的项目栏、
   镜头编号、时长、摄影/灯光注释等制作文字。
3. **角色多视图**：板内正/侧/背/面部特写默认是导演沟通模块；用户也可以明确
   选择干净三视图/四视图/多视图角色板作为视频身份锚点。拿不准时先询问，不自动
   固定为大头照+全身照，也不自动把氛围板中的角色区当主锚。

## 首选提示词

```text
[剧情 + 角色参考 + 场景参考 + 氛围参考]

你是一名专业影视预制作视觉规划师、院线广告导演。请根据输入制作一张工业化标准
电影故事板工作台。

[总体输出]
- 整张画布：21:9 横版；超高清、8K-detail target、写实电影商业质感。
- 版式：工业模块化网格、扁平化导演工作台 UI、极简浅灰/黑白背景、
  黑色细实线分割区块、严格对齐、清晰留白。
- 视觉语言：黑白线稿为基础，少量真实电影缩略图质感。
- 方向标记：红色箭头=角色运动方向；蓝色箭头=镜头运动方向；
  绿色箭头=主光/补光/轮廓光方向。
- 若模型不能原生输出目标像素，先保证构图与内容正确，再后期上采到 8K 交付尺寸。

[项目与镜头规划]
- 适配一支 15 秒短视频；镜头总量按剧情和动作负载决定，不平均切分。
- 若用户指定镜头数，严格生成固定数量与连续编号；否则自动规划足够且不过载的镜头数。
- 若目标成片为竖屏，每个镜头格内部使用 9:16；整张工作台仍保持 21:9。
- 每镜只承载一个主要动作链和一个主要运镜。
- 相邻镜头在景别、角度、高度、构图或镜头语法上至少有一项明显变化，
  避免连续两个几乎相同的镜头。

[镜头语言候选库]
- 景别：大全景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 动作特写。
- 角度：正面 / 侧面 / 斜侧 45° / 背影 / 过肩 / 内反打 / 外反打 / 广角。
- 高度：平拍 / 仰拍 / 俯拍 / 鸟瞰。
- 主运镜：固定 / 推 / 拉 / 摇 / 移 / 环绕 / 手持跟拍 / 上升 / 下降 /
  希区柯克变焦；每镜只选一个，复杂技法仅在叙事需要且可执行时使用。
- 构图：对称 / 三分线 / 荷兰角；明确前景、中景、远景。
- 节奏：一镜到底 / 长镜头 / 快切；按剧情选择，不在同一镜里混写互斥节奏。
- 镜头语法：主观 POV / 过肩 / 反应 / 插入 / 空镜 / 中性轴线重置镜头。

[连续性硬规则]
- 遵守 180° 轴线；必须越轴时，先加入看得见的中性机位、运动过轴或空间重建镜头。
- 全程角色站位、视线、进出画方向、屏幕运动方向清楚且连续。
- 角色、场景、服装、道具、时间状态和光源方向高度统一。
- 镜头画面内部不得出现摄影机、灯架、工作人员或无意穿帮。
- 每个镜头格内部无字幕、无标题、无对白文字、无水印、无 Logo；
  制作文字只放在镜头格外的表格与注释区域。
- 声音方案默认只有环境声与动作音效，不使用 BGM；用户另有要求时再覆盖。
- 信息不足时按剧情、时代、空间和角色动机合理补全，并在底部备注区披露补全项。

[灯光硬规则]
- 每镜明确角色面部主光、补光、轮廓光和环境光方向，脸部有专业灯光师塑形，
  保留环境氛围色调，不黑脸、不平光塑料感。
- 人物面部使用柔和主光 + 前置反射补光，肤色自然均匀，保留立体层次。
- 前景可使用灯光、烛光、射灯等 motivated practical light 打在面部。
- 背景可使用窗外、大门或云层的冷白/暖色光、体积光或丁达尔光，
  漫射到墙地并形成角色轮廓光。
- 绿色箭头必须与图中实际光影方向一致。

[必须包含的五个模块]
1. 顶部项目信息栏：
   项目标题、影片类型、成片时长、总镜头数、角色数量、场景数量、整体基调、
   拍摄限制。工业无衬线字体、信息层级清晰。
2. 角色参考区：
   同一角色的正面、侧面、背面、面部特写；展示服装、发型、身材、气质，
   浅灰背景、比例统一、五官稳定。此区仅作工作台展示，不替代独立身份锚点。
3. 场景设计区：
   主场景全景、关键道具特写、空间关系、平面俯视示意图、白色高亮机位线、
   蓝色镜头运动虚线轨迹、红色角色调度箭头、绿色灯光方向箭头。
4. 分镜表格区：
   每格独立编号，包含镜头时长、镜头语言（景别/角度/高度/运镜/构图/节奏/
   镜头语法）、画面内容、角色动作、人物情绪、对白/旁白字段、光影氛围。
   镜头画面内部保持干净，不把这些字段烧进画面。
5. 底部备注说明区：
   灯光方案、整体情绪、风格说明、环境音效、摄影笔记、情绪关键词、
   轴线/连续性风险和信息补全项。

[文字与交付]
- 先尽力生成清楚、对齐、无乱码的项目栏与制作注释。
- 关键生产文字、数字、镜头编号和尺寸必须在第二阶段用本地确定性排版复核/替换；
  图像模型文字不得作为唯一生产真源。
- 最终无 JSON、代码字符泄漏、随机 watermark 或无关品牌标识。
```

## 视频交接必带前缀

如果这张故事板被加入 Seedance `referenceImages`，视频提示词必须先写：

```text
[提示词主导 / 氛围板低约束]
@图片N 是故事板/多宫格氛围参考，仅提取色彩、光线、材质、时代感、空间气质和
视觉母题。最终视频的故事因果、镜头构图、动作、顺序、时长与导演调度以文字
提示词为主；不要求逐格一致，不复制网格布局、箭头、边框、编号、文字或工作台 UI。
角色身份以用户选定的 identity-hard 资产为准（可为独立大头照+全身照、
三视图/四视图/多视图角色板或其它确认资产）；导演可自由重构机位、转场、微动作、
运镜插值与特效，同时保持身份连续、动作自然、物理反馈可信、画面稳定、无无意字幕。
```

用户明确要求精确复刻某一格时，先裁出该格，去掉箭头/边框/文字并重绘为干净
关键帧，再把它从 `atmosphere-loose` 升为 `keyframe-strong`。
