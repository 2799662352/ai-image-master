# 12 项内容覆盖参考（形式自由）

本参考吸收实测模板中“创作意图 → 优先级 → 结构 → 导演参考 → 技术与声音 →
Dense Caption”的稳定顺序。先完成上游素材映射和镜头规划，再逐项检查以下
12 项内容是否有有效落点。**方括号标题、顺序与空行都不是硬格式**：可改成自然
小节名、内联标签或连续散文；不要为了套模板破坏提示词连贯性。

## 《完美1.md》学习参考对照

本文件明确把用户提供的《完美1.md》作为**学习参考**，是面向 Seedance 的泛化
适配稿，不是原文镜像，也不依赖用户机器上的 Q 盘路径。

- **吸收**：演出核心与情感曲线、可调整优先级、空间关系、导演意图与动态参考、
  表演/运动、视觉、声音、技术规格、交付前检查以及最终 Dense Caption。
- **不照搬**：固定 10 秒、把 99%/70% 等权重冒充 API 参数、固定导演/作画师/
  作品名单、特定角色和座舱剧情、每帧都必须运动等场景专属硬规则。
- **改写原则**：保留“意图统领技法”的方法，把具体人名与作品改为可核实、
  可替换参考；上游收束权重作为可调整的**语义方向**保留，并展开为可执行职责。

## 使用前选择

```text
媒介 profile：真人 | 2D 动画 | 3D 动画（可多选、可组合）
电影检索意图：[无 / 电影感 / 电影级 / 指定类型；用于检索技法，不是硬分类]
语言：
- 日式 2D：用户要求或面向日本受众时优先日语正文
- 真人 / 3D：需要精确技术词时优先中英混合
- 台词：沿用用户提供或素材中的语言；除非用户要求，否则不擅自翻译
内容结构：路径 A 使用连续任务正文；路径 B 覆盖总体设定、镜头流程、风格与约束
三组语义，但可合并、重排或融入散文，不强制三段
```

不适用的内容可简写“无对白”“沿用源视频”或“沿用已核实参考”。12 项不能漏，
但不要求逐项显示标题。

## 语言终检

- 日式 2D 在用户要求或面向日本受众时，正文是否为自然日语而非逐字机翻？
- 真人、3D 需要技术表达时，是否合理使用中英混合而非重复双译？
- 台词是否沿用用户指定或素材原有语言，且没有未经要求擅自翻译？
- 语言切换后，素材 token、12 项内容、镜头规划和用户硬约束是否完整？
- 是否把本文件的方括号名称误当成必须原样输出的模板？若是，改回更自然的表达。
