# 12 字段完整输出模板

此模板吸收实测模板中“创作意图 → 权重 → 结构 → 导演参考 → 技术与声音 →
Dense Caption”的稳定顺序。先完成上游素材映射和路径 A/B 内容，再把同一内容
填入以下 12 个字段。

## 《完美1.md》学习参考对照

本文件明确把用户提供的《完美1.md》作为**学习参考**，是面向 Seedance 的泛化
适配稿，不是原文镜像，也不依赖用户机器上的 Q 盘路径。

- **吸收**：演出核心与情感曲线、可调整权重、空间关系、导演意图与动态参考、
  表演/运动、视觉、声音、技术规格、交付前检查以及最终 Dense Caption。
- **不照搬**：固定 10 秒、固定 99%/70% 等权重、固定导演/作画师/作品名单、
  特定角色和座舱剧情、分镜权重必须低于 1%、每帧都必须运动等场景专属硬规则。
- **改写原则**：保留结构和“意图统领技法”的方法，把具体人名与作品改为可核实、
  可替换参考；把绝对比例改为随用户任务变化的语义重心。

## 使用前选择

```text
媒介 profile：真人 | 2D 动画 | 3D 动画（可多选、可组合）
电影检索意图：[无 / 电影感 / 电影级 / 指定类型；用于检索技法，不是硬分类]
语言：
- 日式 2D：用户要求或面向日本受众时优先日语正文
- 真人 / 3D：需要精确技术词时优先中英混合
- 台词：沿用用户提供或素材中的语言；除非用户要求，否则不擅自翻译
内容路径：A 简单连续任务句 | B 总体设定 + 分镜 + 风格约束
```

不适用的内容写“无对白”“无新增作品参考”或“沿用源视频”，不得删字段。

## 可填充成品

```text
[任务与创作意图]

媒介 profile：[真人 / 2D 动画 / 3D 动画；可组合]
电影检索意图：[如适用，写要调查的摄影/调度/灯光/声音/叙事方向]
核心意图：[观众首先看到什么，最后感受到或意识到什么]

[创作重心与自由度]
语义权重：[按用户意图动态分配；不是模型参数]
不可改：[用户资产、身份、构图、动作或风格硬约束]
可自由调整：[不影响核心意图的摄影、节奏、环境细节]

[空间结构与主体绑定]
环境：[时间、天气、场景、前中后景、尺度]
主体：[<主体N>@图片N / @视频N / @音频N + 稳定特征]

[动作流程与镜头设计]

[导演与参考系]
意图：[演出逻辑 / 节奏 / 空间调度 / 情感 / 张力 / 摄影机 / 声画]
已核实参考：[可替换的人名/作品 + 真实职务 + 本任务采用的具体技法]
或中性技法：[未检索时只写可执行技术，不虚构归属]

[表演或运动系统]
真人：[动机、blocking、呼吸、视线、微表情、重心与接触]

3D：[weight shift、rigging、contact、inertia、secondary motion、deformation]

空间层次：[透视、景深、遮挡、轮廓和背景处理]

[声音设计]
台词：[说话者 + {用户给定语言的台词} + 语气 + 声源位置 + 口型/表情同步]

音乐：[进入/退出点、节奏作用、对白期间让位]
无对白时：[明确写“无对白”及声音如何推进]

[时空一致性]
锁定：[身份、服装/几何、材质/配色、道具、背景、光源、轴线]
动作连续：[方向、速度、轨迹、接触、惯性、遮挡和收势]
类别边界：[2D 可控演出性形变；真人/3D 保持可信几何]

[技术规格与约束]
规格：[时长、画幅、分辨率、风格锚定]
默认约束：[高清稳定、无无意字幕、无水印、无 Logo]
风险约束：[多人防重复 / 人脸手部 / 材质贴图 / 编辑保持项]

[多粒度对齐检查]
粗粒度：[整体场景、任务和情感曲线是否一致]
中粒度：[每个角色/物体的动作、关系、镜头落点是否明确]
细粒度：[台词-口型-表情、SE-动作、颜色/道具/材质是否对应]

[综合 Dense Caption]
[用当前类别对应语言写一段不重复总结：主体 + 空间 + 动作因果 + 情感曲线 +
摄影/动画/渲染方法 + 用户给定语言的台词与声音 + 一致性 + 交付目标]
```

## 语言终检

- 日式 2D 在用户要求或面向日本受众时，正文是否为自然日语而非逐字机翻？
- 真人、3D 需要技术表达时，是否合理使用中英混合而非重复双译？
- 台词是否沿用用户指定或素材原有语言，且没有未经要求擅自翻译？
- 语言切换后，素材 token、12 个字段、路径 A/B 和用户硬约束是否完整？
