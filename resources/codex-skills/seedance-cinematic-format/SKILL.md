# Seedance Cinematic Prompt Format

<!-- skill-budget: fast -->

## 角色与边界

角色：**纯知识辅助模块**，只提供格式骨架、类别差异与完整性检查。

- 上游已经完成任务分类、素材编号、主体绑定和路径 A/B 判定。
- 本模块不负责任务编排，不调用其它 skill、生成工具或 QA 工具。
- 本模块不能取代上游的一段式/三段论内容，只负责把同一内容装入稳定的结构。
- Sora 资料只贡献“字段组织方法”；成品继续使用 Seedance 的素材语法、任务语义与约束。

## 不可删减的通用骨架

**每次视频提示词都保留以下 12 个字段，字段可写得很短，但不可删除。**
允许在任意字段下增补子项；不允许用新增字段替换既有字段。
确实不适用时写“无对白”“沿用源视频摄影/声音”“不新增作品参考”，不要为了
填满字段虚构要求。

```text
[任务与创作意图]
任务类型 / 类别 / 这段视频最需要传达的一件事。

[创作重心与自由度]
列出本次各维度的语义权重与可自由调整范围；百分比只是提示词强调度，
不是模型参数。用户明确给出比例时优先使用用户比例。

[空间结构与主体绑定]
场景、时间、天气、主体位置关系，以及 <主体N>@图片N / @视频N / @音频N 绑定。

[动作流程与镜头设计]
按因果顺序写动作、镜头顺序、单镜主运镜、景别与焦点变化。

[导演与参考系]
写导演意图、节奏、空间调度、情感表达、张力、摄影和声画联动。
导演名与参考作品不是固定清单：可按用户意图替换；未核实时写技法特征，
不要凭记忆杜撰人名、职务或代表作。

[表演或运动系统]
真人写动机/调度/微表情；2D 写关键姿势/动画物理/中间帧；3D 写质量感/
惯性/绑定变形。三者都要写动作起因、过程、反馈与收势。

[视觉设计]
色彩、光源逻辑、空间层次、材质/线条、摄影或渲染观感。

[声音设计]
台词、环境声、动作音效、音乐进入/退出点、声画同步和对白可懂度。

[时空一致性]
主体身份、服装/材质、背景、光源方向、屏幕轴线、动作衔接、几何与深度连续。

[技术规格与约束]
时长、画幅、分辨率、风格锚定、画质/稳定/字幕/水印/Logo/多人防重复等约束。

[多粒度对齐检查]
粗粒度检查整体场景与情感曲线；中粒度检查每个角色/物体的动作关系；
细粒度检查台词-口型-表情、音效-动作、色彩/道具等关键细节是否落到画面。

[综合 Dense Caption]
用一段密集但不重复的总结串起：主体 + 空间 + 动作因果 + 情感曲线 +
摄影/动画/渲染方法 + 声音 + 一致性目标。
```

## 媒介 Profile 选择

真人、2D 动画、3D 动画是可组合的**媒介 profile**，不是互斥类别。先读最接近
任务的一份；混合媒介确有需要时再叠加另一份相关段落，不要机械堆满全部规则：

| Profile | 识别信号 | 读取 |
|---|---|---|
| 真人 | 真人表演、实拍、短剧、广告、纪录、摄影机/镜头语言 | [真人增量](references/live-action-film.md) |
| 2D 动画 | 日漫、国漫 2D、手绘、赛璐璐、逐帧、作画 | [2D 动画增量](references/2d-animation-film.md) |
| 3D 动画 | CG、3D 国漫、PBR、角色绑定、三维渲染、虚拟制片 | [3D 动画增量](references/3d-animation-film.md) |

“电影 / 电影感 / 电影级”是**检索与创作意图词**：它提示上游调查镜头、调度、
灯光、声音、剪辑或叙事方法，但不是独立 profile。混合媒介允许组合，例如
“真人表演 + 2D 涂鸦叠加”或“2D 角色 + 3D 场景”；只在规则冲突时确定主体媒介，
避免把 2D 演出性形变与真人/3D 几何约束互相覆盖。

## 语言建议

- **日式 2D 动画**：面向日本受众或用户明确要求时优先用自然日语正文。
- **真人、3D 动画**：需要精确技术词时优先中文 + 英语混合；中文负责叙事、
  表演、主体绑定和约束，英语负责摄影、灯光、材质、绑定和渲染。
- 这些只是默认建议，不是硬约束；用户明确指定语言时始终服从用户。
- **台词沿用用户提供或素材中的语言**。中文保持中文，日文保持日文；未指定时
  按请求文本、角色设定、源音频与目标受众判断，除非用户要求，否则不擅自翻译。
- 素材 token 原样保留，同一信息不做重复双译；语言变化不能删掉 12 个字段。

需要直接填充时读取[完整输出模板](references/prompt-output-template.md)。模板只提供
容器和语言占位，不能替代上游已经完成的素材映射、路径 A/B 内容或用户原话。

## 动态参考与权重

1. 先提炼用户真正的创作意图，再决定导演、作品和技法参考。
2. 用户指定导演/作品时，保留其意图，但只写可核实的技法特征。
3. 用户未指定时，允许完全不写人名，用“长焦压缩 + 克制调度 + 环境声主导”
   这类物理可执行描述替代。
4. 权重必须能随任务调整；字段本身不能随权重降低而消失。
5. 参考与用户资产冲突时，用户资产、身份锚点和明确构图优先。

只有用户点名真实人员/作品、要求专业复刻或引用准确性会影响结果时，才由上游
按[分类调查方法](references/research-methods.md)核实。普通任务直接写可执行技法，
不为填 `[导演与参考系]` 强制联网，也不把社区归因当成官方事实。

## 从 Sora 规则吸收什么、不照搬什么

吸收 `.cursor/rules` 与用户实测模板中稳定有效的结构思想：

- 四视角 structured caption：空间结构、动作流程、情感方向、技术规格。
- 粗/中/细三层文本-画面对齐。
- 导演描述七槽位与动态参考替换。
- 时空一致性、声音同步、类别化运动系统和最终 Dense Caption。

不照搬模型专属或成本失控的规则：

- 不对任何媒介固定语言；日式 2D 的日语、真人/3D 的中英混合都只是默认建议。
- 不固定 10 秒或 70/20/8/1 权重。
- 不强塞固定导演、作画师或作品名单；真实归属需要核实。
- 不要求每个简单任务都做多站点检索；只有用户点名真实人员/作品、要求考据
  或专业复刻时才检索。
- 不把“每帧必须高运动”或屏幕变化百分比当硬指标；运动强度由叙事意图决定。
- 不把 Sora 专属能力、参数或结论冒充成 Seedance 能力。

## 完整性自检

交付前逐项检查：

- 12 个通用字段均存在；允许“无对白 / 无音乐”，但不能直接省略声音字段。
- 原有素材编号、主体标签、任务句式和路径 A/B 信息均未丢失。
- 已选择与任务有关的媒介 profile；混合使用时没有互相冲突。
- 角色/物体在粗、中、细三个粒度都有可见落点。
- 动作有起因、连续过程、环境反馈和收势，不是形容词堆叠。
- 导演与参考作品可替换且服务于意图，不把固定名单当质量咒语。
- 2D 的演出性变形与真人/3D 的几何连续性只在对应主体上生效，没有互相污染。
