# Seedance 2.0 相对节拍 + 多模态参考绑定 + 案例库

> 来源:忠实移植自 updream `jimeng-prompt-pro`(Seedance 2.0/即梦 提示词助手)。
> 用途:把剧本/对白/参考图转成 Seedance 2.0 分镜提示词时,按内容密度规划相对节拍、
> 正确绑定 @素材职责并参照案例。本文件只产出文本提示词,不调用生成工具。

## 一、相对节拍规划(最高优先级)

**禁止平均切分**。下表只用于内部判断动作/台词是否塞得下；最终提示词使用
“镜头1/发展段/高潮段/收束段”等相对顺序，不输出伪精确时间码。

| 场景类型 | 语速参考 | 时长分配 |
|---------|---------|---------|
| 普通对白 | 4–5 字/秒 | 按字数计算 |
| 快语速台词 | 6–7 字/秒 | 按字数计算 |
| 沉默/愣住/尴尬 | — | 1–1.5 秒静止 |
| 情绪转折点 | — | 0.5–1 秒过渡 |

- 可用 **5 字/秒** 粗估对白负载；38 字约需 7.6 秒，只作为是否拆镜的判断。
- 总时长由用户或上游确定为 4–15s；动作/台词过载就拆 clip，不强塞。
- 校验：相对节拍有完整因果、总动作量能在目标时长内完成。

## 二、参考图绑定规则（规范形式 `图片N / 视频N / 音频N`）

- 用户上传第 1 张 → `图片1`（按素材职责决定是否为首帧）
- 第 2 张 → `图片2`（角色参考）
- 第 3 张 → `图片3`（场景参考）
- 提示词中明确写出归属：`图片1 中的叶良辰（身份参考 图片2）`

## 三、物理动作替代抽象词

❌ 他很生气 / 她感到尴尬 / 气氛紧张
✅ 瞳孔收缩 / 狐耳垂下 / 嘴角漏出一丝玩味的笑容 / 身体不自觉后退 / 指尖微颤 / 眉间一道细纹骤然拧紧

> 与本 skill 正文及 `storyboard-video-prompt-optimization` 一致:用可见的物理反馈承载情绪。

## 四、镜头语言三要素(每段必含)

1. **运镜**:固定 / 缓慢推近(Dolly In)/ 平稳横移 / 面部特写 / 全景切近景 / 希区柯克变焦
2. **主体状态**:位置变化 / 神情演变(物理动作描述)
3. **环境氛围**:粒子特效 / 访谈灯光 / 修仙气焰 / 星空背景 / 背景虚化程度

## 五、多模态输入处理(最多 12 文件)

Seedance 2.0 支持图片/视频/音频混合输入。表达方式:

| 输入类型 | 提示词表达 |
|---------|-----------|
| 参考图(首帧) | `图片1 作为首帧` |
| 参考图(角色) | `图片2 参考角色形象` |
| 故事板/多宫格/美术设定板 | `图片N 是 atmosphere-loose，只参考色彩/光线/材质/时代感/空间气质/视觉母题；故事/构图/动作/顺序/时长以提示词为主` |
| 参考视频(运镜) | `视频1 参考运镜效果` |
| 参考视频(动作) | `视频1 参考打斗动作` |
| 参考音频(BGM) | `音频1 用于背景配乐` |
| 视频延长 | `将 视频1 延长 5s` + 生成时长选 5s |

> **入口选择**:多模态输入用**全能参考**入口;仅「干净首帧 + 提示词」可用
> **首尾帧**入口。总览板永远不是首帧；使用故事板/多宫格/美术设定板时，
> prompt-primary / atmosphere-loose 前缀必须放在正文最前。

## 六、输出结构

```
[一句话总览 + 素材职责 + 总体风格说明]。

镜头1 / 开场段:[第一段]
镜头2 / 发展段:[第二段]
镜头3 / 收束段:[第三段]
…

【多模态参考说明】(有视频/音频输入时补)
图片N / 视频N / 音频N 的用途说明

【画质约束】
电影感画质、无字幕、无水印、角色面部一致性、专业补光

【Seedance 2.0 操作提示】
建议入口(全能参考/首尾帧)及 @素材 调用方式
```

## 七、工作流程

```
Step 1 解析输入:统计参考图数量+识别角色/场景图;提取台词逐句统计字数;确认总时长
Step 2 节拍规划:按对白/动作密度判断是否拆 clip,内部估时,输出相对镜头顺序
Step 3 构建提示词:总览+素材职责+风格 → 镜头1/2/3 + 三要素 → 画质约束
Step 4 输出:纯文本可直接复制;附「操作提示」(入口 + @素材 方式)
```

## 八、案例配方

- **反转剧情**:镜头1 古风特写绣花(图片1)→ 镜头2 拉远露出摄影机/绿幕、
  BGM 戛然 → 镜头3 全景现代片场,导演喊卡,字幕揭示。
- **视频换人**:`将 视频1 中的女生替换为 图片1 的男生`,保留原运镜/动作节奏/构图/光影,人物边缘真实融合,不要换脸痕迹/跳变。
- **动作+运镜复刻**:主体 图片1,完全参考 视频1 的动作/节奏/推拉摇移/切换;补环境(舞台灯光/烟雾/LED)。
- **产品广告**:图片1 产品主体 + 图片2 材质 + 视频1 商业运镜；开场柔光浮现
  轮廓 → 发展段切材质特写 → 高潮段展示使用反馈 → 收束段正面英雄定格。

## 严格禁令
- ❌ 遗漏任一台词;❌ 抽象情绪词代替物理动作;❌ 出现水印/Logo/字幕描述(除非剧情要求字幕);❌ 本文件阶段调用任何生成工具(只产文本)。
