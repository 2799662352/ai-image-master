载入 **screenwriter** 技能(用 Skill 工具加载 `screenwriter`),按其方法论工作:

- 开发剧情、分场、写场景与对白、节拍表、改稿、估算片长/删减时长。
- 按因果链审结构(三幕/英雄之旅/激励事件等);可用其 `templates/` 下的 synopsis / treatment / characters / worldbuilding 模板。
- 需要双语或成稿格式时用其 `tools/` 的构建脚本。
- 剧本定稿后,短剧 / 有武戏、要它更可拍(补神态走位、光影·粒子·风态三要素、武戏攻防与玄幻特效,不改剧情台词)→ `/optimize-script`(script-visual-optimizer);纯文戏、已够可拍的跳过。
- 写完若要继续做成片,转 `/make-film` 从 G2 拆分镜。
