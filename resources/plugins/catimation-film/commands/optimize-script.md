载入 **script-visual-optimizer** 技能(用 Skill 工具加载 `script-visual-optimizer`),按其步骤工作:

- 先盘点六类输入(大纲、角色小传、单集剧情、场景、角色、道具资产),缺的不编;只在影响核心结果时合并问一次。
- 核心底线不动:剧情主线、人物关系、人设、所有原台词 / OS / 内心独白原文、武打胜负与实力设定。拆短句不改字,补对方反应只补非语言反应。
- 有武戏或用户要对标爆款时才做参考拆解,作品名必须核实;纯文戏跳过。
- 文戏补神态、微表情、站位走位(四个方向词)与每场景的光影 / 空气粒子 / 风态三要素;武戏补五段发力、环境联动、真实受创;玄幻特效与光影粒子融合。
- 输出按时间顺叙、连续成段、不含任何运镜 / 景别术语的文字脚本,末尾最多两条附注;提交前过一遍它的自检清单。
- 改完若要继续做成片,转 `/make-film` 从 G2 拆分镜;单集直接出片走 catimation-video 入口(镜头语言在那一步补)。
