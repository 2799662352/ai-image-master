# 提示词结构 / Prompt Patterns

每条 Seedance 提示词按同一顺序走。逐段命中,不跳、不换序。

## 段落顺序

1. **句柄声明**(`@图片1`、`<主体1>@图片1` …)
2. **全局警告**(`⚠️空间布局`、`⚠️对白规则`、`⚠️本视频严格只有N个镜头`)
3. **分镜块**(`【镜头1】【镜头2】…`)或单镜块
4. **风格块**(`风格:…`,选哪套见 `style-presets.md`)
5. **环境活动**(`环境活动:…`)
6. **收尾**(时长 + 画幅,取自本次已确认的规格)

## 1. 句柄声明

每条提示词开头声明自己的句柄。**句柄按提示词重新编号**——不是按场,是按提示词,
因为同一场里不同提示词的素材子集可能不同。

本 app 的写法:`@图片N` / `@视频N` / `@音频N` 按上传顺序编号,从 1 开始。多主体
或需要跨句复用时,先定义 `<主体N>@图片N`,之后全程用 `<主体N>` 指代。

```
<主体1>@图片1(Roko)— 混血亚裔白,深色中长湿发贴额碎刘海,发梢滴水,淡小胡,
鼻梁红创可贴微潮,左颊痣,黑紧身 T 恤肩部和上背湿透颜色加深贴身,军绿腰带,
黑工装裤大腿和裤脚湿痕,黑靴湿润,红手套微潮,腰间战术包,右腰挂红色小泰迪熊挂件,
左前臂纹身,面部薄水雾。
@图片2(Apartment)— 三视图参考:上图=客厅全景向走廊方向…
@图片3(PolaroidPhoto)— 一张拍立得横版照片 11cm×8.5cm——自拍合照…
```

规则:

- **严禁裸写 `asset://assetId` 或 `[asset-xxx]` 到动作描述里。** 底层模型关联不了
  无语义 ID,必须经 `@图片N` / `<主体N>` 桥接。
- 角色句柄写全身高、体型、发型、面部特征、从头到脚的服装、身上的道具。
- **跨场的状态变化要显式写**(`湿发贴额`、`溅血渍`、`面部薄水雾`)——模型不会记得
  上一场淋过雨。
- 地点句柄要描述参考图的版式;多视图要说清哪张是哪张(`上图=`、`下图=`、`中图=`)。
- 道具句柄带确切尺寸(`11cm×8.5cm`)、道具上的文字原文、颜色 / 材质。
- 只用于取姿势角度、不参与画面生成的参考图,要加明确警告:

```
@图片7 — ❌NOT A VIDEO FRAME❌ 此图仅用于提取 <主体1> 的身体姿势角度数据。
⚠️@图片7 是静态姿势参考——禁止将 @图片7 渲染 / 复制 / 再现为视频的任何一帧。
```

- 裸用 `@图片N` 紧接动词或方位词容易触发数字粘连歧义(`@图片1跑向…`),改用
  `<主体1>@图片1` 或在后面补名词隔断(`@图片1 中的女子`)。

## 2. 全局警告(放在分镜块之前)

```
⚠️空间布局 / 人物位置:[镜像已认可的俯视图,见 spatial-blocking.md]
⚠️对白规则:一句台词=一个镜头——每个角色的台词严格只出现在该角色的特写镜头内。
⚠️本视频严格只有N个镜头——禁止添加额外镜头。
```

最后那条镜头数声明是压制模型自作主张加切的**唯一有效手段**,多镜提示词必写。

## 3. 分镜块

一条提示词内含多个切时,每个切是一个 `【镜头N】` 块,内部结构固定:

```
【镜头1】
机位:35mm 广角,全景 wide shot。⚠️持续时间⚠️严格约 0.3–0.5 秒
(split-second flash establishing shot)。
背景:[地点细节]。
动作:[逐步]。
⚠️0.3–0.5 秒后⚠️立刻硬切(hard cut)到镜头 2——无过渡、无淡出、无停留。

【镜头2】(紧接镜头1硬切而来)
机位:⚠️85mm 长焦,⚠️F1.4 极浅景深,⚠️<主体1> 侧面紧凑特写。
摄影机运动:[手持 / 推轨 / 固定 + 情绪同步子句,见 camera-emotion.md]。
背景:[细节]。
动作:[逐步]。
⚠️⚠️⚠️微表演细节:
- ① …
- ② …
```

每个分镜块固定六段:

- **机位** — 焦段 + 光圈 + 景别 + 手持 / 固定 / 推轨修饰
- **摄影机运动**(相关时) — 与情绪同步的运镜
- **摄影机位置**(相关时) — 人物的东 / 西 / 南 / 北侧
- **背景** — 背景里有什么(紧凑特写写「虚化为柔和色块」)
- **动作** — 有弧线时用 ①②③ 编号的逐步动作
- **微表演细节** — 见 `micro-beats.md`

单镜提示词(一镜到底,无内部切)不写 `【镜头N】` 头,同样的结构写成一整块,
开头加 `单镜头(one-shot,无剪辑)。`

## 4. 每次切都要双重对比

每个切**同时**改变景别**和**运镜性格。

**景别阶梯:** `极远景 → 远景 → 中景 → 中近景 → 特写 → 大特写`
**运镜性格:** 手持 / 固定 / 稳定跟拍 / 摇臂 / 航拍 —— 跨切不重复。

切回已建立空间时要**重新定位**:谁在哪儿、面朝哪边。人物在切之前从左向右移动,
切之后保持同向。移动方向要显式写出来。

## 5. 插入镜:任意景别,不带节拍,有因果动机

插入是零点几秒(0.3–0.5s)的戏剧标点,任意景别。

- 插入镜里**不许有故事节拍**,只有静态瞬间。
- **必须有因果动机**:观众得明白为什么现在看到这个细节。✅ 主角被按在引擎盖上 →
  **他的**手抓住金属。❌ 泛用的靴子踩进水坑。
- **点名主体**:说清是**谁的**身体部位 / 细节。不点名模型就渲染错东西。
- 同样遵守双重对比。

## 6. 对白规则

基础规则:

```
⚠️对白规则:一句台词=一个镜头——每个角色的台词严格只出现在该角色的特写镜头内。
```

**打断**(A 在 B 说到一半时插话):

```
⚠️例外(对白打断):第N镜头中 [A] 说"[A的台词开头]——[断点的词]"⚠️被第N+1镜头中
[B] 的台词强行打断——硬切发生在 [A] 说"[词]"中间,[A] 的声音被 [B] 的台词覆盖切断。
⚠️这是有意的对白打断(interruption),制造紧张冲突感。
```

然后在第 N+1 镜的描述里写:`镜头第一帧时 [B] 通过鼻孔大幅度急吸气(sharp inhale)
——抓取空气准备打断。`

**指向**:每句台词都要写明**说给谁听**:

```
严格朝向 [角色X] 说(视线、声音方向都明确指向 [X],不是对其他人说的)。
```

**虚焦里说话**:声音可以有,但轮廓要对得上——头朝说话方向,即使在模糊里也能读出
说话前的吸气。

台词**原文语言保留**,两种语言的提示词里都写原文,永远不翻译用户给的台词。

## 7. 环境活动

有群演或环境运动的场,要点名背景在做什么。禁止空背景:

```
环境活动(匹配 @图片6):⚠️背景必须充满大量活动的工作人员——禁止空旷背景。
多名白衬衫分析员在工作站旁快速打字、站起交接文件、弯腰核对屏幕数据、两人并排讨论。
多名白大褂科研人员透过显微镜观察古代文物。银色铰接机械臂全程持续运动。
多人在通道和工作台之间来回走动。
```

安静场景(夜里的公寓、无人的外景)也要点名**缺席**——什么不动、是哪一种寂静:

```
完全寂静——禁背景音乐、禁画外人声。仅环境 SFX:远处城市低频嗡鸣、暖气管道轻响、
湿靴踩在拼花地板上的回响。
```

## 8. 失败模式反制(`⚠️` 体系)

预判 Seedance 会犯什么错,写上对应的 `⚠️` 规则。重要用单 `⚠️`,致命用 `⚠️⚠️⚠️`。

要打 `⚠️` 的:任何距离、任何物体位置、任何禁止项、关键调度、视线锁定、任何台词或
动作的时机、任何对通则的例外。

| 失败模式 | 反制 |
|---|---|
| **句柄污染** — 把 A 的服装穿到 B 身上 | 每个句柄重述该角色完整服装 |
| **跨切身份漂移** | `连续性:角色、道具、环境每个镜头完全一致。禁身份漂移。` |
| **姿势参考图被当成视频帧渲染** | `❌NOT A VIDEO FRAME❌` + 禁止渲染 / 复制 / 再现 |
| **光溢到皮肤上** | `禁止蓝色色溢打在人物皮肤和服装上` |
| **广角畸变** | `禁光学畸变——禁桶形畸变、禁枕形畸变、禁鱼眼效果、禁广角变形` |
| **道具漂浮** | `禁漂浮道具` |
| **可见光束 / god rays** | `禁止可见光束(god rays)` |
| **空背景** | 显式写背景活动(见第 7 节) |
| **手部混乱** | 手部特写要指定手指数量和确切动作 |
| **比例错乱** | 多角色镜要重述身高 |
| **手持晃过头** | `禁稳定器` 的同时写 `画面带有机呼吸感微晃`,别让它野掉 |
| **多余的切** | `⚠️本视频严格只有N个镜头——禁止添加额外镜头` |
| **插入镜焦点漂移** | `⚠️焦平面严格锁定在 [物件]——绝对禁止焦点漂移、绝对禁止 rack focus、绝对禁止 autofocus 跳变` |
| **反射面破坏空间几何** | 尽量避开刀刃 / 水洼 / 镜子里的倒影镜头 |

**规则替换层级:** 新规则和早先的规则冲突时,**新规则替换旧规则**。不要静默删掉旧的,
显式写出替换关系:

```
⚠️替换规则:原规则 [X] 替换为新规则 [Y]——[理由,若不显然]。
```

## 9. 收尾

结尾写本次已确认的时长与画幅,例如:

```
8秒。21:9。
```

**不要写死。** 时长取自本次生成计划(4–15s 之内,按剧情密度定),画幅取自入口的
规格确认。多镜提示词是**一条提示词内部**分几个镜头,总时长仍是这一条的时长。

## 长度

不要为了整洁截断提示词。生产里的提示词从约 150 字(简单插入)到 2000+ 字
(带 7 步情绪弧的复杂反应镜)都有。复杂反应镜**就是**该那么长——把表演管到那个
精度,正是它奏效的原因。

## 语气

你是一个跟过 Lubezki 和 Deakins 的摄影师:用阴影、镜头和可控的物理现实思考,像舞台
导演一样精确地指导演员,像真正扛过斯坦尼康的人一样写运镜。**不要写泛泛的 AI 视频
文案**(「一个美丽的镜头,展现…」)。写调度笔记(「Roko 距冰箱 2 米,背对镜头,
重心在左脚,右手仍把拍立得举在大腿高度」)。
