# 微表演目录 / Micro-Beats

**提示词里不许留笼统情绪。** 每一句情绪指示都要拆成具体的肌肉、呼吸、眼神、皮肤。
这是「AI 味视频」和「有表演的视频」之间最大的一条分界线。

## 1. 基本做法:拆不动就让用户四选一

剧本或用户写「他看起来 [某种情绪]」时,停下来拆。拆不出确信的版本,就把选择题
交给用户。

以「惊讶」为例,该问的是:

> 哪一种惊讶?
> **(a) 轻度正面** — 眉毛轻扬,嘴唇微张,瞳孔扩张约 0.3 秒,一次柔和鼻吸。无多余动作。
> **(b) 震惊** — 急促口吸气,双眼睁大,身体冻结在原地,一只手不自主抬至胸前。
> **(c) 不敢相信** — 一次缓慢眨眼,头微微侧倾,嘴唇收紧,只有一侧眉毛抬起。
> **(d) 惊喜** — 眼睛点亮(眼神光强化),笑容**逐步**建立,双肩放松下沉。

「紧张」「悲伤」「愤怒」「害怕」「若有所思」「动心」同理——每个泛称形容词都有
三到五种截然不同的生理实现。

## 2. 按情绪分类的目录

### 愤怒 / 决心 / 暴怒

```
- 颊部咬肌(masseter)通过皮肤可见地搏动
- 颈部颈动脉脉搏可见
- 太阳穴血管浮起
- 鼻翼在重音词上扩张
- 瞳孔收缩(focus tightening)
- 眼角外缘收紧(genuine intensity,不是廉价眯眼)
- 高潮时刻不眨眼
- 眉骨 / 鼻翼处微汗珠
```

### 焦虑 / 紧张

```
- 一次喉结上下吞咽(visible swallow)
- 台词前一次短促浅吸气(短促鼻吸)
- 用舌头舔润干燥的下唇
- 下唇轻微内收
- 脸颊毛细血管充血泛红
- 关键词上瞳孔扩张
- ⚠️除非剧本明确写了,否则不哭
```

### 悲伤 / 脆弱(不落泪)

```
- 眼角外缘下垂
- 眼睛湿润带眼神光(wet with catchlight)——但⚠️不流、不淌、不闪烁泪光
- 眉头中央皱起(corrugator muscle)
- 嘴唇轻微颤抖
- 头部微微低垂
```

### 掌控 / 平静 / 居高临下

```
- 平稳均匀的呼吸(与紧张的对手形成对比)
- 手指 / 手臂放松
- 缓慢均匀的眨眼(slow blink)
- 下颌微抬(chin lift)
- Duchenne 微笑——眼角外侧出现细纹。⚠️逐渐建立,不是从已完成的状态开始
```

### 沉重 / 被压垮

```
- 双肩下沉(heavy shoulders)
- 头部微微下垂
- 深而缓慢的呼吸
- 声音比平时更低沉、更闷
- 回答时头部轻微侧倾(5–15°)
```

### 震惊 / 冻结

```
- 镜头开始瞬间——身体冻结 0.3–0.5 秒,无任何移动
- 瞳孔在冻结瞬间扩张
- 嘴唇微微张开(lips part)但无声
- 一次延迟的、急促的鼻吸气在 freeze 结束后
- 眼睛锁定在触发源上——无眨眼、无视线偏移
```

### 强忍(最难写的一种:把情绪写成物理抵抗)

```
- 他在试图忍住——每一块面部肌肉都在对抗涌上来的情绪
- 颧骨处咬肌慢慢收缩
- 喉结一次延迟的、用力的吞咽
- 眼睛逐渐湿润,眼眶积聚泪水使眼球开始泛光——但泪不落下
- 一次缓慢、深、控制的吸气——胸腔可见起伏
- 下颌微抖一次——立刻被收紧
```

## 3. 单镜头内的情绪弧:编号节拍

一个连续镜头里情绪发生变化时,写成带编号的节拍序列,每拍写明哪块肌肉松、哪块紧:

```
①开始——[情绪 A]——[具体肌肉指征]
②过渡——[触发事件]——[哪些肌肉松开 / 绷紧]
③下一阶段——[情绪 B]——[新的指征]
④…
⑦结尾——[最终情绪]——[最终指征]
```

同时要显式声明**整段弧里脸上必须始终可见什么**(眉毛、下颌、呼吸、眼睛)。

**每个编号节拍都要绑定一个相机阶段**——见 `camera-emotion.md` 第 2 节。相机是
焦点人物的情绪替身,人物从暴怒走到克制,相机的不安必须跟着一段段减弱,而且要写
清楚在第几拍开始转变。只写表演不写相机,模型会用同一种晃法从头晃到尾。

## 4. 对白的三拍结构

每一句台词都配三拍:

- **台词前**:吞咽、吸气、舔唇、体态变化——让声音有起手式
- **台词中**:哪几个词是重音,重音时鼻翼 / 瞳孔 / 语调怎么变
- **台词后**:约 0.5 秒屏息再释放,然后才是下一个动作

范例:

```
台词前:一次短促鼻吸气,喉结一次吞咽。
台词:"Don't ask me again."——重音落在 "again",鼻翼在该词上扩张。
台词后:保持视线锁定在对手身上 0.5 秒——然后微微移开。
```

台词原文用什么语言就写什么语言,不要翻译。

## 5. 虚焦里的旁听者不是静止的

焦点人物清晰、其他人虚化时,虚化的人**仍然在演**。要写:

- 他们的头和视线指向哪里
- 肩膀和头的微动
- 对关键时刻的反应(即便在虚焦里也读得出来)
- 明确的时间错位:「主角先转头;0.4 秒后第二人;再 0.4 秒第三人」

**三个人永远不会同步。** 多人反应一律错开 0.3–0.5 秒。

## 6. 表演里禁止出现的

- ❌「就站在那儿说话」——永远有微动作
- ❌ 卡通式夸张表情 / 用力过猛
- ❌「眼睛望向天花板」表示思考——点名具体的视线方向
- ❌ 默认流泪——只有剧本明确要求才流
- ❌ 多角色完全同步——一律错开时间
- ❌ 泛称的「看起来很紧张 / 很开心」——拆到肌肉、呼吸、眼睛

## 7. 反 AI 自检

交付任何一条提示词之前,读一遍它的表演段落,问自己:

> 这段读起来像从 AI 提示词模板里生成的,还是像一个看过演员排练的导演写的笔记?

读起来像模板就重写。微表演应该来自一次具体的表演,不是一张清单。
