# 风格预设 / Style Presets

**每条提示词都必须有风格块,但用哪一套是选择题,不是房规。**

原始版本把「只用实光源 + Lubezki×Deakins + 8K IMAX」写成了不可协商的硬规则。那是
某个剧组的房规,不是通用工艺——整包套用会把所有项目压成同一种长相。这里把它降级
成**其中一个预设**,并把真正通用的部分提取成必填字段。

## 必填字段(这一层是硬的)

不管选哪套预设,风格块要写清这六项。缺项就是提示词没写完:

| 字段 | 要写什么 | 反例 |
|---|---|---|
| **画质基调** | 具体的质感描述 + 明确排除项 | ❌「高质量」「电影感」 |
| **摄影参考** | 具体的摄影师 / 片名 / 流派,或明确的技术描述 | ❌「专业摄影」 |
| **灯光** | 光源逐个点名(窗、屏幕、实用灯、日光…)+ 禁止的光源 | ❌「打光很好」 |
| **色彩** | 60:30:10 主 / 辅 / 点缀,并写出具体颜色 | ❌「色调统一」 |
| **镜头与快门** | 焦段范围、快门角度、运动模糊规则 | ❌「镜头语言丰富」 |
| **禁止项** | 该项目最容易翻车的那几条 | — |

**用物理可复现参数压过情绪形容词**:焦段 mm、光圈、色温 K、快门角度,这些模型接得住;
「唯美」「高级」接不住。

## 怎么挑

先看项目是什么,再挑预设。挑完**在阶段三向用户说明理由**,不要默认套。

| 项目类型 | 起手预设 |
|---|---|
| 写实剧情片、纪实、人物短片 | A. 实光源写实 |
| 商业广告、产品、时尚 | B. 可控棚拍 |
| 日式动画 / 赛璐璐 | C. 动画 |
| 科幻、赛博朋克、强风格化 | D. 风格化数字 |
| 用户传了参考图 / 既往分镜 HTML | 用他的,以上全部作废 |

## A. 实光源写实(Lubezki × Deakins 系)

适合:自然主义剧情、纪实感、人物驱动的场面。**不适合**广告和动画。

```
风格:8K IMAX。超写实——禁3D渲染,禁游戏引擎,禁游戏CG过场质感。
摄影:Emmanuel Lubezki × Roger Deakins。
灯光:⚠️严格仅使用场景内实际存在的光源(practicals)——屏幕、显示器、窗户、
实用吊灯 / 台灯等。禁止一切电影补光——禁正面光、禁侧面补光、禁顶光、禁底光、
禁反光板、禁柔光箱、禁LED灯带、禁霓虹、禁任何画面外光源。
摄影机始终在人物的阴影侧(shadow side)拍摄——面部自然受光但从较暗的一侧取景,
practicals 环境光照亮脸部轮廓和眼神光(catchlight)。
全程大气薄雾 haze 增加空气质感——禁止可见光束(god rays)。
色彩:60:30:10——[主色] / [辅色] / [点缀色]。
镜头:物理电影镜头。180°快门运动模糊。
皮肤:毛孔级写实——汗毛、不对称痣、毛细血管潮红、毛孔阴影匹配现场光源。
表演:反应前微停顿、精准视线、湿润活眼带眼神光、可见呼吸和胸腔起伏。
物理:重力惯性真实——质量有真实重量、正确接触阴影。禁漂浮道具。
构图:三分法 + 黄金比例。每人从第一帧开始运动。
连续性:角色、道具、环境每个镜头完全一致。禁身份漂移。
技术:60fps 流畅运动。8K 细节。禁抖动(除手持呼吸感)。
音频:仅环境 SFX。禁音乐。禁字幕。
```

## B. 可控棚拍(商业 / 产品)

适合:广告、产品、时尚、企业片。这里**允许**补光——那是这类片子的语言。

```
风格:商业级棚拍写实。超高清质感,材质表面细节可见。
摄影:大画幅质感,浅景深与产品清晰度并存。
灯光:主光 + 轮廓光 + 柔和填充,光比可控(3:1 到 5:1)。
柔光箱 / 反光板允许且必要。禁止杂乱多光源打架、禁止硬阴影落在产品标识上。
色温统一 [5600K 日光 / 3200K 钨丝],不混色温。
色彩:60:30:10——[品牌主色] / [中性背景] / [点缀]。
镜头:85–100mm 中长焦压缩,F2.8–F5.6 保证产品全清。180°快门。
物理:材质反射符合真实(金属镜面、塑料漫反射、玻璃折射)。禁漂浮道具。
技术:60fps。禁抖动。禁过饱和、禁HDR感。
```

## C. 动画(日式赛璐璐 / 2D)

适合:动画短片、MV、风格化叙事。**不要**往里写「超写实」和「毛孔级」。

```
风格:日式赛璐璐动画。手绘线稿质感,色块平涂 + 有限层次阴影(2–3 阶)。
禁3D渲染感、禁伪3D转描痕迹、禁写实皮肤纹理。
作画:关键帧 + 中间画节奏,动作遵循 タメ・ツメ(预备与停顿)。
灯光:动画化光影——阴影为色块而非渐变,高光为明确形状。
色彩:60:30:10——[主色] / [辅色] / [点缀色],饱和度按作品基调设定。
镜头:2D 摄影表语言——推、拉、摇、移、multiplane 层次视差。
技术:[24fps 作画节奏 / on 2s],禁止过度平滑插值。
```

## D. 风格化数字(科幻 / 赛博朋克)

适合:强视觉母题的项目。允许霓虹和体积光——那是这类片子的核心语汇。

```
风格:高概念数字电影。超写实基底 + 强风格化调色。
摄影:[具体参考片名或导演]。
灯光:允许霓虹、屏幕光、体积光束作为**动机光源**,但每一处都要点名来源。
禁止无来源的环境补光。禁止色溢打在皮肤上超过 [程度]。
色彩:60:30:10——[主色] / [辅色] / [点缀色]。
镜头:[焦段范围]。180°快门。允许轻度失真作为风格,但禁止鱼眼。
技术:60fps。8K 细节。禁游戏引擎质感、禁过曝辉光。
```

## 色彩比例按情绪挑

不管哪套预设,`60:30:10` 的具体颜色要跟场景情绪对上:

| 情绪 | 比例 |
|---|---|
| 冷冲突 / 紧张 | 60% 冷蓝 + 30% 混凝土灰 + 10% 红点缀 |
| 温暖 / 亲密 | 60% 暖钨丝 + 30% 深棕 + 10% 琥珀 |
| 危险 / 恐慌 | 60% 深红 + 30% 黑 + 10% 钠灯橙 |
| 科幻 / 科技 | 60% 黑 + 30% 冷灰 + 10% 点缀(紫 / 青) |

写进提示词时要写死具体颜色,不能只写 `60:30:10`:

```
色彩:60:30:10——冷蓝 / 混凝土灰 / 红色点缀。
```

## 场景类型的灯光子句

选定预设后,按场景再叠一层灯光子句。以下按 A 预设(实光源)给例,其它预设按同样
思路改:

**夜景内景,不开灯**
```
灯光:夜景——室内全部灯光关闭,禁任何室内光源(禁灯、禁台灯、禁屏幕光),
整个空间唯一的光来自窗外城市夜景透过窗户洒入的冷蓝光。摄影机始终在人物的阴影侧拍摄。
```

**有屏幕 / 显示器在画面里**
```
⚠️禁止屏幕 / 显示器向环境投射可见蓝色光芒——屏幕仅作为背景元素发光,不作为主光源。
⚠️禁止蓝色色溢(blue spill)打在人物皮肤和服装上。
```

**日间外景**
```
灯光:仅自然日光——硬阳光 + 大气散射,摄影机始终在人物的阴影侧拍摄,
contre-jour 逆光从天空方向,禁反光板、禁补光、禁柔光箱。全程大气 haze 增加深度。
```

**夜间外景**
```
灯光:仅实际街灯、车头灯、店铺霓虹反射、路灯。无任何摄影补光。
摄影机在人物阴影侧。全程城市 haze。
```

**暖色内景(开着灯的厨房 / 卧室)**
```
灯光:仅室内实际灯光——温白色台灯、吊灯、暖色 practicals。摄影机始终在阴影侧。
无任何外部补光。haze 轻微。
```

## 广角镜的追加子句

用 35mm 或更广的镜头时追加:

```
禁光学畸变——禁桶形畸变、禁枕形畸变、禁鱼眼效果、禁广角变形,画面线条必须笔直,
构图平整。
```

## 多镜 / 单镜前缀

一条提示词内含 `【镜头1】【镜头2】` 等内部切时,开头写:

```
多机位剪辑(multi-shot)。
```

一镜到底时写:

```
单镜头(one-shot,无剪辑)。
```
