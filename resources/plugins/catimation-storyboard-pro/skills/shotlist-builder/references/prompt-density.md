# 提示词密度 / Prompt Density

镜头行怎么分组成提示词。

## 没有固定比例

同一份分镜表里,实测的分组比例差得很远:

- 某场 7 行 → 5 条提示词(1:1.4)——密集,一拍一条
- 某场 3 行 → 1 条提示词(3:1)——合成一个连续情绪单元
- 某场 42 行 → 约 9 条(4.7:1)——典型动作场覆盖

**按场判断,不要套比例。**

## 合并:五条全满足才合

把多个镜头行并进一条提示词,要求同时满足:

1. 同一批人物在画面里
2. 同一地点(或同一地点的同一区域)
3. 是一个**连续的情绪 / 时间单元**——没有时间跳跃,没有大的情绪转向
4. 能在一次 Seedance 生成的时长里演完(**4–15s**)
5. 合并后的中文提示词不超过实际可用长度(约 2500 字)

## 拆分:任一命中就拆

1. **跨地点硬切**(公寓 → 闪回)
2. **主要角色进出场**改变了句柄表
3. **画幅 / 焦段变化**需要自己起范(广角建立 → 紧凑插入)
4. **表演弧需要独占一整条**——一个跨 7 个情绪节拍建立起来的反应镜,值得单独一条,
   不要和动作捆在一起
5. **插入 / 空镜**切到道具或屏幕——这类各自一条大特写提示词

## 一条提示词内部的多镜

一条提示词**可以**含 `【镜头1】/【镜头2】/【镜头3】` 内部切,条件是这些切共享地点和
人物。语法见 `prompt-patterns.md` 第 3 节。

用多镜的场合:

- 一个连续情绪瞬间里的 2–3 个快切(广角建立 → 紧凑反应 → 低角度收尾)
- 基调上是一个单元的蒙太奇(照片扫过 → 停在某张 → 手伸进去,一条三拍)

用单镜的场合:

- 一次连续表演配一个运镜
- 情绪重量需要不被切打断地落地的地方

## 实例

**3 行合成 1 条(合并)**

- 行 11.1:人物在公寓里,气氛压抑
- 行 11.2:一滴泪落下
- 行 11.3:闭眼,崩溃啜泣

三行是厨房地板上一次连续的情绪塌陷。一条提示词,内部 `【镜头1】【镜头2】` 两拍,
同地点同人物。**不要把悲伤切碎。**

**7 行拆成 5 条(拆分)**

- 提示词 1:开门 + 靴子跨过门槛
- 提示词 2:走廊走向客厅(需要自己的一口气)
- 提示词 3:客厅环视 + 窗 + 转向冰箱(一镜到底,50mm)
- 提示词 4:冰箱大特写——照片滑过 + 手伸进去
- 提示词 5:照片特写 + 人物的脸 + 转身

五个不同的机位、五个不同的焦段、五段不同的情绪微拍。它们各自撑得起一条。

## 拿不准时

**宁可多条、每条短**,不要往 15 秒里硬塞。Seedance 对紧凑提示词的处理明显好于超载
提示词,而且用户可以按顺序连着跑。

## 标签

每条提示词配一个短的方括号标签,供 HTML 表头一眼扫过:

- `[MS-CU · 开门 + 靴子]`
- `[ECU · 冰箱照片滑过 + 取照片]`
- `[CU · 脸部 + 转身]`
- `[Wide → MCU · 空间建立 + 反应]`
- `[多镜 · 3 反应 + 对白]`

景别缩写用 `plan-types.md` 里的那套。
