# 运镜 ↔ 情绪同步 / Camera-Emotion Sync

**相机是焦点人物的情绪替身。** 运镜、焦段和镜头时长由人物的情绪状态决定,不是由
「怎样看起来最电影感」决定。愤怒配不安的手持,平静配极微的呼吸,震惊先冻结。
这是 AI 视频里最常被违反的一条,每条提示词都要显式纠正。

## 1. 情绪 → 运镜映射

| 焦点人物情绪 | 相机性格 | 中文写法 |
|---|---|---|
| **愤怒 / 暴怒 / 紧绷 / 濒临爆发** | 手持呼吸,**不安、不规律**——呼吸节奏被打断,可见上下 / 左右抽动。幅度小,节奏乱。 | `摄影机不安、紧张——画面有较明显的呼吸式漂移、上下微抖、左右轻摆。手持摄影,画面带有不规则的呼吸节奏。禁稳定器。` |
| **平静 / 掌控 / 自信** | 手持呼吸,**平滑**——呼吸稳定,微幅规律。 | `摄影机平稳、流畅、克制——只剩下极细微的、规律的呼吸式微动。手持摄影但呼吸感极微。禁稳定器。` |
| **悲伤 / 脆弱** | 手持,**缓慢、低位**——呼吸频率降低,画面轻微下沉。 | `摄影机缓慢、低位手持——呼吸节奏放慢,画面有极轻微的下沉感。` |
| **震惊 / 揭示** | 静止 + 极缓推进或后拉——开头硬冻结,然后极慢移动。 | `镜头开始严格静止——0.5 秒后开始极缓慢推进 / 拉远(push-in / pull-out),整段移动距离不超过 15 厘米。` |
| **动作** | 清晰运动,运动模糊只在快门范围内。 | `60fps 流畅运动,180° 快门运动模糊,禁止超出快门范围的拖影。` |
| **终局 / 判决** | 0.3–0.5 秒正上方定格,时间静止。 | `严格正上方俯拍(top-shot)。0.3–0.5 秒 freeze frame。所有人物位置冻结。时间静止。` |

## 2. 单镜头内的相机分段(和表演节拍绑定)

一个连续镜头里情绪发生变化时,相机同步变化,**按阶段写清楚,并绑到
`micro-beats.md` 里的编号节拍上**:

```
⚠️镜头开始(步骤①②阶段,人物处在怒气):摄影机⚠️明显手持、不安、紧张——
画面有明显的呼吸式漂移、上下微抖、左右轻摆。

⚠️随人物情绪逐步缓和(步骤③④⑤):摄影机的不安⚠️逐渐减弱——呼吸式漂移幅度变小,
左右晃动减少,画面开始稳定。

⚠️镜头结尾(步骤⑥⑦,人物稳定下来):摄影机⚠️变得平稳、流畅、克制——
只剩下极细微的、规律的呼吸式微动。
```

不绑编号,模型不知道在这一条 10 秒的镜头里什么时候该转变,结果就是从头晃到尾。

## 3. 焦段选择

| 用途 | 焦段 | 光圈 |
|---|---|---|
| 极致情绪特写(额头到下巴填满画幅) | **85mm** 或 **100mm** | F1.4 |
| 中景对白、双人镜 | **50mm** | F2.0 – F2.8 |
| 广角 / 建立镜 | **35mm** | F4 – F5.6 |
| 插入 / 物件细节 | **50mm** 或 **85mm**,焦点锁死在物件上 | F1.4 |
| 微距(毛孔、水珠、织物) | **45mm 微距** | F2.8 |

用到广角或大光圈时,一律加**禁畸变**:

```
禁桶形畸变、禁枕形畸变、禁鱼眼效果、禁广角变形,画面线条必须笔直,构图平整。
```

浅景深插入和情绪特写要**锁焦**:

```
⚠️焦平面严格锁定在 [物件 / 人物] 上——绝对禁止焦点漂移、绝对禁止 rack focus、
绝对禁止 autofocus 跳变。
```

## 4. 推轨与移动

极慢的推轨(插入、器物特写)要**写明确切距离和时间**:

```
整个 7 秒内摄影机后移总距离仅约 10–15 厘米。速度慢到几乎察觉不到。
禁 zoom 变焦,禁突然推拉。
```

永远不要写 `zoom`。写物理移动:`dolly`、`track`、`crane`、`push-in`、`pull-out`。

## 5. 镜头时长

| 镜头类型 | 时长 |
|---|---|
| 硬切进场 / 闪现建立镜(极短广角) | **0.3 – 0.5 秒**(是零点几秒,不是 1 秒) |
| 一句台词,中等长度 | **3 – 7 秒** |
| 无台词的反应(带情绪弧) | **5 – 10 秒** |
| 插入 / 广角 / 定格 | **0.3 – 2 秒** |
| 完整情绪弧的特写(5–7 个编号节拍) | **8 – 15 秒** |

**这些是镜头内部的节奏,不是生成时长。** 单次 Seedance 生成落在 **4–15s**;上表里
短于 4 秒的镜头要么并进一条多镜提示词内部,要么先生成 4 秒再后期裁。

## 6. 可直接套用的模板

### 6.1 对白的极致特写(85mm,F1.4)

```
机位:⚠️85mm(或 100mm)长焦,⚠️F1.4 极浅景深,⚠️<主体1>⚠️严格的极致大特写
——构图严格「额头到下巴填满画幅」,脸⚠️必须占据画面绝大部分。
⚠️⚠️⚠️摄影机⚠️严格手持,全程明显的呼吸式漂移和微动——⚠️真实摄影师贴身跟拍的
呼吸感、心跳感。⚠️摄影机⚠️主动跟随脸部运动——头部任何细微的转动、抬起、下沉、
目光移动,摄影机都微微跟随调整构图。
摄影机位置:[人物的东 / 西 / 南 / 北侧].
背景:⚠️完全虚化为模糊色块和柔光斑——所有细节都强烈散焦。
动作:[逐步微表演节拍].
⚠️⚠️⚠️微表演细节:
- ① …
```

### 6.2 道具插入(锁焦)

```
机位:50mm / 85mm 大光圈定焦,⚠️F1.4 极浅景深,⚠️焦平面从镜头第 1 帧到最后 1 帧
严格锁定在 [物件] 上——绝对禁止焦点漂移、rack focus、autofocus 跳变。
⚠️清晰度规则:画面中⚠️只有 [物件] 绝对清晰锐利,所有其他元素强烈散焦虚化为
模糊色块和柔光斑(heavy bokeh)——背景永远模糊。
摄影机 [角度]。⚠️⚠️⚠️dolly out 运动幅度极小:整个 X 秒内总位移仅约 10–15 厘米
——速度慢到几乎察觉不到。禁 zoom,禁突然推拉。
```

### 6.3 闪现建立镜(零点几秒)

```
机位:35mm 广角,全景 / 远景。⚠️持续时间⚠️严格约 0.3–0.5 秒(split-second flash
establishing shot——只是瞬间空间定位的闪现,不是完整构图镜头)。
整体空间构图——[所有关键元素的位置]。
动作:[瞬间]——⚠️0.3–0.5 秒后⚠️立刻硬切到镜头 2——无过渡、无淡出、无停留。
```

### 6.4 收尾的顶拍定格

```
【镜头 N(最后)】
机位:严格正上方俯拍(top-shot)。0.3–0.5 秒 freeze frame。
背景:严格匹配 [地点]。
动作:所有人物位置冻结。时间静止。
```

## 7. 禁止的运镜

- `禁zoom变焦` — 只用物理移动
- `禁稳定器` — 写了手持就要看得见呼吸感
- `禁抖动(除手持呼吸感外)` — 不要在有意的手持之外乱抖
- `禁过度运动` — 剧情是私密的,相机就要私密。别为了炫技加运镜。
