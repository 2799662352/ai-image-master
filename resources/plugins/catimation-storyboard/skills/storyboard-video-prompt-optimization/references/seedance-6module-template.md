# Seedance 2.0 六模块紧凑优化模板(≤1900 字)

> 来源:忠实移植自 updream `video-prompt-optimizer`(视频提示词优化师)。
> 用途:把任意极简/粗糙创意,一次重构成**可直接复制**的 Seedance 2.0 视频提示词。本 skill 正文是「四法则」(首帧霸权/数值视觉化/单一主导/时间线);本模板是「成稿骨架」——当用户要一份**完整、自带模块标题、可直接交付**的提示词时用它。

## 强制纪律

1. **创意保真** — 100% 基于用户原始创意核心,不擅改主题/人物/剧情走向,只做细节补足。
2. **字数合规** — 完整提示词总字数**严格 ≤ 1900 字**;超出则精简非核心冗余,保留各模块必要信息。
3. **模型适配** — 不写 Seedance 2.0 无法实现的复杂运镜/超现实逻辑。
4. **格式规范** — 用分级标题区分模块,段落清晰,禁止大段无分段文本。
5. **语言规范** — 中文为主体,仅保留通用专业英文关键词,不堆砌无意义英文。
6. **合规** — 不生成低俗/色情/暴力/敏感/违规内容(配合 `storyboard-negative-control/references/compliance-filter.md`)。
7. **特殊需求优先** — 用户额外特殊要求优先满足,再套下列模块。

## 六大模块(缺一不可)

### 模块 1 · 核心人物全维度设定
- **基础人设**:姓名、年龄、性别、身份背景、性格、核心情绪、与剧情适配性
- **外貌细节**:五官、发型发色、肤质、身形、标志性特征、面部微表情基准
- **服装造型**:款式、面料质感、配色、配饰、与场景/人设/时代的适配
- **动作与互动**:核心剧情动作、肢体语言、与场景/道具互动、随情绪的神态变化

### 模块 2 · 场景与环境完整设定
- **核心场景**:空间定位、结构、核心陈设、关键道具、景深层次
- **时间与天气**:时间节点(晨/午/昏/夜)、天气、自然环境细节、动态变化
- **场景质感**:年代感、材质质感、整体氛围、与剧情/情绪的适配

### 模块 3 · 灯光与色调专业设定
- **主光**:类型、位置、强度、色温、硬光/柔光
- **辅助光**:补光位置/强度、阴影细节、对比度、暗部处理
- **氛围光**:环境光色调、氛围光源(烛光/霓虹/天光/火光)、光影的叙事作用
- **整体色彩**:色彩风格、色偏、饱和度、对比度、胶片质感

### 模块 4 · 影视级分镜与镜头设计(视频核心)
拆 **3–8 个连贯分镜**,每镜含:
1. 分镜序号 + 单镜时长
2. 景别(全/中/近/特写/大特写)
3. 运镜(固定/推/拉/摇/跟/移)
4. 核心画面内容(人物动作、场景变化、剧情推进)
5. 镜头叙事目的(传递的情绪/信息)

> 与本 skill 正文「时间线分配运动算力」一致:一镜一核心动作,避免运动权重稀释。

### 模块 5 · Seedance 2.0 专属参数与风格规范
- **基础参数**:分辨率、帧率、画幅(适配主流短视频规格)
- **画面风格**:整体风格、参考影视/摄影风格、质感要求
- **连贯性强制**:人物/场景/光影色调在全部分镜的一致性,防跳变/变形
- **画质优化**:锐度、抗畸变、无穿帮、画面干净度、细节丰富度

## 触发兜底
输入过短(仅几字/关键词)或需求不明 → 先主动询问核心视频创意,获取后再执行;已有明确创意则直接优化,不必额外询问。
