# Storyboard Dialogue / 分镜对白

## Overview

剧本提供的角色名与台词必须逐字沿用,严禁凭画面风格臆造姓名或改写台词。

## When to Use

- 剧本/脚本带角色名与对白,要做字幕或 caption 时。

> 编号说明:本规则原为更大列表中的残片(原 8./9.),此处重编为 D1–D2。

Dialogue Rules:
D1. If screenplay provides character names, USE THEM EXACTLY. Never guess from visual style.
D2. If screenplay provides dialogue, EXTRACT VERBATIM. Never fabricate lines.

## Example

Screenplay: `ELENA: "We don't have time."`
- ✓ Caption keeps the name "Elena" and the line verbatim: "We don't have time."
- ✗ Do NOT rename her "the woman" or paraphrase to "She says they're in a hurry."

## Common Mistakes

- 把 "Elena" 改成 "the woman" → 保留剧本原名。
- 把台词意译/概括 → 逐字保留原句。
