# Seedance 2.0 合规审核与改写过滤器

> 来源:忠实移植自 updream `seedance-prompt-filter`(Seedance 2.0 提示词审核优化器)+ `prompt-optimizer`(合规检查输出格式)。
> 用途:写视频/图像提示词前做一次合规自检,把可能触审的表述**正向化改写**,在不改变创意核心的前提下提高过审率。与本 skill 的「负向/误解控制」互补——这里管**内容合规**,本 skill 正文管**画质误解**。

## 二、A–G 改写策略

| 策略 | 适用类别 | 改写方向 | 示例(原 → 改) |
|------|---------|---------|----------------|
| A 正向化改写 | 反乌托邦类 | 把"毁灭/对抗"换成"重建/协作" | 末日废土,幸存者互相残杀争夺资源 → 未来生态重建世界,人类团结协作修复环境 |
| B 完全架空 | 时政敏感类 | 创造全新虚构世界观,完全不涉现实 | 现实政治/历史/民族 → 原创架空世界观 |
| C 文化正向化 | 宗教迷信类 | 换成传统文化/民俗艺术 | 驱鬼仪式、邪术害人 → 传统文化庆典、民俗艺术表演 |
| D 弱化细节 | 犯罪/暴力类 | 暗示性冲突,去可模仿/血腥细节 | 详细犯罪过程、血腥画面 → 暗示性冲突,正义战胜邪恶 |
| E 虚构原创 | 公众人物/品牌类 | 换原创角色、虚构品牌 | 现实人物/品牌 → 原创角色、虚构品牌 |
| F 公序良俗 | 低俗/伦理类 | 健康着装、正向价值观 | 暴露、性暗示、不良价值观 → 健康着装、正向价值观 |
| G 安全处理 | 危险动作类 | 艺术化处理,去除可模仿细节 | 详细危险动作描写 → 艺术化呈现,去可模仿步骤 |

## 三、完整改写示例

**原输入:**
> 末日废土世界,一个性感女战士穿着暴露的皮衣,手持枪械在废墟中与变异怪物血腥厮杀,到处都是断肢和鲜血

**命中:** ①反乌托邦(末日废土、厮杀) ⑥低俗(性感、暴露) ⑧暴力血腥(血腥厮杀、断肢、鲜血)

**改写后:**
> 未来生态探索世界,一位身着未来风格战斗服的女性探险家,手持能量武器在神秘遗迹中与未知生物进行激烈对抗,场景充满科幻氛围与探索精神

**应用策略:** A 正向化(废土→生态探索)+ F 公序良俗(性感暴露→未来风格战斗服)+ D 弱化暴力(血腥厮杀→激烈对抗)+ 去血腥元素。

## 四、合规检查输出格式(来自 prompt-optimizer)

向用户交付审核结果时,按此结构:

1. **核心违规点** — 逐条指出哪些词没过审 + 理由。
2. **总结为什么没过审** — 一句话直给。
3. **100% 合规改写** — 理解用户核心表达后,给一版**不影响表达**、轻松过审的版本。
4. **技术用语修正** — 检查镜头语言等专业名词是否精准,不精准则给修改建议。

## 五、规则

1. **保持创意核心** — 优化时尽量保留原始情感基调与视觉风格。
2. **多重检测** — 命中多类时全部处理。
3. **用户确认** — 展示结果后询问是否满意/需调整。
4. **迭代优化** — 按反馈进一步微调。
5. **平台差异** — 本清单针对 Seedance 2.0 审核机制;其他平台标准不同,策略需针对性调整。正式生成前建议先用改写版小测。
