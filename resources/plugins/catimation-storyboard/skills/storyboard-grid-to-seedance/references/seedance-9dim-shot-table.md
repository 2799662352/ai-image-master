# 9 维度分镜填充手册

每个镜头要填满 9 个维度,不可缺项。本文件是每一维度的参数范围、常见配方、典型写法。写分镜的时候对着这个表逐项填,不会漏也不会乱。

## 填表前先标参考职责

| 素材 | reference_role | priority | creative_freedom |
|---|---|---|---|
| 文字提示词 | `prompt-primary` | 故事/构图/动作/顺序/时长/导演调度最高 | 不负责身份像素锚定 |
| 用户选定角色锚点（大头照+全身照 / 多视图板 / 其它确认资产）/ 产品主图 | `identity-hard` | 身份最高 | 不改核心外观 |
| 干净首帧/关键帧/尾帧 | `keyframe-strong` | 当前片段构图与画质优先 | 允许连续运动补完 |
| 故事板/多宫格/美术设定板 | `atmosphere-loose` | 仅色彩/光线/材质/时代感/空间气质/视觉母题 | 可重做故事/构图/动作/顺序/转场；不复制文字边框 |
| 无素材覆盖的导演决策 | `director-free` | 服从核心意图 | 转场、微动作、运镜插值、节奏、粒子可发挥 |

需要逐格准确执行时，先拆格、去边框文字并重绘为干净关键帧，把对应素材角色从
`atmosphere-loose` 升为 `keyframe-strong`。使用整板时，提示词前必须先写
“提示词主导 / 氛围板低约束”职责前缀。

## 维度 ① · 景别

景别决定观众和人物的心理距离。短剧 8-15s 内要做阶梯递进,不能来回跳。

| 景别 | 简称 | 画面范围 | 情绪效果 | 适用 |
|---|---|---|---|---|
| 大全景 | ELS | 人物极小,环境为主 | 交代环境,孤立感,史诗感 | 开场、结尾 |
| 全景 | LS | 人物全身 | 环境+人物关系 | 介绍场景 |
| 中全景 | MLS | 人物膝盖以上 | 动作+表情并重 | 行走、对话 |
| 中景 | MS | 人物腰部以上 | 对话标配,情绪可见 | 日常戏主力 |
| 中近景 | MCU | 人物胸部以上 | 情绪为主 | 情感戏主力 |
| 近景 | CU | 人物肩部以上 | 表情主导 | 特写瞬间 |
| 特写 | ECU | 脸部主导 | 细微情绪 | 情绪锚点 |
| 大特写 | XCU | 局部(眼/唇/手) | 符号、象征 | 情绪爆发点 |

**阶梯递进铁律(4-5 镜短剧模板)**:
- 入画:大全景 / 全景(交代世界)
- 推进:中景 / 中近景(认识人物)
- 高潮:近景 / 特写(进入情绪)
- 收尾:拉回中景 / 全景(情绪回落)

禁止写"这一镜是中景到特写的推镜"——那是运镜,不是景别。一个镜头只标一个起始景别(推镜的话标起始或结束,选主要的)。

## 维度 ② · 机位(角度 + 焦段 + 光圈 + 运镜)

### 角度

| 角度 | 效果 | 典型场景 |
|---|---|---|
| 仰角(向上 5-30°) | 人物高大、崇高感 | 英雄出场、权威人物 |
| 微仰(0-5°) | 讨喜、青春感 | 少女、温暖对话 |
| 平视 | 平等、自然 | 日常、对话 |
| 微俯(0-10°) | 温顺、可爱 | 女主凝视、肖像 |
| 俯角(10-45°) | 渺小、压抑、观察 | 权力对比、情绪压迫 |
| 鸟瞰(接近 90°) | 抽离、宏观 | 开场、结尾 |

### 焦段

| 焦段 | 特性 | 用途 |
|---|---|---|
| 24mm 广角 | 空间感大,略有畸变 | 环境、全景 |
| 35mm 标准广角 | 接近人眼 | 双人对话、环境+人物 |
| 50mm 标准 | 还原人眼视角 | 中景、日常戏 |
| 85mm 人像 | 经典人像焦段,压缩空间 | 人物特写、半身肖像 |
| 105mm 长焦 | 极致虚化,压缩感 | 仙气逆光、大头照 |
| 135mm+ | 偷拍感、极度压缩 | 高级质感、抽离 |

### 光圈

| 光圈 | 景深 | 用途 |
|---|---|---|
| f/1.2-1.4 | 极浅(只焦点人物清晰) | 人像特写、仙气 |
| f/1.8-2.0 | 浅 | 人像、环境虚化 |
| f/2.8 | 中浅 | 双人清晰、背景虚化 |
| f/4-5.6 | 中 | 多人戏、环境+人物都清楚 |
| f/8 | 深 | 全景、风景 |

### 运镜

**只选一个主运镜,不叠加。** 详见 seedance-6-rules.md 第五节的 8 大运镜表。

### 组合范式(拿来就用)

| 镜头类型 | 机位组合 |
|---|---|
| 人物定妆半身 | 微俯 5° / 85mm / f/2 / 固定(或缓慢推镜) |
| 情绪特写 | 平视 / 85-105mm / f/1.4 / 固定 |
| 对白中景 | 平视 / 50mm / f/2.8 / 固定 |
| 双人对峙 | 平视略低 / 35-50mm / f/2.8 / 固定 |
| 开场大全 | 微俯 / 24-35mm / f/5.6 / 缓慢推镜 |
| 行走跟拍 | 平视 / 35mm / f/2.8 / 跟镜或侧移 |
| 回眸瞬间 | 微仰 3° / 85mm / f/1.8 / 固定 |
| 旋转动势 | 低机位 / 50mm / f/2 / 固定(主体旋转) |

## 维度 ③ · 灯光(主光 + 补光 + 光比)

### 主光方向决定氛围调性

- **前侧光(右前 45°)**:明暗分明,戏剧感,古装剧标配 → 配 LUT-A / D
- **侧逆光(右后 45°)**:仙气,透光感,rim light 勾轮廓 → 配 LUT-B / C
- **正逆光**:剪影、全身发光、Magic Hour → 配 LUT-C
- **顶光**:伦勃朗式、戏剧、人物雕塑感 → 配 LUT-D
- **底光**:恐怖、诡异(慎用,除非恐怖片)
- **平光(1:2)**:柔和、美颜、肖像 → 配 LUT-E
- **单一实用光(侧前低角度)**:文艺、卡拉瓦乔 → 配 LUT-F

### 光比表

| 光比 | 描述 | 情绪 |
|---|---|---|
| 1:1 | 无光比,纯漫射 | 产品、美颜 |
| 1:2 | 极柔,微阴影 | 肖像、静谧 |
| 1:3 | 柔和日常 | 仙气、治愈 |
| 1:4 | 中戏剧 | 古装剧日常 |
| 1:5 | 强戏剧 | 冲突、对手戏 |
| 1:6 | 极强戏剧,半明半暗 | 文艺片、逆光 |
| 1:8+ | 极端戏剧 | 悬疑、恐怖 |

### 关键光效(按需叠加 1-2 个)

- rim light(轮廓光,勾头发)
- halation(光晕,暖色头发边缘)
- bloom(光溢出,高亮区发光)
- lens flare(镜头光斑)
- 体积光 / 丁达尔效应(光束)
- 眼神光(双眼清晰高光点)
- 反射光(补亮暗面细节)

## 维度 ④ · 调色(5 要素)

直接抄 LUT 参数。lut-aesthetics.md 里每款都有现成参数,照抄即可。

每个镜头必须写清:
1. **色温** XK
2. **高光** Hue X°,饱和度 +X
3. **中间调** 描述
4. **阴影** Hue X°,饱和度 +X
5. **局部增强** 哪些元素特意强化(比如 "朱红唇色饱和度 +10 作为点睛")

## 维度 ⑤ · 氛围感(4 要素)

1. **梦幻感** ★☆☆☆☆ ~ ★★★★★
   - ★★ 追求真实文艺
   - ★★★☆ 中性电影
   - ★★★★☆ 偏梦幻古装
   - ★★★★★ 宣传大片 / 仙气满级

2. **空气感**
   - 粒子大小:1-5 px(尘埃) / 5-15 px(花瓣) / 15-30 px(雪/桃花瓣)
   - 密度:5% 几乎无 / 15% 轻 / 30% 中 / 50% 重 / 80% 满屏
   - 方向:从 A 向 B 飘

3. **轮廓光**(rim light)
   - 无 / 微弱 / 明显 / 极强
   - 颜色:暖金 / 冷白 / 粉红

4. **光晕 / 眼神光**
   - 眼神光:柔和 / 清晰 / 戏剧性
   - halation:是否有 / 颜色

## 维度 ⑥ · 画面内容(场景 + 服饰 + 动作 + 表情)★ 最重要

### 场景
必须具体到 **"地点 + 时间 + 道具锚点"**。

```
❌ 古代客栈内
✅ 古代客栈二楼靠窗的方桌,黄昏窗外暗光,
   桌上有一盏油灯、一个青瓷茶壶、半碗残茶
```

### 服饰
必须具体到 **"形制 + 主色 + 材质 + 细节"**。

```
❌ 古装
✅ 交领右衽宋制汉服,青灰绿色苎麻,橘红珊瑚色抹胸内搭,
   领口有暗纹刺绣,袖口有磨损感
```

### 动作
必须写 **"动作链"**,不要写状态。

```
❌ 她在发呆
✅ 她先是缓慢把茶杯放下,指尖在杯沿停顿一下,然后头慢慢侧向窗外,
   视线聚焦在远处一个点上
```

### 表情(★★★ 硬核门槛)

**生理细节是硬门槛**。每个镜头的表情描述必须包含至少 2 个生理反应:

| 情绪 | 生理锚点库(挑 2-3 个写进描述) |
|---|---|
| 震惊 | 瞳孔瞬间放大 / 嘴唇微启 / 呼吸停滞 / 身体后倾一寸 |
| 心动 | 睫毛连续颤两下 / 耳尖发红 / 视线停滞后错开 / 嘴角极微上扬 |
| 隐忍悲伤 | 眼眶泛红 / 下唇微咬 / 喉结滚动 / 视线下移 / 鼻翼轻扇 |
| 隐忍愤怒 | 颌线绷紧 / 牙关咬合 / 太阳穴青筋微跳 / 指节发白 |
| 紧张 | 指尖摩挲衣角 / 鼻尖细汗 / 喉结上下 / 呼吸变急 |
| 疲惫 | 眼皮半垂 / 肩线下沉 / 呼吸延长 / 嘴角自然下垂 |
| 暧昧迟疑 | 上齿轻咬下唇内侧 / 眉心微蹙 / 眼神游移一瞬 |
| 坚定 | 下颌微抬 / 眼神聚焦不游移 / 呼吸匀长 / 唇线平直 |
| 崩溃前一刻 | 嘴角微颤 / 眼眶蓄泪未落 / 喉结猛滚 / 肩膀轻抖 |
| 释怀微笑 | 眼角弧度微深 / 鼻翼松弛 / 唇线自然上扬 / 呼吸变长 |

### 整体检验标准

每个镜头的画面内容字段,写完后读一遍问自己:
- 有没有写到 **指节发白 / 睫毛颤动 / 鼻尖渗汗** 这个级别?
- 动作是不是写成了动作链(先...然后...接着...)?
- 场景有没有具体道具锚点?
- 服饰有没有写到材质?

任何一项没过,重写。

## 维度 ⑦ · 台词

格式:**说话人 + 语气 + "原文"**

```
女主,低声几乎是自言自语:"原来...原来是这样啊..."
```

语气词库:
- 克制 / 压抑 / 颤抖 / 低沉 / 沙哑 / 轻叹
- 冷静 / 平稳 / 淡漠 / 疏离
- 急促 / 喘息 / 哽咽 / 破音
- 温柔 / 含笑 / 轻快 / 试探

**无台词时**写"无对白"或"环境留白"。不允许空着。

**长对白(>8 字)** 转方案 B(后期配音),提示词里不写台词只写嘴部动作。

## 维度 ⑧ · 音效(3 层)

必须写 3 层,不允许只写 1 层:

1. **前景音**(人物行为产生):
   - 脚步声、衣料摩擦、呼吸、心跳、手指敲击、杯盏碰撞、剑拔出鞘...

2. **环境音**(场景自带):
   - 风声、鸟鸣、蝉鸣、雨声、雪落、炭火噼啪、远处街市人声、更夫打更...

3. **配乐 / 音乐**(情绪主导):
   - 古筝轻挑 / 箫声悠远 / 二胡拉长音 / 琴声点缀
   - 电影感弦乐低音 / 单音钢琴 / 大提琴独奏
   - 环境氛围电子垫音 / 东方 drone 持续低音
   - **留白**(这是有效的设计,不是偷懒)

### 音效 "留白"的正确用法

```
音效:无配乐,前景是她放下茶杯的轻响 +
自己略微急促的呼吸,环境的客栈嘈杂声在此刻被抽离
```

留白不是"没有音效",是"主动设计的静默"。要写出来。

## 维度 ⑨ · 备注(技术参数)

1. **焦点**:人物的哪一部分锐利(右眼 / 左眼 / 双眼 / 嘴唇 / 手指 / 道具)
2. **颗粒 %**:直接抄 LUT 参数
3. **速度修饰**:Slow / Smooth / Subtle / Cinematic / Intimate / Dreamy(只选一个)
4. **特殊帧**:
   - 首帧特殊要求("开场第一帧是纯黑")
   - 末帧特殊要求("结尾定格 1 秒再淡出")
   - 中段特殊节拍("发展段有一个硬切回闪")

## 写完一个镜头的自检 Checklist

- [ ] 9 维度全部填满,无空字段
- [ ] 画面内容包含至少 2 个生理细节
- [ ] 动作写成"动作链"(先…然后…接着…),不是静态状态
- [ ] 只有一个主运镜,且运镜与主体动作分开写
- [ ] 光影三要素(方向 + 色温 + 光比)齐全
- [ ] 调色参数直接沿用本片 LUT,没有自创漂移
- [ ] 台词 ≤8 字用原生音频(方案 A),>8 字转后期配音(方案 B)
- [ ] 音效写满 3 层(前景 / 环境 / 配乐,或主动留白)
- [ ] 正向稳定目标已写；只有明确风险才追加简短排除项
- [ ] `@` 素材逐镜重标,编号已逐一核对无误
- [ ] 每份参考已标 prompt-primary / identity-hard / keyframe-strong / atmosphere-loose / director-free
- [ ] 总览板没有被当作 firstFrame，也没有要求复制边框、编号、文字或拼贴版式
- [ ] 使用故事板/多宫格时，mandatory 提示词主导前缀已写在正文之前

全部打勾,这个镜头才算"写完"。任意一项空缺,Seedance 就可能在那一项上翻车。
