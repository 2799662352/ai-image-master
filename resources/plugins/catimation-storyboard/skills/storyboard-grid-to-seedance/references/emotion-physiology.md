# 抽象情绪 → 生理反应翻译表

这是提示词写作经验，不是对 Seedance 奖励模型训练数据或内部理解机制的断言。
把“很伤心”改写成呼吸、视线、肌肉张力和动作过程，会得到更可执行、可观察、
可质检的表演要求。

> 本表条目逐条来自 updream `seedance-cinematic-drama` 的 `seedance-rules.md`(情绪翻译表)与 `shot-template.md`(生理锚点库),仅整理合并,无新增杜撰条目。配合本目录 `seedance-9dim-shot-table.md` 维度⑥使用。

## 三、过程 > 状态

视频提示词需要描述“变化如何发生”，而静态情绪标签没有动作信息。把情绪写成
一条可见过程：

```
❌ 她很伤心
✅ 她先是一怔,眼眶慢慢泛红,下唇颤了一下终于咬紧,眼泪没有落
```
