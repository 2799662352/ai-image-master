# 6 款电影写实美学 LUT 包

这是六张已经过反推验证的电影级美学锚点,每一款都是一个独立可用的视觉 VI(视觉识别)包。每次做方案,从这 6 款里选 1 款(或用户自定义)作为全片基调,然后**全片锁死同一套参数**——这是保证"同一部片子"感觉的关键。

## 选款决策树(5 秒决定用哪一款)

```
用户的高光文案情绪是什么?
├─ 日常 / 市井 / 俏皮 / 温暖对话      → LUT-A · 茶橙酒楼暖光
├─ 独处 / 心事 / 仙气 / 治愈瞬间      → LUT-B · 粉绿花园柔光
├─ 宣传 / 高光 / 绽放 / 浪漫定格      → LUT-C · 金粉黄昏逆光
├─ 冲突 / 对峙 / 权谋 / 高潮戏剧      → LUT-D · 青绿张艺谋重彩
├─ 凝视 / 含蓄 / 哀愁 / 人物志        → LUT-E · 雾紫凝眸肖像
└─ 疲惫 / 诗意 / 文艺 / 静默          → LUT-F · 青赭文艺片油画
```

如果文案横跨多种情绪,选"情绪落点"对应的那一款(不是开头)。

## LUT-A · 茶橙酒楼暖光

**一句话定调**:东方夜色市井特写 · 茶橙对比经典美学 · 暖色实用光源主导

### 核心参数
- **色温**:3000K(钨丝 / 烛光 / 灯笼光源模拟)
- **光比**:1:4(中戏剧对比,暗部有层次不死黑)
- **主光向**:右侧 45° 前侧光(暖色)
- **辅光**:左侧极微弱反射光,不破戏剧感
- **轮廓光**:背后暖黄 rim light 勾勒头发
- **眼神光**:双眼清晰暖色高光

### 调色参数
- 高光:Hue 40°(琥珀金黄),饱和度 +25
- 中间调:暖橙色氛围
- 阴影:Hue 190°(青绿色),饱和度 +20(由道具承担,如青瓷茶杯)
- 肤色:偏暖偏白,粉嫩自然

### 氛围
- 梦幻感:★★★★☆
- 空气粒子:几乎无(室内场景)
- Bokeh:圆形柔和散景(灯笼变温暖光斑)
- 胶片颗粒:8-12%(轻微)

### Seedance 提示词风格词(每镜贴尾)
```
茶橙电影 LUT,3000K 钨丝光,光比 1:4,暖色前侧光,
高光琥珀金黄 Hue 40° 饱和 +25,阴影青绿 Hue 190°,
圆形柔和 bokeh,胶片颗粒 10%,ARRI Alexa 电影色
```

### 参考关键词
ARRI Alexa 自然电影色,《梦华录》《知否》级别古装剧剧照,东方婉约美学,市井静谧瞬间

### 最适合的场景
- 两人在酒楼 / 茶馆 / 客栈对话
- 夜晚室内的暖心瞬间
- 俏皮少女心、市井烟火气
- 暖色实用光源为主的场景

## LUT-B · 粉绿花园柔光

**一句话定调**:东方仙侠剧阳光花园剧照 · 粉绿柔光美学 · 日系电影感与古装融合

### 核心参数
- **色温**:5200K(自然日光,清晨 10 点或下午 3 点柔光)
- **光比**:1:3(柔和不戏剧)
- **主光向**:右后方侧逆光 ★ 核心
- **关键光效**:
  - 背光透光(蝴蝶翅膀半透明发光 / 花瓣透光)
  - 头发 rim light(侧后方光勾发丝光晕)
  - 空气感体积光(轻微光束朦胧)
  - 轻微 bloom 晕染

### 调色参数
- 高光:Hue 65°(黄绿色),饱和度 +15,轻微过曝柔化
- 中间调:粉绿平衡(粉色花 + 绿叶相互呼应)
- 阴影:Hue 170°(青绿色),饱和度 +20,不死黑
- 肤色:偏白偏粉,有美颜质感

### 氛围
- 梦幻感:★★★★★ 拉满
- 空气粒子:极细微空气尘埃在光中漂浮(仙气)
- Bokeh:大而圆的柔光散景
- 胶片颗粒:3-5%(追求通透数码感)

### Seedance 提示词风格词
```
粉绿柔光 LUT,5200K 自然日光,侧逆光,光比 1:3,
高光黄绿 Hue 65° 饱和 +15,阴影青绿 Hue 170°,
背光透光发丝 rim light,轻微 bloom 高光溢出,
空气中微尘漂浮,胶片颗粒 3%
```

### 参考关键词
《长相思》《与凤行》《千古玦尘》《苍兰诀》级别仙侠花园戏

### 最适合的场��
- 独处赏花 / 花园偶遇
- 少女心事 / 仙气独白
- 治愈清新瞬间
- 需要大量自然光和透光美学的场景

## LUT-C · 金粉黄昏逆光

**一句话定调**:古装仙侠剧宣传大片 · 金粉桃花逆光体 · 转身瞬间的东方浪漫

### 核心参数
- **色温**:2900K 极暖(Magic Hour 黄金时刻)
- **光比**:1:6(戏剧对比,但逆光自然)
- **主光向**:正背逆光 / 顶逆光 ★ 核心
- **关键光效**:
  - 全身 rim light 金色光环
  - 水袖 / 长发透光半透明
  - lens flare 镜头光斑
  - ���强 bloom 大气辉光(金色光雾占画面 30%+)
- **面部补光**:必须加(逆光下否则黑脸)

### 调色参数

- 中间调:金粉色笼罩一切
- 阴影:Hue 15°(暖褐色),饱和度 +10,**阴影也不冷**
- 肤色:金粉色,强暖偏移

### 氛围
- 梦幻感:★★★★★ 满分
- 空气粒子:大量花瓣飞舞(前景大瓣 + 背景无数小瓣)
- 花瓣方向:从左上向右下飘落,呼应动势
- Bokeh:大而柔和的圆形光斑(樱花虚化成粉光斑)

## LUT-D · 青绿张艺谋重彩

**一句话定调**:张艺谋式东方重彩电影 · 青绿戏剧调 · 戏剧冲突的视觉化

### 核心参数
- **色温**:4200K 偏冷 + 绿色色调偏移 ★ 核心
- **光比**:1:5-1:6(强戏剧对比)
- **主光向**:顶侧光(从上方稍偏前打下)
- **光源类型**:模拟烛光 / 暖色实用光,但被调色偏冷覆盖
- **关键光效**:
  - 脸部明暗交界清晰(鼻梁深投影,颧骨受光)
  - 眼窝深邃,眼神光微弱但犀利
  - 金色头饰 / 服饰金线在顶光下高光璀璨
  - 暗部保留层次,不死黑
  - 伦勃朗式绘画光的东方版本

### 调色参数
- 高光:Hue 45°(金黄),饱和度 +35(金色极艳)
- 中间调:青绿基调(Hue 170°),饱和度 +15
- 阴影:Hue 190°(深青绿),饱和度 +20,**阴影偏冷**
- 肤色:青绿化 + 粉红高光(**非暖色肤色**,张艺谋招牌)
- 服饰色彩:高饱和但青绿作为"共同溶剂"串联各种鲜艳色
- 唇色:朱红在青绿背景中跳出(点睛色)

### 氛围
- 梦幻感:★★☆☆☆(不追求梦幻,追求戏剧张力)
- 空气粒子:微弱环境尘埃(宫殿陈旧感)
- Bokeh:轻柔但不规则(老镜头散景)
- 整体质感:油画 + 戏曲 + 电影胶片三合一
- 胶片颗粒:12-18%(明显)
- 无花瓣 / 无蝴蝶 / 无光斑 / 无 bloom

高光金黄 Hue 45° 饱和 +35,中间调青绿 Hue 170°,
阴影深青绿 Hue 190°,肤色青绿化带粉红高光,
朱红点睛,伦勃朗式绘画光,胶片颗粒 15%,油画质感

### 参考关键词
《满城尽带黄金甲》《金陵十三钗》《影》《妖猫传》级别东方重彩电影

### 最适合的场景
- 双人对峙 / 质问 / 密谈
- 高潮冲突戏
- 宫廷权谋场景
- 需要戏剧张力而非观赏性的画面

## LUT-E · 雾紫凝眸肖像

**一句话定调**:古装剧半身肖像剧照 · 紫雾桃花色调 · 凝眸回望的静谧美学

### 核心参数
- **色温**:5800K 中性略偏冷,带青绿色调偏移
- **光比**:1:2 近似平光(极柔和)
- **主光向**:右前方 45° 柔和侧光
- **光源类型**:自然漫射光(阴天 / 树荫下的软光)
- **关键光效**:
  - 几乎无明显投影(软光均匀照射)
  - 脸颊柔和高光(反光板式补光)
  - 眼神光柔和漫射
  - **无 rim light**(特意不勾轮廓)
  - 头发细节保留,发丝层次清晰

### 调色参数
- 高光:Hue 340°(粉紫),饱和度 +10(低饱和)
- 中间调:雾紫色笼罩人物服饰,与雾绿背景呼应
- 阴影:Hue 190°(青绿),饱和度 +15,背景主导
- 肤色:冷白 + 粉嫩(古装剧美颜肤色)
- 对比度:低对比,整体通透柔和
- 色彩策略:紫(人物)+ 粉(桃花)+ 青绿(背景)三色三分,都低饱和
- 唇色:Hue 355° 粉红点睛

### 氛围
- 梦幻感:★★★★☆
- 空气粒子:几乎无
- Bokeh:柔和奶油散景(桃花变粉色小色块,非圆形光斑)
- 整体质感:雾感 + 通透 + 低饱和,像蒙了一层柔纱
- 胶片颗粒:4-6%(轻微)
- 后期:轻度 HDR 暗部拉亮 + 柔焦滤镜
- **无 bloom / 无光斑 / 无粒子**——纯靠人物和色彩说话

## LUT-F · 青赭文艺片油画

**一句话定调**:文艺电影质感 · 青赭冷暖互补 · 疲惫诗意的油画式静默美学

### 核心参数
- **色温**:3600K(暖室内 / 黄昏自然光,整体偏暖但暗部压冷)
- **光比**:1:6(强明暗对比,大面积阴影包裹,只留一束主光)
- **主光向**:右前方低角度侧光(窗光 / 门缝光 / 一盏台灯)
- **辅光**:几乎不补,任由暗部沉下去(文艺片的留黑美学)
- **轮廓光**:弱,或仅发梢一缕,不刻意勾边
- **眼神光**:仅一个小而克制的点,强调"疲惫但有神"

### 调色参数
- 高光:Hue 35°(赭黄 / 暖琥珀),饱和度 +20(暖部偏艳)
- 中间调:青赭过渡,暖肤冷景
- 阴影:Hue 195°(青蓝),饱和度 +15(**冷低暖高**,冷暖互补)
- 肤色:暖黄带病态感,不美颜、保留瑕疵与质感
- 对比度:中高,暗部厚重
- 色彩策略:暖(人物 / 光)与冷(阴影 / 环境)互补,像一幅做旧油画
- 唇色:自然偏淡,不点睛(文艺片不追求跳色)

### 氛围
- 梦幻感:★★☆☆☆(不追求梦幻,追求"真实的疲惫与诗意")
- 空气粒子:微弱浮尘,逆光时可见
- Bokeh:粗颗粒不规则散景(老胶片镜头味)
- 整体质感:油画 + 做旧胶片 + 文艺片
- 胶片颗粒:18-22%(明显,刻意做旧)
- **无花瓣 / 无蝴蝶 / 无光斑 / 无 bloom**——靠颗粒与明暗叙事

### Seedance 提示词风格词
```
青赭文艺片油画 LUT,3600K 暖光暗部压冷,右前低角度侧光,光比 1:6,
高光赭黄 Hue 35° 饱和 +20,阴影青蓝 Hue 195° 饱和 +15,冷暖互补,
肤色暖黄保留质感不美颜,中高对比暗部厚重,做旧油画质感,胶片颗粒 20%
```

### 参考关键词
《一代宗师》《刺客聂隐娘》《路边野餐》级别文艺电影的疲惫诗意质感

### 最适合的场景
- 文学瞬间 / 旁白独白段落
- 人物疲惫、沉思、回望的诗意时刻
- 需要"静默叙事"、靠光影与颗粒讲故事的文艺片片段
- 刻意做旧、反糖水、反 AI 味的高级感画面

## 用法总结

1. **先选款**:用开头"选款决策树",按文案的**情绪落点**(非开头)定 1 款。
2. **锁参数**:把该 LUT 的全部参数(色温 / 光比 / 主色 / 颗粒 / 饱和 / 对比 / bloom)抄进方案的"整体色调",全片所有镜头共用同一套。
3. **逐镜复读**:每个镜头的提示词都重复该 LUT 的 3 个核心风格词,防止逐镜漂移。
4. **自定义也要锁**:如果用户给了自定义美学,同样要把它量化成上述参数后再锁死——"锁"比"选哪款"更重要。

> 一部片子只用一款 LUT。换 LUT = 换片子。这是"电影感"和"AI 拼贴感"的分水岭。
