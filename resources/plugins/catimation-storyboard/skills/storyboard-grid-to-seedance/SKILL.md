# Storyboard Grid to Seedance（网格/设定板 → 图生视频）
<!-- skill-budget: fast -->

## Overview

**单帧、网格故事板和电影美术设定板是三种职责不同的资产，不冲突：**

1. **用户选定的身份锚点**负责脸、服装、产品外观等不可漂移项；可为大头照+
   全身照、三视图/四视图/多视图角色板或其它确认资产。
2. **干净单帧/首尾帧**负责当前生成单元的画质、空间与精确构图，是视频强输入。
3. **故事板/多宫格/美术设定板**默认只作氛围图，负责色彩、光线、材质、时代感、
   空间气质与视觉母题，不要求构图、内容、动作或顺序完全一致。
4. **导演自由区**负责转场、微动作、运镜插值、节奏和特效补完。

图像阶段便宜，先用图像模型把多镜结构可视化，再进入昂贵的视频阶段很有效；但不要宣称视频模型会把一张网格**可靠解析成 N 个独立时间帧**。整板适合“松散指导”，精确逐格执行必须拆格。

> **锚点纪律:** 身份锚点服从用户需要；大头照+全身照、多视图角色板或其它确认
> 资产均可。用户未指定且身份关键时先询问，低风险才采用大头照+全身照默认。
> 氛围网格或美术设定板不得在未确认时自动冒充身份锚点或 `firstFrame`。
>
> **有板即用的提示词硬门:** 只要视频输入含故事板/九宫格/多宫格/美术设定板，
> 提示词必须先声明“文字主导、整板只作低约束氛围参考、导演可重构镜头”，不能把
> 这段职责前缀当可选建议。

## When to Use

**用本 skill:**
- 想用图像模型生成 3×3 / 4×4 / 16 格故事板，一次性看整段剧情和镜头推进。
- 想生成“俯视机位图 + 镜头对应表 + 立面/剖面 + 材质/灯光 + 人设/剧情”的电影美术设定板。
- 已有网格/设定板，要在“整板松散指导”与“拆格精确执行”之间选正确路径。
- 动作/舞蹈/编舞序列:把连续动作排成网格当动作参考。
- 漫画页 / 多帧蒙太奇 / 试镜网格这类"格子即时间轴"的玩法。

**不用本 skill,改用:**
- 要逐镜连续性受控的完整制片包(角色/场景圣经 + 衔接矩阵 + 剪辑边界矩阵 + 双语提示词)→ 超出本 skill 范围,交给上层制片包编排流程。
- 单镜画面问题(光不对/动作不实/角色不一致/构图弱)→ 对应的 `storyboard-*` 技法 skill。
- 端到端成片编排 → 交给上层成片编排入口,不在本 skill 范围。

## Quick Reference

| 资产 | 参考强度 | 负责 | 不负责 |
|---|---|---|---|
| 文字提示词 | **primary** | 故事因果、构图、动作、顺序、时长、导演调度 | 身份像素锚定 |
| 用户选定角色资产（大头照+全身照 / 多视图板 / 其它确认资产） | **hard** | 身份、脸、服装/产品核心外观 | 镜头顺序 |
| 干净关键帧/首尾帧 | **strong** | 当前片段的空间、构图、画质、起止状态 | 全片节奏 |
| 故事板/多宫格/美术设定板 | **atmosphere-loose** | 色彩、光线、材质、时代感、空间气质、视觉母题 | 故事/构图/动作/顺序/时长/身份 |
| 导演自由区 | **free** | 转场、微动作、运镜插值、粒子、节奏 | 改写核心剧情与身份 |

`primary / hard / strong / atmosphere-loose / director-free` 是**语义职责**，不是模型
API 权重。不要把 `70% / 20% / 1%` 写成仿佛可精确控制的参数；它本质是显式分工，
减少粗糙参考图与文字意图争夺控制权。

网格规格按**项目规划密度**选择，不等于单次视频时长：3×3 适合一场戏的 6–9 个节拍，4×4 适合长片段/整场总览。Seedance 单次生成仍按当前工具的 4–15s 限制拆成多个生成单元。

## 方法 ① · 用图像模型先做两类总览资产

### A. 序列网格故事板

需要先可视化故事结构或制作氛围参考时生成；它不是每个视频请求的硬前置。
工业化 21:9 导演工作台、红/蓝/绿方向箭头、角色/场景/分镜/备注五模块的完整
首选写法见 [GPT Image 故事板提示词三（首选）](references/gpt-image-industrial-storyboard-prompt.md)。

- **声明网格**:`Create a storyboard in a [3×3 / 4×4 / 4-column] grid format`(或 `Output as a single image`)。
- **声明阅读顺序**:`left-to-right, top-to-bottom reading order`。
- **每格 = 一个节拍**:`Each panel: [shot type] + [one action beat]`。
- **锁场景与角色**:`Consistent character design and scene across all panels`;在提示词开头固定 `Scene setting: [location], [time], [lighting direction], [fixed background]. Maintain unchanged across all panels.`
- **区分用途**:要直接拆格当关键帧时生成无字净版；要评审时可生成编号草板，但最终生产文字用本地确定性排版，避免乱码。

**通用网格模板(可填):**
```
Create a [N]-panel storyboard grid for a [length]-second [genre] film:
- [C] columns × [R] rows, left-to-right, top-to-bottom reading order
- Each panel: [shot type] + [one action beat]
- Location: [setting], Time: [day/night], Mood: [atmosphere]
- Consistent character design and scene across all panels
- Clean visual panels; no generated captions or production text
Output as a single image.
```

### B. 电影美术设定板

需要把故事脉络、机位、空间、材质和灯光放在一张 16:9 板上评审时生成。采用结构：

- 顶部：项目/场次标题。
- 左上：俯视平面图 + 机位方向。
- 右上：3×3 镜头对应缩略图。
- 中部：立面/剖面与人物尺度。
- 底部：材质、道具、灯光、色板。
- 侧栏：角色定位、剧情摘要、情绪递进。

图像模型负责**视觉底图与缩略图**；机位编号、尺寸、表格、长中文/日文说明由本地排版叠加，不能依赖图像模型生成可读生产文字。完整可填模板见 [电影美术设定板参考](references/cinematic-art-direction-board.md)。

## 方法 ② · 默认：提示词主导 + 整板氛围低约束

把整板作为全能参考中的氛围辅助图；即使板本身较粗，只要色彩/灯光/材质信号可读，
文字提示词仍可主导成片。板与身份或剧情冲突时不要硬用：

- `图片1/图片2`：用户选定的 identity-hard（可为大头照+全身照或多视图板）。
- `图片3` 干净关键帧：当前片段构图/画质 strong。
- `图片4/图片5` 故事板、多宫格或美术设定板：氛围 atmosphere-loose。
- 文字提示词主导故事、构图、动作、顺序、时长与导演调度。
- 允许模型自由设计机位、转场、微动作、运镜插值与特效，但不得改变角色身份、
  核心剧情因果和关键道具归属。

**必带前缀（有板即用；按实际素材删改，不照抄不存在的编号）：**
```
[提示词主导 / 氛围板低约束]
图片4、图片5 仅作氛围参考，只提取色彩、光线、材质、时代感、空间气质与视觉母题。
最终视频的故事因果、镜头构图、动作、顺序、时长与导演调度以本提示词为主；
不要求逐格一致，不复制网格布局、边框、编号、文字或拼贴版式。
图片1 / 图片2 是用户选定的角色主锚，锁定 <主体1> 的身份与妆造；图片3 如为干净关键帧则锁当前片段
画质与空间。导演可自由重构机位、转场、微动作、运镜插值与特效，保持身份连续、
动作自然、物理反馈可信、画面稳定、无无意字幕。
```

这实现了用户所说的“降低故事板权重”，但用的是**职责解耦**而不是伪造百分比；
它可能降低粗糙板对构图的负面牵引，不是保证更好结果的“欺骗参数”。

## 方法 ③ · 拆格精确执行

用户要求严格跟随某几格的构图/动作/顺序时，不要只塞整板：

1. **拆格**：裁出当前 4–15s 生成单元真正需要的 1–3 格，不要把 16 格全塞进一次生成。
2. **清理**：去掉边框、编号和文字，必要时重绘为干净关键帧。
3. **绑定**：每格分别绑定 `图片N`，写清“起点 / 关键动作 / 末态”；角色身份由
   用户选定的 identity-hard 资产负责。
4. **分段**：长片按生成单元分别出片，再用动作、视线、遮挡、构图或声音桥接剪辑。
5. **工程化**：两条路径的最终视频提示词都交 `sd2-pe` 覆盖八大要素、12 项内容
   与五大必备块再生成；复杂多镜/混合媒介任务加载 seedance-cinematic-format,
   轻量连续任务可跳过，输出标题与分段形式自由。

## Common Mistakes

| 错误 | 纠正 |
|---|---|
| 认为单帧与多宫格只能二选一 | 单帧负责身份/精确构图，整板负责氛围 |
| 把网格整图当唯一输入或 `firstFrame` | 整板只作 atmosphere-loose；身份和首帧用干净图 |
| 承诺模型会把一张网格可靠解析成 N 帧 | 松散指导可保留整板；精确执行必须拆格 |
| 用 70/20/8/1、<1% 冒充模型参数 | 改写为 primary/hard/strong/atmosphere-loose/director-free 职责 |
| 有故事板却没写提示词主导前缀 | 有板即用 mandatory 前缀，明确板只供氛围 |
| 要“导演自由”又要求逐格/逐像素复刻 | 先选松散指导或精确执行，不把冲突指令塞同一段 |
| 让图像模型生成关键生产文字 | 图像模型出视觉底图；标签、尺寸、表格本地排版 |
| 一格里塞多个动作 | 一格一镜一动作;复杂动作拆成相邻格 |
| 长提示词堆满场景细节 | 短而清的运动意图优先;细节交给关键帧 |
| 跳过 sd2-pe 直接生成 | 视频提示词最终必经 `sd2-pe` 工程化 |
