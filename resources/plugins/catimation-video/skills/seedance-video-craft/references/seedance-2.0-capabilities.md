# Seedance 2.0 能力与本 app 运行时限制

来源：公开技术资料 + 本 app `generate_video` 工具 schema。调用参数和枚举以本 app
运行时为准；公开资料中的内部机制和效果结论只作背景，不外推成单次任务保证。

## 一句话定位

Seedance 2.0 支持文本、图像、音频、视频参考，并可生成带音频的视频。本 skill
只依赖可观察接口能力，不把“单一架构/内部表示”当作提示词事实。

## 运行时参数表

| 维度 | 本 app 值 | 备注 |
|---|---|---|
| 生成时长 | **4–15 秒** | 短于 4s 的成片节拍先生成至少 4s 再后期裁切 |
| 输出分辨率 | **480p / 720p / 1080p** | 默认 720p；1080p 仅满血 `2.0`，Fast 不可用 |
| 输入模态 | 文本、图像、音频、视频 | 可混合 |
| 图像参考上限 | **9 张** | 全能参考配额 |
| 视频参考上限 | **3 段、合计 ≤15s** | 全能参考配额 |
| 音频参考上限 | **3 段、合计 ≤15s** | mp3/wav |
| 画幅 | **16:9 / 9:16 / 4:3 / 3:4 / 1:1 / 21:9** | 以工具枚举为准 |
| 变体 | Seedance 2.0 / Seedance 2.0 Fast | Fast 仅在用户明确要快/省时使用 |
| 模型 ID | `doubao-seedance-2-0-260128` | 参考，以本 app 实际配置为准 |

Skill 写作规范为 `@图片1 / @视频1 / @音频1`；工具边界规范就是同一形式 `@图片1 / @视频1 / @音频1`，
原样发给上游、不删 `@`（这是火山 OpenAPI 的提示词写法）。运行时唯一动的是工作台 chip 的
`【@图片1】` 外壳（解成 `@图片1`）；`@Image1`、`<图片1>` 等外部写法不会被替你改，重写时就写成规范形式。

## 编辑 / 操控能力

当前工具把以下任务统一走全能参考输入：

- **主体控制**：用参考图约束或替换人物/物体身份。
- **运动参考**：参考视频提供动作、运镜或节奏。
- **风格参考**：图像/视频提供色彩、材质、灯光或视觉语言。
- **视频延长/编辑**：源视频放入 `referenceVideos`，提示词明确延长或编辑目标。

这些能力不等于效果保证；参考之间冲突、动作过载或身份锚点不足仍会失败。

## 公开资料强调的改进方向

公开资料强调复杂交互、运动、物理合理性、长程一致性、视觉真实感、可控性与声画
协同有所改进。这里只把它们作为 QA 维度，不写“90% 首次可用率”或“必然不穿帮”
一类无法由当前任务验证的承诺。

## 证据边界

- 接口参数、枚举和上限：以本 app 工具 schema 为准。
- 导演参考、模型内部机制、训练数据与奖励模型：没有可核实来源时不作事实陈述。
- “比某模型更强”“某类动作成功率更高”：必须有具名基准与条件，否则改写为经验
  建议并要求实际出片验证。

## 可用于出片 QA 的维度

- 多模态参考是否各有明确职责，且没有互相争夺身份/构图控制权。
- 复杂动作是否保持主体身份、接触、重心、惯性与空间连续。
- 画面、动作音、环境声、对白/口型是否同步。
- 生成结果是否符合提示词与用户资产，而不是只符合笼统“电影感”。
