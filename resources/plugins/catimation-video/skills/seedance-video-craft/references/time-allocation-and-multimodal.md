# Seedance 2.0 时间切分 + 多模态参考绑定 + 案例库

> 来源:忠实移植自 updream `jimeng-prompt-pro`(Seedance 2.0/即梦 提示词助手)。
> 用途:把剧本/对白/参考图转成 Seedance 2.0 分镜提示词时,**按内容密度切时长**、**正确绑定 @素材**、并参照成熟案例配方。本文件只产出**文本提示词**,不调用生成工具(出片仍走本 app 的 generate_video)。

## 一、时间切分逻辑(最高优先级)

**禁止平均切分**,按内容密度分配:

| 场景类型 | 语速参考 | 时长分配 |
|---------|---------|---------|
| 普通对白 | 4–5 字/秒 | 按字数计算 |
| 快语速台词 | 6–7 字/秒 | 按字数计算 |
| 沉默/愣住/尴尬 | — | 1–1.5 秒静止 |
| 情绪转折点 | — | 0.5–1 秒过渡 |

- 默认按 **5 字/秒** 计算。计算示例:38 字台词 ÷ 5 = 7.6 秒。
- 总时长默认 15s,可指定 4–15s(Seedance 2.0 上限 15s)。
- 校验:所有分段时长之和 = 总时长;不得遗漏剧本任何一句台词。

## 二、参考图绑定规则(`<图片N>` / `@素材`)

- 用户上传第 1 张 → `<图片1>`(通常作首帧)
- 第 2 张 → `<图片2>`(角色参考)
- 第 3 张 → `<图片3>`(场景参考)
- 提示词中明确写出归属:`<图片1> 中的叶良辰(参考 <图片2>)`

## 三、物理动作替代抽象词

❌ 他很生气 / 她感到尴尬 / 气氛紧张
✅ 瞳孔收缩 / 狐耳垂下 / 嘴角漏出一丝玩味的笑容 / 身体不自觉后退 / 指尖微颤 / 眉间一道细纹骤然拧紧

> 与本 skill 正文及 `storyboard-video-prompt-optimization` 一致:用可见的物理反馈承载情绪。

## 四、镜头语言三要素(每段必含)

1. **运镜**:固定 / 缓慢推近(Dolly In)/ 平稳横移 / 面部特写 / 全景切近景 / 希区柯克变焦
2. **主体状态**:位置变化 / 神情演变(物理动作描述)
3. **环境氛围**:粒子特效 / 访谈灯光 / 修仙气焰 / 星空背景 / 背景虚化程度

## 五、多模态输入处理(最多 12 文件)

Seedance 2.0 支持图片/视频/音频混合输入。表达方式:

| 输入类型 | 提示词表达 |
|---------|-----------|
| 参考图(首帧) | `@图片1 作为首帧` |
| 参考图(角色) | `@图片2 参考角色形象` |
| 参考视频(运镜) | `@视频1 参考运镜效果` |
| 参考视频(动作) | `@视频1 参考打斗动作` |
| 参考音频(BGM) | `@音频1 用于背景配乐` |
| 视频延长 | `将 @视频1 延长 5s` + 生成时长选 5s |

> **入口选择**:多模态输入用**全能参考**入口;仅「首帧图 + 提示词」可用**首尾帧**入口。(配额上限以本 skill 正文「9 图 / 3 视频 / 3 音频」为准。)

## 六、输出结构

```
[一句话总览 + 素材引用说明 + 总体风格说明]。

0-X秒画面:[第一段]
X-Y秒画面:[第二段]
Y-Z秒画面:[第三段]
…

【多模态参考说明】(有视频/音频输入时补)
@素材名 的用途说明

【画质约束】
电影感画质、无字幕、无水印、角色面部一致性、专业补光

【Seedance 2.0 操作提示】
建议入口(全能参考/首尾帧)及 @素材 调用方式
```

## 七、工作流程

```
Step 1 解析输入:统计参考图数量+识别角色/场景图;提取台词逐句统计字数;确认总时长
Step 2 时间规划(深度推理):先标留白(沉默/转折)给 1–1.5s;按字数分配其余;验证总和=总时长
Step 3 构建提示词:总览+素材引用+风格 → 逐段 [起-止秒]+三要素 → 画质约束词
Step 4 输出:纯文本可直接复制;附「操作提示」(入口 + @素材 方式)
```

## 八、案例配方

- **反转剧情**:0–5s 古风特写绣花(@图片1)→ 5–10s 镜头快拉远露出摄影机/绿幕、BGM 戛然 → 10–15s 全景现代片场,导演喊卡,字幕揭示。
- **视频换人**:`将 @视频1 中的女生替换为 @图片1 的男生`,保留原运镜/动作节奏/构图/光影,人物边缘真实融合,不要换脸痕迹/跳变。
- **动作+运镜复刻**:主体 @图片1,完全参考 @视频1 的动作/节奏/推拉摇移/切换;补环境(舞台灯光/烟雾/LED)。
- **产品广告(15s)**:@图片1 产品主体 + @图片2 材质 + @视频1 商业运镜;0–3s 柔光浮现轮廓 → 3–7s 环绕切材质特写 → 7–12s 多角度旋转 → 12–15s 正面定格 + 品牌字幕。

## 严格禁令
- ❌ 遗漏任一台词;❌ 抽象情绪词代替物理动作;❌ 出现水印/Logo/字幕描述(除非剧情要求字幕);❌ 本文件阶段调用任何生成工具(只产文本)。
