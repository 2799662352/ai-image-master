# 30秒视频提示词 QA

## 硬门槛

任一适用项为“否”时，先修复再交付。

| 门槛 | 通过问题 |
|---|---|
| 成品可用 | 用户能否不补上下文，直接把正文粘贴到目标平台？ |
| 一行因果 | 能否用“任务→异常→选择→重释”一句话讲清？ |
| 复杂度预算 | 是否最多只有两个高风险变量，并且只有一个核心机制？ |
| 开场状态 | 第一秒是否有清楚人物、任务、物件或异常？ |
| 结束变化 | 结尾是否与开场可见不同，又没有开启第二个故事？ |
| 反转回看 | 反转是否使用已出现的空间、物件、关系或规律？ |
| 媒介一致 | 真人、2D或3D是否从头到尾保持同一媒介逻辑？ |
| 参考职责 | 每张图是否被检查、限定职责、保真度和污染项？ |
| 连续动作 | 手、脚、接触、重心、道具位置和不可逆状态是否前后连贯？ |
| 摄影机物理 | 能否按位置、高度、距离、轴线和前景实际摆放摄影机？ |
| 镜头动机 | 摄影机是否一次只执行观察、跟随、反应、揭示或停稳中的一种？ |
| 灯光动机 | 主要光线是否有场景内来源、方向和层次？ |
| 同步声音 | 声音是否对应可见事件，并在未明确要求时没有背景音乐？ |
| 定制禁令 | 禁止项是否针对本条最可能发生的失败，而非通用词堆砌？ |
| 无垫图纯净 | 文生视频正文是否完全没有图片、参考图、角色卡或外部文件引用？ |
| 即梦固定音频 | 即梦提示词是否包含规定的无背景音乐原文？ |

## 评分

每项0—2分：

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 高概念钩子 | 静态介绍 | 有异常但不清楚 | 第一秒出现清楚且可执行的异常 |
| 因果与节拍 | 堆事件或跳跃 | 大致能跟上 | 五段动作构成同一条因果链 |
| 复杂度控制 | 多场景多角色多规则 | 有一处过载 | 一个空间、任务、机制与反转 |
| 反转质量 | 突然新增设定 | 有惊喜但线索弱 | 使用既有线索完成回看重释 |
| 媒介原生 | 媒介漂移 | 标签正确但行为泛化 | 动作、材质和反转适合该媒介 |
| 参考与硬锁 | 图像污染或漂移 | 有锁但不完整 | 职责、污染项、优先级与状态清楚 |
| 动作物理 | 瞬移、滑步、断接触 | 基本连续 | 重心、惯性、接触与物件状态完整 |
| 摄影与空间 | 运镜词堆砌 | 有焦段或位置 | 机位、焦段功能、轴线和动机统一 |
| 光线与质感 | 只写“电影感” | 有光源但层次弱 | 来源、方向、曝光和媒介质感一致 |
| 声音与禁令 | 音画无关或泛化 | 基本相关 | 逐项同步并针对本条失败定制 |

重要成品至少17/20，且因果、复杂度、反转、参考/硬锁、动作物理不得为0。

## 常见症状与最小修复

| 症状 | 主要层 | 最小修复 |
|---|---|---|
| 30秒像预告片拼贴 | 因果/复杂度 | 删除一个场景、一个规则和多余转折，恢复单线任务 |
| 画面高级但没故事 | 钩子/选择 | 给主角一个可见任务，并让异常迫使一次选择 |
| 反转像硬塞 | 反转 | 在前14秒加入一个可见线索，结尾只重释该线索 |
| 人脸或服装变化 | 参考/硬锁 | 恢复原始身份锚点，排除其他图对脸和服装的控制 |
| 角色卡姿势被复制 | 参考职责 | 只保留身份与服装，明确忽略展示姿势与构图 |
| 画风突然真人或3D | 媒介 | 重申媒介原生动作、线条或材质，并禁止跨媒介 |
| 像幻灯片 | 动作/摄影 | 写重叠连续动作和一个响应事件的摄影机行为 |
| 运动物体瞬移 | 物理/状态 | 为每次出现补上一拍来源、接触、轨迹和落点 |
| 镜头很乱 | 摄影机 | 保留一个机位逻辑和一种主要行为，删除无动机绕拍甩镜 |
| “电影感”像广告棚拍 | 灯光/表演 | 加入真实任务、非摆拍重心和场景内光源，减少品牌词 |
| 负面词很长仍失控 | 禁令 | 删除无关禁词，只保留身份、媒介、物理、空间与本条专业风险 |
