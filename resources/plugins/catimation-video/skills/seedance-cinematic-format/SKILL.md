# Seedance Cinematic Prompt Format

<!-- skill-budget: fast -->

## 条件触发（复杂提示词结构叶子）
路径 B、多镜、混合媒介、需要展开导演/作品参考或用户明确要求完整结构时，与
sd2-pe 一起加载。路径 A 的轻量连续任务可跳过，由上游直接完成八大要素、
12 项覆盖清单和五大内容块。类别 reference 仍按需渐进披露。

## 角色与边界

角色：**纯知识辅助模块**，只提供内容要素、类别差异与完整性检查。

- 上游已经完成任务分类、素材编号、主体绑定和镜头规划(单镜/多镜)。
- 本模块不负责任务编排，不调用其它 skill、生成工具或 QA 工具。
- 本模块不能取代上游的任务正文，只负责补充复杂场景需要的稳定内容维度。
- Sora 资料只贡献“内容组织方法”；成品继续使用 Seedance 的素材语法、任务语义与约束。

## 不可遗漏的 12 项覆盖清单（形式自由）

加载本叶子时，最终提示词必须覆盖以下 12 项内容，但**不要求逐项写方括号标题，
不要求空行分块**。可以使用自然小节名、内联标签或连续散文；交付前能逐项定位
到有效内容即算覆盖。允许增补子项，不允许用新增内容替代既有要素。确实不适用
时可简写“无对白”“沿用源视频摄影/声音”“沿用已核实参考”，不要虚构要求。
下列方括号名称只是语义索引，不是强制输出模板。

```text
[任务与创作意图]
任务类型 / 类别 / 这段视频最需要传达的一件事。

[创作重心与自由度]
按 `prompt primary / identity hard / keyframe strong / atmosphere-board loose /
director free` 列出职责与可自由调整范围。上游收束权重块必须保留；百分比只
表达语义强调方向，不是模型参数或 API 控制项，并要同时转换成可执行职责。

[空间结构与主体绑定]
场景、时间、天气、主体位置关系，以及 <主体N>（参考 图片N）/ 视频N / 音频N 绑定。

[动作流程与镜头设计]
按因果顺序写动作、镜头顺序、单镜主运镜、景别与焦点变化。

[导演与参考系]
写导演意图、节奏、空间调度、情感表达、张力、摄影和声画联动。
导演名与参考作品不是固定清单：可按用户意图替换；归属没把握先检索核实
再落笔，不要凭记忆杜撰人名、职务或代表作。

[表演或运动系统]
真人写动机/调度/微表情；2D 写关键姿势/动画物理/中间帧；3D 写质量感/
惯性/绑定变形。三者都要写动作起因、过程、反馈与收势。

[视觉设计]
色彩、光源逻辑、空间层次、材质/线条、摄影或渲染观感。

[声音设计]
台词、环境声、动作音效、音乐进入/退出点、声画同步和对白可懂度。

[时空一致性]
主体身份、服装/材质、背景、光源方向、屏幕轴线、动作衔接、几何与深度连续。

[技术规格与约束]
时长、画幅、分辨率、风格锚定、画质/稳定/字幕/水印/Logo/多人防重复等约束。

[多粒度对齐检查]
粗粒度检查整体场景与情感曲线；中粒度检查每个角色/物体的动作关系；
细粒度检查台词-口型-表情、音效-动作、色彩/道具等关键细节是否落到画面。

[综合 Dense Caption]
用一段密集但不重复的总结串起：主体 + 空间 + 动作因果 + 情感曲线 +
摄影/动画/渲染方法 + 声音 + 一致性目标。
```

## 媒介 Profile 选择

真人、2D 动画、3D 动画是可组合的**媒介 profile**，不是互斥类别。先读最接近
任务的一份；混合媒介确有需要时再叠加另一份相关段落，不要机械堆满全部规则：

| Profile | 识别信号 | 读取 |
|---|---|---|
| 真人 | 真人表演、实拍、短剧、广告、纪录、摄影机/镜头语言 | [真人增量](references/live-action-film.md) |
| 2D 动画 | 日漫、国漫 2D、手绘、赛璐璐、逐帧、作画 | [2D 动画增量](references/2d-animation-film.md) |
| 3D 动画 | CG、3D 国漫、PBR、角色绑定、三维渲染、虚拟制片 | [3D 动画增量](references/3d-animation-film.md) |

“电影 / 电影感 / 电影级”是**检索与创作意图词**：它提示上游调查镜头、调度、
灯光、声音、剪辑或叙事方法，但不是独立 profile。混合媒介允许组合，例如
“真人表演 + 2D 涂鸦叠加”或“2D 角色 + 3D 场景”；只在规则冲突时确定主体媒介，
避免把 2D 演出性形变与真人/3D 几何约束互相覆盖。

## 语言建议

- **日式 2D 动画**：面向日本受众或用户明确要求时优先用自然日语正文。
- **真人、3D 动画**：需要精确技术词时优先中文 + 英语混合；中文负责叙事、
  表演、主体绑定和约束，英语负责摄影、灯光、材质、绑定和渲染。
- 这些只是默认建议，不是硬约束；用户明确指定语言时始终服从用户。
- **台词沿用用户提供或素材中的语言**。中文保持中文，日文保持日文；未指定时
  按请求文本、角色设定、源音频与目标受众判断，除非用户要求，否则不擅自翻译。
- 素材 token 原样保留，同一信息不做重复双译；语言变化不能漏掉 12 项内容。

需要查看完整覆盖示例时读取[输出覆盖参考](references/prompt-output-template.md)。
该文件只提供内容索引和语言占位，标题可改可并；不能替代上游已经完成的素材映射、
镜头规划内容或用户原话。

## 动态参考与优先级

1. 先提炼用户真正的创作意图，再决定导演、作品和技法参考。
2. 用户指定导演/作品时，保留其意图，但只写可核实的技法特征。
3. 用户未指定时，主动检索并核实 **2–3 个**贴合意图的真实导演/作品参考候选，
   各附一句适配理由**供用户挑选**（默认推荐首选，用户不选或要求直出时用
   推荐项继续）；某条归属查无实据就换成可核实的其它参考，规格不降。仅当
   检索工具完全不可用时，才写“长焦压缩 + 克制调度 + 环境声主导”这类
   无归属可执行描述。
4. 优先级必须随任务调整；内容要素不能因优先级降低而消失。
5. 故事板/多宫格与文字冲突时，文字提示词主导故事、动作、构图、顺序和时长；
   身份锚点与干净关键帧分别保住身份和当前片段画质/空间。
6. 多参考图按五类职责声明，避免互相争夺控制权：
   - **prompt / primary**：文字提示词决定故事因果、镜头构图、动作、顺序、时长
     和导演调度。
   - **identity / hard**：用户选定的角色资产（大头照+全身照、三视图/四视图/
     多视图角色板或其它确认资产）或产品主图，锁身份与核心外观。拿不准时询问用户。
   - **keyframe / strong**：干净关键帧、首帧、尾帧，锁当前片段空间、构图与画质。
   - **atmosphere-board / loose**：故事板、九宫格/多宫格和电影美术设定板只提供
     色彩、光线、材质、时代感、空间气质与视觉母题。整板不作 `firstFrame`，
     不复制边框、编号、文字或拼贴版式，也不要求逐格一致；需要精确复刻时先拆格
     并清理成干净关键帧。
   - **director / free**：转场、微动作、运镜插值、节奏、粒子与特效可补完，
     但不能改写身份、核心剧情因果或关键道具归属。

只要出现 atmosphere-board，正文前必须先输出上游定义的“提示词主导 /
氛围板低约束”职责前缀；这是有板即用的必填段，不是可选建议。

永不降级、每次高规格：`[导演与参考系]` 每次都要有已核实的真实参考，不因
任务简单缩水。人名、作品、职务归属没把握就按[分类调查方法](references/research-methods.md)
走全流程核实再落笔。已核实的知识要**复用**：先查项目参考知识库与本会话
调查回执，命中直接引用、不重复检索；未命中再检索，新回执写回知识库。
查无实据的归属换成可核实的其它参考；禁止凭记忆杜撰，也不把社区归因当成
官方事实。

## 从 Sora 规则吸收什么、不照搬什么

吸收 `.cursor/rules` 与用户实测模板中稳定有效的结构思想：

- 四视角 structured caption：空间结构、动作流程、情感方向、技术规格。
- 粗/中/细三层文本-画面对齐。
- 导演描述七槽位与动态参考替换。
- 时空一致性、声音同步、类别化运动系统和最终 Dense Caption。

不照搬模型专属或成本失控的规则：

- 不对任何媒介固定语言；日式 2D 的日语、真人/3D 的中英混合都只是默认建议。
- 不把固定时长或 70/20/8/1 等百分比冒充 API 参数；上游要求的收束权重作为
  **语义方向**保留，并用可执行职责解释每个比例如何影响取舍。
- 不强塞固定导演、作画师或作品名单；真实归属需要核实。
- 不照搬“每次从零重查”的成本模式：检索规格不打折，成本靠**复用**摊薄——
  已核实参考进知识库，后续任务先查库再上网，不重复核实同一归属。
- 不把“每帧必须高运动”或屏幕变化百分比当硬指标；运动强度由叙事意图决定。
- 不把 Sora 专属能力、参数或结论冒充成 Seedance 能力。

## 完整性自检

交付前逐项检查：

- 12 项通用内容均有有效落点；允许“无对白 / 无音乐”，但不能直接省略声音设计。
- 原有素材编号、主体标签、任务句式和镜头规划信息均未丢失。
- 已选择与任务有关的媒介 profile；混合使用时没有互相冲突。
- 角色/物体在粗、中、细三个粒度都有可见落点。
- 动作有起因、连续过程、环境反馈和收势，不是形容词堆叠。
- `[导演与参考系]` 非空且高规格：有已核实的真实参考(仅检索工具不可用时
  才是无归属技法)；新核实的回执已写回参考知识库供复用；导演与参考作品
  可替换且服务于意图，不把固定名单当质量咒语。
- 2D 的演出性变形与真人/3D 的几何连续性只在对应主体上生效，没有互相污染。
