# 2D 动画格式增量

本文件只补充 2D 动画 profile 的写法，**不得删减通用骨架字段**。它可以与真人
或 3D 规则按需组合；“电影 / 电影级”只作为调查演出、摄影与声音方法的检索意图
词。素材绑定、路径 A/B、任务句式和兜底约束继续以上游结果为准。

## 语言建议（不是硬约束）

- **日式 2D 动画在用户明确要求或面向日本受众时优先使用自然日语正文**；
  其它情况服从用户指定语言与项目语境。字段名可保留中文以维持稳定结构。
- 动画技法优先使用准确日语，如「レイアウト」「間」「タメとツメ」
  「フォロースルー」「撮影処理」；不确定的术语用可执行动作描述，不生造日语。
- **台词沿用用户提供或素材中的语言**：中文保持中文，日文保持日文；未指定时
  按角色、源音频和目标受众判断，除非用户要求，否则不擅自翻译。
- 素材 token、主体标签和 `@图片N / @视频N / @音频N` 原样保留。

## 类别目标

把动画的“演出性变形”与“身份/空间连续性”分开：静态识别特征、角色关系和
空间因果必须稳定；姿势、透视、速度、残影和形状允许为导演意图服务。
动画物理追求**说服力大于现实物理准确性**，但不等于随机崩坏。

## 建议创作重心

百分比是语义强调度，不是模型参数，可随用户意图调整：

```text
导演意图与情感曲线 30% / 作画与关键姿势 25% / 动画物理 15% /
身份及时空连续 15% / 摄影色彩声音 10% / 参考作品 5%
```

用户强调角色还原、分镜或动作时可提高对应项；其它字段仍要保留。

## 各字段的 2D 增量

### [任务与创作意图]

- 明确这一段动画要放大的情感、冲突或视觉奇观。
- 用“平静 → 察觉 → 爆发 → 余韵”等可见状态变化替代抽象主题口号。

### [空间结构与主体绑定]

- 固定发型轮廓、服装配色、标志配饰、身高关系和关键道具。
- 写清前中后景、角色站位和剪影关系；演出性透视变化后要回到可识别空间。

### [动作流程与镜头设计]

- 给出预备姿势、关键姿势、极端姿势、缓冲/收势和环境二次运动。
- 一镜一主运镜；镜头加速、旋转或透视夸张必须有明确情绪/冲击意图。
- 不强制绝对秒数，按镜头顺序和动作节拍组织。

### [导演与参考系]

使用七个槽位组织，导演与参考作品**可替换**：

```text
演出逻辑 / 节奏 / 空间调度 / 情感表达 / 张力释放 / 摄影机运动 / 声画联动
```

用户点名作品/人员时先核实其真实职务与技法；否则写“强剪影关键姿势、
长停顿后瞬时爆发、空间压缩”等技法，不杜撰归属。

### [表演或运动系统]

- 动画物理允许拉伸、挤压、残影、透视压缩和超越关节范围的演出性形变。
- 形变必须有起势、方向、力线、冲击点和恢复，不能把崩脸/断肢误当风格。
- 中间帧保持动作轨迹、角色身份、配色和体积趋势连续。
- 头发、衣摆、烟尘、光效等二次运动要响应主体速度和方向。

### [视觉设计]

- 明确线条特征、赛璐璐明暗层级、色块关系、背景绘制与摄影合成。
- 要求纯 2D 时显式排除厚重 3D 塑料感、纹理漂移和无意的写实皮肤。
- 光影、特效和镜头模糊服务关键姿势，不遮掉脸与轮廓识别点。

### [声音设计]

- 用户给定语言的台词与口型开合、表情变化和身体动作同步。
- 冲击音落在接触帧，预备动作可用短暂静音或吸气建立张力。
- BGM 节拍可辅助动作节奏，但不要求每个动作都机械踩点。

### [时空一致性]

- 锁定身份、服装、道具、背景方位、光源逻辑与动作因果。
- 允许演出性变形，但变形前后必须回到同一角色和同一空间。
- 关键帧之间的运动轨迹连续，不突然换手、换方向、换站位或换造型。

## 2D Dense Caption 公式

```text
[キャラクターと2Dアイデンティティ] は [階層化した空間と立ち位置] に位置し、
[演出意図と感情曲線] に沿って [予備動作 → キーポーズ → 極端姿勢／衝撃 →
フォロースルー] を連続して行う。[線・セル影・色彩・単一の主カメラワーク] と
[演出的な変形・二次動作] で説得力を作る。{ユーザー指定言語の台詞}、SE、BGM
をキーポーズと同期し、アイデンティティ、配色、道具、空間、中割りの連続性を
維持する。
```

## 类别检查

- 演出性夸张是否有意图和恢复，而不是随机崩坏？
- 是否写出预备、关键、极端和收势姿势？
- 身份、配色、道具、空间与中间帧是否连续？
- 线条、赛璐璐、背景与摄影合成是否明确？
- 导演与参考作品可替换并服务意图，而不是固定名单？
