# 真人格式增量

本文件只补充真人 profile 的写法，**不得删减通用骨架字段**。它可与 2D/3D
视觉元素按需组合；“电影 / 电影感”只作为调查摄影、调度、声音与叙事方法的
检索意图词。素材绑定、镜头规划、任务句式和兜底约束继续以上游结果为准。

## 语言建议（不是硬约束）

- 需要精确技术表达时优先使用**中文 + 英语混合**：中文负责故事意图、表演动机、
  主体关系、素材绑定和硬约束；英语负责 camera/lens、blocking、lighting、
  texture、sound design 等影视技术词。用户指定其它语言时服从用户。
- 不做逐句机械双译，同一信息只写一次，以最准确、最可执行的语言表达。
- **台词沿用用户提供或素材中的语言**：中文保持中文，日文保持日文；未指定时
  按角色设定、源音频和目标受众判断，除非用户要求，否则不擅自翻译。

## 类别目标

把“像电影”拆成可执行的表演、调度、摄影、光线、材质和声音指令。真人质感
来自有动机的行为与镜头观察，不来自“8K、大片感、顶级质感”等空泛形容词。

## 建议创作重心

百分比是语义强调度，不是模型参数，可随用户意图调整：

```text
导演意图与叙事 30% / 人物表演 25% / 时空连续 20% /
摄影与光线 15% / 声音 5% / 参考作品 5%
```

用户明确要求构图、身份或广告产品准确时，提高相应项；其它字段仍要保留。

## 各字段的真人增量

### [任务与创作意图]

- 一段只设一个主要戏剧动作：试探、隐瞒、决定、告别、发现等。
- 写清观众应该先看到什么、最后意识到什么。

### [空间结构与主体绑定]

- 说明人物前后左右、视线方向、可行动区域和关键道具。
- 多人场景固定屏幕轴线与进出画方向，避免跳轴和角色换位。
- 真人脸素材受限时，沿用上游可用的虚拟身份锚点，不绕过平台约束。

### [动作流程与镜头设计]

- 每个动作写“动机 → 预备 → 执行 → 物理反馈 → 收势”。
- 一镜只保留一个主运镜；焦段、机位、景别和焦点变化服务于戏剧意图。
- 简单单镜也要写可见的前后变化，避免只写“站着说话”。

### [导演与参考系]

使用七个槽位组织，导演与参考作品**可替换**：

```text
演出逻辑 / 节奏 / 空间调度 / 情感表达 / 张力释放 / 摄影机运动 / 声画联动
```

若人名或作品未经检索核实，不写“某导演风格”，直接写可执行技法。不要把真实
导演、摄影师或作品名当作不可替换的固定咒语。

### [表演或运动系统]

- 用处境和动机驱动表演：角色为何做动作、做完后身体与环境如何回应。
- 情绪改写为微表情和身体细节：呼吸、视线停留、吞咽、肩背张力、手指动作。
- 避免同一时刻让脸、手、身体和镜头都做高强度运动。

### [视觉设计]

- 写主光来源、方向、软硬、色温倾向和环境反射；保持光源逻辑连续。
- 区分皮肤、头发、布料、金属、玻璃等材质的反光与运动反馈。
- 可写镜头感：长焦压缩、广角近距离、浅景深、焦点转移、轻微手持等。

### [声音设计]

- 用户给定语言的台词包含说话者、语气、空间位置；对白期间让 BGM/SE 让位。
- 环境声建立空间，动作音与接触瞬间同步，避免画面有动作但声音无反馈。
- 无对白也明确写“无对白，以环境声和动作音推进”。

### [时空一致性]

- 锁定脸、发型、服装、道具持有关系、屏幕轴线、光源方向和场景布局。
- 动作速度、惯性、重心、接触和遮挡遵循真实世界的可观察反馈。
- 非刻意转场不允许背景、时间、天气或人物位置突然跳变。

## 真人 Dense Caption 公式

```text
[人物及身份锚点] 在 [时间/空间/位置关系] 中因 [动机] 完成
[动作因果链]；camera observes with [shot size / lens compression /
single primary move / focus transition]，[key light / color contrast] 塑造
[情绪曲线]，{用户给定语言的台词}、ambience、SE 与动作同步；
全程保持 [身份/轴线/道具/光源/物理反馈] 连续，达到 [交付规格与约束]。
```

## 类别检查

- 表演是否由动机驱动，而非“微笑、转头、走路”的空动作？
- 人物是否有稳定站位、视线和屏幕轴线？
- 光线、材质、重心、接触和环境反馈是否可信？
- 对白、口型、表情和环境声是否同步？
- 导演与参考作品可替换并服务意图，而不是固定名单？
