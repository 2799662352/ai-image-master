# 3D 动画格式增量

本文件只补充 3D 动画 profile 的写法，**不得删减通用骨架字段**。它可与真人
表演或 2D 表面风格按需组合；“电影 / 电影级”只作为调查调度、镜头、灯光与声音
方法的检索意图词。素材绑定、镜头规划、任务句式和兜底约束继续以上游结果为准。

## 语言建议（不是硬约束）

- 需要精确技术表达时优先使用**中文 + 英语混合**：中文负责故事意图、主体关系、
  资产绑定与约束；英语负责 camera/lens、rigging、PBR/NPR、materials、
  lighting、rendering 等三维技术词。用户指定其它语言时服从用户。
- 不做逐句机械双译，同一信息只写一次，以最清楚的语言表达。
- **台词沿用用户提供或素材中的语言**：中文保持中文，日文保持日文；未指定时
  按角色设定、源音频和目标受众判断，除非用户要求，否则不擅自翻译。

## 类别目标

把 3D 电影感落实为稳定几何、角色绑定、质量惯性、PBR 材质、灯光与摄影。
造型可风格化，但网格体积、骨骼关系、材质归属和空间深度必须连续，避免
“模型融化、贴图游泳、材质跳变、关节穿插”。

## 建议创作重心

不用固定百分比。按任务写有序职责：

1. `identity-hard`、几何/骨架/材质归属和核心剧情因果不可改。
2. 导演意图决定调度、动作取舍与视觉焦点。
3. `keyframe-strong` 锁当前片段空间/构图/画质；绑定、接触、质量和惯性保持可信。
4. 材质灯光渲染、摄影声音和已核实参考为上述目标服务。
5. 转场、微动作、相机插值、粒子与节奏属于 `director-free`，但不能导致拓扑/身份漂移。

用户强调角色还原、动作、产品材质或特定构图时调整顺序；其它字段仍要保留。

## 各字段的 3D 增量

### [任务与创作意图]

- 明确是角色表演、动作、产品展示、奇观或环境叙事。
- 写清视觉焦点如何从开始状态变化到结束状态。

### [空间结构与主体绑定]

- 固定角色比例、脸部体块、服装/盔甲层级、道具归属和场景尺度。
- 写清坐标关系、前中后景、遮挡、接触面和相机可移动区域。

### [动作流程与镜头设计]

- 动作写“重心准备 → 发力 → 位移/旋转 → 接触反馈 → 惯性衰减 → 收势”。
- 一镜一主运镜；相机路径、速度变化和焦点跟随必须连续。
- 高速动作保留清晰剪影，避免身体与相机同时无规则高速旋转。

### [导演与参考系]

使用七个槽位组织，导演与参考作品**可替换**：

```text
演出逻辑 / 节奏 / 空间调度 / 情感表达 / 张力释放 / 摄影机运动 / 声画联动
```

参考作品只用于提炼可执行的镜头、造型、材质、灯光或动作原则。未核实来源时
直接写技法，不给真实人员强行归因。

### [表演或运动系统]

- 角色动作遵循骨骼层级、关节方向、重心转移和重量感。
- 面部表演保持五官拓扑和体积，表情变化不能引发脸型、年龄或身份漂移。
- 布料、头发、软体、粒子和刚体对主体运动有延迟与惯性响应。
- 风格化 squash/stretch 可以存在，但网格必须可恢复且不穿模。

### [视觉设计]

- 明确材质类别及其 roughness/metallic/transmission 趋势。
- key light、fill light、rim light 和 environment reflection 保持逻辑连续。
- 写清写实 PBR、风格化 NPR、黏土或低多边形等单一渲染方向。
- 保持 topology、texture/UV、surface details 和 shadow attachment 稳定。

### [声音设计]

- 脚步、碰撞、机械、布料和环境声匹配材质、质量与空间距离。
- 用户给定语言的台词与口型、表情、头部运动和声源位置同步。
- 空间混响体现房间尺度；BGM 不掩盖关键动作音和对白。

### [时空一致性]

- 锁定 geometry volume、skeleton proportion、material ID、texture、
  prop parenting 和 light direction。
- 保持深度、透视、接触、遮挡、阴影和反射连续。
- 禁止 mesh melting、limb intersection、texture swimming、material popping、
  joint inversion 和无因位移。

## 3D Dense Caption 公式

```text
[3D 主体与身份/几何锚点] 位于 [尺度明确的三维空间与位置关系]，
围绕 [导演意图] 完成 [重心准备 → 发力 → 位移/接触 → 惯性衰减 → 收势]；
camera uses [shot size / lens language / continuous path / focus tracking]，
[PBR or NPR materials + lighting + rendering look] 塑造 [情绪曲线]，
[用户给定语言的台词/SE/BGM] 与质量和空间同步；全程保持
[geometry/skeleton/material/texture/depth/light] 连续，满足 [交付规格与约束]。
```

## 类别检查

- 几何、骨架、材质、贴图和道具归属是否稳定？
- 动作是否有重心、质量、接触、惯性和收势？
- 灯光、阴影、反射、深度与遮挡是否连续？
- 是否明确 PBR/NPR 等单一渲染方向并避免材质冲突？
- 导演与参考作品可替换并服务意图，而不是固定名单？
