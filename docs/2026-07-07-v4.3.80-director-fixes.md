# v4.3.80 发版说明(2026-07-07)

导演台(Director)大版本修复与体验升级。上一版 v4.3.79 只包含 Codex 0.142.5 +
gpt-image-2 渠道,本版把此后积累的全部导演台修复一次性发出。

## 3D 渲染(大模型虚化/闪动)

- **模型归一化**(`normalizeModel`):导入的大尺寸模型自动缩放到合理舞台尺度,
  消除超大包围盒引发的深度精度崩坏(虚化/不可视)。
- **相机近平面自适应**(`adaptCameraNear`):按场景包围盒动态调整 near/far,
  抑制 z-fighting 像素闪动。
- **材质加固**(`hardenImportedMaterials`):导入材质统一双面/去透明度陷阱,
  避免面片消失。

## 无限网格

- 网格平面顶点跟随相机 XZ 平移(Fyrestar InfiniteGridHelper 同款):镜头移到
  哪里,地面就铺到哪里,视觉上真·无限;网格线仍锚定世界坐标,不随相机漂移。
- 淡出改以相机为中心(不再以世界原点),`fadeStart/fadeEnd` 40/220 → 160/900;
  次级细线提前淡出防摩尔纹。

## 录制视频(关键帧运镜)

- **时长可调**(1–3600s),不再固定 8s;导出时长 = 关键帧首→末跨度,与时间轴
  严格一致。
- **预览只播关键帧区间**,不再包含首尾空白段;支持**循环预览**(🔁 按钮,默认开)。
- **画幅比例与机位页共用** `directorAspect`(全屏/1:1/4:3/3:4/16:9/9:16/3:2/2:3/21:9):
  - 主屏安全框改 JS contain 适配 —— 竖版(9:16 等)不再被 CSS maxHeight 压成宽扁形;
  - Preview 缩略图画布跟随所选比例(横版贴宽/竖版贴高,不拉伸变形);
  - 比例下拉不再被 Preview 面板 `overflow:hidden` 裁掉后半截;
  - 导出视频按所选比例**居中裁剪**(与安全框预览一致),不再忽略比例。

## 镜头库(通用格式导入/导出/预设)— 新功能

录制时间轴新增「🎥 镜头」按钮,打开镜头库弹层:

- **通用格式导入**:支持 4 种来源,网上找到的镜头动画可直接用 ——
  - `glb / gltf`:glTF 2.0 相机动画(**事实标准**;Blender「导出 glTF 2.0 +
    勾选 Cameras」、C4D/Maya 烘焙相机均可)。导入时用 AnimationMixer 逐时刻
    烘焙**世界**位姿采样 —— Blender 导出的相机几乎总被包在动画父容器里
    (three.js 论坛 #2612/#29085 经典坑),直读轨道会错,烘焙采样永远正确;
  - `fbx`:FBXLoader 同款烘焙采样;
  - `json`:`director-camera@1` 包裹(本软件导出)或**裸 AnimationClip JSON**
    (three.js 生态标准序列化,轨道名任意节点前缀均可);
  - glTF 核心规范相机 FOV 不可动画化 → FOV 从相机定义读常量;烘焙相机每帧一键
    的会自动抽稀到 ≤120 关键帧,保持可编辑。
- **导出**:当前运镜一键导出 `.json`(标准 AnimationClip 序列化,可再导入本软件
  或供 three.js 项目直接 `AnimationClip.parse`);也可「存入我的镜头」。
- **我的镜头**:导入的镜头统一标准化为 director-camera@1 JSON 落 IndexedDB
  持久化,跨会话可用;点击装入,可删除。
- **8 个镜头预设**:环绕 360°/180°、推近/拉远 Dolly、升/降 Crane、横摇 Pan、
  后拉揭示 —— 全部以「当前相机位姿 + 注视目标」参数化,所见即基准。
- **拖入时间轴**:预设/我的镜头卡片可直接**拖到时间尺**,落点时刻插入,关键帧
  (◆)全部显示在轨道上可逐个编辑(点选 seek / 双击删除);落点区间内旧关键帧
  自动让位;点击卡片 = 覆盖整条时间轴。
- 装入的镜头超出时间轴时长时自动加长时间轴。

## 动画拖入 K 动画时间轴 — 新功能

- 右栏「动画」页的**动画库卡片**与**我的动画卡片**可直接拖到 K 动画时间尺:
  在选中的高级假人上临时跑 mixer,按 4Hz(上限 20 帧)把动画采样成**姿势关键
  帧**插入落点,逐帧可编辑(选中→摆姿→更新/删除);采样完自动恢复原姿势,
  不改现场。
- 新增 stage 能力 `sampleAnimToPoseKeys`(fbx/glb/gltf/json 全格式,走既有
  `loadAnimClip` + 骨骼名重定向通路)。

## K 动画(姿势关键帧)

- **预览无缝循环**:预览剪辑只编译关键帧首→末区间(LoopRepeat 播到末帧立即回
  首帧)。此前剪辑编译到完整时长(如 8s),关键帧只到 3.7s 时后半段冻在末姿势,
  看起来像"播完停住"。导出 .json/.glb 仍用完整时长,不受影响。
- 时间尺 scrub / 游标同步按区间换算。

## UI 层次与交互

- 录制/K 动画时间轴 zIndex 40/42 → **10**:低于底栏弹出面板(假人/镜头/机位),
  录制中打开弹层不再被时间轴盖住点不到。
- 底栏「添加模型 / 普通假人 / 高级假人」三个下拉**互斥打开**,不再互相叠压。
- 右栏面板在录制/K 动画模式下让出底部 150px:「加载更多」等底部按钮不再被时间
  轴挡住。
- **点空白处取消选中**:单击(位移 < 4px)空白即 `deselectAll()`;拖动旋转视角
  不误清选区。
- 导演台 **AGENT 按钮**修复:`features/agent-chat` 改静态导入(动态 import 被
  Rollup chunk 合并后命名导出损坏,点击报 `syncAgentHostIntoFullscreen is not a
  function`)。
- **ImageViewer 全屏可见**:模态挂到 `document.fullscreenElement`(fallback body),
  全屏状态变化时自动重挂 —— MCP 截图在导演台全屏下正常弹出,不再压在底层。
