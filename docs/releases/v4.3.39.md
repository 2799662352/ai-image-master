# v4.3.39 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub 源码同步
> 上一个发布版本:v4.3.38

## 概览

本次为 Seedance 视频生成的默认策略调整,以及交互式 `ask_user` 头脑风暴卡片的引导精修。

## 变更

### Seedance 默认改用满血版 2.0
- 默认模型由 `2.0-fast` 改为 **`2.0`(满血版,`doubao-seedance-2-0-260128`)**,仅在用户明确要求快/便宜/草稿时才用 `2.0-fast`。
- 单次视频时长范围由 `3–12s` 放宽为 **`4–15s`**(默认 5s)。
- 分辨率默认保持 **720p**,不再擅自跳 1080p;规格未明确时,生成前用 `ask_user` 卡片主动与用户确认分辨率 / 时长 / 画幅。
- 同步更新 `catimation-video` 技能文案与 `generate_video` 工具描述。

### `ask_user` 头脑风暴卡片精修
- 去除选项数量的隐性「4 个上限」:卡片可承载按需 3–6、最多 8 个选项(代码本无 cap,系技能措辞导致)。
- 大多数情况下提出 方案 / 方向 / 选项时优先用单张可点击卡片而非纯文本编号列表;非绝对强制(纯讨论 / 迭代阶段可留文本)。
- 同步更新 `catimation-brainstorm` 技能与 `ask_user` 工具描述(描述仍 ≤500 字符,遵循渐进式披露)。

## 测试
- `videoTools` / `taskManager` / `firstPartySkills` / `askTools` 单测全部通过;时长边界(4/15 通过、3/16 拒绝)与 1080p 守卫测试同步更新。

## 升级方式
- 桌面端将通过 COS 热更新自动检测并下载 v4.3.39。
- 手动:重新下载安装包 `catimation-cyberpunk-master-4.3.39-setup.exe`。
