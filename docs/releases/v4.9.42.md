## 概述

两件事:

1. **视频工作台接入 Roneyun-cn 渠道,模型选择改成「渠道 → 模型」两级面板**(#461):新增 `cn-seedance-2.0` / `cn-seedance-2.0-fast` / `cn-seedance-2.0-mini` / `cn-seedance-2.5` 四个模型,工作台卡片、Codex 聊天的 `generate_video`、`video_workbench_*` 的 MCP 工具都能选到。
2. **视频相关技能补上 cn 模型的说明**(#462):`catimation-video`、`catimation-video-workbench`、`sd25-pe` 的正文原来一个字没提 cn 模型,agent 能选到却不会按同名模型挑对提示词底座。随 app 内置的技能已更新;插件商城与技能商城另走一条通道,已在发版前发布(#463 回写发布状态)。

## 变化

### Roneyun-cn 视频渠道(#461)

- 四个模型的别名就是网关上的模型名;时长、分辨率、素材上限、编辑 / 延长等能力照火山同名模型填,**与网关实测不一致的三处以网关为准**:
  1. **素材只收公网链接**:不登记、不核验人像库。卡片上已有的 `asset://` 在提交前换回公网地址,换不出来就整单拦下并说明是哪几个,一个 id 都不会发出去;本地文件一律先中转成公网链接,不走 base64 内联;传输层还有最后一道检查。
  2. **没有样片**:网关对 `draft` / `draft_task` 直接返回 400(未扣费)。
  3. **没有联网搜索**:网关对 `tools` 直接返回 400;卡片上联网开关默认开,提交时按能力表过滤,不会把 `tools` 发出去。
- 平台余额与自填 Miau Key 两个钱包都走 Miau 网关;价格表按生产价目与网关价目表填(与火山同名行同档)。
- **模型选择改成两级面板**:左栏是渠道(带数量,当前模型所在渠道有圆点),右栏是该渠道的模型;悬停、点击、键盘都能切换渠道;Esc、点面板外、失焦、缩放、面板外滚动都会关闭。分组与叫法从能力表现算,以后加模型只要在能力表登记渠道。
- 任务详情「上游」对 Roneyun-cn 显示 Roneyun-cn。
- MCP:`generate_video` / `video_workbench_*` 的说明与枚举补上 `cn-seedance-*`;各工具 schema 体积均在 16384 B 上限内。

### 视频技能与商城(#462、#463)

- `catimation-video`:提示词底座映射加上 cn(`cn-seedance-2.5` → `sd25-pe`;`cn-seedance-2.0` / `-fast` / `-mini` → `sd2-pe`);新增一段说明 cn 是「同名模型的第二条线路」,只有三处不同(只收公网链接 / 没有样片 / 没有联网);**用户点名 Roneyun-cn 才传 `cn-seedance-*`,不替用户换渠道**;cn-2.0 的 1080p、cn-2.5 的编辑 / 延长没实测过,要如实说。
- `catimation-video-workbench`、`sd25-pe`、`resources/plugins/AGENTS.md`、两个 session-start 钩子同步映射与「无样片 / 无联网」。
- 商城:插件 `catimation-video` 1.0.48 → 1.0.49,单技能 `sd25-pe` 1.0.7 → 1.0.8,已发布到 COS;重新下载两个 zip,sha256 与线上 catalog 一致,解开后含 `cn-seedance`。
