# v4.9.25 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.24

## 概述

两件事,都在**视频工作台**:**① 云备份 + 云端回收站:剧自动备份到云端,本地删掉后云端还留一段时间,能找回;② 素材预传地址持久化:重启后素材不再退回本地路径、也不再重复上传。** 起因是有同事本地数据丢了,没有任何可恢复的副本。

## 变化

- **剧云备份**(默认开启,登录后自动运行):
  - 备份的是剧的工程文件(卡片、提示词、参数、素材和结果的 **URL**),**不上传本地素材**。只有本地路径、没有 URL 的素材 / 结果会被跳过,界面会提示数量,这类内容请用「导出当前剧」另存。
  - 静默 30 秒后上传,最长 5 分钟必上传一次;只传有变化的剧,服务端按内容哈希去重;每部剧云端保留最近 5 份。
  - 剧栏新增「云备份」按钮和状态点;弹窗里可以开关自动备份、立即备份、查看云端剧列表、**把云端最新一份恢复为新剧**(同名自动改名,不覆盖本地)。
  - 服务端是独立的私有存储桶,按登录账号隔离,不碰业务数据库。
- **回收站**:保留期 **本地 30 天 + 云端再 30 天,最长 60 天**。
  - 本地把剧删到回收站后,云端活副本也会移进**云端回收站**;云端回收站里可以恢复,也可以永久删除。
  - 本地回收站里的剧 **30 天后自动清除**,弹层里显示「还剩 N 天」。升级前已经在回收站里的旧条目,**从升级那天起算 30 天**,不会升级当天被清空;系统时钟回拨不会提前清。
  - 本地「彻底删除」会同步把云端剩余期限收紧到 30 天以内;没备份过的剧彻底删除后无法恢复。
  - **不会静默复活**:如果云端回收站里已经有同一部剧,别的设备再上传它会被拦下,备份弹窗里列出冲突,由你明确选「保留这份」才恢复备份。
- **素材预传地址持久化**:卡片素材预传到云端后的地址现在会随剧保存,**重启后素材不再回到本地路径、也不再重复上传**。水合时先校验本地文件有没有变(大小 + 修改时间),提交前再确认云端地址还有效;验证不了就退回原来的现传流程,**不会因为验证失败拦住提交**。本地路径原样保留,AI 读到的仍是本地路径。

## 注意

- **对话框里的「删除云端副本」现在是软删除**(进云端回收站)。如果这部剧本地还在,下一轮备份会把它当作「自己删了又回来」重新备份,云端回收站里会留一条到期前的旧记录,不影响数据。
- 备份不包含本地独有的素材文件;换电脑恢复后,这类素材需要自己重新导入。
- 云端回收站的过期由服务端兜底(回收站前缀上有 61 天的存储生命周期规则),本地「彻底删除」时的云端收紧是尽力而为,不跨重启重试。

## 已验证

- **客户端测试**:视频工作台相关目录 + 备份主进程 + 账号守卫共 107 文件 1414 条通过;`typecheck:ci` 7 existing / 0 new。**变异检查 21 种全部被测试抓到**(过程中补了三处原先漏掉的用例:云端活副本比删除新得多时不软删、回收站 30 天清除的页面调用、时钟回拨倒计时封顶)。
- **服务端对真实私有桶做过端到端**(测试服和生产各一遍,用后端自己签的短期令牌、`selftest-*` 剧号,结束后桶里无残留):上传 / 去重 / 保留 5 份 / 读取 / 软删 / 回收站读取 / 不静默复活 `DRAMA_TRASHED` / 恢复 / 同号活剧存在时不覆盖 `DRAMA_EXISTS` / 期限收紧 / 永久删除 / 非法 id 与无令牌拒绝,全部通过。服务端已在生产开通。

- 预传地址的云端有效性检查(HEAD)没有对真实 COS 跑过,只有注入假响应的单测;首次真机使用时请留意日志。
- 多设备冲突(同一部剧在另一台设备上被删又被改)只有单元测试覆盖,没有两台真机对跑。
- 历史版本选择器没做:服务端保留最近 5 份,界面目前只能恢复最新一份。
