# v4.9.32 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.31

## 概述

一件事:**腾讯 GPT Image 2.6 现在可以涂抹局部(mask)重绘和灯箱擦除了**。4.9.31 里这两个渠道被挡在 mask 之外,理由是「2.6 的 mask 没验证过」;这次用真实调用验证后放开。

## 变化

- **2.6 支持 mask 局部重绘**:`custom-model-og-v2.6-f`(Flare)、`custom-model-og-v2.6-s`(Sunburst)带遮罩图编辑时不再被早失败拦下,走和 2.5 相同的 `/v1/images/edits` JSON 形状(`images:[{image_url}]` + `mask:{image_url}`)。
- **灯箱擦除沿用当前渠道**:用户当前选的是 2.6 时,擦除继续用该渠道,不再被悄悄换成 2.5 Sunburst。给 agent 的指令里带了「同档位比 2.5 贵约 4 倍,一次做对、别无谓重试」。
- **MCP `generate_image` 说明与 `catimation-image` 技能同步**点名 2.6 可用于 mask / 擦除。为了不超过 Codex 工具 schema 的 16384 字节预算,压缩了几处重复说明(没有删参数)。

## 注意

- **一次 2.6 擦除约 ¥0.22,是 2.5 的约 4 倍。**
- 本版没有改默认出图渠道,也没有改 2.5 的任何行为。
- 合并后 `catimation-image` 的 SKILL.md 变了,插件市场的 `catimation-core` 需要随版再发布一次(1.0.36)。

## 已验证

- 真实调用(2026-11-06,生产网关,`custom-model-og-v2.6-f`,1024² low,14.4 s):遮罩外每通道平均差 1.61、仅 0.06% 的像素差超过 40(基本原样保留);遮罩内黄色像素 16278 → 0(被重绘掉);额度 110980 ≈ ¥0.222。
- 相关目录(`agent-chat` + `services/api` + `src/main/mcp` + `firstPartySkills`)183 个文件 2186 条通过;新用例在旧源码上先红;`typecheck:ci` 7 条既有 / 0 条新增;`skills:gen:check`、`audit:skill-arch` 通过。

## 还没覆盖的地方

- **只实测了 `-f`(Flare)**。`-s`(Sunburst)与它同渠道、同适配器,但没有单独调用过。
- 只有一次调用的结果,没有多次采样;没在真实窗口里走过灯箱擦除的完整流程。
- MCP `generate_image` 的 schema 仍贴着 16384 字节预算,余量很小,下次再加渠道说明会先被 `toolSchemaBudget` 守卫拦住。
- 上面的真实调用是直接打生产网关,**没有经过安装包里的应用走一遍**(生成页、批量页、Codex 出图面板、灯箱擦除的界面流程都没在真实窗口里看过)。
