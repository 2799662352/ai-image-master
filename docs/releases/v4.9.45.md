# v4.9.45 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.44

## 概述

一件事:**登录失效时,桌面端说清楚原因并给「重新登录」入口**(#473)。

另有一处服务端改动不在本版内、已于 2026-11-21 13:35(北京时间)单独上线:生产登录有效期从 7 天改为 100 年。

## 变化

### 登录失效的提示与入口(#473)

起因:有客户在人像库看到一句「Token 无效或已过期」和一个「重试」,重试多少次都一样。根因在服务端(生产把登录有效期配成了 7 天,已改);桌面端的问题是,平台不认登录凭据时,界面把后端原话直接显示出来,没有告诉用户要重新登录。

- **提示改成「登录已失效,请重新登录」**:判定规则是「平台回 401,且响应里没有后端错误码」。带错误码的 401 不算(那是平台自己的上游凭据问题,重新登录没用)。接在所有带登录凭据的请求上:余额、组织、配额、支付配置、用量明细与汇总、建充值单、查充值单、人像库、网关 token 的换取。
- **人像库的报错面板多一个「重新登录」按钮**(「重试」保留):点击直接走浏览器授权,**不需要先退出登录**,成功后自动重新加载列表。不先退出,是因为退出会清掉网关 token 与当前计费池,并把计费来源打回自有 Key。
- **已登录状态下重新登录、回来的是另一个账号时,会先清掉上一个账号的网关 token**:网关 token 按计费池缓存、键里不含用户,不清的话新账号的请求会带着上一个人的 token,钱记在上一个人头上。
- **只改提示,不清凭据、不自动登出**:后端的鉴权中间件把任何异常(包括查库失败)都回成 401,据此自动登出,等于一次数据库抖动就清掉所有人的网关 token。

## ⚠️ 行为变化(请知悉)

- 登录失效时,人像库、设置页账号区等位置显示的文字由后端原话变为「登录已失效,请重新登录」。
- **只有人像库有「重新登录」按钮**。设置页账号区只换了文案、没加按钮(旁边有「退出登录」);顶栏账号徽标不显示这类报错。
- 从人像库重新登录成功后,顶栏徽标上的余额不会立刻刷新,要等下一次扣费、打开设置页或重启应用。
- 出图 / 出视频 / Codex 对话用的是网关 token(不过期),不受登录失效影响;登录失效时这些照常可用,只有人像库、余额、充值、用量这类走登录凭据的地方会报错。
- **13:35 之前签发的登录仍按 7 天到期**(到期时间已写在登录凭据里,改配置不会延长),这些用户需要重新登录一次;之后新登录的不再过期。
- 本版没有改技能 / 插件文件,插件商城与技能商城不需要随版发布。

## 还没覆盖

- **没有在真机上走过「重新登录」**:它要打开系统浏览器、用真实账号授权,只有组件测试和主进程单测覆盖。登录等待时的全屏覆盖层是既有的 `DesktopLoginPage`,本版没有改动,但「已登录状态下触发它」此前没人走过。
- **没有拿真实账号登录一次、读返回的到期时间**:服务端「100 年」只验证到配置与实签 token。
- 没有主动探测登录是否失效,仍然是用到相关功能时才发现;`probeLiveness()` 依旧没有调用方。
- 换账号后渲染层的计费来源不会自动复位(它仍标着「平台余额」,而主进程已没有网关 token,平台余额请求会 401,不扣任何人的钱),要等重新取一次凭据 —— 打开设置页或重启应用时会自动做。这一段没有另做处理。
- 只在 Windows x64 验证;没测 NSIS 覆盖升级 / electron-updater,只测了构建产物,这部分由发版流程的三道闸与 Authenticode 校验兜底。

## 回滚

不涉及数据库版本迁移,没有存储格式变化。出问题时回退 #473 重新发版即可。服务端的登录有效期是生产 compose 里的一行配置,与本版无关,回滚方式见部署记录。
