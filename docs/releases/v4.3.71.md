# v4.3.71 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub 源码同步
> 上一个发布版本:v4.3.70

## 概览

本次对齐 **Codex 原生 AGENTS.md(项目文档)全部能力**。经核对官方源码(`codex-rs/core/src/agents_md.rs`)确认:AGENTS.md 加载逻辑全在 `codex-core` 引擎里,app-server(本 app 使用的 WebSocket 协议)一样生效;不存在全局 `~/.codex/AGENTS.md`(原生已删)。因此不自造轮子,只把"输入喂对 + 暴露原生旋钮"。

## 变更

### 原生 AGENTS.md 对齐
- **`.git` 根 → cwd 逐级拼接(P1,已就位)**:thread 的 cwd = `writableRoots[0]`,而文件浏览器选择工作目录会经 `setAllowedRoots` → `writableRoots` 生效。所以在所选工作目录放 `AGENTS.md` / `AGENTS.override.md`,Codex 会原生从 `.git` 根向下逐级拼接并注入(嵌套优先、prompt 覆盖 AGENTS.md 均为引擎自带)。
- **`project_doc_max_bytes=65536`(P2)**:项目文档预算由默认约 32 KiB 提升到 64 KiB,较大的 AGENTS.md 不再被截断(设 `0` 则完全关闭加载)。
- **`project_root_markers=[".git"]`(P2)**:显式钉住原生默认根标记,避免用户手改的 `~/.codex/config.toml` 移动根检测基准;找不到标记时引擎仅按 cwd。
- **`project_doc_fallback_filenames=["CLAUDE.md", "GEMINI.md"]`(P2)**:跨工具对齐——除 `AGENTS.override.md` / `AGENTS.md` 外,`CLAUDE.md` / `GEMINI.md` 也被当作项目文档(候选顺序:override → AGENTS.md → 回退名)。

以上三项均在 `codexLaunch.ts` 以 `-c` 注入,并已对 0.142.2 二进制冒烟确认被接受(`initialize` 握手 OK、`config/read` 往返 97 keys、干净退出,无 `deny_unknown_fields` 拒绝)。

> 说明:真正的"多个独立仓库各贴 AGENTS.md"依赖 app-server 的多环境(multi-environment)协议,当前单 cwd 已覆盖"单仓库根→cwd 层级拼接"这一主用例;跨独立仓库的多根拼接留待后续协议支持。
