# v4.9.39 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.38

## 概述

两件事:

1. **视频工作台「剧栏」整理**(#447–#451):剧栏固定一屏高,剧和分段都能拖动排序,剧可以分组(文件夹式),导入 / 导出收成剧栏底部一处。
2. **接入 Seedance 2.5 Flash 与 Seedream 5.5**(#452):视频工作台、图片生成页、Codex 聊天的出图渠道选择器、MCP 生成工具都能用。

## 变化

### 视频工作台剧栏

- **固定一屏高**(#447、#451):剧栏高度不再跟着右侧任务卡的数量被撑长,剧列表在栏内自己滚。滚动页面时剧栏大小保持不变(页面往下滚、剧栏粘到顶部后停住,下方会留一块空白)。
- **导入 / 导出 / 云备份 / 回收站收到剧栏底部一行**(#447):剧总览头部原来的导入 / 导出两个按钮已删,入口只剩剧栏底部这一处。
- **剧可以拖动排序**(#448、#451):整行都能抓起来拖(不必再找悬停才出现的点阵),落点画一条黄色插入线;聚焦点阵后按 ↑ ↓ 键也能挪一格。置顶的剧始终排在不置顶的前面,不允许跨置顶拖动。
- **分段卡可以拖动排序**(#449):总览里拖到另一张卡的左半 / 右半 = 插到它前 / 后,竖线标落点;右键菜单新增「前移一格 / 后移一格」。
- **分段卡拖到剧栏某部剧上有落点提示**(#451):能放的剧行亮黄色虚线框和「移入此剧」,不能放的(当前剧自己、源剧只剩一段)显示禁止。
- **剧分组**(#450):剧栏里可以新建分组(文件夹式),剧能拖进 / 拖出分组,整组也能拖;分组可折叠、可重命名、可解散,标题上显示剧数和已出片总时长。设计稿约定黄色是唯一强调色,所以分组靠折叠箭头、文件夹图标、成员缩进和左侧细线区分,没有新增颜色。

### Seedance 2.5 Flash(`2.5-flash`)

- 视频工作台模型下拉里新增「Seedance 2.5 Flash」,MCP 视频工具的模型枚举同步。
- 规格按网关接入说明:480p / 720p、4–30 秒、参考素材 10 图 / 5 视频 / 5 音频、支持编辑和延长、**没有样片**。
- 界面上的美元价格是**估算**(按 Seedance 2.0 的数折算);实际扣费以网关结算为准。

### Seedream 5.5

- 图片生成页下拉、Codex 聊天出图渠道选择器(火山豆包系列「更多」里,不进常用)、MCP `generate_image` 渠道枚举里都新增 5.5。
- **图层拆分 5.5 也支持**。agent 显式点名 5.5 才用 5.5;没指定仍用 5.0 Pro,界面上的「图层分离」按钮也仍固定 5.0 Pro。
- 新增 HTTP 524 的提示:前置代理等不到上游时,上游可能已经出图并计费,请先看账单和日志,不要立刻重试。

## ⚠️ 行为变化(请知悉)

- **导出 / 导入的工程文件带分组**:`.catwb.json` 的 `project.group` 只在剧有分组时才写,没有分组的剧导出的文件和以前完全一样。导入或云端恢复一个带分组的文件时,会**自动并入本机同名分组**(没有就新建);导入确认页会先写明。
- **云备份**:分组变化会改变云备份指纹,会触发出一个新的云版本。
- **导入 / 导出入口位置变了**:只在剧栏底部,总览头部不再有。
- **分段卡拖动**:源剧只剩一段时,不再露出顶部「新建一部剧并移入」投放框(原来放下去只会多出一部空剧)。
- **空分组**(新建了还没放剧)只存在本机,放进第一部剧才真正写进库;折叠状态也只是本机偏好,不进撤销 / 备份。
- **库结构**:分组是剧记录上的一个可选字段,**没有升库版本、没有新建表**。

## 还没覆盖

- **没用真实令牌打过网关**:Seedance 2.5 Flash 的真实提交、Seedream 5.5 的真实出图和图层拆分都没跑过,只做了界面和本地校验。
- **Flash 的联网搜索、智能时长、编辑 / 延长上游是否接受**没验证(接入说明写明「Flash 本身没有单独验证」,按 2.5 填);**5.5 图层拆分的计费口径未知**;5.5 的分辨率档位表照 5.0 Pro 抄的(文档只实测过 1K 1:1),没配参考图张数上限。
- 生产网关是否已配好 5.5 / Flash 的渠道与分档计费,没有查。Miau 画布后端还没有 5.5、网关渠道测试按钮不认 5.5,这两处不在本仓库。
- 视频效果反馈(Case 平台)的模型白名单**没加 Flash**:该名单要求新视频模型人看过再放进去。
- 剧栏的拖动在真窗口里用的是合成事件(Playwright),真实鼠标的手感以维护者试用为准;窄窗(≤1100px)布局、窗口低于保底高度 360px 的表现、macOS / Linux 都没在真窗口里验。
- 没测真实云备份「上传 → 恢复」带分组的往返,也没测老版本客户端读带 `group` 的库或文件(按代码判断老版本会忽略这个字段、剧栏平铺显示)。
- 分组里的剧进回收站再恢复时 `group` 名会跟着回来;若期间分组已解散,会重新长出一个只含它的同名分组(读代码推断,没专测;可再「移出分组」)。
- 没测 NSIS 安装包的安装 / 覆盖升级 / electron-updater 自动更新,只测了构建产物;这部分由发版流程的三道闸与 Authenticode 校验兜底。只在 Windows x64 验证。

## 回滚

不涉及数据库版本迁移。出问题时回退对应 PR 重新发版即可。退回 v4.9.38 后,已写入的 `group` 字段会留在剧记录里、旧版不使用它(按代码判断,没有用旧版实际打开过带分组的库)。
