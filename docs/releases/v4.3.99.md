# v4.3.99 发布说明

> 发布渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 兜底
> 基线版本：v4.3.98

## 概览

本版将常用本地视频后期能力统一收敛到随应用提供的 `ffmpeg-win` skill。
字幕、水印、混音、变速等操作直接使用已捆绑的 FFmpeg 8.1，无需安装额外
CLI、Docker 或配置云端 API Key；没有新增运行时二进制和安装包依赖。

## FFmpeg 本地后期增强

- 新增 SRT/ASS 字幕压制与 MP4 软字幕配方，覆盖 Windows 盘符转义、
  `force_style` 定位和中文字体设置。
- 新增换音轨、旁白与 BGM 混音、延迟进场、水平/垂直翻转及旋转配方。
- 水印配方补充 PNG 半透明叠加；既有变速、音量、淡入淡出、拼接、抽帧与
  九宫格流程保持不变。
- `/edit-video` 与视频插件 session hook 统一为：优先探测并使用本地
  `ffmpeg` / `ffprobe`，仅在本地 CLI 不可用时回退到 ffmpeg-win Docker
  MCP。
- 扩充中文触发词，用户不必点名 FFmpeg；“加字幕 / 加水印 / 混音 / 变速 /
  调音量 / 淡入淡出 / 镜像翻转”等现有素材后期请求会直接命中该 skill。

## 安装与升级安全

- `mediakit-cli` 独立 skill 和二进制分发链已完全移除；其本地编辑能力均由
  纯 FFmpeg 配方承接。
- 首方 skill 安装器可安全接管内容哈希精确匹配历史已发布版本的无标记
  `ffmpeg-win` 副本，并刷新为当前版本。
- 未知来源副本、内容被修改的副本和带有不匹配托管标记的副本仍原样保留，
  不会覆盖用户定制。
- 发布契约锁定生产运行时组件仅为 Codex、FFmpeg 与 Docker MCP，并明确
  阻止 mediakit fetch、版本字段、构建资源或 digest 条目回归。
