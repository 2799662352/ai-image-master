# v4.9.8 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.7

## 概述

视频工作台新增 Seedance 2.5「样片」模式:先出 480p 样片便宜看效果,满意再一键生成 1080p 成片。同时修好了素材库引用串库导致的「素材不存在」报错,以及素材库 / 视频素材缩略图不显示的问题。

## 样片模式(Seedance 2.5 · 平台余额)

- **参数栏「🎞 样片」开关**:选 Seedance 2.5 时出现。打开后这张卡出 480p 样片(按 480p 计费),分辨率自动锁定 480p;开关会随卡片保存。自填 Key 下暂不支持,开关置灰并说明原因。
- **一键生成 1080P 成片**:样片出片后,卡片结果下方出现「样片 480P」角标和「⤴ 生成 1080P 成片」按钮。成片沿用样片的提示词、参考素材、时长、比例、随机种子与音频,按 1080p 计费;成片作为这张卡的新版本,样片那一版仍可在版本记录里切回查看。样片从生成起 7 天内有效,超期或切换到自填 Key 时按钮置灰并说明原因。
- **AI 也能用**:agent 可以先出样片(`generate_video` 带 `draft`),你满意后让它出成片(`finalize_video_draft`);工作台里也能批量开样片、对样片卡一键出成片(`video_workbench_finalize_draft`,同样受「允许 AI 自动生成」开关约束)。
- 成片提交失败时的提示改成中文说明,例如「找不到这条样片:网关只认同一个账号、同一个计费池里生成的样片」。

## 素材库修复

- **「素材不存在」报错**:平台余额下,AI 挑选、存放素材以前走的是自填 Key 的人像库,拿去平台提交时上游回 `asset … is not found`。现在 AI 的素材库工具跟随当前计费:平台余额用当前计费池的素材库。提交前还会核对卡上引用的素材是否在当前计费池里,查不到就在提交前用中文点名拦下,不会白排一次队、白扣一次钱。
- **缩略图与原图**:素材库素材的缩略图以前只去自填 Key 的库里找,平台素材库的永远查不到。现在按计费查对应的库;预览弹窗查询中显示转圈,看大图用原图,素材库里的视频、音频可以直接播放。
- **视频缩略图**:本地参考视频现在显示第一帧缩略图(优先用系统缩略图,拿不到再用自带 ffmpeg 截帧,不花钱);素材库里的云端视频复用数据万象封面。

插件市场已同步(catimation-video 1.0.44)。其余 4.9.7 的功能不受影响,无需重新设置。
