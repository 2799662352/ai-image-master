# v4.4.6 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.5

## 概览

本版接入火山豆包 **seed-audio-1.0** 音频生成全链路:新增「音频生成」页
与作品库(COS 云存储 + 本地保存),`generate_audio` MCP 工具让 Codex
agent 可直接出配音/旁白/音效,聊天时间线新增内嵌音频播放器卡片,并
新增 `catimation-audio` 首方入口 skill(与图片/视频入口对称)。

## 音频生成页(新 tab)

- 新页面 `AudioPage`:自然语言描述场景即可生成语音/旁白/音效/背景音,
  支持 `mp3` / `wav` / `opus` 格式、0.25–4.0 倍速、最多 2 段参考音频做
  风格融合;单次输出约 120 秒上限。
- 作品库 `AudioLibraryStore`(IndexedDB,内存降级):生成记录含
  prompt / 时长 / 计费秒数,可播放、下载、删除。
- 三级持久化:COS 桶(`image-history/audio/`)→ 本地
  `audio-history/` 目录 → base64 兜底;preload 新增 `audioHistory`
  IPC(`uploadCos` / `save`),主进程新增 `audioHistoryFiles` 服务。
- i18n 四语言(zh-CN / zh-TW / en / ru)补全音频页文案。

## `generate_audio` MCP 工具(agent 出音频)

- main 端薄层 `audioTools`:参数透传 + banner 包装,复用渲染层
  `AgentToolExecutor.generateAudio` → 与音频页同一共享核心
  (`generateAudioToLibrary`),agent 出的音频和手动出的进同一个库。
- 请求固定走 Miau API 站点(seed-audio-1.0 仅此网关);自然语言
  `input` 驱动多说话人/口音/环境音/背景乐,不接受旧 TTS speaker id。
- 返回 `✅ generate_audio DONE` + 时长 + COS URL + 本地路径。

## 聊天音频卡片

- `ArtifactCard` 新增内嵌 `<audio controls>` 播放器卡片(🎵 + 文件名 +
  原生播放/进度/音量),按 mime `audio/*` 或扩展名识别,排在图片
  缩略图/文件分支之前;播放源经 `toRenderableUri`(COS https 直连、
  本地路径转 `local-file://`)。
- 生成生命周期与图片/视频对称:转圈气泡「正在生成音频…」→ 完成变
  播放器卡片 / 失败显示「音频生成失败」+ 错误信息;`threadId` 透传,
  卡片路由到发起对话(并行会话安全)。
- `ArtifactItem.mediaKind` 加 `'audio'`;`AttachmentRef.kind` 联合不变
  (音频用 `kind:'file'` + audio mime,避免联合类型全局波及)。

## `catimation-audio` 首方入口 skill(app-only)

- 音频唯一顶层入口,教内嵌 agent「配音/旁白/念一段/tts →
  `generate_audio`」:自然语言 input、不传固定 speaker、>120s 拆多次、
  参考音频做风格融合。
- 走单一真源生成链(`generate-first-party-skills.mjs` →
  `firstPartySkills.generated.ts`),随应用分发,不进插件市场。
