# v4.9.36 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.35

## 概述

**Seedance 现在只经 Miau 网关。** 删掉了 vvdance 直连这一整条路(「海外 / 国内」站点切换、设置页的 vvdance Key + Secret、直连 Ark 客户端、vvdance 素材库与官方素材)。出 Seedance 只有两个钱包:**登录 + 平台余额**,或**自己填的 Miau API Key**。

顺手修了一个既有 bug:视频工作台里的 **seed** 和**联网搜索**以前从来没有发给网关(只有 vvdance 直连会发),界面显示已启用、请求里却什么都没有。现在两条钱包都会带上。

## 变化

- **删除**:设置页 Seedance 区块(站点切换 + vvdance Key / Secret)、`RegionSwitch`、vvdance 素材库、人像选择弹窗里的「官方素材 / 虚拟人像」与弹窗内上传、「@ 人像库」联想(它只读 vvdance 库)。
- **seed / 联网搜索生效**:`metadata.seed`(取整,0 合法)与 `metadata.tools = [{type:'web_search'}]`;没填、没开时请求里一个字都不出现。由样片生成成片那一支不带(方舟沿用样片的 seed,再传会被拒)。
- **两个钱包各自钉死**:任务提交时落锤用哪个钱包,轮询也按它走;任一通道未注册就报错,**不会跨钱包回落**(不会出现「以为扣平台余额、实际扣自己的 Key」)。
- 万相 / 可灵 / 深度捕捉的路由不变。
- 技能 `catimation-portrait-library` 改为「人像库只在平台余额下存在」。

## ⚠️ 行为变化(请知悉)

- **自填 Miau Key 没有人像库**:agent 的 `list_portrait_library` 返回空页 + 说明,`add_to_portrait_library` 报错;真人参考图会被上游拒,错误里有人话翻译。人像库只在平台余额下可用。
- **样片(draft)只在平台余额下开放**;自填 Key 的分辨率沿用保守上限。
- **Seedance 取消不可用**:网关没有取消接口,界面如实提示「取消后仍会计费」。
- **卡片上「实际 seed」不再有值**:网关响应不回传实际使用的 seed。
- 以前用 vvdance 直连的用户升级后,Seedance 会改走 Miau(要么登录用平台余额,要么在设置里填 Miau Key)。用户机器上旧的 `seedance-credentials.bin` 成了孤儿文件:没读它、也没删它,不影响使用。
- 视频工作台上与 vvdance 相关的内部名字(`provider: 'vvdance'` 等)暂时保留,语义现为「Seedance 家族」,改名留给后续清理。

## 已验证

- CI(TypeScript / 单元测试与覆盖率 / Contracts / Skill Architecture / Vite Build / Electron Stable E2E)在合并前全绿;`typecheck:ci` 7 个既有 / 0 个新增。
- 真网关烟测(自填 Miau Key,脚本直接调用传输层,不是在应用窗口里):
  - `2.0-fast` 与 `2.0-mini` 都是 480p / 4 秒 / 纯文本 / 无音频,提交 → 排队 → 运行 → 成功;
  - 结算按 token:同样 40,594 个 token,mini 与 fast 的扣费比 0.6216,等于网关倍率 11.5 / 18.5;
  - 故意传超范围 seed,方舟以 `param: seed` 拒绝(证明 seed 到了上游);seed = 42 加联网搜索同时带,任务成功完成,用量日志没有额外联网计费项。
- seed / 联网的测试是先红后绿(改动前 5 条失败、改动后全过);两个钱包互不回落、万相 / 可灵 / 深度捕捉不被劫持都有测试钉住。
