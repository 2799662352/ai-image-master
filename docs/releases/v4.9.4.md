# v4.9.4 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.3

## 概述

这一版把通义千问 **3.8 Omni Flash** 接进应用:它是全模态模型——文本、图片、视频、**音频**都能看和听,而且比 3.7 Plus 便宜。它成为 Codex 理解类工具的默认模型,也能在 Codex 页面直接选作主对话模型;Qwen 3.7 Plus / Max 继续保留,两代并行,老会话和老 skill 里写的模型名意思不变。

## Codex:Qwen 3.8 Omni Flash

- **模型选择器**里新增「Qwen 3.8 Omni Flash」,走 Miau 网关,平台余额和 Miau Key 都能计费,可直接当主 agent 用(工具调用已在生产网关验证)。
- **理解工具默认换成它**:`understand_video` / `understand_document` / `web_research` / `understand_canvas_video` 不指定模型时用 omni;需要更强的推理时仍可点名 3.7 Max(`max`)或 3.8 旗舰(`flagship`),3.7 Plus(`plus`)也还在。
- **看视频连声音一起听**:默认模型分析视频时会读音轨,不再是「只看画面、听不见」。发布前用一段 126 MB 的游戏开场实测:画面按时间顺序描述准确,主持人 13 句台词逐字转写,配乐与音效也一并说明。
- **Qwen 3.7 Plus / Max 保留**:目录、路由、默认兜底都没动,与 3.8 一代并行一段时间。

## 新工具:`understand_audio`

- 直接把 mp3 / wav / m4a / aac / ogg / flac / opus 交给 agent「听一下 / 转写 / 这段录音说了什么 / 这首歌什么风格」;本机文件自动中转到云端换公网地址,和视频理解同一条链路。
- 视频的音轨先用 ffmpeg 抽出来再喂它;长录音按 ≤20 分钟切段。
- 音频只有 omni 听得见,这个工具固定走 omni,不会兜底到听不见的模型。
- 旧的「把音频包成黑屏 MP4 喂视频理解」路径已从 skill 里全部删掉——那个方法从来没让模型真正听见过。

## 稳定性

- 理解请求遇到上游要求流式(某些兼容模式下 Omni 只接受流式输出)时会自动改为流式重发并拼回整段回答,同一会话内之后直接走流式,不多花一次往返。

其余 4.9.3 的功能不受影响,无需重新设置。
