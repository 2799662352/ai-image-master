# v4.3.92 发布说明

> 发布渠道：腾讯云 COS 热更新（`releases/latest.yml`）
> 基线版本：v4.3.91

## 概览

本版完成 CATIMATION Skill 编排的「减法式重构」：图片/视频各自唯一顶层入口、四级任务分层与调用预算、单向依赖(DAG)、按风险 QA,并建立 skill 单一真源生成链与全仓架构验证器。普通单镜请求从命中十余个 skill 收敛到入口 + sd2-pe 两个,专业/制片场景仍可逐级升级。

## Skill 编排架构重构

- `catimation-image` / `catimation-video` 成为图片/视频领域唯一顶层入口,独占宽泛触发词;内建快速/标准/专业/制片四级分层,预算分别为 ≤2 / ≤3 / ≤5 / 按阶段加载。
- 入口维护本回合 routing receipt(`task_level`、`direction_confirmed`、`spec_confirmed`、`prompt_engineered`、`qa_completed`、`generation_attempts`),下游只读不重复执行;规格整回合只确认一次。
- `director-orchestrator` 不再「每次必用」,移除 STEP -1 强制路由,仅在专业/制片级由入口加载做复杂镜头 13 维设计。
- `catimation-video-director-router` 降级为症状修复查找表(太假/动作怪/站桩/混脸/风格跑偏),不再是生成前置门,fanout 0。
- `seedance-video-craft`、`animation-craft`、全部 `director-*` / `storyboard-*` 收窄为纯专业知识叶子:不反向调用入口、router、调度器、生成工具或 QA 工具。
- QA 改为按风险触发且由入口唯一执行:快速 QA(默认)→ 视觉 QA(人脸/多人/复杂动作)→ 内容 QA(多镜剧情/台词口型)→ 发布 QA(正式交付);自动修正上限 2 次。
- `film-studio` 定位为制片级外壳(budget: studio),按 G0–G8 阶段加载,每镜生成仍委托两个入口。

## 单一真源与生成链

- 新增 `resources/first-party-skills/`(canvas/understand/director-stage 权威 Markdown 源);`scripts/generate-first-party-skills.mjs` 生成 `firstPartySkills.generated.ts`,应用内首方安装不再手写内联字符串。
- 新增 `scripts/sync-top-level-skills.mjs`:顶层 `skills/` 镜像保留流水线 frontmatter(name/appliesTo/priority),description + 正文跟随插件权威源。
- `publish:marketplace` 自动串联 first-party 生成、顶层同步、codex 镜像三步;dry-run 走 `--check`。
