# v4.7.8 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.7.7

## 概述

这一版修一个会让你误以为「生成失败了」的问题，并把使用明细里的退款和模型汇总做得能看懂。

## 视频提交不再被 30 秒掐断

此前提交视频任务的请求有一个 30 秒硬超时。带多张参考图或用全能参考时，网关要先把每张图拉下来校验才返回任务号，30 秒经常不够——客户端主动断开，卡片显示一句英文 `This operation was aborted`。

更要紧的是：客户端断开，网关并不会取消，任务照跑、照扣费，只是你这边看到的是「失败」。

现在：

- 提交的等待上限放宽到 **5 分钟**；查询任务状态仍是 30 秒（那是轻量接口，超了会自动重试）。
- 真的等到 5 分钟还没响应时，提示会如实说明：「任务可能已被网关受理并计费，请到使用明细核对」，而不是一句看不懂的英文。

## 使用明细

**按模型汇总默认只露前 5 条。** 之前用过的模型越多、汇总列表越长，下面的「调用记录」就被挤成一条缝。现在按花费降序只展示前 5 个模型，其余折进「展开其余 N 个模型 · 合计 ¥x」——折叠不藏账，数据一条不少。

**退款看得见了。** 视频、高清这类异步任务失败后网关会退款，但此前明细里看不到，只能从余额猜。现在：

- 失败已退款的那笔显示绿色「**已退款**」标记，金额写成 `+¥x`（退回的预扣额），模型名保留，能对上是哪次生成。
- 还在生成中的任务标「结算中」，提醒这笔预扣可能变。
- 记录区头部多一行「本页 N 笔退款 +¥x」。

> 「已退款」依赖网关同期的一项修复（视频任务结算改走统一账本）。生产网关部署完成后，新发生的失败任务才会以「已退款」出现；此前已退过的旧任务不会补显示。

## 其它

- 提交超时的文案按整分钟说「5 分钟」而不是「300 秒」。
