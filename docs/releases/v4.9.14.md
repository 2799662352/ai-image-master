# v4.9.14 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.13

## 概述

AI 助手(codex 对话框)的模型选择器新增 Miau 网关上的 DeepSeek Flash 和 DeepSeek V4 Pro,用平台余额结算,排在 DEEPSEEK 分组最上面。

## DeepSeek Flash / DeepSeek V4 Pro(Miau)

- **在哪里选**:AI 助手输入框下方的模型选择器,DEEPSEEK 分组最上面两行「DeepSeek Flash（Miau）」和「DeepSeek V4 Pro（Miau）」。API易 和 Right.Codes 两个网关下都能选。
- **结算**:走 Miau 网关,扣平台余额;用的是和图片生成同一枚 Miau 密钥,不用另外配置。
- **DeepSeek Flash**:1M 上下文,能看图(聊天里附的图片会直接送进模型),是 DeepSeek 系列里最便宜的一档。
- **DeepSeek V4 Pro**:1M 上下文,旗舰档,适合长任务和编码;不能看图。
- **思考深度**:两个模型都支持 Low / High / Max 三档。

## 其他变化

- 原来两个 Miau DeepSeek 的显示名加上了日期,改为「DeepSeek V4 Flash 0731（Miau）」和「DeepSeek V4 Pro 0813（Miau）」,用法不变。
- Right.Codes 网关下的 DeepSeek V4 Pro 改走 Miau 平台余额。之前在 Right.Codes 网关选了 DeepSeek V4 Pro 的用户,升级后改用 Miau 密钥结算;Right.Codes 网关下仍保留 DeepSeek V4 Flash。
- 选 Miau DeepSeek 聊天时,后台记忆整理改用更便宜的 DeepSeek Flash。

其余 4.9.13 的功能不受影响,无需重新设置。
