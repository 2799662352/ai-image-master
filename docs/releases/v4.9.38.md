# v4.9.38 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.37

## 概述

**底层运行时升级,没有新功能,也没有新增界面。** Electron 43.2.0 → 45.3.2(Chromium 150 → 156,Node 24.18 → 24.22),内置 Codex CLI 0.168.0-alpha.3 → 0.169.0,并把登录凭据和腾讯云凭据迁到 Electron 的异步加密接口(同步接口将在 Electron 46 删除,提前做完才能继续跟进 Electron)。

## 变化

- **Electron 45.3.2**(#444):官方文档写 v43 支持到 2027-01,不是紧急升级;但 44 / 45 有两处不改会坏的变更,趁现在一并处理。
  - **「复制图片」**:Electron 44 起删除了 `clipboard.writeImage`。只升版本号的话,「复制图片」会静默失败(界面不报错、只是复制不到)。已换成新的剪贴板写法;右键菜单里的「复制文本」也适配了新的异步返回。
  - **构建依赖**:`node-abi` 旧版不认识 Electron 45,`pnpm install` 会失败;加了一条依赖覆盖。只影响构建,不影响安装包。
- **Codex CLI 0.169.0**(#443):协议改动全是新增、没有删除,我们的代码不读新增字段,**没有改应用代码**。锁文件里 5 个文件的 SHA-256 与官方发布页摘要逐个核对一致。
- **凭据改用异步加密接口**(#445):登录凭据和腾讯云凭据。已保存的凭据**不会失效**:用真 Electron 43.2.0 / 38.7.2 写出的旧文件,新版读得出(含中文字段);新版写出的文件,Electron 43 的同步接口也读得回,所以万一退回旧版也不会丢登录。

## ⚠️ 行为变化(请知悉)

- 启动时先读完凭据再创建窗口(之前是同步读,没有这一步)。
- 登出现在会等凭据文件删除完成,才算登出。
- 系统加密不可用或写盘失败时,降级为「仅本次会话」的内存凭据,语义与旧版一致。
- 没有改动数据库。

## 还没覆盖

- **没用真实登录态跑真实模型对话 / 真实出图 / 真实视频生成**;Codex 回合只用「本地假的 Responses 服务」对比过新旧二进制的事件序列。
- **没测 NSIS 安装包的安装 / 覆盖升级 / electron-updater 自动更新**,只测了 `--dir` 解包产物;这部分由发版流程的三道闸与 Authenticode 校验兜底。
- **只在 Windows x64 验证**(也是唯一发布目标)。macOS Keychain、Linux(kwallet / libsecret / `basic_text`)的凭据后端没测;Linux `basic_text` 的持久化策略保持原样。
- `shouldReEncrypt === true` 的真实路径没法在真机触发,只在单测里用假 `safeStorage` 覆盖。
- 没走真实登录配对流程和真实 COS 上传:验证的是凭据层(读 / 写 / 登出 / 迁移)和 IPC 登录态出口,不是登录与上传的整条链路。
- 画布「落盘后经 `local-file:///` 回读」这条链路没有专门走(拖图测的是 `blob:` 路径)。
- Chromium 升级后,本地浏览器侧数据(画布、IndexedDB 等)由新内核原地升级;「升级后再退回 4.9.37」这个组合没有测。
