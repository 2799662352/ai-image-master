# v4.9.5 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.4

## 概述

选 **Qwen 3.8 Omni Flash** 当 Codex 主模型时,聊天里附上的**音频、视频会直接送进模型**——它自己看画面、听声音,不再需要先调用理解工具绕一圈。4.9.4 让理解工具用上了 omni,这一版把主对话也接上。

## Codex 主 agent:音视频附件原生理解

- 把 mp4 / mov / mkv / webm 等视频,或 mp3 / wav / aac 等音频拖进聊天框,选 Omni Flash 发送,模型在这一轮里就能描述画面、转写台词、判断配乐——发布前用一段 126 MB 的游戏开场实测:按秒给出画面时间线,主持人前三句台词逐字转写。
- 本机文件会先自动中转到云端换成公网地址(和视频理解工具同一条链路),126 MB 约 40–50 秒;大文件请耐心等这一步。
- 音频只接受 mp3 / wav / aac / amr / 3gp:m4a、ogg、opus、flac 这些容器上游不认,会退回成文件路径提示,让 agent 用 ffmpeg 转成 mp3 / wav 或交给 `understand_audio`。中转失败同样退回路径提示,这一轮消息照常发出。
- 其他模型(GPT、Grok、Qwen 3.7 / 3.8 Max 等)行为完全不变:音频仍走 Codex 原生附件,视频仍是文件路径,由 agent 决定是否调用理解工具。
- 提醒:Codex 每轮都会把整段对话历史重发,所以同一个线程里的音视频每轮都会再算一次 token(一段两分钟 1080p 大约 3 万 input tokens)。聊完一段视频想换话题,开个新线程最省。

其余 4.9.4 的功能不受影响,无需重新设置。
