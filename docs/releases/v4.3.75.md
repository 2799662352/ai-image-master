# v4.3.75 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub 源码同步;技能/插件市场同步发布到 COS(`skills/catalog.json` + `plugins/plugins-catalog.json`)
> 上一个发布版本:v4.3.74

## 概览

本次把「**运镜与结构化描述知识库**」(阿里百炼 RAG,权威运镜术语 + 结构化分镜描述范式)**宽泛地接入 skill / 插件 / hook 生态**——让 agent 在**做视频、做图、以及用户直接问运镜/分镜术语**时都会**先查知识库再落笔**,而不是只凭记忆。知识库通过应用内置的 `cinematography_kb` MCP 暴露为 `search_cinematography_kb` 工具(「设置 → 运镜知识库」填 `DASHSCOPE_API_KEY` 后可用),所有接入点均为**条件式**:工具不存在 / 未配 key 时静默退回联网检索,不报错卡流程。

## 变更

### 知识库接入(skill / hook / 插件)
- **`director-orchestrator`(最高杠杆,所有图/视频提示词的总调度)**:写「运镜(4)/ 景别焦段(2)/ 机位角度(3)/ 构图(5)」等字段前,先调 `search_cinematography_kb` 取库里真实术语与结构范式,联网检索降为兜底;STEP 0 增补提醒。
- **全局 session-start hook(`catimation-core`)**:`session-start` 与 `session-start-codex` 的 `session_context` 各增一行知识库全局意识——覆盖用户直接问运镜/分镜术语的场景。
- **首方 skill(app 内置,随 installer/热更新下发)**:`catimation-video`、`catimation-image` 在提示词步骤加入知识库指针(做视频/做镜头相关图前先过一遍)。
- **具体提示词 skill**:`sd2-pe`(Seedance 2.0 兜底)、`storyboard-video-prompt-optimization` 加入知识库指针。
- **其余运镜相关 skill**:`director-cinematic-composition`、`director-shot-sequence-patterns`、`seedance-video-craft` 加入知识库指针(后者把知识库置于联网检索之前)。

## 兼容性与降级
- 所有知识库指针均为条件式:`search_cinematography_kb` 工具不可用(未配 `DASHSCOPE_API_KEY` / 非 Codex 环境)时,skill 静默退回原有联网检索路径,行为与旧版一致,不报错。
- 未配置知识库 key 的用户升级后**无感**,不影响既有出图/出片流程。

## 升级方式
- 桌面端将通过 COS 热更新自动检测并下载 v4.3.75。
- 手动:重新下载安装包 `catimation-cyberpunk-master-4.3.75-setup.exe`。
- 技能/插件市场为 app 版本**解耦**通道:装了 Claude Code / Cursor / Codex 插件的用户,在各自「插件/技能市场」即可拉到升版后的插件与技能。
