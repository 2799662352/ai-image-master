# v4.9.12 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.11

## 概述

AI 助手给新会话自动起标题,单次开销降到原来的八分之一左右,模型也改成跟着当前渠道走,不再固定用 gpt-5.5;标题改按你的第一条消息来起,重启后不会再把老会话的标题重起一遍。

## 会话自动起标题

- **更省**:以前每个新会话起标题时,后台会另开一个完整的 AI 会话,连同全套系统说明、记忆和所有工具定义一起发出去,一次约 5.7 万 token。现在照 Codex 官方终端版的做法,只把你的第一条消息发给模型,不带工具和记忆,一次约 7 千 token。
- **模型跟着渠道走**:千问渠道用 qwen3.8-flash,DeepSeek 渠道用 DeepSeek 的 flash 模型,Right.Codes 的 Grok 和 Claude 渠道直接用当前对话的模型,其余渠道仍用 gpt-5.5;除 Right.Codes 的 Grok 和 Claude 渠道外,推理强度都调到低档。以前不管在哪个渠道聊天,起标题都固定用 gpt-5.5。
- **标题更贴题**:以前发给模型的是一段内部数据,不是你的消息原文,起出来的标题有时对不上;现在直接按你的第一条消息来起。
- **出得更早**:第一条消息发出去就开始起标题,和 AI 的回复同时进行,不用等回复结束。
- **不再重复扣费**:以前重启应用后,在老会话里再聊一句会把标题重起一遍、再扣一次钱;现在只有新建的会话才会起标题。
- **不再混进记忆**:以前起标题的会话会被 Codex 记忆收进去,每个新会话的记忆里都多出一条无关的内容;现在起标题用的是一次性的临时会话,不会进记忆,也不会占用当前对话。
- 起标题失败(比如 30 秒没有返回)时,保留默认标题,也就是第一条消息的前 40 个字。

其余 4.9.11 的功能不受影响,无需重新设置。
