# v4.3.70 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub 源码同步
> 上一个发布版本:v4.3.69

## 概览

本次聚焦 **Codex 运行中「插话」(steering)** 与 **发送键改为 Enter 直发** 两项聊天交互体验:回合运行时输入框不再禁用,回车即把内容作为 `turn/steer` 追加到当前回合(而非新开一轮),Stop 仍可随时中断——对齐 Codex 官方 TUI 的手感。

## 变更

### Codex 运行中插话(turn/steer)
- 接入 Codex app-server 官方 `turn/steer`(openai/codex#10821):回合运行期间把用户新输入**追加到同一回合**,复用原回合的事件流,无需等待或打断。
- 六层贯通:`CodexProtocolClient.steer`(带 `expectedTurnId` 的 RPC)→ `CodexLocalBackend`(透传)→ `AgentManager.steer`(抽出 `assembleTurnInput` 复用附件 / 提示 / skill 组装与用户消息落库)→ IPC `agent:turn-steer` → preload `agent.steer` → 渲染层 store `steer()` 动作(乐观插入用户气泡,失败回滚草稿)。
- 无活动回合 / 后端不支持 steer 时安全回退:自动降级为普通 `send()` 或以 `error` 事件提示,不会丢消息。

### 发送键改为 Enter 直发
- 聊天输入框:**Enter = 发送**(运行中则为「插话 steer」),**Shift+Enter = 换行**;Cmd/Ctrl+Enter 仍保留发送(肌肉记忆)。
- 增加输入法合成保护:`isComposing` 期间的回车不触发发送,避免中文 / 日文候选词上屏时误发。
- 运行中不再禁用输入框、附件按钮与发送按钮;按钮文案随状态切换 `Send` / `Steer` / `Save & Submit`,占位符提示新快捷键。

## 测试
- 新增专项单测全部通过:`CodexProtocolClient.steer`(无活动回合拒绝 / 携带正确 `expectedTurnId`)、`AgentManager.steer`(命中活动回合、无 threadId 空操作、后端不支持时报错)、`ipc` 的 `agent:turn-steer` 转发、`MentionInput` 的 Enter 直发 / Shift+Enter 换行 / 运行中路由到 steer / IME 合成不误发。
