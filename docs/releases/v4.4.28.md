# v4.4.28 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.27

上一版把参考素材的上传挪到了「拖进去那一刻」,但你看不见它。这一版把这件事显示出来。

## 素材上传现在看得见

4.4.27 起,图和视频拖进视频工作台就开始往云端传,不用等你点生成。问题是界面上没有任何
痕迹——传没传、传完没有、传失败了没有,全靠猜。点生成时如果卡住,你也分不清是在等上传
还是在等别的。

现在每个素材缩略图右下角有个小角标:

- **转圈** —— 正在传
- **打勾** —— 传完了,点生成会直接用云端地址
- **感叹号** —— 传失败了

传失败不影响你继续用。点生成时会退回原来的路子,把文件交给主进程现场处理,只是要多等
一会儿。角标是给你看的信息,不是拦路的关卡。

## 悬停看地址,右键复制

鼠标停在缩略图上,提示里会连云端地址一起显示。想拿这个地址做别的事——发给别人、贴进
别的工具、在浏览器里打开核对传的是不是那张图——右键有两项:**复制链接**、**在浏览器中
打开**。

只有传完的素材才有这个菜单,没传完的右键还是系统默认菜单。

## 一件我们试过又退掉的事

角标状态**不会跨重启保留**。关掉应用再打开,已经传完的素材会回到「没传」的样子,下次点
生成会重新传一遍。

这不是没做完,是做了之后退掉的。把云端地址存进本地看起来更省事,但那个地址指向的对象
可能早就被清理了——存下来的是个看着有效、点进去 404 的死链,而且它会让「点生成」直接
拿去用,失败得比重传一次更难看。重传的代价是一点带宽和几秒等待,死链的代价是一次莫名
其妙的任务失败。

后面如果给这些地址加上有效期和自愈重传,再把它捡回来。
