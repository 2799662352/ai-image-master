# v4.5.5 发行说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.5.4

## 紧急修复:4.5.4 里图片和视频打不开

**如果你已经升到 4.5.4,请更新到这一版。**

4.5.4 里文件面板的图片/视频预览会显示「加载失败:无法读取 …」,点什么都打不开。
4.5.3 及更早版本不受影响。

## 怎么回事

4.5.3 之后的一次改动把预览改成了一种流式协议,想解决「点开大视频卡死」。那条路在
Windows 上走不通 —— 系统在解析地址时会把盘符(`D:`)吞掉,请求根本发不出去。

这个问题在发布前**已经被发现并撤回过**,但撤回没能进到发布分支:合并流程在同步主干
时,把撤回当成了「没有改动」而用主干上的旧版本覆盖了它,于是坏代码原样发了出去。

这一版把撤回重新做了一遍,并加了一条守卫测试防止同样的代码再次出现。

## 4.5.4 的其余改进都还在

- 点开媒体不再卡死(原生解码,不再用逐字节循环还原)
- 文件监视的重复广播(「越用越卡」)已修
- 文件树点选与展开更跟手
