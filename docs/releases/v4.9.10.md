# v4.9.10 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.8

## 概述

聊天框能说话了:语音输入、朗读回复。谷歌 Nano Banana 三个模型现在也能用平台余额出图;内置 Codex 升级到 0.159.2,AI 助手终于能看到出图、出视频工具的完整参数说明;宠物支持自己安装,新版宠物的视线会跟着鼠标走。

## 语音

- **语音输入**:输入框旁边的麦克风。识别引擎可选「千问实时识别」(平台余额)或「Vosk 离线识别」(免费,首次使用下载约 44 MB 模型)。也可以按住 F8 说话,松手结束这段话。
- **说完后**:在设置里选「自动发送」或「只填进输入框,我自己发」。自己发的模式下,识别的文字接在你已经打的字后面,不会覆盖。
- **停一下不会被抢着发出去**:「停顿多久算说完」可选 1 / 2 / 4 秒(默认 2 秒);句子停在「然后」「那个」「就是」或逗号这类还没说完的地方时,会自动多等一倍。等待发送时麦克风下面有倒计时条。
- **朗读回复**:喇叭按钮。引擎可选「千问实时合成」或「豆包音频」(都走平台余额),可以选音色、分句朗读、限制每条回复最多念多少。系统拦下自动播放时,点一下喇叭就能继续。
- 语音和朗读合成了一个按钮,设置面板不会再被侧边栏挡住。

## 谷歌 Nano Banana 走平台余额

- **Nano Banana 2 / Nano Banana Pro / Nano Banana**:计费切到「平台余额」后,这三个模型以前仍然扣「API 站点」里自填的密钥。现在和腾讯 image、Seedream 一样扣账号余额,没填自填密钥也能直接出图。
- 自填密钥的用户:这三个模型的请求改走 HTTPS 加速域名,密钥不再经过明文 HTTP。

## 内置 Codex 升级到 0.159.2

- **AI 看得到完整的工具说明**:出图、出视频和视频工作台批量建卡 / 批量修改这四个工具的参数说明较长,旧版 Codex 超过 5,000 字节就会把所有参数说明删掉,AI 只看得到参数名(比如「用户附了图必须当参考图传进来」「count 在按 token 计费的渠道上会翻倍收费」这类规则)。现在说明完整保留。
- **GPT-6 系列**:新增 GPT-6.1 Sol / GPT-6 Sol / GPT-6 Luna,与 GPT-6 Astra 一样按 272K 上下文处理;此前被当成未知模型按 200K 提前压缩、切换时还会重启。
- Windows 下 Codex 启动后台进程时不再闪黑窗口。

## 宠物

- **自己装宠物**:把宠物包放进 `<CODEX_HOME>/pets`(默认 `~/.codex/pets`,和 Codex 桌面端是同一个文件夹),选择器里就会出现,带「自装」标记;选择器底部有「打开宠物文件夹…」入口。尺寸不对的包会被跳过,不会错位。
- **视线跟着鼠标**:新版(V2)宠物待机时会看向鼠标(16 个方向),鼠标停下 2.5 秒后回到待机动画。
- **内置三色 Pixel Miku**(经像素画作者同意随客户端分发)。
- 宠物按钮缩成一个小图标。
- 修复:窗口缩小或面板挪位后,宠物可能被拖到可视区域外「消失」,现在会自动拉回可见区域。

其余 4.9.8 的功能不受影响,无需重新设置。
