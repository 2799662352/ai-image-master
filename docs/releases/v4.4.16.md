# v4.4.16 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.15

## 出图

- **谷歌生图返回 URL 时不再报「生成失败」**:Gemini 原生端点并不总是回内联
  base64——网关把产物传到对象存储后,整条响应里只有一条写在文本里的预签名 URL。
  此前的解析只认 `inlineData`,于是图明明已经生成成功,界面却报「未能从响应中
  提取图片」。现在文本里的图片地址同样收下。
- **顺带修掉预签名 URL 被截断**:同一段解析服务的另一条分支(Chat Completions
  文本内嵌图片)会把地址截断在 `.png` 处,丢掉后面的签名参数——这样的链接必然
  403。现在连查询串一起取。

## 网络抖动下的出图

- **生成失败不再无声无息**:单图生成页此前遇到任何失败——网络断连、上游报错、
  重试耗尽、超时——都只是把按钮变回"开始生成",既不出图也不报错,原因只在
  开发者工具里看得到。现在会把上游给的原因直接告诉你。同一个原因连续失败两次
  时的第二次、以及并发点两次时把别人的图算成自己的,一并修正。
- **图片加载失败会自己重试**:生成结果网格、大图预览、历史卡片与历史大图,
  遇到网络抖动会退避重试两轮,仍失败才显示占位。此前生成页是浏览器原生裂图、
  历史卡片则一次判死不自愈。重试用重新挂载而非给地址加参数——这些是预签名
  地址,改查询串会让签名失效。
- **转存重试**:出图后把字节抓回本地、再推云端的那一步此前只试一次。它一失败
  就同时没有本地副本也没有云端副本,历史里只剩一条几小时后过期的临时地址。
  现在会重试,但对签名过期(403)这类确定性失败不做无谓重试。

## 视频工作台

- **时长下拉补齐 7 / 9 / 11 / 13 / 14 秒**:此前只列了 4/5/6/8/10/12/15,想要
  7 秒或 9 秒的镜头只能退而求其次选 6 秒或 8 秒。这五个值并非上游不支持——
  校验层收敛的一直是连续的 4–15 秒区间,是选项表本身列漏了,其余链路本来就接受。
