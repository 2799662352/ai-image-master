# v4.4.9 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.8

## 概览

本版聚焦两条线:**Codex 0.145 深度适配**——原生音频输入、编辑重发的
服务端上下文分支、跨会话记忆(memories)三项上游能力全部接入;
以及**工作台/界面体验**——agent 操作工作台时可观测全局状态,
工作区展示栏可单独收起,宠物浮层不再被工作区面板遮挡。

## Codex 0.145 深度适配

- **原生音频输入(#96)**:聊天附件里的音频文件(wav/mp3/m4a/ogg/
  opus 等)改为以 Codex 原生 `localAudio`/`audio` 输入项发送,
  模型可直接理解音频内容,不再只收到一段文件路径文本;
  时间线渲染同步标记为音频类型。
- **编辑重发的上下文分支(#97)**:编辑历史消息重发时,主进程用
  `thread/fork` + `lastTurnId` 在被编辑回合之前分叉服务端会话,
  与本地 UI 截断严格对齐——原会话保留,新分支干净续写;
  同步修复了旧消息在重开会话时从数据库"复活"的问题;
  分叉失败时自动降级为同线程重发并给出警告提示。
- **跨会话记忆 memories(#99)**:冒烟实证 `features.memories` 在
  0.145 已转 stable 且启动配置固定开启;接线
  `thread/memoryMode/set` 与 `memory/reset` 两个 RPC(协议客户端→
  Backend→AgentManager→IPC→preload 五层贯通);设置页新增
  「跨会话记忆」开关(默认开,关闭时显式下发
  `-c features.memories=false` 并持久化)与两步确认的
  「清除记忆」按钮。

## 工作台与界面体验

- **agent 全局状态观测(#95)**:5 个 `video_workbench` MCP 工具
  对齐 MCP 2025-11-25 结构化输出(`outputSchema` +
  `structuredContent`);`status` 返回页面清单(ID/名称/卡片数)
  与当前活动页,引用素材附带紧凑名称与 ID,写操作(加卡/改卡/
  开工/删卡)一并返回全局工作台摘要——agent 每次操作后都能
  看清整个工作台的最新状态。
- **工作区展示栏可单独收起(#98)**:文件浏览器 + 查看器面板新增
  收起按钮,CSS 滑出但保持挂载(画布 keep-alive 不卸载),
  左缘留一条把手可随时展开;打开画布/AI 改动/引用等自动解除收起,
  露出底下的生图生视频界面。
- **宠物浮层层级修复(#98)**:宠物改为 portal 到 body 顶层渲染,
  层级高于工作区浮层,不再被文件浏览器面板盖住;
  锚点镜像定位仍跟随输入框。
