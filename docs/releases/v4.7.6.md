# v4.7.6 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.7.4

## 概述

这一版加两个模型，并把出图的默认渠道换成腾讯 image2。

> 4.7.5 因发布流水线中断未上线，其内容已并入本版。

## 聊天新增 DeepSeek V4（可用平台余额）

模型选择器里多出 DeepSeek V4 Flash 与 DeepSeek V4 Pro 两档（标注「Miau」的那两行）。

与原有的 Right.Codes DeepSeek **并存**，不是替换——两边是同一代模型的不同来源，差别在于新增这两档走 Miau 网关，因此**能用平台余额结算**；原有那两档仍只能用自填 Key。名字上带日期后缀（`-0731` / `-0813`）的是新增的这两个。

## 出图新增腾讯 image2 fast

生成页、聊天的出图渠道、MCP 工具三处都能选到。

与原有的腾讯 image2 是两个不同的模型、两条不同的渠道，可以按需要挑：

|  | 腾讯 image2 | 腾讯 image2 fast |
|---|---|---|
| 出图耗时 | 约 30s | 约 20s |
| 价格 | 基准 | **约 1/6** |
| 一次出图张数 | 1 张 | 可多张 |

能力上两者一致：文生图、参考图编辑、比例 × 分辨率（1K/2K/4K）× 清晰度三参数、网关去水印都支持。

## 默认出图渠道改为腾讯 image2

此前默认是 VIP。**已经手动选过渠道的用户不受影响**，保留自己的选择；没选过的会落到腾讯 image2。

需要注意一点：腾讯 image2 只经 Miau API 代理提供，所以没配 Miau API 站点 Key 的用户会看到明确的提示「未配置『Miau API』站点的 API Key」。到「API 设置」为 Miau API 站点填入 Key 即可，**不需要**切换当前站点。

聊天里 agent 仍可为具体任务自行切换渠道（比如出前后一致的组图时切到万相 2.7 pro）——选择器设的是默认，不是锁死。

## 其它

- 出图渠道清单收敛成一处。此前生成页、聊天、MCP 各存一份，新增模型时容易出现「有的地方看得见、有的地方没有」——现在三处同源。
- 顺带补齐了 agent 技能文档里此前漏登记的渠道（千问 Image 3.0 Pro、腾讯 image2），agent 现在能正确响应「用千问出图」这类点名。
