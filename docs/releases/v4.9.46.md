# v4.9.46 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.45

## 概述

一件事:**设置页「API 站点」里的「本地服务」改成「自定义网关」,可以填任意 new-api 网关的完整地址(本机 / 局域网 / 公网),并且复用官方 Miau 网关的全部能力**——出图、对话理解、视频、Codex 的 Miau 通道,都发往你填的地址、用你自己填的 API Key(#475、#476)。

## 变化

### 自定义网关可填完整 URL(#475)

- 站点卡片改名「自定义网关」(内部 key 仍是 `local`,已存的 Key 和当前站点选择都不丢)。
- 原来的端口框改成网关地址输入框,可填 `https://…`、`http://192.168.…`、`api.example.com`、`3000`;失焦后归一化;不合法时提示并写明当前仍在用哪个地址;公网明文 `http` 会有警告。
- 旧版 `ai_image_local_port` 升级后仍然生效。
- 地址里的站点子路径(如 `/newapi`)会保留。
- 内容安全策略(CSP)的 `connect-src` 放行 `http:`,否则局域网 / 公网明文网关的请求会被浏览器层拦掉;`img-src` / `media-src` **刻意没放**。

### 自定义网关复用 Miau 的全部能力(#476)

选中「自定义网关」后,下面这些都改发到你填的地址,并使用该站点下你自己填的 Key:

- 出图(包括 Miau 专属模型)、对话理解;
- Seedance / cn-seedance / 万相视频;
- Codex 的 Miau 通道(Codex 会因此重启后端一次,见下方「行为变化」)。

**不在范围内,仍只走官方网关**:平台余额、人像库、充值。设置页加了一段说明,写明哪些功能发往这个地址、哪些只在官方网关上可用。

**核心约束:平台的钱不会发往你填的地址。** 平台影子 token 和归属头(`X-Platform-User-Id` / `X-Project-Id` / `X-Producer-Project-Id` / `X-Catimation-Billing`)只属于官方网关:

- 主进程:自定义期间平台 token 不再取用;带归属头的请求发往自定义地址会直接抛错;Codex 的平台头在自定义期间为空(即使你把官方域名填进去也一样)。
- 渲染端:选中自定义网关时「有效计费来源」恒为「自填 Key」,但**你在额度页里选的偏好不会被改写**,切回官方后原样恢复。视频工作台(提交 / 体检 / 分辨率口径)、人像库弹窗、智能擦除都读这个有效值;主进程的视频工作台提交处另有一道同样的兜底。

## ⚠️ 行为变化(请知悉)

- 站点显示名:「本地服务」→「自定义网关」。
- 选中自定义网关后,视频工作台的分辨率口径按「自填 Key」算(组件测试里 Seedance 2.5 的分辨率下拉从 480p / 720p / 1080p / 4k 收成 480p / 720p;其它模型按各自的自填 Key 口径,没逐个核),人像库弹窗改显示「自填 Miau Key 模式下没有人像库……」的提示、不再请求人像库。
- 切换自定义网关(或在其下改 Miau Key)会让 Codex 后端重启;关闭自定义网关时可能重启两次。
- **平台余额下已提交的 wan3 / depth / kling 视频任务,切到自定义网关后会继续轮询,打到自定义地址并带你自己的 Key**(这一类任务“轮询跟提交时钱包一致”的约束在这里不成立)。有未完成的这类任务时,先别切。
- 自定义网关返回 `http://` 的图片地址时,因为 `img-src` 没放行,图可能显示不出来。
- `asset://` 人像库引用在自填 Key 下不可用。
- 语音、`videoBadcase`、知识库的平台中转仍走官方网关。
- 本版没有改技能 / 插件文件,插件商城与技能商城不需要随版发布。
