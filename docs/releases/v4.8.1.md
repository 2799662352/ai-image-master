# v4.8.1 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.8.0

## 概述

视频工作台的一部剧现在可以整体导出成一个工程文件，再在任何一台机器上导入回来。上一版剧栏底部两个灰着的按钮「导入工程 / 导出当前剧」这次亮了。

## 导出当前剧

剧栏底部「导出当前剧」，或总览右上「导出工程」，先出一个确认页：

- 一行看清要导出什么：「剧名 · N 段 · M 镜 · K 个素材（其中 j 个待上传）」。
- 保存位置默认在「文档 / CATIMATION 工程 / 剧名.catwb.json」，旁边「更改…」可以换地方。
- 一句说明：**素材和成片以云端地址保存；文件包含全部提示词。** 文件里没有图片字节、没有本地路径，一部剧几十到几百 KB。

点「导出」后，还没有云端地址的本地素材、只有本地副本的成片会先上传再写文件，进度就在页上；上传服务器连不上就整个不写——不会留下半份工程，失败原因会写明是网络问题。写完显示「已导出到 …」和「在文件夹中显示」。

老项目里常有参考图所在的盘没挂、或者文件已经删了。这种情况导出会先停下来，把找不到的素材全部列出来：挂上盘再「重试导出」，或者点「跳过缺失素材并导出」——这些素材从对应卡片上去掉，其余原样导出，成功后会注明跳过了几个。

## 导入工程

剧栏底部「导入工程」（或总览右上）打开系统对话框选 `.catwb.json`；也可以把文件直接拖到左侧剧栏上。确认页显示：

- 剧名（可改；本机已有同名剧时自动加「(2)」）
- 「N 段 · M 镜 · K 个素材」，以及「导出于 <时间> · 客户端 <版本>」
- 点「导入为新剧」：永远新建一部剧，同一文件导两次是两部独立的剧；已完成 / 失败的卡保留状态和成片地址，当时排队或生成中的卡重置为待生成。

由更新版客户端导出的文件、格式不对或损坏的文件，在确认页直接给出原因，按钮不可点。

## 其它

- 以前粘贴进卡片的图片如果一直是内嵌的 base64（离线粘贴、当时上传失败、老版本存下的），启动后会在空闲时自动补一次上传换成云端地址；成功后卡片体积变小、导出也不用再等。
- 工程文件格式带版本号，未知字段会被保留放行，后续版本可以平滑扩展。
