# v4.3.69 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub 源码同步
> 上一个发布版本:v4.3.68

## 概览

本次聚焦 **apiyi MCP(Gemini 音频 / 视频深度理解)的接入可靠性**:复用设置里的 Key、无 Key 时不再拖慢 agent 启动、工具稳定可见、单个慢启动服务器不再拖垮整张工具面板、每个 MCP 服务器可单独刷新。同时附带出图默认渠道调整、`file://` 媒体在沙箱渲染进程的显示修复,以及首方 skill / 出图质检同步。

## 变更

### apiyi MCP:复用 Key、无 Key 不启用、工具稳定返回
- **复用设置里的 Key**:apiyi-mcp 的 `APIYI_API_KEY` 直接读取「设置 → API易」站点保存的 Key(`apiKeys['apiyi-mcp']`),用户无需在 MCP 面板二次填写。Key 在 codex 启动时通过 `-c mcp_servers.apiyi.env.APIYI_API_KEY` 注入,**永不写入 `config.toml`**。
- **改 Key 即时生效**:更换 Key 时仅在「值确实变化」时重启 codex,使新 Key 立刻生效;开机 / MCP 页冷启动的幂等回推为 no-op,不会造成重启风暴。
- **无 Key 自动不启用**:localStorage 与 `config.toml` 均无 Key 时,启动参数注入 `mcp_servers.apiyi.enabled=false`,避免无 Key 的 apiyi 进程在 agent 首轮 `list_all_tools()` 上挂起拖慢启动。
- **工具稳定可见**:把 `apiyi` / `mcp__apiyi` 加入 `features.code_mode.direct_only_tool_namespaces`,工具不再被 `tool_search` 延迟暴露;有 Key 时套用 `startup_timeout_sec=60`、`tool_timeout_sec=2000` 的宽松超时。
- **单个不拖累全部**:`mcpServerStatus/list` 的 RPC 超时由默认 30s 提升到 **90s**(大于最大单服务器 `startup_timeout`),apiyi 慢启动期间其余服务器工具照常显示,apiyi 就绪后自动补齐,不再误弹失败横幅。
- **逐个刷新**:每个 MCP 服务器卡片新增独立「刷新」按钮(`refreshServer` + `syncingByName`),可单独刷新而非一起全量刷新。

### 出图默认渠道改为腾讯 image2(无水印 / 快)
- `generate_image` / `generate_images` 默认渲染渠道由 `gpt-image-2-vip` 改为 **`custom-imagemodel-gt`(腾讯 image2,约 30s、无水印)**。
- 新增可选渠道 **`gemini-3.1-flash-image`(Nano Banana 2,谷歌 Gemini 原生端点,快、按需 4K)**;`gpt-image-2-vip`(OpenAI 官道)保留为稳定备选,`wan2.7-image-pro`(万相 2.7 pro,超清 / 编辑 / 组图)按需选用。
- gpt-image-2 三轴参数(比例 × 分辨率 × 质量)路径修正:vip 编辑(multipart)请求同样携带 `quality`;腾讯 image2 的 multipart 回落路径补 `extra_body: { logo_add: 0 }` 去水印。

### `file://` 媒体在沙箱渲染进程的显示修复
- 沙箱渲染进程无法直接加载 `file://`(Chromium 报 "Not allowed to load local resource")。现在在唯一渲染入口 `toRenderableUri` 将 `file://` 归一化为 `local-file://`,并在 `useResolvedMediaSrc` 中把 `file://` 字节走 IPC 读取。
- 修复 codex 产物落盘回退路径、Seedance 任务监听、codex MCP `file://` 资源链接产出的图片 / 视频在聊天中不显示的问题。

### 首方 skill 与出图质检同步
- 首方内置 skill(`firstPartySkills`)与插件市场 `catimation-*` 源对齐;`catimation-image` Step 5 自检升级为「符合要求 / 质量合理 / 风格一致 / 过 skill 门」四项验收清单,不达标带改进提示词重生成。

## 测试
