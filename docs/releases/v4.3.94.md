# v4.3.94 发布说明

> 发布渠道：腾讯云 COS 热更新（`releases/latest.yml`）
> 基线版本：v4.3.93

## 概览

本版将应用内 Plan 模式对齐 Codex 0.144.1 的实验接口契约，补齐线程级设置、
动态推理强度、状态确认与降级体验；同时将桌面构建和发布流水线收敛为 Windows
单平台，修复 E2E 参数传递问题。

## Plan 模式

- 使用 `collaborationMode/list` 获取官方 Plan 预设，并根据当前模型能力动态过滤
  推理强度，不再硬编码固定档位。
- 已有线程通过 `thread/settings/update` 更新下一回合设置，并消费
  `thread/settings/updated` 完整状态通知；旧版 Codex 自动降级为仅下一回合生效。
- Plan、Default、Auto 及具体推理强度在切换线程、模型和恢复会话时保持一致，
  UI 明确区分即时生效、下一回合生效、待确认和失败状态。
- 相同 mode/effort 的更新可能只返回空确认而不发送通知；现已在成功确认后结束
  pending，后续服务端通知仍会校准最终状态，避免界面永久等待。

## Windows 构建与发布

- GitHub Build、CI 打包和 Release 流程仅生成 Windows 安装包。
- 打包前显式下载 Codex、FFmpeg 和 Docker MCP Windows runtime，并使用
  `GITHUB_TOKEN` 访问 GitHub。
- 修复 Playwright project 参数被额外 `--` 解析为测试过滤条件的问题。
- 新增工作流契约测试，守护 Windows runner、runtime 下载、产物路径和 E2E 命令。

## 验证

- Plan 模式关键回归：104/104 通过。
- Windows-only 工作流契约：5/5 通过。
- `npm run build:vite`、Windows 安装包、blockmap 与 `latest.yml` 在发布流程中验证。
