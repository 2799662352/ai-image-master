# v4.9.11 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.10

## 概述

登录后,AI 助手查运镜知识库和 Sakuga 数据集直接扣平台余额,不用再自己申请阿里云密钥;顶部导航标签在窗口放不下时可以左右滑动;内置 Codex 升级到 0.161.0。

## 运镜知识库 / Sakuga 检索走平台余额

- **登录后按平台余额计费**:AI 助手查运镜知识库(`search_cinematography_kb`)和 Sakuga 数据集(`query_sakuga_dataset`)时改扣账号余额,不再需要在「设置 → 运镜知识库」里填 DashScope / DashVector 密钥。
- **价格**:运镜知识库每次 ¥0.1;Sakuga 检索每次 ¥0.3(向量检索 ¥0.1 + 生成查询向量 ¥0.2)。上游报错的请求不扣费。
- **自填密钥仍可用**:没登录、或平台暂时提供不了这项服务时,自动改用你自填的密钥;余额不足、上游报错这类情况会直接提示,不会改扣你自己的密钥。
- 登录、登出、切换计费方式即时生效,不用重启 AI 助手。
- 修复:AI 助手的启动日志不再把自填的 DashScope / DashVector 密钥明文写进日志。

## 顶部导航标签可以左右滑动

- 窗口不够宽时,顶部功能标签(生成图片 / 批量生成 / … / AGENT)以前会两头被截掉,最左、最右的页签点不到。现在放不下时可以左右滑动:鼠标移到标签栏上,灰色底线下方会浮出一条细滑块,可以拖动,也可以点滑轨跳过去;在标签栏上滚鼠标滚轮也能左右滑。
- 切换页签时,当前页签会自动滚到看得见的位置。
- 标签放得下时,外观和以前一样。

## 内置 Codex 升级到 0.161.0

- 用 `/goal` 设定或清除目标时,会明确记成「你下的指令」,线程重新加载或上下文压缩之后,AI 仍然知道这个目标是你设的。
- 上游修复:请求失败重试时遵守服务器给出的等待时间;恢复会话时带上最新的历史记录。

其余 4.9.10 的功能不受影响,无需重新设置。
