# v4.9.33 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.32

## 概述

三件事:① **GPT Image 2.6 能出 GIF 动图和 SVG 矢量图**(默认渠道腾讯 2.6 与 apiyi 官转 2.6 都支持);② 接入 **apiyi 官转 GPT Image 2.6**(Flare / Sunburst);③ 出图渠道面板「按系列」补全,以及走 Miau 的 agent 线程不再把锅甩给 Right.Codes。

## 变化

- **GIF / SVG 输出。** 生成页选 GPT Image 2.6 后多一项「输出格式」(PNG / GIF 动图 / SVG 矢量),高级参数里有 GIF 帧数(2–16,不填 = 9 帧)、GIF 每帧时长(20–2000 毫秒,不填 = 200)和 SVG 写手选项。批量页同一份参数表。只支持文生图、一次一张,不能带参考图 / 遮罩 / 透明底(带了会在发请求之前给出中文原因,不会悄悄降级)。
  - **腾讯 2.6(`custom-model-og-v2.6-f` / `-s`,含默认渠道):** SVG 写手固定 `gpt-5.4-mini`,只开放推理强度 `none` / `low`(默认 `low`;`medium` 约 110 秒、`high` 上游会断连,不开放)。GIF 每帧最长边 **512**——不随 1K / 2K / 4K 档放大,因为费用随拼图面积走。
  - **apiyi 官转 2.6(`gpt-image-2.6-flare` / `-sunburst`):** SVG 写手默认 `gpt-4.1-mini`,可选 `gpt-5.6-terra`、`gpt-6-luna`。GIF 每帧最长边 960。
  - **不开放:** JPEG 输出、`complexity`(上游没有可见效果)、`markup` 图层(网关不转发)。
- **agent / MCP。** `generate_image` 的 `modelParams` 认这些键;agent 在不支持的模型上要 GIF / SVG、或把两家的写手键用串(`svg_model` 只给 apiyi,`svg_effort` 只给腾讯),会被明确拒绝并点名可用型号,不会再悄悄拿到一张 PNG。`catimation-image` 技能同步。
- **接入 apiyi 官转 GPT Image 2.6**(Flare / Sunburst):文生图、原生多图、透明底、mask 局部重绘 / 灯箱擦除都经真实调用验证。
- **出图渠道面板「按系列」补全。** 进了「常用」「备用」的渠道不再被从系列里拿走(之前 GPT Image 系列缺 2.6 Sunburst / 2.5 / image2,Gemini 系列缺 Nano Banana 2.1);左栏「更多模型」改为「全部模型」。
- **走 Miau 的 agent 线程知道自己跑在什么上面。** 千问 / DeepSeek / Grok 的 Miau 渠道用的是 `rightcode` / `apiyi` 这类内部组名,模型读到配置后会把 Miau 侧的行为说成 Right.Codes 的问题;火山 DeepSeek 还会说「没有 web_search 工具」(平台托管的搜索本来就不在函数工具列表里)。新建线程现在带一条简短的开发者说明。只对**新线程**生效。

## 修复

- **agent 出图落盘把 GIF 存成 `.png`。** apiyi 的 GIF 存在 `.png` 键下并回 `Content-Type: image/png`,而 agent 出图落到 uploads 的那条路径只信响应头,结果文件名是 `<hash>.png`、内容却是 GIF,播放器按静图处理。现在以文件头字节为准。
- **GIF 在 1K / 2K / 4K 档上被网关拒绝(400)。** 这些档按「每帧」给尺寸,放进拼图全部超预算;GIF 请求现在一律把每帧缩到安全尺寸。
- **GIF / SVG 上传云端时落成 `.png`、`image/png`。** 现在上传也以文件头字节为准,SVG 不再成为裂图。

## 注意

- **费用(按次 / 按 token,实测):** 腾讯 GIF 默认画质(高)下 512² 9 帧约 ¥0.51,4 帧低画质约 ¥0.11;腾讯 SVG 1K 低画质约 ¥0.24、2K 低画质约 ¥0.42、2K 高画质约 ¥0.81。apiyi 官转的 GIF 每帧上限 960,同样 9 帧约比腾讯贵 3 倍。**不要把腾讯的 SVG 写手换成 `gpt-4.1-mini`**:同档实测贵 3.4 倍。
- apiyi 官转 SVG 的写手模型费用上游不回传,网关只按出图 token 收费,所以没有统计。
- SVG 在界面里用 `<img>` 显示(脚本不会执行);桌面端本身不做 SVG 净化,另存为 / 在别处打开前请当作不可信文件。
- 合并后 `catimation-image` 的 SKILL.md 变了,插件市场的 `catimation-core` 随版再发布一次(1.0.37)。
- MCP `generate_image` 的 schema 贴着 16384 字节预算(现 16359),下次再加说明会先被 `toolSchemaBudget` 守卫拦住。

## 已验证

- 真实窗口 + 生产网关(2026-11-09):腾讯 `-s` GIF(4 帧 / 120 ms / 512×512,`.gif` 后缀,`image/gif`)、腾讯 `-s` SVG(合法 `<svg>`,20 个 path,`.svg` 后缀,`image/svg+xml`)、腾讯 `-f` GIF(1K 档请求实际 512×512、2 帧 / 200 ms);帧数越界、跨格式参数在界面上给出拒绝文案;让 agent 经 MCP 出过一张真 GIF(16 帧);apiyi 的 `.png` 键 GIF 经落盘路径现在得到 `.gif`(文件头 `GIF89a`)。
- 更早的真实调用:GIF 2 / 9(默认)/ 16 帧、尺寸 512 / 720 / 960、每帧 50 / 100 / 3000 ms,SVG `none` / `low` 与 2K 高画质,JPEG 输出(没有开放),两家渠道各自的拼图尺寸上限。
- 新增用例先红后绿;相关目录单元测试通过;`typecheck:ci` 7 个既有 / 0 个新增;`skills:gen:check`、`audit:skill-arch` 通过。
