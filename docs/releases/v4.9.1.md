# v4.9.1 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.9.0

## 概述

一处修正：4.9.0 安装包里顶栏按钮、模型选择器等一批样式没有生效（顶栏是一排没有边框的小字，模型按钮只剩文字）。开发环境里看不到这个问题，所以 4.9.0 发出去才暴露。

## 顶栏 / 模型选择器样式恢复

原因是页面里引用 `css/main.css`（它串着 base / components / animations / responsive 五个样式文件）的那一行用了相对路径的预加载写法，打包时被构建工具整个丢掉，于是这五个文件在安装包里一直没有加载过——以前顶栏的样式压在另一套工具类上看不出来，4.9.0 把新顶栏和厂商分组模型面板的样式放进 `components.css` 之后就直接裸奔了。

现在改成普通的根路径样式引用，打包后按相对路径正确加载。升级到 4.9.1 后你会看到 4.9.0 说明里描述的样子：

- 顶栏是一排同高的方形按钮（AGENT / 导演台 3D / 活动 / 余额 / 设置 / UPDATE / 语言），横幅铺到窗口两侧到头，Logo 两行。
- 模型按钮显示「厂商小标签 + 模型名」，点开是左厂商、右模型的两栏面板。

其余 4.9.0 的功能（GPT Image 2.5、原生多图、Codex 抽屉改版、草图板、图片标注 / 擦除、Codex 0.154.0）不受影响，无需重新设置。
