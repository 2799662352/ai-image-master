# v4.9.24 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.23

## 概述

三件事:**① 接入 NovelAI 四个模型(生成页 / Codex 出图渠道 / MCP / 技能);② Codex 页「出图渠道」选择器改成两栏分区面板;③ 修复聊天面板缩窄时输入框工具栏被挤乱、弹层被挡住的问题。** 插件市场的 `catimation-core` 同步发布 1.0.34(`catimation-image` 补了 NovelAI 说明)。

## 变化

- **NovelAI 四个模型**:`nai-diffusion-5-full` / `nai-diffusion-5-curated` / `nai-diffusion-4-5-full` / `nai-diffusion-4-5-curated`(V5 与 V4.5,各有 Full / Curated 两套数据集)。**只经 Miau 网关**,按**每张图**固定价计费(约 ¥0.6–0.65/张,1K / 2K 同价),`count` 1–4 张。默认出图渠道不变。
  - **可调参数**(生成页、批量页、MCP 共用一张参数表):数据集模式(动漫 / 兽人)、负面提示词、**角色提示词**(每个角色有自己的提示词、角色专属负面词和 x / y 位置;V5 最多 22 个、V4.5 最多 6 个)、步数、CFG、采样器、噪声调度、种子、图生图强度 / 噪声(只在带 1 张参考图时生效)。未设置就是默认;**越界值一律拒绝,不会悄悄截断**(因为按张计费)。透明底只有 V5 支持,参考图至多 1 张。
  - **agent(MCP)**:`generate_image` / `generate_images` 的 `modelParams` 现在同时认悠船和 NovelAI 的参数,各自只对自己的渠道生效。技能里写明「用户明确要求才传」,agent 不会默认乱设。
- **Codex 页「出图渠道」选择器改成两栏面板**:左边分区(最近使用 / 常用 / 备用渠道 / 更多 · 按系列),右边是该分区的渠道、一句话说明和价格量级(只有确认过口径的 NovelAI 标价)。支持悬停切分区、键盘操作、把备用 / 更多里的渠道**固定到常用**(最多 10 个)、最近使用最多显示 3 个。渠道的选择、MCP 枚举和默认渠道都没动。
- **输入框工具栏窄屏分级收起**:聊天面板缩窄时,药丸**形状和高度不变、不丢任何按钮**,先用省略号收短名称,再收起徽标 / 推理等级 / 待机的「语音」字样,协作模式在更窄时只留图标,极窄才整颗换行。出图渠道和模型弹层现在夹在输入框范围内,不会冲出右边被挡住。
- **插件市场**:`catimation-core` 1.0.33 → 1.0.34(`catimation-image` 补 NovelAI 四条渠道与用法);其余插件和单技能没有变化。

## 注意

- NovelAI 每张约 ¥0.6,`count` 设 4 就是约 ¥2.4;失败不会自动重试(`maxRetries: 0`),由你决定是否重来。
- 工具栏收起的宽度阈值(约 600 / 520 / 450 px)是按系统字体量出来的,不同字体下可能差几个像素。

## 已验证

- **相关测试全过**:NovelAI 的参数表 / 请求装配 / MCP / 参数面板各一组测试;两栏面板 53 条测试 + 6 种变异检查全被抓到;工具栏收起 10 种变异检查全被抓到;`features/agent-chat` + `features/voice` 139 文件 1392 条通过;`typecheck:ci` 7 existing / 0 new;`audit:skill-arch` 0 违规。
- **工具栏在真浏览器里量过**:把真实输入框渲染出的 DOM + 项目自己的 Tailwind 编出的 CSS,在 340–760 px 逐档量:无横向溢出、四颗主药丸高度恒为 27 px、460 px 以上单行不丢按钮、450 px 以下整颗换行。
- **插件市场线上读回**:`plugins-catalog.json` 里 `catimation-core` = 1.0.34。

## 还没覆盖的地方

- **没有对真实网关出过 NovelAI 图。** 网关会不会按预期处理角色提示词的位置(`character_prompts`)和负面词,没有验证;要用用户确认过的测试令牌(每张约 ¥0.6)才能测。
- **没有在安装包里看过新选择器和工具栏**:两栏面板与窄屏收起只在开发窗口里看过,没有装包实测。
- NovelAI 的「风格封面选择器」(64 张)是二期,没做;氛围迁移 / 角色精准参考上游暂不可用,没有暴露。
- 价格量级只给了 NovelAI,其他渠道没有填(不抄网页版的近 30 天均价,口径不同)。
