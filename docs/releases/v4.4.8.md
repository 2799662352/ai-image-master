# v4.4.8 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.7

## 概览

本版两件事:**Seedance 海外/国内站点路由**——同一套生成链路可在
海外站(默认)与国内站之间一键切换,模型 ID 随站点自动映射;
以及全新的**「生成视频」工作台**——卷轴式并发卡片页,批量提交、
后台轮询、草稿自动保存,agent 也能经 MCP 工具直接操作工作台。

## Seedance 海外/国内站点路由

- **双站点支持**:海外 GLOBAL(`vvdance.ai`,模型
  `dreamina-seedance-2-0` / `dreamina-seedance-2-0-fast`,默认)与
  国内 CN(`vvdance.yongmuai.com`,模型 `doubao-*`);API 域名、
  模型 ID、素材库端点全部随站点自动路由。
- **region 持久化**:站点选择与 API Key 一样经主进程 `safeStorage`
  加密落盘,渲染端只见状态;MCP `generate_video` 工具与设置页共享
  同一份配置。
- **设置页切换**:Seedance 配置卡新增「海外站 / 国内站」切换按钮,
  切换即时生效,无需重启。
- **防御性修复**:`seedance:set-config` handler 包 try/catch,
  非法输入不再让 IPC 链路整体报错。

## 「生成视频」工作台

- **卷轴式并发卡片页**:新顶层 tab「生成视频」(与画布 tab 换位),
  每次提交生成一张任务卡,多任务并行滚动展示——排队 / 生成中 /
  完成 / 失败状态实时更新,完成卡片可直接预览与下载。
- **复用 Seedance 生成链路**:提交走与聊天 `generate_video` 同一条
  `SeedanceTaskManager` 通道(buildContent → 提交 → 后台轮询 →
  本地落盘 + COS 备份),`source: 'workbench'` 标记让任务不再冒出
  聊天气泡。
- **IndexedDB 草稿**:提示词、参考图、参数改动自动存草稿,
  关页面/重启应用回来原样恢复。
- **5 个 `video_workbench` MCP 工具**:agent 可列出 / 读取 / 填充 /
  提交 / 清空工作台任务,与用户人机协同——用户在工作台摆好素材,
  一句话让 agent 批量开工。
- **宫格拆图隐藏**:历史页宫格拆图入口按新交互收进卡片菜单,
  减少误触。
