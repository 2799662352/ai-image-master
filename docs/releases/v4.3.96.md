# v4.3.96 发布说明

> 发布渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 兜底  
> 基线版本：v4.3.95

## 概览

本版重点强化 Windows x64 的构建、验证、发布与回退链路，并将内置 Codex CLI
升级至 0.144.3。应用功能与 app-server 协议保持兼容，无需迁移现有会话或配置。

## 发布可靠性

- CI 统一使用阻断式质量门禁，覆盖 TypeScript、单元测试与覆盖率、稳定 E2E、
  Skill 架构、工作流契约及 Vite 构建。
- Windows 安装包只构建一次，并以 SHA-256、SHA-512、文件大小和发布清单锁定
  唯一规范制品，后续 GitHub Release 与 COS 共用同一份制品。
- GitHub Release 与 COS 发布支持安全重试；COS 版本资产不可变，频道清单采用
  显式提升，避免半完成发布被客户端看到。
- 新增只读预检、失败摘要、历史制品恢复、公开可见性复验和热更新频道回退流程。
- Windows Authenticode 签名保持可选；启用证书时，发布链路会在上传前后复验签名。

## 跨平台 CI 修复

- TypeScript 技术债基线会归一化仓库绝对路径，在 Windows 与 Linux runner 间
  保持一致。
- Linux CI 现在能正确解析 Windows 保存路径中的文件名。
- 覆盖率门槛按跨平台 V8 基线校准，仍作为阻断式门禁保留。
- Electron E2E 使用隔离的用户数据目录，避免单实例锁与本地数据库互相干扰。

## Codex CLI 0.144.3

- 内置 Codex CLI 从 0.144.1 升级到 0.144.3。
- 此次升级不包含 app-server API 或 wire schema 变更；0.144.2 的 Guardian
  自动审查提示词回归已由上游回滚。
- Windows x64 的可执行文件、沙箱组件和路径代理均由固定 SHA-256 校验，
  防止上游资产被静默替换。

## 验证

- `main` 分支的 TypeScript、单元测试与覆盖率、稳定 Electron E2E、
  Skill 架构、发布契约和 Vite 构建全部通过。
- Codex 0.144.3 自动升级工作流完成，三个 Windows x64 运行时资产摘要已锁定。
- 正式发布前继续通过 `release.yml` 的只读 COS 预检、完整质量门禁和 Windows
  规范制品 dry-run 验证。
