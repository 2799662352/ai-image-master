# v4.9.22 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.21

## 概述

一件事:**视频工作台的任务详情里新增「效果问题反馈」**,Seedance 2.x 出片效果不对(角色漂移、字幕错误、闪烁、杂音等)时,可以直接把问题报给火山 Case 平台,并回来查处理进度。

## 新增:任务详情里的「效果问题反馈」

- **入口**:视频工作台 → 已完成的卡片 → 「详情」→ 「请求参数」下面的「效果问题反馈」→「提交 / 查看反馈」。
- **提交内容**:问题描述(必填,最多 5000 字)、问题类型(可多选,共 11 类:角色形象漂移、字幕生成错误、生成了 Logo / 水印、风格漂移、规律性闪烁、视频延长衔接跳变、角色重复出现、音频结尾杂音、中文发音错误、音色参考错误、其他)、联系方式(选填,最多 255 字)。字数按字符算,emoji 算一个。
- **查进度**:提交后点「刷新状态」查看处理状态、处理结果和附件。**只在点击时查询,不会在后台轮询。**
- **一个任务只能提交一次**:提交被拒时会先重查一次,查得到就直接展示已有记录并提示「该任务已提交过反馈」;提交成功但暂时查不到,显示「已提交,等待同步」,不会再给表单让你重复提交。刷新失败时保留上一次的记录。
- **什么时候出现**:任务已完成、模型是 Seedance 2.0 / 2.0 Fast / 2.0 Mini / 2.5、走平台余额(任务号以 `task_` 开头)。**自填 Key 直连、万相、可灵、未完成的任务不显示这一栏**。在历史版本里,按那一版自己的任务号和模型判断。
- **走哪个账号**:用当前选中的计费池的平台凭据请求网关,不扣费(网关侧 0 额度)。如果任务是在另一个计费池提交的,会提示「切换到提交这张卡时的计费池」再试。没登录时提示平台未就绪,请求不会发出。
- **附件**:只显示 https 链接,点击交给系统浏览器打开。

## 需要网关配合

- 网关要配置火山 Case 平台渠道(`VolcBadcase`),并对当前账号的令牌开放;没配时界面会提示「网关暂未对当前账号开通…」,不会影响其他功能。
- 对应网关改动见 new-api #188 / #189;网页版对应改动是 sora-ui #300 / #301。

## 还没覆盖的地方

- 没有对线上网关和火山 Case 平台跑过自动化验证;网关是否已配渠道需要你确认。
- 样片(Draft)任务没有单独排除;`2.0 Mini` 是否在 Case 平台范围内是按 Seedance 2.x 同族假设的。
- MCP / 技能里没有这个入口,只有界面。
- 问题类型不是必填(不选就不带这个字段);上游 Case 平台是否接受不带类型的反馈没有验证过。
