# v4.3.91 发布说明

> 发布渠道：腾讯云 COS 热更新（`releases/latest.yml`）
> 基线版本：v4.3.90

## 概览

本版升级 bundled Codex 到 0.144.1，补齐新模型与 MCP 鉴权协议；修复 9 张以上批量生图、截图粘贴和同名附件问题；同时交付 Sakuga-42M 全量云端检索与本地/OSS 双回源能力。

## Codex 0.144.1

- bundled Codex CLI 从 0.143.0 升级到 0.144.1。
- 新增 `model/list` 协议和离线冒烟校验，聊天模型选择器加入 GPT-5.6 Luna、Terra、Sol，并隐藏 GPT-5.4 以下模型。
- 推理力度选项按原生 `turn/start.model` + `turn/start.effort` 发送。
- 移除全局 272K 上下文窗口覆盖，允许 GPT-5.6 使用目录声明的 372K；继续保留 220K 自动压缩阈值，降低 relay 请求体过大风险。
- 支持 `mcpServer/elicitation/request` 的 0.144 响应信封和外部服务登录 UI。

## 生图与聊天附件

- `generate_images` 单次上限从 8 提升到 20，使用 3-worker 有界并发并保持结果顺序。
- 批量任务中的共享参考图只读取、编码一次，避免重复内存和 IPC 压力。
- 参考图保持原始字节，不做隐式 JPEG 压缩；上游返回 413 时由 Agent 使用 `ffmpeg-win` 生成压缩副本后重试。
- 对话框支持直接粘贴其他软件的截图，普通文本粘贴行为不变。
- 同名截图使用 renderer-only `composerId` 保持稳定身份，修复 `image.png` 重复 React key 和误删全部同名附件。
- `catimation-image` 首方 skill 与插件商城版已同步 413 处理约定。

## Sakuga-42M 全量云检索

- DashVector `sakuga42m` 已灌入 1,117,898 条元数据，索引完整度 1.0。
- `query_sakuga_dataset` / `get_sakuga_clip` 返回描述、技法、作者、作品、分类、时间码和原始来源。
- 优先返回本地原片路径；完整 OSS 镜像验证并启用后，可附带私有、限时签名 URL。
- 新增可恢复的全量灌库与 OSS 同步脚本，支持限流/网络瞬断重试和断点续传。
- `cinematography_kb` 固定为 Codex 直接可见命名空间，并覆盖生产 DashVector endpoint，避免工具被 deferred 后无法发现。
- OSS 源媒体同步仍保持暂停状态；热更新不会自动恢复上传，也不会把 `vectors_full/` 打入安装包。

- `npm run build:win` 通过后生成安装包、blockmap 和 `latest.yml`，并上传腾讯云 COS。
