# v4.9.26 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.25

## 概述

修一个 4.9.25 云备份的遗漏:**云端副本里没有参考图 / 参考视频 / 参考音频**。

## 变化

- **云备份现在会带上本地素材预传后的云端地址。** 拖进视频工作台的本地文件,卡片上记的是本地路径,预传到云端后的地址另存在素材的 `uploadedUrl` 里;4.9.25 的备份只认「本身就是 https」的素材,把这些预传过的素材当成「只在本机」整条丢掉,所以从云端恢复出来的剧没有参考素材。现在图片、视频、音频只要已经预传成功(有 https 的云端地址),备份里就会带上这个地址;本地路径仍然不会进云端副本。
- 「导出当前剧」同源:已经预传过的素材不再被当作「待上传」重复上传一次。

## 注意

- **4.9.25 已经备份到云端的旧版本不会被补上素材。** 升级后,本机还在、且带预传素材的剧,下一轮备份的内容比云端那份多了素材地址(内容指纹不同),会自动传一份新版本;从云端恢复出来的那份「旧副本」本身不会长出素材。
- 没有预传成功的本地素材(预传失败、或升级前入库就没有地址的)仍然不会进云端副本,界面照旧提示数量。
- 草稿卡的提示词、模型、分辨率、比例、时长、模式等一直在备份里,这次丢的只是素材;与具体模型(例如万相)无关。

## 已验证

- 新增 4 条测试,修复前 3 条红;**变异检查 3 种全部被抓到**(不守 https、地址抢在 `src` 前、去掉这一支)。视频工作台相关目录 + 备份主进程 94 文件 1129 条通过,`typecheck:ci` 7 existing / 0 new。
- 在用户本机的工作台数据里读到了同一张参考图的本地路径 + `uploadedUrl` + 指纹三者并存,确认病根与数据一致(只读)。

## 还没覆盖的地方

- **没有在真实安装包里重新跑一遍「备份 → 恢复为新剧」确认参考图回来**,只有单元测试和对本机数据的只读核对。升级后请自己恢复一份云端最新副本看看参考图是否在。
- 只有本地副本的成片视频仍然标草稿(备份只带 `remoteUrl`),本版没有上传本地成片。
