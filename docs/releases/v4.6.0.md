# v4.6.0 发行说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.5.9

## 概览

抬到 4.6.0 而不是补丁位,是因为视频工作台第一次有了**第二家模型提供方**。在此之前
「视频 = Seedance」是焊死在代码里的假设 —— 请求怎么组包、回包怎么解、费用怎么算,
全都只有一条路。这版把提供方抽成一个维度,万相 3.0 是走通这条新路的第一个模型。

其余三块:聊天里的文件引用终于能点开;画布不再因为素材攒多了把 app 拖重启;
批量生成加了两道防线,别再替你花钱。

## 万相 3.0

视频工作台的模型选择器里多了万相 3.0(wan3),和 Seedance 并列。它复用你在通义千问
出图那里已经录过的 Miau 密钥,不用重新填。

**它和 Seedance 不是一回事**,几处差异值得先知道:

- **按秒计费**,不是按 token。卡片和总计里会同时显示美元与人民币两栏,万相那部分
  按上游回传的实际出片秒数算 —— 这个数字要生成完才有,所以事前只能给估算。
- **素材一律走公网 URL**。Seedance 允许把小图直接内联成 base64,万相不接受,所以
  所有素材都会先传到对象存储再给链接。小文件也一样,免得你遇上一个只在小图时才
  出现的怪错误。
- **首尾帧与参考素材互斥**。这是官方的硬规则:用了首帧或尾帧,就不能再挂任何
  `reference_` 类素材(图、视频、音频都算)。以前的实现只挡了视频和音频,参考图会被
  悄悄丢掉 —— 现在会明确告诉你。
- **不走人像库**。万相的提交路径不做人像库入库和资产校验,那套是 Seedance 的。
- **多一个文档 / 网页链接槽**。可以喂一份文档或一条网页链接当素材。

万相还支持一个 Seedance 没有的画幅 `adaptive`(自适应)。反过来,**它不支持 21:9** ——
这条是实跑上游 API 确认的,不是照抄文档:传 21:9 会在任务提交后异步失败,报
`InvalidParameter`。所以遇到这个错不要重试,改画幅才有用。

上游报错现在会翻成人话。`task_not_exist`、`model_not_found`、`invalid_api_key`、
内容审核不通过这些都有对应的中文提示,并且**原始报文照样保留** —— 提示是帮你判断
下一步,不是替你把证据藏起来。

## 聊天里的文件引用能点开了

agent 在回答里提到文件时,以前那些高亮的路径是纯装饰,点了没反应。现在它们是真链接:

- 点开会在文件面板里定位到那个文件
- 带行号的引用(`#L12`、`:42:7` 这类)会直接跳到那一行
- 不只是标准链接,**正文里的裸路径和行内代码里的文件名**也能点

文件打不开时会明确报错,而不是静悄悄什么都不发生 —— 后者会让你以为是自己点歪了。
存在性检查带缓存,不会因为一条消息里提了十次同一个文件就查十次。

另外,agent 改了哪些文件现在在聊天里看得见:一条汇总条列出改动,一行给三个动作,
扫多个文件不用开三个标签页。

## 画布不再把 app 拖重启

**这是本版最要紧的修复。** 画布里的素材原先以 base64 存进快照,素材攒多了之后,
打开画布这一下会把内存顶爆导致 app 重启。改成存磁盘路径 + 自定义协议加载,
快照里只剩路径。

顺带两处:粘贴进来的图片以前会变成空图(剪贴板里的 File 没有磁盘路径,而旧代码只认
磁盘路径),现在走和拖拽一致的落盘流程;画布里的视频改走流式协议,能播、进度条能拖。

## 批量生成:两道防线

「全部生成」是一按就烧掉整批额度的按钮,而它左右紧挨着「删除选中」和「添加卡片」。

**第一道:两步确认。** 第一次点只进入确认态,显示**真正会启动的张数** —— 不是选中数,
因为选中里可能混着正在跑或已经完成的卡,报大了就是骗人。再点一次才提交,3.5 秒不动
自动复位。确认态下如果待启动的集合变了(agent 又填了卡、你改了选中),确认会自动撤销:
按钮写着「确认生成 2 张」却启动 7 张,比没有这颗按钮更坏。

**第二道:「允许 AI 自动生成」总开关。** 工具条上新增,**默认开**,升级后行为不变。
关掉之后 AI 照样能填卡、改规格、排版,但不准替你按生成 —— 它会把卡片准备好,然后请
你自己点。

闸门收在 agent 侧的唯一入口上,而不是散在各个工具分支里:MCP 有两条自动启动的路,
堵一条等于没堵,而且将来加第三条时很容易漏。你手点的那条路永远不过这道闸。

被拦下时**不会留下假的「准备中」卡片** —— 那比不启动更糟,你会等一个永远不来的结果。
AI 收到的是明确的「被用户关掉了」而不是「已开始渲染」,所以它会如实转告你去自己点,
而不是让你干等一条不会来的完成通知。

## 给 agent 用的部分

MCP 的两组视频工具(`generate_video` 和视频工作台那组)现在认识万相。模型、分辨率、
画幅三个枚举改成从能力表派生,以后加模型只动一处,工具自动跟上 —— 以前它们是手写的
字面量,加新模型时会静静地拒绝,而错误信息只说「不是合法枚举值」。

万相的三个提示词 skill 进了技能市场:`wan3-cinematic-30s`(底座)、`wan3-product-tvc`
(产品广告片)、`wan3-emotion-shotlist`(情绪分镜)。选底座的规则从「2.5 还是 2.0」
两选一变成三选一。

`seedance-cinematic-format` 改名为 `cinematic-prompt-format`。这个名字有实际危害:
内容其实是通用的,但 agent 看到 `seedance-` 前缀,跑万相时会跳过它。改名同时补上了
迁移机制 —— 技能装在扁平的命名空间里,改名后老目录没人清会留下孤儿,agent 会同时
读到新旧两份、拿到重复且冲突的指导。现在升级和启动时都会自动清理。

> **升级顺序提示:** 技能市场的目录要在本版上线**之后**再发布。迁移需要客户端代码和
> 市场目录两边同时到位,而迁移代码是这一版才有的。
