# v4.9.0 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.8.3

## 概述

这一版三件事：出图接入 GPT Image 2.5（Flare / Sunburst / All），官转渠道开放一次出多张；Codex 聊天抽屉整体改版——线程可置顶、输入区能画草图、点开结果图可以直接标注 / 评论 / 擦除局部重绘再交回给 Codex；内置 Codex 升到 0.154.0。

## GPT Image 2.5

- 模型列表新增 **GPT Image 2.5 Flare**（速度优先，约 20s，同价取代 gpt-image-2）、**Sunburst**（画质优先，约 40s，改图首选）与 **All**（网页逆向，$0.03/张，尺寸写进提示词）。不接不稳定的 2.5 vip 通道。
- 2.5 的图片质量有五档：低 / 中 / 高 / 超高 / 最高（去掉了会让费用漂移的「自动」档），默认「高」。
- **透明背景**：选 Flare / Sunburst 时出图面板多一项「透明背景」，开启后直接得到带 alpha 通道的 PNG——做贴纸、logo、素材不用再抠图。
- 计费口径不变：走 Miau API 站点用平台额度，走 apiyi 用你的 Key。

## 一次出多张（官转原生多图）

gpt-image-2 / 2.5 Flare / 2.5 Sunburst 与腾讯 image2 fast 现在支持「数量」1–4：一次请求返回同一提示词的几个变体。数量选择器标着「原生支持」，旁边提示**按张计费**（选 4 张约为单张 4 倍），要「几个方案挑一挑」时再加。顺带修了腾讯 image2 fast 配了多图却从不真正下发数量的旧问题。

## 模型选择器分厂商

顶栏的模型下拉换成两栏面板：左边按厂商（Google / OpenAI / 腾讯 / Seedream / Flux / 阿里…）分组，右边是该厂商的模型卡，腾讯 image 单独一档。选中后按钮上显示「厂商小标签 + 模型名」。

## Codex 聊天抽屉改版

- **顶栏**：按钮统一为同一高度的一套控件，顶栏与跑马灯横幅铺到窗口两侧到头，「Update」带英文标签，有更新时亮点。
- **线程侧栏**：可**置顶**（右键 / 悬停菜单，置顶的线程单独一组），可搜索，每条线程显示「N 条消息 · 多久之前」，一键进 Agent 工作台。置顶状态本地保存，并同步给 Codex 线程元数据。
- **输入区**：输入框下方一条整宽的附件条——「添加照片和文件 / 绘图 / 生成图片」直接可点，右端显示附件配额，最左「+」仍能弹出同一份菜单。粘贴、拖入或画的图片在待发送区显示为缩略图，点缩略图可放大预览；此前这类附件在输入区只显示文件名。
- **草图板**：点「绘图」打开画板（与画布同一 tldraw 引擎），选择 / 画笔 / 文字 / 形状 / 橡皮，形状可在矩形 / 椭圆 / 三角形 / 菱形 / 星形 / 云 / 心形 / 箭头 / 直线里选，笔宽是左侧竖向滑块，底部 13 色调色板；确认后草图作为 PNG 附件进消息。
- **图片工具条**（点开任意图片的大图预览）：
  - **标注**：在图上圈出要改的地方，7 种颜色可选（青 / 黄 / 绿 / 紫 / 粉 / 白 / 黑）。
  - **评论**：在图上钉编号并写评论。
  - **擦除**：涂掉要去掉的内容，发送时附带一张与原图同分辨率的 alpha 遮罩，由 GPT Image 2.5 做**真正的局部重绘**（只改涂掉的区域，其余保持不变）。
  - **移除背景 / 调整尺寸**：一键把对应指令交给 Codex。
  - 「发送给 Codex」会把带标注的副本和一段「图片反馈」说明一起放进输入框，随下一条消息发出——标注和评论用的是哪种颜色，说明里就写哪种颜色。
- **结果图卡**：悬停出现毛玻璃的「编辑 / 下载」；透明 PNG 自动识别，显示在深色底上并带 ALPHA 角标，可切棋盘格核对透明区域。

## Agent 与内置能力

- 内置 Codex CLI 升到 **0.154.0**：模型列表新增 GPT-6-Astra；已开的会话会自动拿到新安装插件的工具与 skill；MCP 连接的 OAuth 刷新更稳。已用完整生产启动参数做过离线冒烟。
- `generate_image` 工具新增 `maskImage`（局部重绘遮罩，仅 gpt-image-2 / 2.5 Flare / Sunburst），`catimation-image` skill 同步说明了 2.5 各档、透明背景与多图的用法。
- 插件 / skill 市场已同步发布：catimation-core 1.0.30、director 1.0.20、film 1.0.17、video 1.0.38；`director-character-consistency` 的改图默认渠道改为 gpt-image-2.5-sunburst。

## 升级后你会看到什么

- 线程侧栏多了「Pinned」分组与搜索框，旧线程全部保留、按原时间分组。
- 顶栏模型按钮变成「厂商标签 + 模型名」，之前选的模型不变。
- 输入区的虚线「Add references or files」变成了三个可点的动作，功能不减。
