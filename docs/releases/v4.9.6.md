# v4.9.6 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.5

## 概述

紧跟 4.9.5 的收口版:把 agent 内置技能里残留的「千问听不见声音」旧结论全部改掉,`understand_audio` 对上游不认的音频容器给出明确的转码提示,不再让它白白撞一次报错。

## 内置技能与工具说明

- **`catimation-subagents` 技能**:删掉整节「千问没有音频通道 / 视频理解只看画面 / 音频没有工具」,改为「只有 Omni 档听得见;音频走 `understand_audio`;你自己就是 Omni 主模型时,附件里的音视频已经在你的上下文里」。qwen 子代理默认模型改为 Qwen 3.8 Omni Flash。
- **`catimation-understand` 技能**:新增「怎么问」一节——照千问 Omni 模型卡的推荐结构提问(带时间戳的音画时间线、画面文字、按说话人转写),标准分析建议 ≤4 分钟、多说话人精细分析 ≤2 分钟,长片分段后逐段问再合并。
- **`catimation-video` 技能**:「黑屏 MP4 只用于视频理解」的旧做法改为直接用 `understand_audio`。插件市场已同步(catimation-video 1.0.41)。

## `understand_audio`:容器先验

- 上游只接受 mp3 / wav / aac / amr / 3gp。现在传 m4a / ogg / opus / flac 等格式时,工具在发请求前就返回一条结构化提示,附带 `ffmpeg` 转成 mp3 / wav 的命令,agent 可以直接照做;此前会把请求发出去再收到一句上游 400。

其余 4.9.5 的功能不受影响,无需重新设置。
