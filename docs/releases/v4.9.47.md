# v4.9.47 发布说明

## 概述

两件事:

1. **开源协议从 MIT 改为 PolyForm Shield 1.0.0**(#478)——**v4.9.46 是最后一个按 MIT 发布的版本**,从本版起新发布的代码按 Shield 授权。
2. **Codex 页的 Grok 系列适配 apiyi 的 Responses 服务端工具**(#480):`x_search`(X 搜索)、`code_interpreter`(代码执行)、远程 `mcp`,三个开关**默认全关**。

## 变化

### 协议改为 PolyForm Shield 1.0.0(#478)

- `LICENSE` 换成 PolyForm Shield License 1.0.0 官方原文;`package.json` 与 `deploy/apiyi-fastmcp/pyproject.toml` 的 `license` 字段同步为 `PolyForm-Shield-1.0.0`;README 的徽章与「许可证」一节改写。
- **含义**:用官方安装包做商业内容不受限;禁止拿代码去提供与本软件(或版权人用本软件提供的产品)相竞争的产品。
- **不追溯**:已经按 MIT 取得的副本(v4.9.46 及更早)仍按 MIT。
- 第三方内容(技能 / cdn / 宠物素材 / 启动动画)保留各自协议,不受这次改动影响。
- 这是协议文本与元数据的改动,**不改变任何运行时行为**。

### Grok 系列适配 apiyi 的服务端工具(#480)

涉及渠道:`apiyi-grok`、`rightcode-grok`、以及两个 Miau 的 Grok 渠道(只对 xAI 家族生效,其它模型族不动)。设置在 Codex 页「权限」面板新增的「Grok 服务端工具」区块,改完下一条 Grok 消息生效。

- **联网搜索 `web_search`**:本来就能用,这次没动它的行为。
- **X 搜索 `x_search`**:跟着「联网搜索」走——联网搜索为「关闭」时不会发送(面板里会有提示)。apiyi 文档标注较慢(约 45 s)且很费 token,系统提示里限制一次问答 3 次搜索以内。
- **代码执行 `code_interpreter`**:xAI 服务端的 Python 沙箱,**看不到你本机的任何文件**,只适合精确计算与数据处理;读写本机文件、跑项目命令仍然走本地工具。注入时会在系统提示末尾加一段说明,避免模型把沙箱结果当成本机已改好。
- **远程 MCP `mcp`**:每行一个服务器(`名称 地址` 或只填地址),仅 `https`、不带账号密码、不接受 localhost / 内网地址 / 单段主机名 / IP 字面量,最多 5 个。**这些服务器由 xAI 服务端直连,对话内容会经 xAI 发给对方**;新增地址会弹出和其它高风险权限一样的确认。
- **兜底**:上游对这些工具回 400 / 422 时,自动去掉注入的工具重试一次;重试成功则 15 分钟内对同一份设置不再注入(5xx 不重试)。
- **不影响没开的人**:三个开关都关闭时,发给上游的请求体与 v4.9.46 逐字节一致。
- 文档依据:apiyi 的 Grok 联网搜索 / 代码执行与 MCP 两页;文档标注 `collections_search` 在 apiyi 不可用,没接。

## ⚠️ 行为变化(请知悉)

- 默认情况下**没有任何行为变化**(三个开关默认关)。
- 打开后,Grok 一轮对话可能明显变慢、耗更多 token(X 搜索约 45 s、MCP 约 16 s、代码执行约 6 s,均为 apiyi 文档的参考值)。
- `x_search_call` / `code_interpreter_call` / `mcp_call` 这几类服务端工具的调用过程**目前在聊天界面里不会渲染**(模型的最终回答照常显示);联网搜索 `web_search` 的显示与以前一致。
- 本版没有改技能 / 插件文件,插件商城与技能商城不需要随版发布。
