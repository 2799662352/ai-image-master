# v4.4.7 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.6

## 概览

本版两件事:**修复音频页播放失败**(v4.4.6 用户反馈 `NotSupportedError`,
重启无效)并让音频生成**支持并发**;同时新增 Codex 官方同款
**环境宠物(Pets)**——咕咕嘎嘎 / Doro 蹲在 agent 聊天输入框上方,
随 agent 状态换动画,可抓取拖拽。

## 音频页修复(用户反馈 bug)

- **播放失败根因**:播放源裸拼 `local-file:///C:/...`,Windows 盘符冒号
  未编码被 URL 解析吞成 host,协议处理器拿不到盘符 →
  `NotSupportedError: no supported source was found`,重启无效。
  现统一走 `toRenderableUri`(`C:` → `C%3A`,与聊天卡片同一条已验证路径)。
- **三级播放回退**:本地文件(秒开)→ COS 远程 URL(跨设备可播)→
  base64 兜底;当前源播放出错自动切下一级,全挂才报错。
- **播放代次守卫**:换曲/停播后,旧源迟到的 error/reject 不再误触发回调。
- **并发生成**:点「生成」立即出 pending 卡并返回,不再阻塞后续提交;
  最多 3 路并行,超出 FIFO 排队;每个任务独立 AbortController,
  失败卡片可单独重试;页面销毁时中断全部任务。

## 环境宠物(Codex Pets 同款)

- **官方契约资源**:petdex 社区包(1536×1872 WebP 图集,8 列×9 行,
  单帧 192×208),预装「咕咕嘎嘎」与「Doro」两只,资源随应用分发
  (`public/pets/`)。
- **状态驱动动画**(对齐官方语义):agent 干活 → running;等批准 →
  waiting;出错 → failed;一轮刚跑完 → review(6 秒);其余 idle。
- **待机彩蛋**:空闲每隔 5–10 秒轮播小动作——挥手 → 向左散步 →
  跳一下 → 向右散步(用满图集 9 行动画),贴到窗口边缘自动收工;
  agent 一开始干活立即打断。
- **可抓取**:按住拖到任意位置(拖动中播 jumping「被拎起」动画),
  松手位置持久化,钳制在视口内拖不丢。
- **入口对齐官方**:composer 输入 `/pets`(或 `/pet`)打开选择器——
  首行「关闭宠物」+ 内置宠物列表 + 右侧动画预览,↑↓/Enter/Esc 键盘
  可用;工具栏另有同款药丸样式小按钮(显示当前宠物名)作鼠标入口。
  `/pets` 输完直接回车也会被拦截打开选择器,不会当聊天消息发给模型。
- 选择与位置均持久化 localStorage;宠物永不遮挡输入。
