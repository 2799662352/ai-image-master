# v4.9.16 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.15

## 概述

新增悠船 Midjourney V8.2 两个出图模型(快速 / 极速),生成页、批量生成页和 Codex 对话里都能用,并带原生 2K 开关和一组高级参数。

## 新增:悠船 Midjourney V8.2(快速 / 极速)

- **两个模型**:「悠船-v8.2-快速」和「悠船-v8.2-极速」,走 Miau 平台余额。每次调用出 4 张图。
- **比例**:自适应、1:1、4:3、3:2、16:9、3:4、2:3、9:16。
- **原生 2K**:「开启原生2K」默认开启,直接出原生 2K 分辨率,计费 ×1.5;选「否」则不开原生 2K。
- **高级参数**:图像质量、混沌程度、风格化程度、原始模式、图像权重、风格参考图、风格权重、风格版本、随机种子、排除内容。**不设置的项由模型自动决定**,一般保持默认即可;面板右上角有「全部恢复自动」。
- **参数面板的位置**:生成页和批量生成页在选中悠船模型后出现「开启原生2K」和可折叠的「高级参数」;其它模型不受影响。
- **批量生成页**:加入队列时会把当时面板上的参数固定在任务上,同一次点击加入的多张任务共用同一份参数;再改面板只影响之后加入的任务。图层拆分任务不带这些参数。
- **Codex 对话里出图**:`generate_image` 可以选这两个模型,agent 可以按需传原生 2K 和高级参数;不传就是自动。参考图仍然按 URL 发送。
- **输入校验**:参数值不合法时直接报错并提示原因,不会悄悄改成别的值再发出去;悠船请求失败不自动重试,避免重复扣费。
- **技能和插件商城**:`catimation-image` 技能补充了悠船模型和参数的用法,插件商城 catimation-core 升到 1.0.33。

## 还没覆盖的地方

- 「对比」页暂时还没有原生 2K 和高级参数面板。
- 「导演」页有自己的模型目录,没有悠船。
- 发布前通过了单元测试和 CI 全部检查;快速 / 极速两个模型的真实出图,会在发布后用测试账号各跑一次来确认。

其余 4.9.15 的功能不受影响,无需重新设置。
