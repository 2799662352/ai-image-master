# v4.5.9 发行说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.5.8

本版只有一件事:聊天的模型选择里多了两家新模型,都在 Right.Codes 网关下,
复用你已经录过的那把密钥,不用重新填。

## Grok 4.6

Right.Codes 的 Grok 通道现在能选到 4.6 —— xAI 最新的旗舰,主打写代码、调工具
和长时间跑的代理任务。

通道**默认仍然是 4.5**,4.6 要自己去选。换代模型实际好不好用得先试过才知道,
不该在你升级完应用之后自己就变了。

上下文按 500K 算,而不是 4.5 在这条通道上标的 1M。这个数字不是我们保守,是 xAI
自己对整个 4.x 线的口径;而它会直接决定自动压缩什么时候动手 —— 把 500K 报成 1M
的后果是压缩迟到,你会在对话跑到一半时收到一次上游拒绝,那比早一点压缩难受得多。
哪天实测确认 4.6 在这条通道上真能吃满 1M,再放宽也不迟。

推理档仍是低 / 中 / 高。API易 的 Grok 通道没有 4.6,那边的列表里不会出现它。

## DeepSeek V4

模型选择器里多了一个 DEEPSEEK 分组,排在通义千问和 Grok 之间,里面两个:

- **V4 Flash** —— 快的那个,也是官方的默认对话模型
- **V4 Pro** —— 强的那个,适合写代码和长任务

通道默认给 Flash,Pro 需要自己选。

上下文都按 100 万算,这是 DeepSeek 官方对 V4 全系给的默认口径,不是实验性开关。
推理档给了低 / 高 / 最高,默认高。官方文档里其实还有 minimal、medium、xhigh 几档,
但它们在服务端会被折叠到已有的档位上,摆出来只会让你以为调了什么、实际什么都没变,
所以没放进来。

DeepSeek 这套接口对**不认识的工具类型是直接忽略**的 —— 不报错,工具就是不见了。
所以这条通道走了和通义千问一样的工具桥接,否则出图、出视频这些工具会在 DeepSeek
这边悄无声息地消失,而你只会觉得「它怎么不干活」。

同样只在 Right.Codes 下有,API易 没有开这条通道。
