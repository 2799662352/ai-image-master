# v4.4.27 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.26

这一版围绕「等待」和「靠谱」两件事:把上传挪出你盯着屏幕的那段时间,让 AI 写提示词
时去查真实的镜头术语而不是凭印象编,以及在它可能悄悄弄错的地方拦住它。

## 参考素材拖进去就开始传,不再等你点生成

以前把图和视频拖进视频工作台,它们只是记下了本地路径,一直等到你点「生成」才开始
上传。一张卡九张参考图外加视频,几十上百 MB 的上传就整块压在「点了生成」和「任务真的
建起来」之间——你盯着屏幕干等,而这段时间本来正好可以传。

现在拖进去那一刻就开始传。你写提示词的时候文件已经在路上了,点生成时通常已经传完,
任务几乎立刻建起来。

三类素材都是如此,视频尤其明显——它是里面体积最大的。

传输方式也换了:文件直接从磁盘流式上传,不再先整个读进内存转成 base64。一张 12MB 的图
以前要在内存里变成 16MB 的字符串,现在一个字节都不经过。

没传完就点生成也不会出错,那种情况下走原来的路径,只是要多等一会儿。

## AI 写镜头时会去查真实的运镜术语

「电影感」「镜头很带感」这类词进不了生成模型,`低机位 35mm 前推、焦点从前景手部拉到
背景人脸` 才进得去。

这一版起,**图片和视频的提示词落笔前都会去查运镜知识库**,而且每条至少查三次:要用的
那个镜头运动的权威写法、它在结构化描述里该怎么落字、以及同类的专业范例或修正案例。做
动画风格时还会去查真实的作画技法标签和作画/工作室归属。

图片这条路以前完全没有这一步——镜头和构图两个字段是纯靠模型印象写的,这是这一版变化
最大的地方。

知识库现在只回文本和出处链接。原本还有两个会返回可下载视频片段的工具,已经关掉:写
提示词需要的是能写进字里的名词,不是一段还得下载和裁剪的视频。

## 拖进来一批素材,先给你一张对照表

把剧本连同一个装满图的文件夹一起拖进来时,以前容易直接开始拆镜头。但**素材齐不齐和
素材对不对得上,是两件事**。

现在会先出一张对照表:剧本里的每个角色/道具/地点分别命中了哪张图、缺了什么、多了什么、
哪些对不上号。缺的分两种处理——场景道具这类可以直接补生成,涉及身份的会先问你。

对不上号的一律会问,不会猜。一个名字看不出是谁的文件被当成主角用下去,后面每一条提示词
都错,而画面看着「像那么回事」,不会有任何报错。

超过五张图时改用并发理解,不再一张张看——快很多,也不会把上下文撑爆。

## 批量排卡改成小批出现

让 AI 一次排十几张卡时,以前是憋很久然后一次性全部出现,期间你插不进话、页面上什么都
没有。现在一次最多五张,分几批写——每批一落地你就看得见,还能边看边喊停。

配合「加完就开始渲染」时,前一批已经在跑了,后一批还在写。

## 生图的参考图改成一起传

九张参考图以前是一张传完再传下一张,九次串行等待。现在一起传,顺序不变——提示词里的
「图1 / 图2」仍然严格对应你传的第一张、第二张。

## 其它

- 工作台状态查询改成分页,几百张卡的看板不会再因为一次性倒出全部而被截断。AI 拿到
  的数据以前可能是被悄悄截断的半份,照着半份数据回写会把没看到的字段清成默认值。
- 素材列表过大时会明确报错并说明怎么缩小范围,而不是交出半份让它照着改。
