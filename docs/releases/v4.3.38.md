# v4.3.38 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub 源码同步
> 上一个发布版本:v4.3.37

## 概览

本次累计自 v4.3.37 起的全部改动,核心是 **Seedance 2.0 视频生成 MCP**、**人像库**、以及 **交互式 `ask_user` 头脑风暴**三条主线,外加一个常驻 AGENT 入口。

## 新功能

### Seedance 2.0 / 2.0 Fast 视频生成 MCP
- 接入 Seedance 2.0 / 2.0 Fast,主进程任务管理器 + 双工具轮询。
- 三种模式:**全能参考(默认优先)**、文生视频、图生视频。
  - 全能参考最多 9 张图片、3 段音频(总时长 ≤15s)、3 段视频(总时长 ≤15s)。
  - 技能中显式声明所用模式,默认多用「全能参考」。
- 视频参考(`reference_video`)/ 音频参考(`reference_audio`)角色完整支持。

### 人像库(Portrait Library)
- 视频参考图默认自动入库,MCP 可自主上传 / 搜索 / 引用 / 重命名 / 分组 / 下载。
- 浏览 / 选择页面,默认多选,支持重命名、删除、用户自定义分组移动。
- 新增源码:`portraitTools.ts`、`portraitOverlay.ts`、`mediaRelay.ts`、`usePortraitLibraryOverlay.ts`(此前被已提交代码引用但未入库,本次补齐,修复干净检出构建)。

### 交互式 `ask_user` 头脑风暴
- 新增 `ask_user` MCP 工具:在聊天栏渲染**可点击的交互卡片**(单选 / 多选 / 自由文本 / 跳过),阻塞直到用户作答,作为独立卡片消息持久化。
- 新增 `catimation-brainstorm` 一方技能,引导 Agent 在共创(镜头 / 风格 / 运镜等)与「给我几个选项」类请求时用卡片而非纯文本列选项。
- 视频 / 图像技能链接到本地视频优化 craft 技能;技能层提醒:并发 20 个以上视频任务前请向用户确认。

### 常驻 AGENT 入口
- 顶部导航新增常驻「AGENT」按钮,点击效果与 `Ctrl+Shift+A` 完全一致(切换 Codex Agent 浮层)。

## 优化与修复
- 全能参考 / 罗盘策略对齐图片复用逻辑;后台保存过慢不再阻塞主任务。
- 三个一方技能 `description` 收敛至 ≤500 字符,遵循渐进式披露,降低每会话上下文膨胀。
- 修复 `createItemFromStarted` 缺失 `choiceRequest` 分支导致的穷举 switch 回归。
- 修复人像库标签页在 legacy index.html shell 中的注册(TabManager + ServiceBridge 挂载)。

## 升级方式
- 桌面端将通过 COS 热更新自动检测并下载 v4.3.38。
- 手动:重新下载安装包 `catimation-cyberpunk-master-4.3.38-setup.exe`。
