# v4.7.7 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.7.6

## 概述

这一版给视频加了「高清」功能，修掉登录后聊天被 API Key 拦下的问题，并把内置的 Codex 升到 0.152.1。

## 视频高清（新功能）

「智能去字幕」页现在有两个工具可选：**高清**（默认）与**去字幕**。页面标题和顶部导航同步改为「智能去字幕 / 高清」。

高清有两条渠道，都经 Miau 网关，**登录后直接用平台余额**，未登录用自填的 Miau Key：

|  | 火山 | 阿里 DAMO |
|---|---|---|
| 档位 | 单档 | 算法（标准 / Pro）× 目标分辨率（720p–8K）× 帧率（30 / 60 / 120fps），共 30 档 |
| 价格 | ¥0.1 / 次 | ¥2 – ¥768 / 次 |
| 计费口径 | 按次 | 按次，时长不计入，长视频也按一分钟收 |

选 DAMO 时价格实时显示在档位旁边，¥50 以上标红——提交那一刻就扣费，最便宜和最贵之间差 384 倍，所以一定要在按下去之前看到。切到 DAMO 默认从最便宜的一档（标准 / 720p / 30fps，¥2）起。

上传走 COS 中转，只把 URL 发给网关，不发 base64。使用明细里按模型名记账（`volc-enhance-video`、`damo-aisr-standard-720p-30fps` 等），和视频、聊天一个规则。

## 登录后聊天不再被「填 Codex Agent API Key」拦下

此前只要没填 Codex Agent API Key，聊天就发不出去——哪怕选的是千问、DeepSeek（Miau）这类能用平台余额的模型。现在这道门按模型所在的通道判断：Miau 通道有登录或有 Miau Key 即放行，只有真正需要 Right.Codes / API 易 Key 的模型才会提示填 Key。

## Codex 0.149.1 → 0.152.1

跨五个稳定版。用户可感知的两处：

- **计划卡回来了**。0.152.0 把 Codex 的计划工具改成了默认关闭，不处理的话聊天里的任务清单卡片会无声消失。本版显式开启。
- **Plan 模式不再卡死**。Plan 模式下模型会用 Codex 内置的提问工具向你确认选项，此前应用没有接这个协议，问题永远弹不出来，一轮只能等你手动打断。现在它渲染成和 `ask_user` 同款的提问卡，点选即继续。

顺带把所有等你处理的卡片（命令审批、文件改动审批、提问）从对话区顶部挪到了**输入框正上方**——它们出现时你的眼睛就在那，不会再随对话滚出视野。
