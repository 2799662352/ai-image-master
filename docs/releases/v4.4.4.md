# v4.4.4 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.3

## 概览

本版落地两批会话体验升级:①会话设置面板扩容并支持跨重启持久化,
修复切换模型后 Plan 推理强度不可选的 bug;②回合完成系统通知与
用户消息发送状态 UI,让「后台等结果」和「消息是否送达」都有明确反馈。

## 会话设置批次 1+2(齿轮面板)

- 齿轮面板新增会话调优项:人格(personality)、推理摘要
  (reasoning summary)、原始思维链显示、输出详略(verbosity)、
  联网搜索模式(含 indexed 索引库档位)。
- 「保存为默认」持久化:勾选后设置写入本地快照,应用重启保留;
  不勾选保持历史的内存态语义。「恢复出厂设置」一键清除快照。
- 持久化只存与出厂默认的差异,损坏/非法快照整体回退出厂默认,
  纯净安装零落盘。

## Plan 推理强度修复(核心 bug 修复)

- 根因:渲染层把「网关 id」与主进程返回的「内部通道 id」做严格
  比对,任何一次模型切换后新拉取的协作能力被静默丢弃,Plan 下拉
  只剩「Auto/未读取官方预设」。
- 修复:能力对象显式携带 `gatewayId`,渲染层按网关归属对账;
  同时补齐 `model/list` 缺席模型(如 grok-4.5)的声明式能力解析,
  切换模型后 Plan 强度档位即时可选。

## 回合完成系统通知

- 回合完成或失败且窗口未聚焦时弹系统通知,点击通知回到主窗口;
  用户主动停止与自动重试中的错误不打扰(对齐官方 Codex 桌面端行为)。
- 齿轮面板新增「完成通知」开关(默认开),支持保存为默认。
- 启动时设置 Windows App User Model ID,打包版通知正确归属应用。

## 用户消息发送状态 UI

- 用户气泡新增送达指示:发送中(转圈)→ 已送达(绿勾,主进程
  确认回合被接纳)。
- 发送失败不再整条消息无声消失:气泡留在时间线标红「发送失败」,
  附「重试」按钮,一键按原始快照(文字/附件/引用)重发;重试前
  输入框里的新草稿自动保留。历史消息不显示任何徽章。
