# v4.9.29 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.28

## 概述

视频工作台加了 Seedance 2.5 的 1080p / 4K,样片模式可以「先出 480p 样片,满意后再升 4K 成片」;同时给所有 4K 生成加了一道保护:必须你本人在弹窗里确认两次,AI 没有任何办法代为确认。

## 变化

- **Seedance 2.5 增加 1080p 和 4K(仅平台余额)**。走 Miau 平台余额时,2.5 的分辨率有 480p / 720p / 1080p / 4K;用自己的 Key 直连时仍只有 480p / 720p(上游直连口只开到 720p)。分辨率下拉按「模型 × 计费来源」显示;换了计费来源导致当前档位不可用时,会提示原因,不会悄悄改成别的档位。
- **样片升成片可以选 4K**。样片仍固定 480p;满意后,卡片上有两个按钮:「生成 1080P 成片」(一键)和「生成 4K 成片」(要确认)。成片沿用样片的任务号重新生成,所以画面方向与样片一致,不用重写提示词。
- **所有 4K 生成都要二次确认**(不只是 2.5,2.0 和可灵的 4K 也一样)。点卡片上的「生成」、点「生成 4K 成片」、整页批量生成,遇到 4K 都会弹窗:第 1 步说明会按 4K 计费,第 2 步勾选「我已知晓」后才能点「确认生成 4K」。取消、按 Esc、点空白处都不会提交;连点只提交一次。批量里混着 4K 时,其余卡照常开跑,只有 4K 那几张等你确认。
- **AI 不能确认 4K**。AI 自动开始整板时,4K 卡会被跳过并告诉它「请让用户自己点」;AI 触发「样片升成片」永远只出 1080p;AI 调用的出片工具遇到 4K 一律拒绝。AI 仍然可以把 4K 卡填好,最后一下留给你。
- **费用预估不编价**。2.5 的 1080p / 4K、2.0 的 4K 暂时显示「未估价」(网关还没有确认过的价目),不会给一个偏低的数字。实际扣费以平台为准。

## 注意

- **这改变了以前的行为**:AI 以后不能再靠出片工具或「开始整板」提交 2.0 / 可灵 / 2.5 的 4K,需要你自己点。
- 4K 成片提交后,这张卡的当前结果就是成片,「升成片」按钮会消失;同一张样片没法在界面里再出第二个成片(样片那一版仍在版本记录里)。
- 4K 在上游是独占资源,同一时间大约只能跑 1 个;整批 4K 一起提交时,后面的可能失败,需要重试。
- 本次安装包不含 NovelAI 插件:那两个插件走插件市场的独立通道,11-04 已发布,与这次升级无关。

## 已验证

- 新增 / 改动的测试 + 相关目录共 280 个文件、3483 条通过;`typecheck:ci` 无新增;所有 CI 检查通过。
- 确认关卡做了 17 种变异检查(去掉某道闸、AI 入口放行 4K、弹窗不勾选也能确认、卡片按钮 / 整页批量不弹窗等),16 种被测试抓到;剩下 1 种是改完行为不变的等价写法。

## 还没覆盖的地方

- **没有对真实网关提交过 4K 成片**:这要用测试令牌且会扣费。请求体按网关约定构造,字段由单测断言,但网关对你的账号分组是否开放 2.5 的 1080p / 4K、扣费是否符合预期,需要升级后实际出一条验证(建议先 2.5 样片 + 1080p 成片)。
- **没有在真实安装包里看过弹窗和按钮的样子**,只有组件级测试。
- 4K 价目待网关确认后再补进预估。
- 内置技能文案仍写「成片 1080p」:对 AI 仍然成立(它只能出 1080p),没有改动。
