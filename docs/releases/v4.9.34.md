# v4.9.34 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.33

## 概述

启动画面换新:原来的 Cyberpunk 开场视频换成「访问许可」启动动画(移植自 MIT 项目 dsh-startup-screen),带网页登录闸门、配音和界面音效。

## 变化

- **启动动画「访问许可」取代开场视频。** 品牌是 CATIMATION 猫头 + Orbitron 字标;原来的 8.1 MB 开场视频和「LOADING NIGHT CITY…」加载页都去掉了。每天第一次启动播完整版,其余启动直接进入,随时可跳过(按钮 / Esc)。
- **登录闸门。** 界面里没有密码输入,走已有的网页登录:未登录点主按钮会立刻发起浏览器授权,动画停在原地等结果,登录成功才放行;失败显示一句中文原因、点一下重试;唯一绕过口是「跳过登录」。确认身份那一步有「退出登录 · 切换账号」,退出后可以重新网页登录。
- **配音 + 界面音效。** 6 句英文系统播报(缺素材就静音,不卡动画),文字渐显、阶段推进、十六进制瀑布各有「哒」声;「哒」素材缺失或被拒时回落到原来的合成音。
- **修复:** 重复点登录时,上一轮回环监听的取消会把新一轮的等待态盖成错误(`auth:start-login`)。

## 注意

- 启动动画目前**没有设置页开关**,存档键 `catimation.startup.v1`(`daily` / `always` / `off`)只能手改。
- 配音是用户提供视频里的音轨切成的 6 句,来源与随产品分发的授权**未核实**(见 `src/renderer/src/features/startup-screen/THIRD_PARTY_NOTICE.md`);「哒」声是上游的两个小文件,上游 MIT 只明确覆盖代码。公开推广前请确认。
- 这台机器上登录服务偶发连不上,所以动画里「点了没弹浏览器」时会显示错误原因,点一下可重试。

## 已验证

- `startup-screen` + `main/services/auth` 15 个测试文件 451 条通过;多轮变异检查,存活的只有等价变异;`typecheck:ci` 7 个既有 / 0 个新增;`build:vite` 通过。
- 开发窗口里 6 句配音曾逐句被请求并播放到结束(上一版音频),没有被自动播放策略拦截。

## 还没覆盖

- **没在安装包里走过**:动画像素、猫头着色、真实的登录往返(弹浏览器 → 登录成功放行 / 断网 / 取消 / 跳过 / 退出再登录)都只有单元测试。
- **没听过**:6 句配音每句具体念的是什么、音色是否统一、结尾「Welcome to CATIMATION」的读音与欢迎感;新的「哒」素材在真窗口里是否响。
- 动画底下应用初始化时的主线程卡顿没量过;不播动画的日子,启动时会先是一块空的暗底,直到揭幕。
