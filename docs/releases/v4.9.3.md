# v4.9.3 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.9.2

## 概述

这一版解决「聊天里和生成页的缩略图有时候会破，翻墙时更明显」，把缩略图改成先看桶里已经存好的那一张；同时把生成页的结果区换成一套有状态的卡片——点「开始生成」的那一刻就能看到它在跑、跑了多久、失败了为什么。

## 缩略图不再破

- **为什么会破**：模型直出的图链接是几小时就过期的临时签名链接，转存到自有云盘失败时历史里留下的就是它；实时缩略图每次都要现算，开着代理时可能连不上；而本地一直有一份永不过期的副本，以前却几乎用不到。
- **现在怎么做**：缩略图按一条链依次尝试——桶里已存好的缩略图 → 实时缩略 → 原图 → 本地副本。远端失败会先退避重试几次，不会失败两次就放弃；全部失败画一张干净的占位卡（带「重载」），并每 30 秒自动再试，网络恢复后图自己回来。已过期的签名链接直接跳过，不再白白请求。
- **缩略图存进桶里**：新上传的每张图，云端会同步落一张 512 / 1024 的缩略图对象；老版本客户端上传的图也覆盖（服务端自动处理，客户端不用做任何事）。存量老图仍走实时缩略，不受影响。
- 顺手修掉两个隐患：视频等非图片对象不会再被当成图片去做缩略；聊天里的缩略图加载失败时不再显示浏览器的裂图图标。

## 生成页：状态卡族

- 结果区的每一次生成都是一张卡：**运行中**（转圈、已用 / 预计秒数、进度条）→ **失败**（原因写在卡上，hover 看全文，可「重试」「复制错误」）→ **完成**（缩略图 + 渠道 · 比例 · 分辨率 · 耗时）。排序为运行中 → 失败 → 完成，新的在前。
- 失败卡的「重试」用**那一次的参数**原样再发一次，不受你之后改过的表单影响；每张结果卡可以单独移除。
- 批量生成页的卡片换成同一套组件，虚拟滚动不变。

## 生成页面板小迭代

控件、布局、交互一个都没变：图标全部换成线性图标；输入框、参考图区、主按钮四角加了角标；空的参考图槽和结果区改成斜纹底 + 十字；主按钮右侧标出快捷键与预计耗时（`CTRL+ENTER · ~20S`），输入框里 **Ctrl / ⌘ + Enter 现在真的能直接生成**；「风格 · 选择」从粉色实心改为黄色描边。

其余 4.9.2 的功能不受影响，无需重新设置。
