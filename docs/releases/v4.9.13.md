# v4.9.13 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.12

## 概述

新增谷歌 Nano Banana 2.1 出图模型,画质、图中文字和多轮改图的一致性都比 Nano Banana 2 更好;谷歌出图偶尔把中间稿当成结果显示的问题也一并修好。

## Nano Banana 2.1

- **在哪里选**:生成页和批量页的模型下拉里新增「🍌 Nano Banana 2.1」,排在 Nano Banana 2 后面;AI 助手输入框下方的出图渠道里新增「Nano2.1」。跟 AI 助手说「用 nano 2.1」也能点到它。
- **比上一代好在哪**:画质更好,海报、信息图里的文字错字更少,对话式多轮改图时人物和画面更不容易跑偏。
- **分辨率**:1K / 2K / 4K 三档,默认 1K。**没有 0.5K**,需要小缩略图时请继续用 Nano Banana 2。从 Nano Banana 2 的 0.5K 切过来时会自动改成 1K。
- **比例**:和 Nano Banana 2 一样支持 14 种,包括 1:4、4:1、1:8、8:1 这类超长 / 超宽比例。
- **价格**:按实际用量计费,1K 一张约 $0.03,2K 约 $0.036,4K 约 $0.063。
- 使用平台余额的用户,需要网关同步上线后才能使用这个模型;用自己 API 易 Key 的用户可以直接用。

## 其他修复

- **谷歌出图只显示终稿**:Nano Banana 系列在复杂改图时,会先返回几张中间稿再返回终稿,以前这些中间稿也会当成结果显示出来;现在只保留最后一张终稿。

其余 4.9.12 的功能不受影响,无需重新设置。
