# v4.3.72 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub 源码同步
> 上一个发布版本:v4.3.71

## 概览

本次对齐 **Codex 原生「上下文压缩」(context compaction)** 的完整链路与显示口径,并补齐 **手动 `/compact`**、**`/goal` 目标管理**、**聊天出图通道选择器** 三项交互能力。核心目标:让上下文占用显示与自动/手动压缩行为与 Codex 原生 TUI **逐位对齐**,并用真实模型跑通「实锤压缩」冒烟验证。

## 变更

### 上下文压缩显示对齐 Codex 原生
- **占用取自 `last`(当前上下文占用),而非累计 `total`**:此前 UI 用累计 token 计算百分比,导致长期显示「100%」却看不到压缩通知。现改为从 `thread/tokenUsage/updated` 的 `last`(当前回合上下文占用)派生 `contextUsage`,与 Codex 自动压缩的触发口径一致。
- **12K 基线的有效窗口百分比公式**:新增 `contextUsedPercent(tokens, window)`,对齐 Codex 原生——从「已用」和「窗口」两端各减去 `BASELINE_TOKENS = 12000` 再算比例(`(used−12k)/(window−12k)`),占用≤基线时归 0,填满时封顶 100。贯通圆环仪表(`TokenUsageMeter`)、上下文弹层分段(`tokenSegments`/`ContextPopover`)、高水位提醒(`store` watermark)。
- **「本回合增量」改为「会话累计」**:弹层下方由易误解的单回合 delta 改为累计生命周期用量,信息更真实。
- **高水位提醒**:70% / 90% 水位基于「有效窗口」百分比触发,与仪表读数一致。

### 手动 `/compact`(真实压缩)
- 接入 Codex app-server 原生 `thread/compact/start`,五层贯通(`CodexProtocolClient` → `CodexLocalBackend` → `AgentManager` → IPC `agent:compact-start` → preload → 渲染层 store),与 `/goal` 同构。
- 触发后可在事件流观察到 `contextCompaction` 的 `item/started → item/completed`,历史被总结并丢弃。

### `/goal` 目标管理
- 接入原生 `thread/goal/set|get|clear` 与 `thread/goal/updated|cleared` 通知,聊天内以 `GoalChip` 展示当前目标,支持设置 / 编辑 / 清除。

### 聊天出图通道选择器
- 新增 `ImageChannelPicker`:发图前可选择出图通道,与既有 MCP 出图工具链打通。

## 修复
- **IPC 重复注册**:`agent:compact-start` 未加入 `registerAgentIpc` 的句柄拆除清单,Electron 开发热重载 / 二次注册时抛「Attempted to register a second handler」。已补入 `AGENT_HANDLE_CHANNELS`,`ipc` / `ipc.workspace` 重注册用例恢复通过。

## 测试
- 上下文压缩 / `/compact` / `/goal` 相关单测 **62/62 全绿**(含新增 `contextWindowDefaults.test.ts` 锁定 12K 基线公式;`tokenSegments` / `TokenUsageMeter` / `ContextPopover` / `store.contextWatermark` 断言按新公式重算)。
- `ipc` / `ipc.workspace` / `ipc.compact` / `ipc.goals` **26/26** 通过(修复重复注册后)。
- **真实压缩冒烟**:`scripts/smoke-codex-compaction.ts` 用真实 `gpt-5.5` 网关把 `model_auto_compact_token_limit` 临时压到 12000、喂约 8 万字符上下文,观测到 `contextCompaction` 的 `started → completed`,`contextUsage` 跨压缩边界真实回落(29938 → 24785,Δ ≈ −5153 tokens)——证明是「历史被总结并丢弃」,而非重新计数。
- 其余全量失败项为既有环境基线(jsdom 缺 `getComputedStyle` / 媒体解析无 IPC / `sessionConfig` 默认漂移),与本次改动无关。
