# v4.8.0 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.7.8

## 概述

视频工作台多了一层「剧」。以前所有片子的页面挤在一条页签栏里，十几个页签折成三行，找不到也看不清；现在每部片子是一部剧，剧里是分段，分段里才是卡片。不同剧彼此隔离，切剧一下就到。

## 剧 → 分段 → 卡片

- **左侧剧栏**常驻：每部剧一行，封面、剧名、`段数 · 镜数 · 花费`、最近活动时间，底部一条完成 / 生成中 / 失败的三色比例条；有卡片在生成的剧带黄点计数，有失败的带红点。当前剧黄色左条。双击改名，`+` 新建（新建即改名，Esc 保留默认名）。栏可折叠到只剩封面。
- **剧总览**：进入一部剧先到总览——剧名（点击就地改名）、汇总芯片（段数 / 总时长 / 镜数 / 完成率 / 生成中 / 失败 / 已花费）、按顺序排列的分段网格。每张分段卡有封面、序号、时长、状态角标和三色条；点进分段编辑镜头。
- **分段页**就是原来的工作台：页签改成只显示本剧的分段、**单行横向滚动**不再换行，上方一行面包屑「‹ 剧名 › 分段名」，点「‹」回总览。统计行改为「本段 N 镜」，合计只算当前剧。卡片本身没有任何改动。
- **拖拽**：把分段卡拖到左侧剧栏——落到某部剧上就移入那部剧，落到栏顶部的虚线框就新建一部剧并移入；把卡片拖到页签上，卡片挪到那一段末尾。
- **`Ctrl+P`**：同时搜剧名和分段名，回车直达。
- 删剧走撤销栈，误删可撤销；有卡片正在生成的剧不能删，提示先取消。新建的段默认叫「分段 N」，老页面名字不动。

## 升级后你会看到什么

升级前的所有页面会原样放进一部叫「默认项目」的剧里，一张卡都不会少、名字也不改。总览顶部有一条提示，可以直接给这部剧改名，或把分段拖去新剧。提示点「知道了」即消失。

## Agent（Codex 聊天）

- 所有 `video_workbench_*` 工具只作用于**当前剧**，与你在界面上看到的一致；`status` 与各写工具回带的摘要多了一个 `project` 头。
- 新增四个工具：`video_workbench_list_projects`（列剧与统计）、`video_workbench_switch_project`（切剧，界面同步）、`video_workbench_create_project`（新建一部剧并自带一个分段）、`video_workbench_set_project_summary`（给剧写一行说明，总览剧名下方可见——分段和卡片此前各有一层这样的路标，剧是补上的第三层）。
- `video_workbench_status` 多了 `fields: "concise"`：只回每张卡的 id / 位置 / 状态 / 摘要 / 60 字提示词，体积约为原来的三分之一。agent 查进度、挑卡片时用它，改规格前再拿完整的。
- 新建的卡片 / 分段 / 剧 id 从 36 位 UUID 改为 10 位短 id。id 是不透明句柄，旧数据照旧；一次读 20 张卡就少进模型上下文约五百字符。
- 整板 IR 带剧的标识：你中途切了剧，agent 拿旧 IR 回写会被整份拒绝并被提示重新导出，不会写进另一部剧。
- 批次完成推送里带「剧名 › 分段名」，方便按位置找成片。
