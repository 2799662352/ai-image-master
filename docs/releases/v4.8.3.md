# v4.8.3 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.8.2

## 概述

一处修正：视频工作台卡片上切到历史版本后，「任务详情」面板和脚注的任务号现在跟着你切到的那一版走，不再永远显示最新一轮的结果。

## 任务详情面板跟着版本走

4.8.2 里卡片头部新加的 ⓘ 面板只读卡片顶层字段，而那永远是最新一轮（比如 v2）的结果；你在卡片上切到 v1 再点 ⓘ，看到的还是 v2 的任务号。这一版改成：

- 面板显示的是**卡片当前切到的那一版**：标识 / 时间 / 结果 / 请求参数全部取自该版存档，标题带 `vN/N`，与卡片切换器同一口径。
- 早期版本存档里没有记录的字段（客户端请求 ID、计费来源、提交时间，以及上游任务号功能上线前出的片子）如实标「历史版本未记录」，不拿现在的值充数。
- 「历史版本」区每一行多了「查看」：在面板里切版，卡片同步切；关掉面板后卡片停在刚看的那一版。当前显示的那版标「当前显示」。
- 卡片脚注的 `task:` 也跟着正在播的版本走。
