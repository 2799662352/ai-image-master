# v4.4.22 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.21

一次修复版本:Right.Codes 补上缺失模型,运镜知识库恢复可用。

## Right.Codes 可选 `gpt-5.5-openai-compact`

网关实际售卖的 `gpt-5.5-openai-compact` 不在 Codex 自带的 `model/list` 里,所以模型选择器
一直看不到。本版把它加进 Right.Codes 标准通道的**附加目录**(不影响其它 GPT 动态发现),
并配上与 `gpt-5.5` 一致的 272K 上下文与 Right.Codes 上过滤 `max` reasoning 的策略。

## 运镜知识库不再被 `rerank_top_n` 401 打挂

`search_cinematography_kb` 在传 `top_k` 时会同时塞 `dense_similarity_top_k` 和
`rerank_top_n`。百炼 Retrieve 当前拒绝后者(`field not allowed in agent_config override`),
整次检索直接 401。本版去掉不兼容字段,只保留 `dense_similarity_top_k`。

改的是打包进应用的 `resources/cinematography-kb-mcp/index.js`;本地若还在用
`~/.codex/config.toml` 指到别的脚本路径,需要那份脚本同步去掉该字段,并重启 Codex/MCP
进程后才会生效。
