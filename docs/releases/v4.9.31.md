# v4.9.31 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.30

## 概述

三件事:① Codex 页新增 **Grok 4.7**(走 Miau 网关,扣平台余额);② 出图渠道新增 **腾讯 GPT Image 2.6**(Flare / Sunburst);③ Codex 页模型选择器里不再列出 **Qwen 3.7 Plus / Max**。

## 变化

- **新增 Grok 4.7**。Codex 页模型选择器多了「Grok 4.7」一行(排在 4.6 前),经 Miau 网关调用,计费走平台余额。上下文 500K;思考档位 `low / medium / high`,默认 `high`。Grok 4.5 / 4.6 仍走原来的通道,互不影响。记忆和会话自动起标题固定用 `qwen3.8-flash`,不会落到 Grok 4.7 旗舰上。
  - 价格已在 Miau 后台设好:输入 ≤200K 时输入 ¥14 / 输出 ¥42 / 缓存读 ¥3.5,超过 200K 时输入 ¥28 / 输出 ¥84 / 缓存读 ¥7(每百万 token)。
- **新增腾讯 GPT Image 2.6**:`custom-model-og-v2.6-f`(Flare)、`custom-model-og-v2.6-s`(Sunburst),只走 Miau 平台额度。生成页、批量页、Codex 出图渠道面板(放在「更多 · GPT Image 系列」,不进常用)、MCP `generate_image` 和 `catimation-image` 技能都能选。**同档位 token 约为 2.5 的 4.16 倍,单张明显比 2.5 贵**:面板和技能里都写了「比 2.5 贵」,并让 agent 在用户没点名 2.6 时用 2.5。默认出图渠道没改。
- **Codex 模型选择器隐藏 Qwen 3.7 Plus / Max**。只是不在列表里显示:路由、可用性、已保存的选择都不动,已经选着 3.7 的老对话仍会在按钮和列表首位显示当前所选,不会被悄悄换掉。
- **Codex 内核没升到 0.167.0,仍是 0.168.0-alpha.3**。稳定版 0.167.0 不含修复「This chat uses X, but your current provider is Y」的 openai/codex #59503:按官方仓库的提交关系核对,0.167.0 是从 11 月 1 日前后的 main 拉出的发布分支,只额外挑了两个修复,#59503(11 月 4 日合并)不在里面;当前内置的 0.168.0-alpha.3 包含它。0.167.0 的其余内容在 alpha.3 里也都有(alpha.3 只缺 0.167.0 分支上的 3 个提交,其中两个的原提交已在 alpha.3 里,另一个是发布说明),所以升到 0.167.0 是降级,会把切换错误带回来。

## 注意

- 本版内置的 Codex 内核仍是预发布版 0.168.0-alpha.3(见 4.9.30 说明)。
- Qwen 3.7 被隐藏后,**新用户第一次进千问通道的默认模型仍是 3.7 Max**(按钮上会显示它的名字),这一条没改;理解类工具(`understand_*`)的别名 `plus` / `max` 也仍然指 3.7。
- 2.6 擦除(涂抹局部)没有开放:线上没验证过,灯箱里选了 2.6 再擦除会回落到官转 sunburst。

## 已验证

- Grok 4.7:在 apiyi 上 `/v1/responses` 的非流式、流式、函数工具往返、`reasoning.effort=high` 都 200;`low / medium / high / xhigh / minimal` 200,`max` 和 `none` 返回 400。Miau 生产 `/api/pricing` 里 `grok-4.7` 已有渠道和价格(57 个分组可用)。
- 三个功能 PR 各自的相关目录测试、`typecheck:ci`(无新增)和 CI 检查全部通过;Grok 与隐藏 3.7 做过变异检查,全部被测试抓到。

## 还没覆盖的地方

- **没有用真实 Miau 令牌在应用里发过一轮 Grok 4.7**,所以渠道通不通、实际扣多少都只有后台配置和 apiyi 侧的证据;`xhigh` 上游可用但没经 Miau 发过,因此没放进可选档位;500K 是文档值,没测过超长拒绝;记忆模型 `qwen3.8-flash` 没在 Grok 通道上实际跑过。
- **没有真实生成过一张 GPT Image 2.6 的图**(要用户确认的令牌且会扣费);`xhigh / max`、透明底、参考图改图三条路径在线上没验证过,只是按 2.5 的配置照搬;没有给 2.6 标生成耗时和价格量级。
- 没有在真实窗口里看过模型选择器(Grok 4.7 一行、3.7 被隐藏)和出图渠道面板里的 2.6。
- 「0.167.0 不含 #59503」是按官方仓库的提交关系判断的,没有在 0.167.0 的真实二进制上再跑一遍切换复现(真二进制的复现是在 0.166.0 上做的,见 4.9.30 说明)。
