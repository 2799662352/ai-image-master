# v4.4.0 发布说明

> 发布渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 兜底
> 基线版本：v4.3.99

## 概览

本版升级电影/剧情视频的 Skill 编排与多模态提示词策略。单帧继续负责身份、
关键构图和画质；故事板、九宫格/多宫格和电影美术设定板可作为低约束氛围参考，
由文字提示词主导故事、动作、镜头顺序和导演调度。

## 故事板与氛围参考

- 新增 `GPT Image 故事板生成提示词三（首选）`：21:9 工业化导演工作台、
  9:16 镜头格、红/蓝/绿三色方向箭头，以及项目、角色、场景、分镜、备注五模块。
- 新增电影美术设定板模板：俯视机位、镜头表、立/剖面、材质、灯光、角色与
  剧情总览。
- 只要故事板/多宫格进入视频参考，提示词必须带“提示词主导 / 氛围板低约束”
  前缀；整板不控制故事、构图、动作、顺序、时长或身份。
- 需要精确执行某格时，先拆格、清除边框/文字并重绘为干净关键帧。
- 关键制作文字使用确定性本地排版复核，避免图像模型乱码成为生产真源。

## 身份锚点与 Seedance 对齐

- 身份锚点改为用户驱动：大头照+全身照、三视图/四视图/多视图角色板或其它
  用户确认资产均可作为 `identity-hard`。
- 用户已指定时直接采用；多套候选不明确且身份关键时才询问。
- Seedance 素材引用统一为 `图片N / 视频N / 音频N`；运行时兼容归一化
  `@Image1`、`@图片1`、`【@图片1】`、`<图片1>` 等外部写法。
- 规格与工具 schema 对齐：生成 4–15 秒，支持 480p/720p/1080p 与完整画幅枚举；
  短于 4 秒的成片节拍通过至少 4 秒素材后期裁切。

## 制片编排

- `film-studio` 增加 Skill-first 硬门：G0–G8 每阶段必须实际加载并使用相关 Skill，
  不能只点名或凭记忆复述。
- 阶段交付新增 `skills_used` / `applied` 回执，说明具体使用了哪些 Skill，以及
  落到了哪个字段、资产、提示词或 QA 结论。
- Skill 不可用时记录 `unavailable`，改用已安装的同职责 Skill 或最小原则继续，
  避免单个叶子缺失卡死整条制片流水线。
- 保持按阶段渐进加载，禁止为“多用 Skill”一次性加载全部技能。
