# v4.9.15 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.14

## 概述

视频工作台的「剧」和「分段」有了回收站和右键菜单,删除不再一步就丢数据;同时修复了 DeepSeek(Miau)在调用工具后继续写时偶发的 400 报错。

## 视频工作台:回收站与右键菜单

- **删除先进回收站**:删除「剧」或「分段」后,先进回收站(连同下面的全部分段和镜头),会有提示,按 Ctrl+Z 可以撤销。
- **彻底删除要确认**:在回收站里点「彻底删除」或「清空回收站」,按钮第一下变红显示「确认…」,3.5 秒内再点一次才会真删,不点自动复位。
- **右键菜单**:剧栏里的剧、总览里的分段卡、分段页签、总览头部的剧名,右键都能重命名、置顶 / 取消置顶、Fork、删除。剧栏行和分段卡右上角还有鼠标悬停才出现的「⋯」,和右键是同一份菜单。
- **入口**:剧栏底部有「回收站 (n)」(剧栏折叠时是一个小图标);总览头部新增「删除此剧」。
- **哪些不能删**:唯一的一部剧、一部剧里唯一的一个分段、含有正在生成的卡片的剧或分段。菜单里的「删除」会置灰,鼠标悬停能看到原因。
- **恢复**:恢复的剧排到剧栏末尾,不会切换你当前看的内容;恢复的分段放回原来那部剧的末尾,如果那部剧也在回收站,会先提示「请先恢复那部剧」。
- **Fork**:剧会整部复制(含分段和镜头),名字是「X 副本」;分段复制在原分段后面,名字也是「X 副本」,正在生成的卡片在副本里变回草稿。
- **置顶**:置顶的剧或分段排在最前面并带 PIN 标记;只影响显示顺序,只保存在本机,不改动数据本身。
- **分段页签的 ✕**:以前点一下 ✕ 还要再确认一次,删了就没了;现在点一下直接进回收站,点错了去回收站恢复即可。
- 撤销、重做和 agent 整板改写时,有内容的剧和分段也会进回收站;没有内容的空分段、空剧仍然直接删除,不往回收站里塞。
- 回收站没有改动数据库结构,升级后原有的剧和分段不受影响。

## 修复:DeepSeek(Miau)调用工具后继续写偶发 400

- **现象**:用 DeepSeek Flash 或 DeepSeek V4 Pro(Miau)时,模型调用工具后继续写,偶尔会报「The `reasoning_text` in the thinking mode must be passed back to the API」(400),对话中断。
- **原因**:应用内部的转发层,为了兼容「GPT 对话中途切到 Grok」的情况,会删掉带加密标记的推理记录。DeepSeek 的推理记录也带一个标记,于是连它需要的推理明文一起被删了;而 DeepSeek 要求思考模式下把上一轮的推理原样传回。
- **现在**:保留 DeepSeek 的推理明文,只去掉没用的标记。GPT 切 Grok 的原有处理不变。
- **实测**:在线上用 Miau 调 DeepSeek Flash,每次用全新的对话历史,修复前 10 次里有 6 次报这个错,修复后 10 次全部正常。
- **没覆盖到的**:带日期的「DeepSeek V4 Flash 0731」「DeepSeek V4 Pro 0813」(上游是阿里)没有单独验证;先用千问聊、中途换到 DeepSeek,而且前面的推理记录没有明文的对话,仍有可能遇到。

其余 4.9.14 的功能不受影响,无需重新设置。
