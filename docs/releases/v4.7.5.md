# v4.7.5 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.7.4

## 概述

这一版加两个模型：聊天里的 **DeepSeek V4**，出图里的 **腾讯 image2 fast**。

## 聊天新增 DeepSeek V4（可用平台余额）

模型选择器里多出 DeepSeek V4 Flash 与 DeepSeek V4 Pro 两档（标注「Miau」的那两行）。

与原有的 Right.Codes DeepSeek **并存**，不是替换——两边是同一代模型的不同来源，差别在于新增这两档走 Miau 网关，因此**能用平台余额结算**；原有那两档仍只能用自填 Key。名字上带日期后缀（`-0731` / `-0813`）的是新增的这两个。

## 出图新增腾讯 image2 fast

生成页、聊天的出图渠道、MCP 工具三处都能选到。

与原有的腾讯 image2 是两个不同的模型、两条不同的渠道，可以按需要挑：

|  | 腾讯 image2 | 腾讯 image2 fast |
|---|---|---|
| 出图耗时 | 约 30s | 约 20s |
| 价格 | 基准 | **约 1/6** |
| 一次出图张数 | 1 张 | 可多张 |

能力上两者一致：文生图、参考图编辑、比例 × 分辨率（1K/2K/4K）× 清晰度三参数、网关去水印都支持。

## 其它

- 出图渠道清单收敛成一处。此前生成页、聊天、MCP 各存一份，新增模型时容易出现「有的地方看得见、有的地方没有」——现在三处同源，不会再各自漏。
