# v4.4.21 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.20

这一版没有改任何运行时代码,改的全是**视频工作台的创作纪律**——也就是 agent 在
工作台上替你做决定时依据的那套规则。插件市场已同步发布(`catimation-video` 1.0.26 /
`catimation-film` 1.0.12 / `catimation-storyboard-pro` 1.0.11),已装用户从市场更新
即可拿到;本版让**全新安装**也自带这套基线。

## 工作台从「有工具」变成「有纪律」

此前工作台上出片是不受约束的:同一道「角色片/多镜」硬门只点名 `generate_video`,
工作台被当成了例外——而它天生就是多镜场景,恰恰是这道门最该生效的地方。现在两条
出片面同一口径。

新增 `catimation-video-workbench` skill,掌管工作台这块界面并接上已有的生成链与
导演链。它随应用打包,全新安装即可用。

## 一张卡到底该放几个镜头

原先的规则写的是「一张卡 = 一个镜头,别把镜头1…镜头2 挤进同一张卡」。**这条是错的**,
本版纠正。

Seedance 一次调用本来就能出一段镜头流程,那正是 `sd2-pe` 路径 B 的设计。判据不是数
镜头号,而是**这几镜是不是一个连续节拍**:

- 同场景、同组角色、连着演完、总时长塞得进 4–15s → 放同一张卡。一个搞笑反转
  (铺垫→递进→崩溃)拆成四张卡反而断节奏,因为卡与卡之间不共享上下文。
- 要单独重跑、各镜素材不同、时长超了、跨场景 → 才拆卡。四个各要 5 秒的镜头压进
  一张 15s 的卡,每镜只剩 3.75 秒,那才是真的都演不完。

## 提示词不再有绕过工程化的路

工作台新增「一张卡的 prompt 里要有什么」自检清单:八大要素(引自 `sd2-pe`,已加测试
钉住两处一致)外加工作台特有的三项——主锚全文逐字复制、风格光位逐字复制(不变量),
以及本镜的道具与场景状态(变量,例如椅子这镜立着、下镜翻倒,并行渲染不会自己传递)。

开跑前清点由三项改为**四项**,新增「每张卡的 prompt 都过了 `sd2-pe`」。此前有两条路
能绕过去:整板落地的「正文直接搬」对用户手写的分镜表并不成立,而剧本拆出的镜头表
本来就是散文。

## 剧本能直接变成整板

用户只给一段剧本时,此前没有任何拆镜依据。新增按可拍摄单元切的判据(一句里两个信息
层就拆、两个主体动作且第二个是情绪拐点就拆、单一连续动作不凑数),并要求把拆法连同
镜头数选项一起给用户——镜头数是创作决定,不该由 agent 独自拍板。

## 提问不再打断六次

方向、主锚、镜头表、规格、跑法、音频,一件一张卡等于在渲染第一帧前打断六次。现在
给了三张卡的合并配比。并写明:用户说「你帮我拿主意」不是让你别问,是让你**带着推荐
去问**——但镜头数、影像方向、角色长相这三样不能替他定,错了整板重来。

## 配乐与跨镜续接有了明确交接

- **配乐**:整段配乐交 `catimation-audio`,成片后混音。卡上的 `generateAudio` 出的是
  该镜自己的环境声,跨卡不可能连续;配乐也塞不进 `referenceAudios`(合计 ≤15s)。
- **跨镜续接**:抽尾帧作下一镜首帧要求串行,与工作台的批量并行天然互斥。默认走可并行
  的全能参考+逐卡锚点;需要帧级硬续接就改串行,且**不能混用**——并行跑完再抽尾帧回填,
  已渲的卡不会重跑。

## 分级与预算不再自相矛盾

- **专业 vs 制片看交付物,不看镜头数。** 十个镜头交十段片子仍是专业;两个镜头但要拼好
  配好字幕直接发布就是制片。「用户在哪个页面」不是判据。
- **预算数的是你自己挑的对症技法**,条件强制项(入口、`sd2-pe` 底座、路径 B 结构叶子、
  界面叶子、出图/QA/后期工具)不占额度。此前表格与说明互斥,读法能差到 14 对 5。

## 催促不再是跳过硬门的理由

压力测试发现:说「直接开跑吧,我赶时间」时 agent 会拒绝,但拒绝的依据是它自己推断的
谨慎,不是明文规则。四个 session-start hook 补入明文——用户催促不构成跳过硬门的理由,
多镜漂脸要重跑全部卡片,补门比返工快。

## 重试多了一道整板闸

原先只有单卡 `generation_attempts ≤2`。6 张卡各失败两次就是 12 次付费重投,而半数以上
一起坏时病根通常在整板共用的锚点或素材上。现在:一轮跑完需要重做的卡超过半数时,停下来
找共因,不要逐张重投。
