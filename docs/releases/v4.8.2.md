# v4.8.2 发布说明

> 更新渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 存档
> 上线版本：v4.8.1

## 概述

这一版修掉了画布上「本地图片一放上去就裂开」的老问题，把画布底层的 tldraw 升到 5.4.1，并给视频工作台的卡片加了一个「任务详情」面板——出问题找供应商对账时，终于有一个对方认的任务号可以复制。

## 画布：本地图片不再裂

以前从文件栏拖一张本地图到画布、或让 Agent 把本地图放进画布，图片位置上只剩左上角一行 alt 文字；音频库里本地文件也播不出来，只能回落到云端地址。

根因是本地路径拼成地址时把盘符冒号写成了 `%3A`，这种写法在渲染进程里是一条非法地址，请求根本没发出去。这次改成保留冒号原样，图片、音频都能直接加载；以前存进画布的老记录会在打开时自动修好，不用清数据。

## 画布：tldraw 升到 5.4.1

一次可靠性大修：相机动画偶尔永久卡死、拖放偶发不响应、关闭前最后一秒的编辑丢失、多张图排列时顺序错乱等问题都在这一批里。

顺带修好了一个只在安装包里出现的隐患：新版 tldraw 会把桌面应用当成正式部署，没有 license 时会在画布打开 5 秒后把编辑器整个收掉。这一版随包带上了 license，打包构建缺 license 时也会在构建日志里醒目报警。

透明底的 PNG 现在可以「点穿」：点到透明区域会选中它后面的东西，而不是这张图本身；本地动图也能正常显示。为此放开的本地文件读取权限只对应用自己的顶层页面生效，页面里内嵌的任何第三方网页都拿不到。

## 视频工作台：任务详情面板

生成中或已完成的卡片头部多了一个 ⓘ。点开是一个面板，四块内容：

- **标识**：任务 ID（网关签发）、**上游任务 ID**（火山引擎 Ark 的 `cgt-…` / 阿里云百炼的 uuid，找供应商对账就报这个，黄边高亮）、客户端请求 ID、卡片 ID、计费来源。直连自己 Key 时上游就是同一个号，会说明「没有另一跳」。
- **时间**：提交 / 最近更新 / 已耗时，未完成时每秒刷。
- **结果**：本地成片（可「在文件夹中显示」）、云端永久地址、上游临时地址、持久化状态、实际 seed、计费口径。
- **历史版本**：每次重新生成一行，各自带任务号。

每个 ID / 地址旁边都有「复制」，底部可以「复制全部 JSON」。请求参数里的参考图、参考视频、参考音频记的是**实际递给上游的地址**，本机路径另列作对照；内嵌的 base64 图只写占位，不进文档。

上游任务号在提交后第一次查询就会拿到，不用等成片——任务卡住的时候恰恰最需要它。
