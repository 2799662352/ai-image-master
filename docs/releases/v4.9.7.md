# v4.9.7 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.6

## 概述

视频工作台的两个修复:含真人的参考视频 / 音频不再被网关的隐私检测直接打回;参考图攒到 12 张以后「+ 添加」卡不再消失。

## 视频工作台

- **真人视频 / 音频走素材库中转**:此前上传含真人脸的参考视频会直接收到网关 400(`InputVideoSensitiveContentDetected.PrivacyInformation`),而图片早就有「先登记进人像库、再以 `asset://` 引用」的绕行。现在视频和音频与图片走同一条路:提交前自动登记进素材库(Video / Audio 类型),请求里改为 `asset://` 引用。实测同一段含真人脸的视频,直传被拒、`asset://` 引用正常出片。
- **隐私 400 翻译成中文**:图片 / 视频触发真人检测时,错误里直接给出绕行建议(素材库中转、`ffmpeg-win` 抽关键帧当参考图、换虚拟形象),并保留 request id 便于排查。
- **参考图满 12 张后加号消失**:参考图一到 12 张(满一行),「+ 添加」卡会被排到第一张底下看不见,再也加不进去;22 张铺开成两行时同样找不到。现在加号永远排在最后一张之后 —— 收起态在首行末尾,铺开态跟到最后一张后面(填满整行时另起一行),钉住铺开时常驻显示,不必悬停。

## 内置技能

- **`catimation-video` 技能**:「真人脸」一节改写为「app 提交前会自动把参考图和参考视频登记进素材库、改为 `asset://` 引用;仍被拒时换虚拟形象、Seedance 自产片段二创,或抽关键帧当参考图」。插件市场已同步(catimation-video 1.0.43)。

其余 4.9.6 的功能不受影响,无需重新设置。
