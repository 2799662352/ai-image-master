# v4.9.35 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.34

## 概述

启动动画改成**每次启动都播**。4.9.34 的默认是每天第一次启动才播,实际要的是每次退出再打开都放一遍,让人有时间看完。

## 变化

- **启动动画默认每次启动都播完整版**(随时可跳过:按钮 / Esc)。不需要迁移:默认值只在本地存档没有 `mode` 时生效,4.9.34 用户那份只记了日期的存档升级后直接每次都播。
- 存档里手写的 `daily`(每天一次)/ `off`(不播)仍然优先,存档键 `catimation.startup.v1`;界面上依然没有设置入口。

## 注意

- 每次启动都会加载动画引擎和 6 句配音,启动到看到主界面之前会多一段动画时间(可以跳过)。**没量过具体多出多少**。
- 4.9.34 发布说明里关于配音来源 / 授权未核实、「没听过」的提示仍然成立,这个版本没有换音频。

## 已验证

- `startup-screen` 4 个测试文件 205 条通过(含新增:默认值、4.9.34 存档形状仍播、播完再启动仍播且存档里不带 `mode`、手写 `daily` / `off` 仍被尊重);把默认改回 `daily` 做变异检查,9 条测试变红;`typecheck:ci` 7 个既有 / 0 个新增。

## 还没覆盖

- **没在安装包里连续启动两次看过**:「每次都播」只在单元测试层验证。
- 其余同 4.9.34:动画像素、猫头着色、真实登录往返、配音听感都没在真窗口里走过。
