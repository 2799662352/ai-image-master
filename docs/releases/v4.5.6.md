# v4.5.6 发行说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.5.5

## 人像库选择器能翻页了

在视频工作台点「⭐ 人像库」挑素材时,以前只能看到最新的 60 个,再多的在这个弹窗里
根本够不着 —— 只能先去人像库页找。现在弹窗底部有了翻页(和人像库页同一套「上一页 /
页码 / 下一页」),库里有多少就能翻到多少。

跨页挑选是连着的:第 1 页勾两张、翻到第 3 页再勾一张,底部照旧显示「已选 3 个」,
一次确认全部带进卡片。换来源、换类型、改搜索词都会回到第 1 页,不会停在一个空页上。

## 卡片总量不再有 200 张上限

以前工作台的卡片总数一超过 200 张,系统就会**自动删掉最旧的已完成卡片**给新卡腾地方。
这个上限是跨全部「页」计的 —— 在页面 6 加几张卡,被删的可能是页面 1 上你还想留着的
分镜。现在不再有这个上限,卡片只在你自己删的时候才消失。

## 「默认上传人像库」改成只管生成时入库,并默认开启

这个开关以前管两件事:拖素材进卡片时立刻传一份到人像库,以及生成时把用到的参考图
登记进去。前一条会让拖图变慢,而且多数时候并不需要。

现在它只管后一条 —— 拖素材进卡片不再顺带上传,生成成功后才在后台登记参考图(不影响
出片)。因为不再拖慢任何操作,这个开关默认改为开启;不想入库的话关掉它,人像库就只
收你在人像库页里手动上传的东西。
