# v4.9.21 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.20

## 概述

两件事:**视频工作台、MCP 和技能接入可灵 4.0 / 4.0 Omni(含智能分镜 / 自定义分镜)**,以及**「音频生成」页和 MCP `generate_audio` 登录后改走平台余额**,不再要求自己填 API Key。

## 新增:可灵 4.0 / 4.0 Omni 接入视频工作台

- **两个新模型**(只走平台余额,经 Miau 网关):
  - **可灵 4.0**:文生视频、首帧、首尾帧。
  - **可灵 4.0 Omni**:在 4.0 的基础上支持参考图(最多 10 张)、参考视频(最多 5 段),图和视频合计最多 15 个;不接受音频参考。
- **规格**:时长 3–30 秒整数(没有「智能时长」),分辨率 720p / 1080p / 2k / 4k,画幅 21:9 / 16:9 / 9:16 / 1:1 / 自适应,默认 16:9。没有种子、联网搜索、字幕擦除、样片。
- **素材只收公网地址**:参考图、视频会先中转到自有存储再提交,中转失败不会降级成内嵌数据(上游不收)。
- **预估价**:工作台按网关的价目给预估;带参考视频的卡片按「输入 + 输出」秒数计费、取回的结果里又没有计费秒数,所以**不给估价,标记为「未估价」,以账单为准**。
- **换模型自动收敛**:切换模型时,模式、时长、比例会自动调到新模型允许的值;你手动填的非法值不会被悄悄改掉,而是在「开始」时带着原因拒绝。
- **MCP 与技能**:工具说明、参数枚举都按模型能力表生成;入口技能 `catimation-video` 与 `catimation-video-workbench` 写入规格差异、素材规则、先报价、并发(上游账号并发约 5,共享)等要点。可灵没有专属的提示词写法,没有编造一套方法论。

## 新增:可灵分镜(智能分镜 / 自定义分镜)

- 工作台卡片上可开启**分镜**:
  - **智能分镜**:只写总提示词,由模型自己分镜。
  - **自定义分镜**:自己写 1–6 个镜头,每镜整数秒,**各镜时长之和必须等于总时长**,每镜提示词不超过 512 字。
- 规则集中在一处校验:工作台编辑器、MCP、请求构造用同一套规则,不合规时直接说明原因而不是发出去被上游拒。
- 调整总时长或换模型时,会尽量把镜头时长按比例收敛回合法值;你显式写了分镜就不会被自动改。
- MCP 工具(`video_workbench_*` / `generate_video`)与工作台 IR(导入 / 应用 / 工程文件)都能带分镜;**不写就是单镜头**,应用时可以清掉分镜。`set_spec` 刻意不带分镜字段,避免一句话改规格时误动镜头。

## 修复:音频生成登录后走平台余额

- **现象**:已登录且计费来源是平台余额时,出图和图像理解都能用,但「音频生成」页和 MCP `generate_audio` 报「请先设置 API Key」,agent 还会让你去找 seed-audio 的 Key。
- **原因**:音频生成在发请求前无条件要求本站点有自填 Key,没有给平台余额留豁免,请求到不了网关。
- **现在**:登录 + 平台余额 + 走 Miau 网关时不再要求 Key,只打平台计费标记、不发任何 Key(你另填过 Key 也不会外发);没登录或没选平台余额、又没填 Key 时仍会拦下,提示里多了一句「可登录走平台余额」。「音频生成」页、MCP `generate_audio`、语音朗读共用同一条链路,一处生效。

## 行为变化(顺带)

- 视频工作台的**模式下拉按模型能力过滤**;万相(Wan)不再显示「联网搜索」;切换万相模型时比例也会收敛到合法值。
- 插件市场 `catimation-video` 升到 1.0.47(与本版技能内容一致,已单独发布到 COS)。

## 还没覆盖的地方

- **可灵与音频这两项都没有对真实网关发过请求**:可灵的价目、规格、错误码来自对网关代码的阅读,不是实测;建议第一次用文生 3 秒 720p 的卡跑一次(约 ¥3.6)确认出片和扣费。音频需要你登录后生成一小段,看平台余额有没有变;如果网关没给你的计费分组开放 `seed-audio-1.0`,会回网关的 `HTTP 4xx` 错误原文,不再是「请先设置 API Key」。
- 可灵 Omni 的**参考视频总时长上限 30 秒**本地没有预检,由上游判断。
- 可灵 Omni 的「主体 / 音色」要先在腾讯云点播里建好 id,桌面端没有建主体的入口,这一版不接。
- 带参考视频的可灵卡不给预估价(见上)。
- 音频页上「按输出秒数计费,约 ¥1/分钟」的提示文案(4 种语言)没改。
