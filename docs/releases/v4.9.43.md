# v4.9.43 发布说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.9.42

## 概述

一件事:**Roneyun-cn 视频渠道的样片与联网搜索放开,并在任务详情里同时显示两层任务号**(#465)。

网关 2026-11-18 起对 Roneyun-cn 原样透传 `draft` / `tools`,并且成片的 `draft_task.id` 会被换成上游那一层的火山 `cgt-…` 号(new-api #205 / #206 / #207 / #209,已上线生产)。v4.9.42 的能力表还停在「cn 无样片、无联网」,所以卡片上看不到这两个开关;本版对齐。

## 变化

- **cn-seedance-2.5 可以出样片**:与火山 2.5 一致,仍只在平台余额下可用;样片 → 1080p / 4K 成片走原来的流程。`cn-seedance-2.0` / `-2.0-fast` / `-2.0-mini` **没有样片**(`mini` 带 `draft` 上游回 400「draft is not supported」,未扣费;2.0 / fast 照火山行不开)。
- **四个 cn 模型都有联网搜索开关**,与火山同名行一致。
- **任务详情新增「火山任务 ID」一行(`cgt-…`),可复制**:只有 Roneyun-cn 才有这一行。`task_…`(Roneyun / 网关的号)创建后就有,`cgt-…` 要等网关轮询到、任务跑起来才有;还没到显示「渠道尚未回传」,网关改版(11-18)前就跑完的老任务可能一直没有(显示「这一版未记录火山任务号」)。「复制全部」的 JSON 与版本记录只在有值时才带这个字段,没有这一层的渠道逐字节不变。
- **MCP `finalize_video_draft` 增加可选 `model`**(`"2.5"` 缺省 / `"cn-seedance-2.5"`)。原来写死按 `2.5` 出成片:cn-2.5 的样片会被发到火山渠道,网关按「本人 + 同一上游 + 已成功」查不到。cn 样片成功后的提示也会要求 agent 出成片时带上这个模型。工作台界面里的「生成成片」本来就用卡片自己的模型,不受影响。
- 随 app 内置的技能 `catimation-video` / `catimation-video-workbench` 同步成「样片只给 `cn-seedance-2.5`」。

## ⚠️ 行为变化(请知悉)

- v4.9.42 里 cn 卡片上不出现的样片 / 联网开关,现在会出现(联网默认开,与其它 Seedance 模型一致)。
- **插件商城与技能商城这次没有随版发布**:商城(COS image-master 桶)是独立通道,`catimation-video` 插件的商城版本仍是旧文本(写着 cn 无样片 / 无联网)。需要时另行发布;app 内置的技能已是新文本。

## 还没覆盖

- **cn-2.5「样片 → 轮询到成功 → 成片」完整链路桌面端没有真跑过。** 11-18 上午那次成片被上游拒(`draft task task_… not found for current user`,当时发的是 `task_…`),网关 #207 / #209 修的就是这个;修好后有人报告「修复成功了」,但桌面端这边没有再花钱实测。
- 联网只在 `cn-seedance-2.0-mini` 上实测过网关不再拒;2.0 / 2.0-fast / 2.5 没单独跑过。响应里没有工具调用 / 用量字段,「搜索真的执行了」没有证据。
- 「火山任务 ID」的展示只有单测,没在真 Electron 窗口里看过,也没拿真实网关响应跑过解析(按网关 PR 的 diff 与单测夹具写)。
- MCP 真实调用 `finalize_video_draft` 带 `model` 没跑。平台余额钱包的真实样片提交没跑。
- 只在 Windows x64 验证;没测 NSIS 覆盖升级 / electron-updater,只测了构建产物,这部分由发版流程的三道闸与 Authenticode 校验兜底。
