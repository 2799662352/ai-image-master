# v4.4.30

## 视频工作台:agent 不再把整块看板倒进上下文

以前 agent 查看工作台,会把**所有页**的卡片一股脑读进来。一个装了十几页的工作台等于几百张卡塞进上下文,而你九成时间只在看一页。

- 默认只看**当前页**,每页 **3 张**卡。要看别页得明说。
- 新增**页目录**:一页一条,带该页卡片 id 和每条提示词的开头,让 agent 直接跳到该看的那页,而不是从第 1 页翻到底。
- 新增**页面摘要**:给每一页写一句话说明装的是什么(「追车 · 夜外 · 主角车vs追兵」)。页签上能看到、能改、能删,agent 也能自己写。

## 改一张卡不再动辄「请重新导出整板」

- 你在界面上改了东西导致 agent 的改动撞车时,回执里会带上**那张卡此刻的样子**和**具体哪几个字段对不上**,而不是只说一句版本变了。
- 输入框失焦提交同样的内容不再让 agent 手里的数据失效。
- 「改一张卡」明确走单卡编辑,批量重排才用整板应用。

## 看图看视频

- **一次看多张图**。问题只要牵涉一张以上(「这两张是同一个人吗」「这版和上版差在哪」),现在能在同一次请求里传完 —— 模型把它们当成一组看,才做得了对比。此前只能一张张问,得到的是各说各话的描述。
- **PDF 修好了**。此前把 PDF 当图片发出去,上游读不出内容,所以文档里一直写着「先渲成图效果最好」。现在直接传 `.pdf`,里面的文字和图片都能被原生解析。
- **视频抽帧密度可调**(`fps`)。这个参数其实一直存在,但组请求时被丢掉了,等于永远走默认值 —— 快动作看不清、静态长片白烧 token。
- 理解工具接上 **qwen3.8-max**(`model="flagship"`)。默认仍是更便宜的 plus:两者视频规格相同,旗舰的价值在长文档和复杂推理。
