# v4.4.17 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.16

## 网关加速

- **Miau 网关改走加速域名**:原本直连源站 IP,国内链路不稳。实测同一实例、
  只有 https 可达、成功时耗时与源站相当,故整体切换。
- **谷歌原生出图绕开加速**:Nano Banana 系列(`gemini-3.1-flash-image` /
  `gemini-3-pro-image` / `gemini-2.5-flash-image`)走的是谷歌原生端点,而加速层
  不支持这条路径 —— 表现为请求一律以 524 收场,并被浏览器误报成跨域错误。这类
  模型现在直连源站,其余模型继续享受加速。为什么只有它们:它们把整张图以 base64
  内联回传(数 MB),其余模型只回一条短地址。

## 视频

- **落盘不再挡住入库**:生成成功就立刻写历史记录,不再等本地保存与云端转存出
  结论(最坏要十几分钟)。此前在这段窗口里关掉应用,这次生成就只剩一张工作台
  卡片,而卡片上那条上游地址同样会过期。拿到持久地址后会把历史里的地址原地换掉。
- **下载重试岔开**:视频落盘的两次尝试原本间隔为零,一次几秒的网络抖动会把两次
  一起吃掉。改为三次、退避 3s / 6s。这条路径失败即终局 —— 本地与云端都没有副本,
  只剩会过期的上游地址。
- **时长补齐 7 / 9 / 11 / 13 / 14 秒**:此前只列了 4/5/6/8/10/12/15。这五个值
  并非上游不支持,是选项表本身列漏了。

## 视频工作台素材

- **支持直接填图片外链**:素材行新增「图片链接」按钮,也可从浏览器直接拖图、
  或在卡片空白处粘贴地址。此前只认文件,外链只能先另存到本地再拖进来。
  地址不按扩展名筛 —— 真实图床地址常常没有扩展名。
- **外链自动转存**:挂进来的第三方图片会复制到我们自己的存储,缩略图与提交
  从此不依赖对方在线。人手添加与 agent 通过 MCP 添加**行为一致**(此前只有
  前者会转存)。
- 在提示词里粘贴网址仍然只是文字,不会被劫持成素材。

## 出图

- **谷歌生图返回 URL 时不再误报失败**;**预签名地址不再被截断**(丢掉签名必然
  403);**生成失败不再无声无息**;**图片加载失败会退避重试**;**转存失败会重试**。
  (这些随 4.4.16 已发布,此处仅作索引。)

## Agent

- **引用参考图前先看图**:`generate_video` 与视频工作台的写入工具、以及
  `catimation-video` / `sd2-pe` 两个 skill,都写明了「附了参考图就先 view_image
  看一张,再据看到的内容写提示词」。此前 `view_image` 只被用来检查**自己生成的
  产物**,没有一处要求看**输入** —— 于是提示词照文件名臆想,而模型跟的是画面。
- 相应的 skill 已发布到市场(`sd2-pe@1.0.28`、`catimation-video@1.0.24`)。

## 验证

- 全量单测与 typecheck 债务闸随 CI 执行;本轮新增用例均先写失败测试再实现。
- 网关切换前后均以真实请求实测:同实例校验、协议可达性、失败率与耗时对比。

## 已知未做

- 谷歌原生模型的直连地址目前是源站 IP。若该 IP 变更,**只有这几个模型会失效**,
  其余一切正常 —— 这种偏科故障不易联想。后续应换成一个不经加速的源站域名。
- 图片生成仍无任务恢复:请求中途断连后,即便服务端已出图也找不回来。经实测
  确认是上游能力所限(无异步任务 ID),非本端未做。
- 视频工作台的重启接管仍失效:水合时先把在飞卡片判死,导致对账拿到空集合。
- 开发版与安装版同时运行会撞端口(`os error 10048`)。
