# v4.3.97 发布说明

> 发布渠道：腾讯云 COS 热更新（`releases/latest.yml`）+ GitHub Release 兜底
> 基线版本：v4.3.96

## 概览

本版聚焦「生成图片 / 视频时对话长时间无响应」问题的彻底修复，并将内置
Codex CLI 升级至 0.144.4。应用功能与 app-server 协议保持兼容，无需迁移
现有会话或配置。

## 生成阻塞修复（图片 / 视频）

- Seedance Ark API 请求新增 30 秒硬超时（AbortController）：网络层挂起
  不再演变为整回合卡满工具超时；轮询查询超时可容忍重试，创建超时立即
  报错并出失败卡片。
- 图片任务注册表新增 30 分钟 running 看门狗：终态 IPC 丢失时任务自动判
  失败并给出明确提示（图片可能已渲染，先向用户确认、不要盲目重发），
  杜绝无限轮询。
- 工具完成 / 运行中横幅全面改为「先交付、再质检」纪律：生成完成后模型
  必须先向用户发送一句交付消息，才允许做 QA；轮询期间必须向用户播报进
  度，不再出现静默等待。
- `catimation-image` / `catimation-video` skill 同步更新：质检前先交付、
  质检开始前先announce、`view_image` 至多查看一张代表图（避免多 MB
  base64 挤爆上下文），与工具横幅口径完全一致。

## Codex CLI 0.144.4

- 内置 Codex CLI 从 0.144.3 升级到 0.144.4。
- 上游本次为补丁版本，官方说明无用户可见变更；唯一改动是 Guardian 自动
  审查改为使用模型目录（model catalog）内的策略，不涉及 app-server API
  或 wire schema 变更。
- Windows x64 的可执行文件、沙箱组件和命令代理均由固定 SHA-256 校验。
