# v4.5.7 发行说明

> 更新渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 存档
> 上线版本:v4.5.6

## 文件编辑器不再一边打字一边乱跳

在文件面板里编辑文本时,删字符会让画面上下窜、光标跑到别处 —— 这个从来不是错觉。
根子是每敲一个字都会把整个编辑器重建一遍,滚动位置和光标定位跟着一起被扔掉。现在
它只在真的需要时才重建,打字、删除、连按退格都稳稳待在原地。

顺带修掉两个同源的毛病:切换标签页回来时滚动位置会跳到顶部;编辑区和外层容器抢
滚动,导致滚轮有时不听使唤。

## Markdown 有预览了,而且能看出颜色

`.md` 文件以前只能看源码,一片灰白。现在右上角多了「源码 / 分栏 / 预览」三档:

- **预览**:标题分级、表格、引用、代码块、任务列表都按正常文档排版,排版尺度取自
  VS Code 内置的 Markdown 预览,长文读起来不累。文档里的相对路径图片能正常显示,
  点本地文件链接会直接在左侧文件树里定位过去。
- **分栏**:左边编辑右边预览,两侧滚动互相跟随 —— 源码滚到哪,预览就跟到哪,反过来
  也一样。
- **源码**:标题、加粗、链接、行内代码、引用现在各有各的颜色,和你在编辑器里看到的
  一致,不用再靠数 `#` 来分层级。

每个文件会记住你上次选的是哪一档。

## 音频文件可以直接播了

`mp3` / `wav` / `flac` / `m4a` / `aac` / `opus` 这些以前点开只有一句「二进制文件」,
现在有独立的播放器:进度条、音量、快进一应俱全。生成的配音和音效不用再导出到外面
才能听。

## 参考视频可以圈重点了(编辑视频 · 高级编辑)

用 Seedance 2.5 的「编辑视频」时,最难的是把「改哪儿」说清楚 —— 「把左边第二个人的
外套换掉」这种话,模型经常会理解成别人。

现在卡片上多了「✎ 高级编辑」:打开参考视频,拖到要改的那一帧,在画面上圈一下、画个
箭头、标个号或写句话,保存后这张带标注的图会作为参考图进卡片,提示词里也会自动补上
对应的引用。在帧上圈一下,比任何措辞都准。

入口只在「Seedance 2.5 + 编辑视频 + 有视频素材」三个条件同时成立时出现 —— 少一个
条件点出来也没有意义。出图按源视频的原生分辨率,标题栏会告诉你实际是多少像素。

## 编辑视频的时长不再让你白选

「编辑视频」模式下,输出长度由被编辑的视频决定,固定秒数是选不了的。但界面以前照旧
把 4–30 秒整排列出来,你选了 25 秒、写完提示词、点生成,才收到一句「不能指定固定
秒数」。现在这个模式下时长直接锁成「✨ 智能」,不再摆一排点了必失败的选项。

## 粘贴的图片和标注帧不再拖慢生成

直接粘贴进卡片的图、以及高级编辑拍平的标注帧,以前会以内嵌数据的形式一路带到提交
那一刻才开始上传 —— 那份等待正好落在你按下「生成」的时候。现在它们一进卡片就在
后台转成云端地址,点生成时该传的早就传完了。

同时补上一道准入提示:没有本地文件、又超过 64MB 的素材会被挡在门外并说明原因
(先存到本地再拖进来,本地文件走磁盘流式上传,没有体积限制)。以前这类素材进得来
却永远传不上去,只会一直占着本地存储。

## 国内站开放 Seedance 2.5

国内站的模型下拉里现在能选到 Seedance 2.5,和海外站一致。
