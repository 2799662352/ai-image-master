# v4.4.19 发布说明

> 发布渠道:腾讯云 COS 热更新(`releases/latest.yml`)+ GitHub Release 兜底
> 基线版本:v4.4.18

一次小版本,主要是把 4.4.18 那批工作台改动里**拖不动、拖不进**的两处修掉,
外加一条藏在里面的静默数据丢失。

## 视频工作台的拖拽

4.4.18 上线的「卡片多选 + 拖进聊天栏」实际上拖不动 —— 三处一起修:

- **按住卡片往聊天栏拖变成选中文字**:此前只有那个 ⣿ 小手柄可拖,而且头部行没有
  禁止选中,按住往外拖被浏览器判成选文本。现在**整条头部行都能拖**,⣿ 退化为纯
  视觉抓手。从行内按钮(删除等)起手仍然不会变成拖卡。
- **文件栏里的图片拖不进工作台**:文件栏内部拖拽只带路径、没有文件对象,卡片没
  接住这一类,浏览器于是压根不派发投放事件 —— 表现为「拖过去毫无反应」。现在接
  住了,按扩展名归入参考图/视频/音频;认不出类型的整条丢弃,不猜成图片(猜错会把
  错误推迟到提交时才由上游报出来)。
- **把卡片拖到文件树上会移走视频文件**(未被报告,自查发现):卡片拖拽此前复用了
  文件树的路径词表,而那个词表在文件树里的含义是「可以被移动的工作区文件」。文件
  栏与工作台同屏,所以这是个日常动作 —— 一旦发生,卡片的本地路径与整份版本历史
  一起哑掉。现在卡片用自己的词表,文件树天然忽略。

## 选中更好点了

- **命中区从一行字高扩到整条头部行**(约 18px → 40px),不必再瞄准。悬停有底色,
  选中的卡头部也有底色 —— 此前只有边框变色一处反馈。
- **「取消选中」从一条灰字变成正常按钮**,并补了 **Esc** 快捷键。Esc 在输入框里
  不劫走(那是编辑动作),已被弹层处理掉的也不插手。

## 启动开场视频

换了新片。**启动会比之前多等约 13 秒**(52.4s → 65.8s):开场的放行条件是「视频
播完 + 应用初始化完成」,所以片子多长就得等多久 —— 随时可以点 SKIP,但默认路径
是看完。想更短就换更短的片,不需要改代码。

体积从 29.93MB 降到 8.13MB(1440p → 1080p,这个窗口尺寸下看不出差别),而视频在
仓库里有两份副本,所以安装包与仓库各瘦约 44MB。

## Codex

内置 Codex CLI 升到 **0.146.0**。核对过:全部是加法,没有移除 API,没有触及我们
依赖的通知路由与启动配置。用真二进制验过 —— 33 个生产启动参数全部被接受,
握手、配置读取、模型列表、跨会话记忆的两个实验接口都往返正常。

上游这一版对我们的净收益是 MCP 连接管理:认证/配置变化时保持连接有效、只重连断掉
的服务器而不重启健康连接。

## 验证

- 全量单测与 typecheck 债务闸随 CI 执行;新增用例均先写失败测试再实现。
- 那条静默数据丢失有专门的守卫用例钉着(卡片载荷绝不能伪装成「可移动的工作区
  文件」),放松它会立刻变红。
- Codex 升级走的是仓库既有的两个 smoke 脚本,跑在真二进制上,不是读发布说明推断的。

## 已知未做

- 开场视频偏长(65.8s),尚未裁剪。
- 本地数据库「卡死」而非「退出」时不会自动恢复,只能靠 30 秒池超时兜住(报错、
  降级、对话可继续)。刻意不做「静默即判死」—— 长事务同样不回应探测,按静默去杀
  等于毁掉正在跑的真实事务。
- 崩溃瞬间在飞的写不会重试,只有读会:重试可能已提交的写会造出重复记录。
- 工作台未出片的卡拖进聊天栏只会提示「还没有结果」,不附任何东西。
- 图片生成仍无任务恢复(上游无异步任务 ID)。
- 开发版与安装版同时运行会撞端口(`os error 10048`)。
