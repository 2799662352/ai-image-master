# 导演台 · 光感后处理(曝光 / 辉光 / 色调映射)集成计划

> 目标:把「全景图编辑器」里已验证的 **光感(曝光 / 辉光)** 后处理管线提取为
> **公用模块**,接入 **3D 导演台**,并在遵循 three.js 专业最佳实践
> (`.agents/skills/three-best-practices`)的前提下追加更多电影级调色功能。
>
> 同时已顺手修复:点「生成全景」的一瞬间,当前图自动载入参考图
> (`ImageEditToolbar.tsx`,因为参考图本身就是 img2img 生成全景的输入)。

---

## 1. 现状盘点(信息收集结论)

### 1.1 全景图的光感管线(被复用的「真源」)
`PanoramaEditor.tsx`:

- `WebGLRenderer`:`outputColorSpace = SRGB`,默认 `toneMapping = NoToneMapping`,`toneMappingExposure = 1`。
- `EffectComposer` 链:`RenderPass → DistortionShader(畸变,全景专属) → UnrealBloomPass → OutputPass`。
- 成像决策 `renderFrame()`(关键):
  - **中性**(曲度≈1 且 辉光≈0)→ 直接 `renderer.render`,零全屏重采样,最清晰。
  - 一旦曝光≠1 或 辉光>0 → `renderer.toneMapping = AgX`,走 composer。
  - `OutputPass` 是 composer 模式下**唯一**做 tonemap + sRGB 的环节。
- Bloom 参数:`strength=bloom`、`radius=0.4`、`threshold=0.85`(只对高光起辉,避免整体发灰)。
- 离屏超采样:`composer.setPixelRatio(postPixelRatio)`、RT `samples=4`(MSAA)。
- 缩放 / 截图都同步 `composer.setSize` + `bloom.setSize`。

### 1.2 导演台现状(集成目标)
`DirectorStageScene.tsx`:

- `WebGLRenderer`:`antialias`、`preserveDrawingBuffer:true`、SRGB,**未设** toneMapping/exposure。
- **无 EffectComposer**,直接 `renderer.render(scene, camera)`。
- ⚠️ **渲染调用点分散在 7 处**:实时循环(1135)、缩略图 RT(1432)、单帧截图(1985/1994/1999)、4/12 视角(2035)、录制(2054)。
- 灯光已有:`DirectionalLight` 主光 + `HemisphereLight` 环境光,底栏「灯光」面板已能调强度/方位/仰角/颜色;工程存档已含 `light` 块。
- 已支持全景球背景(`entry='panorama'`,`applyPanorama`)。

### 1.3 核心难点
导演台的**交付物是截图和录制**,所以后处理必须对**全部 7 个渲染调用点**统一生效,
而不仅是实时预览。全景只有一条渲染路径,导演台有七条 → 必须先**收敛为单一渲染入口**。

## 2. 设计:提取公用后处理模块 `LightFx`

新建 `image-editors/postfx/`:

```
postfx/
  lightFxConstants.ts   // 共享常量 + 色调映射选择纯函数
  createLightFx.ts       // 框架无关工厂(three.js,无 React)
```

### 2.1 `lightFxConstants.ts`
```ts
export const LIGHT_FX = {
  DEFAULT_EXPOSURE: 1.0,
  DEFAULT_BLOOM: 0,
  BLOOM_RADIUS: 0.4,
  BLOOM_THRESHOLD: 0.85,
} as const

// 与全景 renderFrame 同构:曝光≠1 或 辉光>0 才切 AgX,否则干净直出。
export function pickToneMapping(exposure: number, bloom: number): THREE.ToneMapping {
  const hasExposure = Math.abs(exposure - 1) > 0.001
  const hasBloom = bloom > 0.001
  return hasExposure || hasBloom ? THREE.AgXToneMapping : THREE.NoToneMapping
}
```

### 2.2 `createLightFx.ts`(公用工厂,全景 + 导演台共用)
```ts
interface LightFxOptions {
  width: number; height: number
  pixelRatio?: number
  extraPasses?: Pass[]        // 全景传 [distortionPass];导演台传 []
}
interface LightFx {
  composer: EffectComposer
  bloom: UnrealBloomPass
  setExposure(v: number): void   // → renderer.toneMappingExposure
  setBloom(v: number): void      // → bloomPass.strength
  isNeutral(): boolean           // 曝光≈1 且 辉光≈0(+ 可选 extra)
  setSize(w: number, h: number): void
  render(camera: THREE.Camera): void          // 自动选 直渲 / composer
  renderToTarget(camera, rt): void            // 截图 / 缩略图 / 录制
  dispose(): void                              // 释放 composer/bloom/RT
}
```

链:`RenderPass → ...extraPasses → UnrealBloomPass → OutputPass`,RT `samples=4`。
`render()` 内部复刻 `renderFrame` 决策(中性直渲,否则 composer)。

> **最佳实践对齐**
> - `postpro-renderer-config` / MSAA:RT `samples=4`,与全景一致。
> - `memory-dispose-render-targets`:`dispose()` 释放 composer + bloom + RT;resize 重建前先 dispose。
> - `render-conditional`:中性零开销直渲,默认不影响现有性能/清晰度。
> - `postpro-merge-effects`:调色统一进**一个** ShaderPass(见 §4)。
> - 颜色管理:composer 模式下 renderer 喂线性、`OutputPass` 唯一 tonemap+sRGB。

### 2.3 全景改造(真正复用,不再各写一份)
`PanoramaEditor` 用 `createLightFx({ extraPasses:[distortion] })` 替换内联 composer;
`renderFrame` 收敛为调用 `lightFx.render(camera)`(畸变也并入 `isNeutral`)。
风险低:行为逐项对齐;若回归则保留旧路径作灰度开关。

## 3. 导演台接入(分阶段)

### Phase 1 — 收敛渲染入口(前置必做)
新增 `renderStage(s, camera, target?)`,替换全部 7 处 `renderer.render`:
- `target` 为空 → `lightFx.render(camera)`(实时)。
- `target` 为 RT(缩略图/录制 stream)→ `lightFx.renderToTarget(camera, rt)`。
- 截图/多视角:渲染到 capture RT 后 readback(保证特效进入像素)。
每个目标尺寸切换时 `lightFx.setSize`(缩略图、1080p/2k/4k、录制分辨率)。

### Phase 2 — 光感 UI + 存档
- 在底栏「灯光」面板(或新「光感」浮窗,复用 `directorFloatingPanel` 的 `glass` 皮肤)加 **曝光 / 辉光** 滑杆,默认中性。
- 扩展工程序列化 `light` 块:`exposure`、`bloom`(+ §4 新参数),save/restore 同步。

### Phase 3 — 更多相关功能(全部 opt-in,默认中性零开销)
| 功能 | 实现 | 最佳实践 |
|------|------|----------|
| 色调映射模式(无/AgX/ACES/Neutral) | `renderer.toneMapping` 下拉 | 颜色管理 |
| **环境光照 IBL** | 全景图经 `PMREMGenerator` → `scene.environment`,金属假人获得真实反射 | `lighting-environment` |
| 对比度/饱和度/色温 | **单个** 自定义 `ShaderPass`(合并) | `postpro-merge-effects` |
| 暗角 Vignette + 颗粒 Grain | 并入同一调色 Pass | 同上 |
| 景深 DoF | `BokehPass`,toggle 后启用,可半分辨率 | `postpro-resolution-scaling` |

### Phase 4 — 验证
`npm run typecheck` + lint + HMR;
- 中性:与现状**逐像素一致**(截图/录制不变、依旧清晰);
- 非中性:辉光/曝光在**实时 + 截图 + 4/12 视角 + 录制**全部可见;
- 卸载无 WebGL 资源泄漏(`renderer.info` 检查)。

## 4. 落地顺序与影响面

1. `postfx/lightFxConstants.ts` + `createLightFx.ts`(新增,零影响)。
2. 导演台 Phase 1 渲染收敛(改 `DirectorStageScene.tsx`,行为不变)。

5. Phase 3 进阶功能逐个加(每个独立 toggle、独立提交)。
