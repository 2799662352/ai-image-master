## 踩坑备忘

- **git worktree 不共享 untracked `.env`**:在 `temp-aim-worktrees/feat-video-workbench`
  真发商城时报缺 `COS_SECRET_ID/KEY`,从主 checkout
  (`temp-ai-image-master-source/.env`)复制一份即可;dry-run 不需要密钥。
- **`memory/reset` 的 params 是 `Option<()>` 且 skip-if-none**:必须整个省略
  params 字段,发空对象 `{}` 会被上游拒绝。
- **发版 dispatch 必须在 main 头部**:tag 不存在时 `resolve-release-sha.mjs` 要求
  dispatch commit == origin/main HEAD,所以 bump PR 合并后不要再往 main 推东西,
  先触发发版。
