# Director 角色一致性与叙事节奏协同设计（完整版 B）

## 背景

当前导演管线已经完成从「用户绝对优先」到「创意简报 + 导演自主」的措辞重平衡，但在复杂场景下仍有两个并存诉求：

1. 人物一致性要更稳（主角色与次角色跨分镜不漂移）
2. 导演演出要更强（镜头语言、构图、光影、节奏保持创作自由）

本设计的目标是建立「先锁角色身份，再释放导演演出」的双层机制，并明确要求导演必须参考用户输入中的节奏与叙事方向进行优化，而非偏离。

## 目标

- 强化主角色与次角色在多分镜中的身份一致性
- 保留导演对镜头与视觉叙事的专业主导权
- 让导演优化严格基于用户给定的叙事方向与节奏主线
- 不改 pipeline 拓扑，不新增 UI 配置，不扩散改动面

## 设计原则

- 角色一致性是硬约束：保证“是谁、长什么样”
- 导演演出是软自由：决定“怎么拍、怎么讲”
- 叙事方向不可逆：可优化表达，不可改写用户故事走向
- YAGNI：优先在 `DirectorPipeline.ts` 内完成闭环

## 方案选择

采用方案 B（完整版）：主角色 + 次角色都进入角色锚点锁定，并在 Pass 3 与 Pass 5 双重注入约束。

不采用：
- 纯措辞轻改（提升有限）
- Pass 4 回灌二次生成（复杂度和耗时过高，留作后续迭代）

## 架构与职责边界

### 1) 角色一致性层（硬约束）

由 Pass 2 角色提取结果扩展为 `Character Identity Lock`，覆盖主角色与次角色：

- 核心外观：脸部特征、发型、体型、年龄感
- 形象要素：服装主色、材质、标志性配件
- 禁漂移项：明确不允许跨 panel 改写的属性

该层仅定义身份一致性，不介入镜头语言。

### 2) 导演演出层（软自由）

保持 Pass 3 的导演身份设定（film director + storyboard artist + prompt engineer）：

- 导演全权决定景别、机位、构图、光影、节奏
- 导演必须围绕 creative brief 演绎，而非机械照抄

### 3) 冲突优先级

当演出想法与角色外观发生冲突时：

1. 角色身份锁优先
2. 导演在不破坏身份锁前提下重选镜头表达

## 数据流与字段设计

## Pass 2：角色锚点增强（结构化）

在现有角色抽取结果基础上增强语义结构：

- `identity_core`: 不可漂移核心身份特征
- `identity_style`: 可弱变化但需连续的造型风格
- `identity_forbidden_drift`: 禁止漂移列表

## Pass 3：分层 prompt 注入（核心改动点）

按固定顺序拼接 system/user 指令：

1. `Character Identity Lock`（主角色 + 次角色）
2. `Director's Creative Brief`（用户叙事方向）
3. `Director Freedom Zone`（镜头语言自主）

并新增显式叙事约束：

- 保留用户意图中的叙事节奏与推进方向
- 以镜头语法优化表达，不改写故事方向
- 允许专业升维，不允许主题反转

## Pass 3：每 panel 层级约束

每个 panel prompt 都附带“角色锁定摘要（短版）”，防止长上下文中后段漂移。

## Pass 5：生图阶段承接

在 contact-sheet 复合 prompt 中同时保留：

- `creative brief (narrative context)`
- 角色一致性摘要（全局 + 分格）

确保“分镜阶段一致性”与“实际生图一致性”对齐。

## 异常处理与回退策略

- 用户节奏描述弱：允许导演补强节奏层次，但不得改主题或叙事走向
- 用户描述与参考图冲突：角色身份锁优先，叙事方向次优先，镜头表达自适应
- LLM 输出偏离叙事方向：在现有 L2/L3 恢复链路中加入偏离反馈，要求回到用户节奏主线

## 测试与验收标准

## 功能验收

1. 角色一致性：主角色与次角色跨 panel 外观稳定
2. 叙事一致性：镜头节奏遵循用户输入方向（如前慢后快、压抑到释放）
3. 导演优化可见：构图、光影、节奏有专业增强，不是机械复述
4. 语言安全：不回退到“最高优先/严格按照”硬服从措辞

## 非目标（本轮不做）

- 不新增 UI 控件
- 不改数据库/持久化结构
- 不改图结构与节点拓扑
- 不做 Pass 4 回灌闭环

## 结论

该设计通过“角色身份锁 + 导演演出自由 + 叙事节奏护栏”三层协同，实现：

- 人物稳定
- 导演可发挥
- 叙事不偏航

并且保持低侵入改动，适合快速迭代验证。
