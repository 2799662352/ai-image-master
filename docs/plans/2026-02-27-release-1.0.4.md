# Release 1.0.4 打包计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将当前所有变更打包为 1.0.4 版本的 Windows 安装包（NSIS + Portable）。

**Architecture:** 更新版本号 → Vite 构建 → electron-builder 打包 → 验证产出。产出目录 `release/`，生成 NSIS 安装包和 Portable 便携版。

**Tech Stack:** electron-builder, electron-vite, NSIS

---

### Task 1: 更新版本号到 1.0.4

**Files:**
- Modify: `package.json:3`

**Step 1: 修改 version**

将 `"version": "1.0.3"` 改为 `"version": "1.0.4"`

**Step 2: 同步根目录 data 副本**

```bash
Copy-Item "src\renderer\public\data\understand-roles.json" "data\understand-roles.json" -Force
```

**Step 3: Commit**

```bash
git add package.json data/understand-roles.json
git commit -m "chore: bump version to 1.0.4"
```

---

### Task 2: 构建 + 打包 Windows 版本

**Step 1: 执行 Windows 打包命令**

```bash
npm run build:win64
```

这会顺序执行：
1. `electron-vite build` — Vite 构建前端
2. `electron-builder --win --x64` — 打包 Windows x64

**预期产出** (`release/` 目录)：
- `CATIMATION-Cyberpunk Master-1.0.4-Setup.exe` — NSIS 安装包
- `CATIMATION-Cyberpunk Master-1.0.4-Portable.exe` — 便携版

**Step 2: 验证产出**

```bash
Get-ChildItem release/*.exe | Select-Object Name, Length, LastWriteTime
```

---

### Task 3: 验证安装包

**Step 1: 测试 Portable 版**

双击 `CATIMATION-Cyberpunk Master-1.0.4-Portable.exe` 运行，确认：
- 应用启动正常
- 模型选择器显示 7 个模型（含 Nano Banana 2）
- 切换 Nano Banana 2 后显示 15 个宽高比 + 0.5K 分辨率
- 图像理解页面显示 7 个角色（含分镜 Pro）
- 导演模式可正常生成
