# Director 横竖方向与 auto 比例交互设计

**日期:** 2026-03-03  
**状态:** 已确认（用户选择 C：完整体验）

## 背景

导演模式新增了“横屏/竖屏”方向选择，并支持“自动跟随比例 + 手动覆盖”。  
当前已知问题是：当比例切换到 `auto` 时，方向会被错误地回退到横屏，造成体验跳变。

## 目标

1. 修复 `ratio=auto` 时方向回退问题。  
2. 保持“自动/手动覆盖”行为可预测。  
3. 补齐方向模式持久化，刷新后保持用户选择。  
4. 完成必要测试，防止回归。

## 约束与依据

- React Hooks 顺序必须稳定，避免热更新期间 hooks order 问题。
- Zustand 多字段对象选择器应使用 `useShallow`，避免不必要重渲染与潜在循环问题。
- UI 保持当前设计风格，不引入额外依赖。

## 方案对比

### 方案 A（最小修复）

仅在 `setRatio()` 中判断 `auto` 并保持方向不变。  
优点：改动最小。缺点：未解决持久化与说明文案完整性。

### 方案 B（中等修复）

方案 A + 持久化方向和自动模式开关。  
优点：行为连续性更好。缺点：UI 提示仍不够明确。

### 方案 C（采用）

方案 B + UI 文案补齐 + 测试覆盖补齐。  
优点：行为一致、可解释、可回归验证。  
缺点：改动面略大于 A/B，但可控。

## 行为定义（最终）

### 自动模式（`isLayoutOrientationAuto=true`）

- 比例是合法 `w:h`（如 `16:9`、`9:16`）：自动更新方向。
- 比例是 `auto` 或非法值：**保持当前方向不变**（用户确认选择 A）。

### 手动模式（`isLayoutOrientationAuto=false`）

- 用户点击“横屏/竖屏”后进入手动覆盖。
- 任意比例变化不改方向。
- 点击“恢复跟随比例”后回到自动模式。

## 持久化策略

新增 localStorage：

- `director.layout-orientation.v1`
- `director.layout-orientation-auto.v1`

恢复策略：

- 若有持久化值，优先使用；
- 若无持久化值，沿用从 ratio 推断的初始化逻辑。

## UI 文案策略

- 自动模式且 ratio 为 `auto`：`跟随比例：auto（保持当前方向）`
- 自动模式且 ratio 为具体值：`跟随比例：<ratio>`
- 手动模式：`手动覆盖方向中`

## 测试策略

1. 自动模式下 `setRatio('auto')` 不改变方向。
2. 自动模式下 `setRatio('9:16'/'16:9')` 能正确切换方向。
3. 手动模式下比例变化不影响方向。
4. 恢复自动后方向按当前 ratio 推断。
5. 方向映射到布局配置（`6grid`、`2closeup`）保持正确。

## 风险与缓解

- **风险:** 初始化读取持久化与默认值冲突。  
  **缓解:** 读函数容错 + 明确优先级（持久化优先）。
- **风险:** HMR 期间 hooks 顺序变化导致 runtime 报错。  
  **缓解:** 保持 `useDirectorGeneration` 单 selector + `useShallow`。

## 验收标准

1. 切到 `auto` 比例不再导致方向回退。
2. 刷新页面后方向与自动模式状态可恢复。
3. 相关单测通过且无新增 lint 错误。
