# Release v3.9.0

> **发布日期:** 2026-04-19  
> **安装包:** `release/catimation-cyberpunk-master-3.9.0-setup.exe` (247 MB)  
> **平台:** Windows x64 | Electron 41 | Node 22

---

## 新功能

### History 页 UI 重构 — "Neon Cyberpunk + Dystopian Underground" 主题

- 整体迁移至 React 组件架构（`DonorShell`, `DonorHeader`, `DonorGrid`, `DonorCard`, `DonorPreview`, `DonorEmpty`, `DonorStorageModal`）
- 虚拟列表（`@tanstack/react-virtual`）支持大量历史记录流畅滚动
- 生成失败 / 上传失败场景显示占位卡片
- 云存储配置子页面（R2 Storage）
- 页面作用域主题样式（`donor-theme.css`），`prefers-reduced-motion` 无障碍支持

### Batch 页 UI 重构 — "Persona 5 Punk Collage + 90s Delinquent Manga Zine" 主题

- 全新 React 组件架构（`PunkShell`, `PunkHeader`, `PunkConfigGrid`, `PunkPromptArea`, `PunkRefDrop`, `PunkResultGrid`, `PunkActionBar`, `PunkBudgetReceipt`）
- 动态模型配置：比例/分辨率选项跟随当前模型自动更新
- 参考图点击预览 + 客户端压缩（`browser-image-compression`）+ 压缩过程 UX 反馈（占位卡 + Toast）
- 每张结果卡带下载按钮
- 预算收据组件（实时显示生成张数 × 单价 = 总费用）
- 红色 Hanko 印章 "実行 / DO IT" 替代旧飘标

### 模型价格精准化

- `ModelConfig` 新增 `price` 字段，Nano Banana 2 ($0.06/张) 与 Nano Banana Pro ($0.09/张) 使用实际价格
- `extractPriceFromModel` 工具函数：优先读 `price` 字段 → 回退解析 `displayName` → 默认 0
- 预算收据与老版 BatchPage 均使用统一价格源

## 修复

| 问题 | Root Cause | 修复 |
|------|-----------|------|
| History 页预览弹窗不显示 | `.donor-theme` CSS `position: relative` 覆盖了 `position: fixed` | Portal 外层用 inline style，内层保留主题 class |
| 云存储测试连接 CORS 报错 | `fetch mode: 'cors'` 被服务端拒绝 | 改为 `mode: 'no-cors'` + `pingByImage` 兜底 |
| History 页布局过小（608px） | `container mx-auto` 约束宽度 | viewport breakout 技术（`100vw` + 负 margin） |
| History 页顶部留白过大 | CSS 通用规则覆盖装饰元素 `absolute` 定位 | inline style 覆盖 + CSS 选择器排除 `:not(.absolute)` |
| Batch 页模型选择不同步 | vanilla JS 与 React Zustand 缺少桥接 | `CustomEvent('model-changed')` 事件驱动同步 |
| Batch 页比例/分辨率下拉不全 | 硬编码选项 | 改为从当前模型配置动态获取 |
| 生成图片覆盖网格滤镜 | `.donor-punk::before/after` 全局 `mix-blend-mode` | 完全移除纹理伪元素 |
| Batch 页切换卡顿 | 每次 tab 切换都 `createRoot` + `render` | 首次挂载后仅切换 `display` 属性 |
| 批量生成不写入 History | `runBatch` 未调用 `addToHistory` | 成功项循环写入 `historyDataServiceTS` |
| JSON 粘贴产生 302 空卡 | `bulkAdd` 按 `\n` 拆分 | 移除自主拆分逻辑，整段文本作为单条 prompt |
| 重启后 History 页空白 | `HistoryManager.init()` 未广播 `notifyChange` | 在 `init()` 完成后显式调用 `notifyChange('init')` |
| 预算收据不显示 + 按钮偏移 | `mask-image` 透明渐变导致元素不可见 | 改用 `dashed border` + `::before` 装饰带 |

## 已知问题（不影响使用）

- `npx tsc --noEmit` 报 87 个预存 TypeScript 错误，主要集中在 `electron/main.js`（catch unknown）、`HistoryManager.ts`/`HistoryDataService.ts`（`HistoryItem` 缺少 `id` 字段声明）、第三方 CDN JS 文件。这些错误不影响 `electron-vite build`，计划在后续版本逐步修复。
- Vite 8 输出 deprecation 警告 `optimizeDeps.esbuildOptions` → `optimizeDeps.rolldownOptions`，功能不受影响。
- `core-services` chunk (1.89 MB) 超过 500 KB 警告，可通过进一步 code-split 优化。
